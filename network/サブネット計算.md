# サブネット計算

[[CIDR]] の `/24` から一歩進んで、

```text
192.168.10.37/27
```

を考える。IPv4 は 32 bit なので、

$$
32-27=5
$$

bit がホスト部。1 サブネットのアドレス数は、

$$
2^5=32
$$

最後のオクテットを 32 刻みで区切ると、

```text
0–31
32–63
64–95
96–127
...
```

`37` は `32–63` に入るので、

```text
network    192.168.10.32
broadcast  192.168.10.63
```

ネットワークアドレスとブロードキャストアドレスを除き、

$$
32-2=30
$$

個をホストに使える。

確認：

```bash
ipcalc 192.168.10.37/27
ip route get 8.8.8.8   # 実際に使うインターフェース・送信元・ゲートウェイ
```
