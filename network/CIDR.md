# CIDR

`192.168.10.37/24` の `/24` は先頭24 bitがネットワーク部という意味。残り8 bitがホスト部なのでアドレス数は、

$$
2^8=256
$$

ネットワーク：`192.168.10.0`

ブロードキャスト：`192.168.10.255`

確認：

```bash
ip -br addr
ip route
ipcalc 192.168.10.37/24
```

IP アドレスだけでなくプレフィックス長までセットで考える。
