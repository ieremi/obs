# カント哲学の用語

認識論・倫理学・美学を中心に、主要35用語を個別ページにまとめる。一般語としての意味と区別するため、個別ページ名には「（カント）」を付けた。ドイツ語表記と関連用語も各ページで確認できる。

## 最初に押さえる関係

| 問い | 用語のつながり |
| --- | --- |
| 何を知り得るか | 感性が直観を与え、悟性が概念で統一する。理性が求める無条件者まで、そのまま理論的に認識できるわけではない。 |
| 何をなすべきか | 格率を普遍的な法則として意志できるかを問う。自律は、自分の欲求を何でも優先することではない。 |
| 美をどう判断するか | 趣味判断は快に基づくが、単に「私は好きだ」という個人的な報告にとどまらない。 |

## 認識論

| 用語 | 概要 |
| --- | --- |
| [[批判哲学（カント）|批判哲学]] | 理性が何を、どこまで正当に認識できるかを、理性自身の働きと限界の検討によって明らかにする立場。 |
| [[コペルニクス的転回（カント）|コペルニクス的転回]] | 認識が対象に合わせられるとだけ考えるのでなく、経験の対象が人間の認識形式に従うと考える発想の転換。 |
| [[アプリオリ（カント）|アプリオリ]] | 個別の経験から導くことなく、その根拠を持つ認識・原理の性格。 |
| [[アポステリオリ（カント）|アポステリオリ]] | 経験に基づいて成立し、その根拠を経験に依存する認識の性格。 |
| [[分析判断と総合判断（カント）|分析判断と総合判断]] | 分析判断は主語概念に含まれる内容を明らかにし、総合判断は主語概念だけには含まれない述語を結び付ける。 |
| [[アプリオリな総合判断（カント）|アプリオリな総合判断]] | 経験からの帰納に頼らず、しかも概念の分析だけにとどまらずに、認識内容を広げる判断。 |
| [[超越論的（カント）|超越論的]] | 対象そのものよりも、対象をアプリオリに認識できる仕方・可能条件に関わること。訳語に「先験的」もある。 |
| [[超越的（カント）|超越的]] | 可能な経験の範囲を越えて原理や概念を用いようとすること。 |
| [[感性（カント）|感性]] | 対象によって触発されることで表象を受け取る、受容的な認識能力。 |
| [[直観（カント）|直観]] | 対象に直接関わる、個別的な表象。多くのものに共通する概念と区別する。 |
| [[純粋直観（カント）|純粋直観]] | 感覚内容からではなく、感性的に対象が与えられる形式に関わる直観。空間と時間がこれに当たる。 |
| [[悟性（カント）|悟性]] | 概念を用いて考え、与えられた直観の多様を判断によって統一する認識能力。 |
| [[カテゴリー（カント）|カテゴリー]] | 経験から抽象するのでなく、経験の対象を思考するための基本形式となる、純粋悟性概念。 |
| [[図式（カント）|図式]] | 純粋悟性概念を感性的な対象に適用するために、構想力が与える時間的な規則・規定。 |
| [[超越論的統覚（カント）|超越論的統覚]] | 多様な表象を、一つの「私は考える」に属するものとして結び付けられる、自己意識の統一。 |
| [[現象（カント）|現象]] | 対象が、人間の感性的な認識条件のもとで与えられるものとして捉えられた姿。 |
| [[物自体（カント）|物自体]] | 人間の感性的な認識条件から独立に考えられた対象。 |
| [[超越論的観念論（カント）|超越論的観念論]] | 空間・時間など、人間の認識条件のもとで対象を現象として認識するという立場。 |
| [[理性（カント）|理性]] | 悟性の認識を原理のもとにまとめ、条件付けられたものから、その条件の系列と無条件者へ向かう能力。 |
| [[理性の理念（カント）|理性の理念]] | 経験の中に対応する対象をそのまま与えられない、無条件的な統一を目指す理性の概念。 |
| [[アンチノミー（カント）|アンチノミー]] | 世界全体を経験の対象のように扱うと、理性が互いに反する主張をともに論証してしまう二律背反。 |

## 倫理学

| 用語 | 概要 |
| --- | --- |
| [[善意志（カント）|善意志]] | 他の条件に左右されず、それ自体で善いとされる意志。道徳法則への尊重に基づいて行為しようとする意志。 |
| [[義務（カント）|義務]] | 道徳法則への尊敬から行為することの必然性。 |
| [[格率（カント）|格率]] | 行為者が自分の行為のために採用する、主観的な実践原則。 |
| [[道徳法則（カント）|道徳法則]] | 特定の欲求や利益に依存せず、理性的存在者の意志を普遍的に拘束する実践法則。 |
| [[定言命法（カント）|定言命法]] | ある目的を欲するという条件なしに、行為の原則を命じるもの。 |
| [[仮言命法（カント）|仮言命法]] | ある目的を欲するなら、そのために必要な手段を取るべきだ、という条件付きの命法。 |
| [[自律（カント）|自律]] | 意志が、理性によって自らに普遍的な法則を与え、その法則に従うこと。 |
| [[他律（カント）|他律]] | 意志を規定する法則の根拠を、理性による自己立法ではなく、欲求の対象・利益などに求めること。 |
| [[自由（カント）|自由]] | 感性的な欲求や自然因果性によってのみ意志を決定されるのではなく、理性的な法則に従って自らを規定できること。 |
| [[目的の国（カント）|目的の国]] | 理性的存在者が互いを目的そのものとして尊重し、共通の法則によって結び付く体系的な共同体の理念。 |

## 美学・目的論

| 用語 | 概要 |
| --- | --- |
| [[反省的判断力（カント）|反省的判断力]] | 与えられた個別的なものに対し、それをまとめる普遍的なものを探す判断力の働き。 |
| [[趣味判断（カント）|趣味判断]] | 対象を美しいと判定する、美的な判断。快の感情に関わりながら、他者の同意を要求する。 |
| [[合目的性（カント）|合目的性]] | あるものの形式や構成を、目的に適ったものとして捉える性格。 |
| [[崇高（カント）|崇高]] | 巨大さや威力を前にして構想力の限界を感じつつ、感性的なものを超える理性の能力を自覚する経験に関わる概念。 |

## 混同しやすい用語

| 対比 | 区別 |
| --- | --- |
| アプリオリ／アポステリオリ | 経験から独立した根拠か、経験に依存した根拠か。 |
| 分析的／総合的 | 概念に含まれる内容の明確化か、それを超える結合か。上の区別とは別の軸。 |
| 超越論的／超越的 | 認識の可能条件を問うことと、可能な経験の範囲を越える使用。 |
| 感性／悟性／理性 | 受容的な直観、概念による統一、原理と無条件的統一の追求。 |
| 現象／物自体 | 人間の認識条件のもとでの対象と、その条件から独立に考えられた対象。 |
| 義務に適う／義務からする | 行為の一致と、行為を規定する動機を区別する。 |
| 定言命法／仮言命法 | 無条件の命令と、目的に依存する条件付きの命令。 |
| 自律／他律 | 理性による自己立法と、欲求対象などを法則の根拠とすること。 |

## 主な著作

| 著作 | 刊行 | 用語を読む際の位置付け |
| --- | --- | --- |
| 『純粋理性批判』 | 1781年、第二版1787年 | 認識の可能性と限界。 |
| 『道徳形而上学の基礎づけ』 | 1785年 | 善意志・義務・定言命法・自律。 |
| 『実践理性批判』 | 1788年 | 実践理性と道徳法則。倫理学をさらに展開。 |
| 『判断力批判』 | 1790年 | 美・崇高・自然の合目的性。 |

日本語の訳語は訳書によって異なる。「超越論的／先験的」などは、原語と文脈も併せて確認する。物自体や超越論的観念論には解釈上の論争があり、入門的な要約を唯一の読解とはしない。
