# 佈

## よみ
| 種類 | よみ | 備考 |
| --- | --- | --- |
| 音 | **フ** | [[布]]と同じ音 |
| 音 | **ホ** | |
| 訓 | **あまねし** | すみずみまで行きわたっている |
| 訓 | **しく** | 広げる。行きわたらせる。日本語では「布く」「敷く」と書く |

- 常用漢字・人名用漢字ではない（**表外漢字**）
- 中国語では bù（普通話）、bou3（広東語）。朝鮮語では 포（po）

## 字義
1. **広く知らせる。おおやけにする。** 「宣佈」
2. **広げる。行きわたらせる。** 「遍佈」
3. **並べる。配置する。** 「佈兵」（兵を配置する）「佈陣」

どの意味も、[[布]]の「ぬの」以外の意味（しく・ひろめる）と同じ。

## 成り立ち
- **形声**。意味を表す **亻**（にんべん）と、音を表す **布** を合わせた字
- 布の「広げる・知らせる」という動詞の意味を、「ぬの」という名詞の意味と書き分けるために、にんべんをつけた字

## 布との関係
| 地域 | 書き方 |
| --- | --- |
| 日本 | 動詞の意味でも **布** を使う。「宣布」「分布」「配布」「布告」「布陣」。佈は辞書で見る程度の字 |
| 中国（簡体字） | 佈は **布** にまとめられた（簡体字では佈を使わない） |
| 台湾・香港（繁体字） | 「ぬの」は布、「広げる・並べる・知らせる」は佈と書き分けることがある。ただし布で書く例も多い |

### 「分佈」と書くことはあるか
| 地域 | 「分佈」の扱い |
| --- | --- |
| 日本 | 現代ではふつう書かない。**分布** と書く（戦前の例は下を参照）。佈は常用漢字にも人名用漢字にもないので、公用文や教科書、新聞では使わない |
| 中国（簡体字） | 書かない。**分布** と書く |
| 台湾・香港（繁体字） | **分佈** と書くことが多い。分布と書くこともある。Wiktionary は分佈を繁体字の形、分布を簡体字の形および異体の形としている |

- 日本語の文章で「分佈」を見かけたら、中国語の文の引用か、繁体字の文献から書き写したものと考えられる
- 台湾の教育部の辞典がどちらを推薦形にしているかは確かめられなかった

### 戦前の日本での「分佈」
戦前の日本では「分佈」と書いた例がある。J-STAGE で「分佈」を検索すると（2026-11-15）、題名にこの語をふくむ論文が 2 件見つかる。どちらも明治・大正の医学雑誌『順天堂医学』の論文。

| 年 | 題名 | 著者 |
| --- | --- | --- |
| 1903（明治 36） | [「モルモット」ニ於ケル精嚢ノ**神經分佈**ノ知見補遺](https://www.jstage.jst.go.jp/article/pjmj/M36/370/M36_902/_article/-char/ja) | 阿久津三郎、佐藤恒祐 |
| 1915（大正 4） | [農村ニ於ケル十二指腸蟲**分佈**ノ調査（茨城縣眞壁郡竹島村ニ於ケル）](https://www.jstage.jst.go.jp/article/pjmj/T4/511/T4_439/_article/-char/ja) | 三上文七、寺本徳太郎 |

- 「分佈」で 13 件ヒットし、残りの 11 件は戦後の中国語・台湾関係の論文などで、題名に「分佈」をふくまない
- 戦前にどちらの書き方が多かったかは、この検索だけでは判断できない。分布と書く例との比較はしていない
- 日本で佈を使わなくなった理由は、当用漢字表（1946 年）に佈が入らなかったことによると考えられる。漢字の制限によって「分布」の書き方だけが残った（[[当用漢字・常用漢字の変更履歴]]）。ただし、この因果関係は確かめていない
