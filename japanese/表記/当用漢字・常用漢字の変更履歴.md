# 当用漢字・常用漢字の変更履歴

戦後の漢字表の字数は、**当用漢字1,850字（1946年）→常用漢字1,945字（1981年）→常用漢字2,136字（2010年）**と変わった。変更には、字を追加・削除する「字種」、字の形を扱う「字体」、読みを扱う「音訓」の三つがある。

## 年表

字数欄は一般向けの漢字表の総字数。関連する報告・字体表・教育用の別表を、そのまま追加字数には数えない。

| 年月日 | 漢字表・資料 | 字数 | 変更内容 |
| --- | --- | ---: | --- |
| 1946年11月16日（昭和21） | 当用漢字表 | 1,850 | 法令・公用文書・新聞・雑誌などで使う漢字の範囲を示した。 |
| 1948年2月16日（昭和23） | 当用漢字音訓表 | 1,850 | 各字で使う音読み・訓読みを定めた。字種の追加ではない。 |
| 同日 | 当用漢字別表 | 1,850 | 当用漢字のうち、義務教育で読み書きを指導する881字を示した。総字数は変わらない。 |
| 1949年4月28日（昭和24） | 当用漢字字体表 | 1,850 | 字体の標準を示した。異体の統合や略体の採用など、新字体の標準化に関わる変更。 |
| 1954年（昭和29） | 当用漢字補正資料 | 1,850のまま | 28字を削り、28字を加える案。**内閣告示による字種の入れ替えは実施されなかった。** |
| 1956年7月5日（昭和31） | 同音の漢字による書きかえ | 1,850 | 表にない字などを含む語について、同音の別の漢字を使う表記を報告。字種の追加ではない。 |
| 1973年6月18日（昭和48） | 当用漢字音訓表の改定 | 1,850 | 読みを増補し、1948年の音訓表を廃止。 |
| 1981年10月1日（昭和56） | 常用漢字表 | 1,945 | 当用漢字に95字を追加。字種・音訓・字体を一つの表に統合し、漢字使用の「目安」とした。 |
| 2000年12月8日（平成12） | [[表外漢字字体表]] | 1,945のまま | 常用漢字表の外にある1,022字について、印刷標準字体などを示した。常用漢字の追加ではない。 |
| 2010年11月30日（平成22） | 常用漢字表の改定 | 2,136 | 196字を追加し、5字を削除。既存の字の音訓なども見直した。1981年の告示を廃止。 |

出典：[文化庁「これまでの漢字政策について」](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/kokugo/kokugo_29/gijishidai/shiryo_7_2.html)、[国立国語研究所『常用漢字の音訓』](https://repository.ninjal.ac.jp/record/1854/files/kk_nkss_014.pdf)、[2010年の常用漢字表告示](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji/index.html)。

## 1954年の補正案は、正式な入れ替えではない

当用漢字補正資料では28字ずつの入れ替えが提案された。正式な追加字と区別するため、以下は追加案として掲載する。

### 追加が提案された28字（全字・未告示）

亭　俸　偵　僕　厄　堀　壌　宵　尚　戻  
披　挑　据　朴　杉　桟　殻　汁　泥　洪  
涯　渦　渓　矯　酌　釣　斉　竜

削除案には「且・丹・但・朕・脹」などがあった。

新聞などでは補正資料に基づく運用が行われたが、国の当用漢字表そのものが28字入れ替わったわけではない。後の1981年の常用漢字表も、当用漢字から字種を削除せず、95字を加えて成立した。

出典：[国語審議会「当用漢字修正資料取り扱いについて」](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kakuki/05/tosin01/index.html)、[文部科学省・1981年の改定に伴う対応資料](https://www.mext.go.jp/b_menu/shingi/chousa/shotou/076/shiryo/__icsFiles/afieldfile/2010/09/27/1297645_02.pdf)。

## 1981年：当用漢字から常用漢字へ

| 項目 | 変更 |
| --- | --- |
| 字種 | 1,850字に95字を追加して1,945字。削除なし。 |
| 追加字 | 下記に95字すべてを掲載。 |
| 音訓 | 従来からの字に約360の音訓を追加。新たな95字にも音訓を定めた。 |
| 字体 | 従来の当用漢字では「燈 → 灯」を変更。新たな字には「螢 → 蛍」「齊 → 斉」などの整理を加えた。 |
| 表の構成 | 字種表・音訓表・字体表を統合。旧字体とのつながりを示すため、括弧内にいわゆる康熙字典体を添えた。 |
| 表の性格 | 当用漢字の制限的な性格から、一般の社会生活における漢字使用の目安へ。 |

単なる名称変更ではなく、使える字や読みを増やし、表の位置付けも改めたもの。[国語審議会による1981年改定の要点](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kakuki/19/tosin01/04.html)、[国立国会図書館「漢字表（字種・字体の変遷）を調べる」](https://ndlsearch.ndl.go.jp/rnavi/humanities/post_576)

### 字が増えなくても、読みが増える

従来から常用漢字だった字にも、次のような音訓が追加された。

| 字 | 追加された読みの例 |
| --- | --- |
| 委 | ゆだねる |
| 育 | はぐくむ |
| 応 | こたえる |
| 関 | かかわる |
| 創 | つくる |
| 旬 | シュン |

例えば「関」が表にあることと、「かかわる」が表にあることは別の問題。[文部科学省「常用漢字表改定に伴う学校教育上の対応について」](https://www.mext.go.jp/component/b_menu/shingi/toushin/__icsFiles/afieldfile/2010/10/08/1298254_02.pdf)

## 書き換え・交ぜ書きへの影響

| 関連する変化 | 例 | 注意点 |
| --- | --- | --- |
| 同音の別字に書き換える | 雇傭 → 雇用 | 字体を変える新字体化とは別。 |
| 一部を仮名にする | 拉致 → ら致、覚醒剤 → 覚せい剤 | 字が常用漢字に加わると、漢字表記を採用しやすくなる。ただし媒体の運用や法令の改正時期は別。 |
| 元の字が後から表に入る | 臆測／憶測、肝腎／肝心 | 追加によって、過去の書き換え先だけが唯一の表記とはいえなくなる。 |

「醒」は2010年に追加されたが、法律名「覚せい剤取締法」が「覚醒剤取締法」になったのは2020年4月施行の改正。**漢字表の改定と、個々の文書・法律の表記変更は同時とは限らない。** [法務省『令和2年版犯罪白書』](https://hakusyo1.moj.go.jp/jp/67/nfm/n67_2_7_3_2_0.html)

個々の表記と扱いは、[[同音の漢字による書き換え]]、[[交ぜ書き]]を参照。

## 人名用漢字・教育漢字との区別

| 区分 | 主な対象 |
| --- | --- |
| 当用漢字・常用漢字 | 一般の社会生活で使う漢字。 |
| 人名用漢字 | 子の名に用いる漢字の制度。追加があっても、常用漢字の総字数が増えたことにはならない。 |
| 教育漢字 | 学校での指導範囲・配当。学習する学年などの変更と、常用漢字表の字種変更は区別する。 |
| JIS・Unicode | 情報機器で文字を扱うための規格。収録されていても常用漢字とは限らない。 |

関連制度の区別：[文化庁「これまでの漢字政策について」](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/kokugo/kokugo_29/gijishidai/shiryo_7_2.html)
