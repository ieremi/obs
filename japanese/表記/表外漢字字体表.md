# 表外漢字字体表

**常用漢字表にない漢字を印刷するとき、どの字体を選ぶかのよりどころを示した表。** 2000年12月8日、国語審議会が文部大臣に答申した。比較的よく使われる1,022字を取り上げ、印刷標準字体を示し、そのうち22字には簡易慣用字体を併記した。

常用漢字を1,022字追加したものではなく、表にない字の使用を禁止するものでもない。[文化庁「表外漢字字体表」解説](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/sanko/hyogai/index.html)、[答申・作成目的及び適用範囲](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kakuki/22/tosin03/05.html)

## 常用漢字表との違い

| 項目 | 常用漢字表 | 表外漢字字体表 |
| --- | --- | --- |
| 主な役割 | 一般の社会生活における漢字使用の目安。 | 表外漢字を使う場合の、印刷文字の字体選択のよりどころ。 |
| 掲げるもの | 字種・字体・音訓。 | 印刷標準字体・簡易慣用字体・字体に関する注記など。 |
| 読みの扱い | 使用の目安となる音訓を示す。 | 配列・検索のために読みを添えるが、使用する音訓を規定しない。 |
| 数 | 1981年は1,945字、2010年改定で2,136字。 | 2000年の答申時に1,022字。その一部は後に常用漢字になった。 |

## 印刷標準字体と簡易慣用字体

| 用語 | 意味 |
| --- | --- |
| 印刷標準字体 | 印刷文字で標準として使う字体。原則としてこちらを優先する。 |
| 簡易慣用字体 | 使用実態を踏まえ、印刷標準字体に替えて使っても差し支えないとされた字体。22字に併記される。 |

簡易慣用字体は、印刷標準字体を廃止して置き換えるものではない。どちらを使うかは、文書や媒体の事情に応じて判断する。[答申・適用範囲](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kakuki/22/tosin03/05.html)

## 3部首許容

しんにゅう・しめすへん・しょくへんには、印刷標準字体とは異なる部首の形を既に使っている場合、変更を求めない扱いがある。これを「3部首許容」という。

| 部首 | 許容の対象となる形の概略 |
| --- | --- |
| しんにゅう | 点一つのしんにゅう。 |
| しめすへん | 「ネ」の形のしめすへん。 |
| しょくへん | 常用漢字の新字体に見られる形のしょくへん。 |

これは、簡易慣用字体22字の併記とは別の扱い。原表に載っていない表外漢字にも、既にその部首の形を印刷で使っている場合には適用してよいとされる。[答申「字体表の見方」第5項](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kakuki/22/tosin03/15.html)

## 手書き・固有名詞との関係

対象は印刷文字で、これに準じる画面表示や字幕も含む。**手書き文字の形を直接規定する表ではない。** また、従来の文献や、現に人名・地名に使われている字体を否定するものでもない。[文化庁解説](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/sanko/hyogai/index.html)、[答申・適用範囲](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kakuki/22/tosin03/05.html)

字体と、書体のデザインの違いも区別する。原表に例示された明朝体の形だけを、唯一の正しい見た目としているわけではない。[答申「字体表の見方」第3・4項](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kakuki/22/tosin03/15.html)

## 2010年の常用漢字表改定との関係

「表外」は常用漢字表との関係で決まるため、2000年当時に表外だった字が、後に常用漢字になることがある。例えば「曽・痩・麺」は、2010年に常用漢字へ追加された。

| 2000年の印刷標準字体 | 2000年の簡易慣用字体 | 2010年に常用漢字となった字体 |
| --- | --- | --- |
| 曾 | 曽 | 曽 |
| 瘦 | 痩 | 痩 |
| 麵 | 麺 | 麺 |

そのため、2000年の原表に載る1,022字がすべて、現在も表外漢字だとはいえない。常用漢字となった字の扱いは、改定後の常用漢字表を参照する。[2010年の常用漢字表](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji/index.html)、[簡易慣用字体一覧の注記](https://ja.wiktionary.org/wiki/簡易慣用字体)
