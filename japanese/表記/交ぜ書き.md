# 交ぜ書き

「拉致 → ら致」「破綻 → 破たん」のように、熟語の漢字の一部を仮名にする表記。ここでは、当用漢字・常用漢字の範囲に合わせるなどの理由で使われてきた、漢語を中心とする例を集める。

**矢印は表記の対応を示し、右側への変更を勧めるものではない。** 過去に使われた表記も含み、媒体や時期によって採用する形は異なる。「漢字で書けない語」の一覧でもない。

文化庁の審議会議事録では、新聞で「ら致」「だ捕」を「拉致」「拿捕」に戻し、振り仮名を付けるようになった経緯が報告されている。[文化審議会漢字小委員会・第11回議事録](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/kanji_kako/11/gijiroku.html)

## かつての「覚せい剤」表記

「覚醒剤」は、かつて法令でも「覚せい剤」と交ぜ書きされ、法律名も「覚せい剤取締法」だった。2020年4月施行の改正で、法律中の表記は「覚醒剤」、題名は「覚醒剤取締法」に改められた。したがって、一覧の「覚醒剤 → 覚せい剤」は、過去の表記との対応も示している。[法務省『令和2年版犯罪白書』第7編第3章第2節](https://hakusyo1.moj.go.jp/jp/67/nfm/n67_2_7_3_2_0.html)

## 似た表記との違い

| 種類 | 例 | 変わるもの |
| --- | --- | --- |
| 交ぜ書き | 拉致 → ら致 | 一部の漢字を仮名にする。 |
| 全体を仮名にする表記 | 拉致 → らち | 語全体を仮名にする。交ぜ書きとは分ける。 |
| 同音の漢字による書き換え | 雇傭 → 雇用 | 漢字を別の漢字に替える。 |
| 言い換え | 牽引 → 引っ張る | 語そのものを替える。 |

「皮ふ科」「処方せん」などは、漢字が使える場合でも読み手への配慮から選ばれることがある。新聞の表記方針にも違いがある。[毎日ことばplus「交ぜ書き、漢字制限…新聞の用語原則はどう決まったか」](https://salon.mainichi-kotoba.jp/archives/35878)
