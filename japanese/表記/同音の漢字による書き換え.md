# 同音の漢字による書き換え

「雇傭 → 雇用」「車輌 → 車両」のように、当用漢字表にない漢字を、同じ音の別の漢字に置き換えた表記の一覧。当用漢字制定後の1956年に国語審議会が報告した「同音の漢字による書きかえ」を中心に、主な例を挙げる。

「舊 → 旧」のような旧字体から新字体への変更とは区別する。また、歴史上の書き換えの一覧であり、**現在も右側だけが正しい、という意味ではない**。後の常用漢字表への追加によって、元の表記も使われるようになった例がある。

出典：[国語審議会「同音の漢字による書きかえ」前書き](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kakuki/03/bukai03/03.html)、[文化庁・漢字小委員会資料（2015年11月27日、原報告とその後の扱いを収録）](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/shoiinkai/iinkai_20/pdf/shiryo_3.pdf)。

## 1956 年の報告にない書き換え

報告の一覧にはないが、新聞・軍事・学術用語などで同じように書きかえられ、定着した例。**以下は文化庁の資料で確かめたものではない**（一般的な知識による）。

| 元の表記 | 書き換え | 分野・備考 |
| --- | --- | --- |
| 邀撃 | 要撃 | 軍事。迎え撃つこと。「邀」は「むかえる」。いまは同じ意味の **迎撃**（げいげき）を使うことが多い |
| 聯隊 | 連隊 | 軍事。報告の「聯 → 連」による。ほかに聯合艦隊 → [[連合艦隊]] |
| 掃蕩 | 掃討 | 軍事。「蕩」は「はらいのける」 |
| 潰走 | 壊走 | 軍事。報告の「潰滅 → 壊滅」と同じ形 |
| 戦捷 | 戦勝 | 軍事。「捷」は「かつ」 |
| 擡頭 | 台頭 | 「擡」は「もたげる」 |
| 醵出・醵金 | 拠出・拠金 | 「醵」は「お金を出しあう」 |
| 萎縮 | 委縮 | 新聞。「萎」は 2010 年に常用漢字になり、いまは「萎縮」に戻った |
| 鍛煉・精煉 | 鍛錬・精錬 | 「煉」は「ねる」 |
| 撰者・撰集 | 選者・選集 | 「撰」は「えらぶ・文章を作る」 |
| 函数 | 関数 | 数学の学術用語。中国語ではいまも「函数」 |
| 沙漠 | 砂漠 | |
| 輿論 | 世論 | 読みも「よろん」から「せろん」が生まれた。いまはどちらの読みもある。**同じ音ではない** 書きかえ |

## 常用漢字になった後の扱い

1956年の書き換え先を、そのまま現在の唯一の表記とはできない。文化庁の2015年資料では、次のように整理されている。

| 例 | その後の扱い |
| --- | --- |
| 研磨 → 研摩 | 「磨」は1981年に常用漢字となった。常用漢字表の用例は「研磨」。 |
| 臆説 → 憶説、臆測 → 憶測 | 「臆」は2010年に追加。常用漢字表では「臆説」「臆測」を掲げ、「憶説」「憶測」とも書くとしている。 |
| 肝腎 → 肝心 | 「腎」は2010年に追加。常用漢字表では「肝腎」を掲げ、「肝心」とも書くとしている。 |
| 広汎 → 広範、理窟 → 理屈 | 「汎」「窟」が2010年に加わった後も、同資料所収の法令用語の方針では「広範」「理屈」を続ける。 |
| 闇夜 → 暗夜 | 「闇」は2010年に追加されたが、常用漢字表に掲げる読みは「やみ」。追加されたからといって、音読み「アン」まで表内の読みになったわけではない。 |

出典：[文化庁・漢字小委員会資料、10〜14ページ](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/shoiinkai/iinkai_20/pdf/shiryo_3.pdf#page=10)。

引用や固有名詞は元の表記を尊重する。文章を直すときも、語の意味や使う場面を確認し、機械的な一括置換はしない。
