# 日本の政策金利の推移

1976〜2026年の日本銀行の政策金利をまとめる。政策金利として何を使うかがこの間に2度変わっているので、まずその区分を押さえる。

| 時期 | 政策金利・操作目標 | 説明 |
| --- | --- | --- |
| 〜1995年 | **公定歩合** | 日銀が民間銀行に貸し出すときの金利。規制金利の時代には、預金金利などがこれに連動した。 |
| 1995〜2001年 | **無担保コール翌日物金利** | 1994年の金利自由化完了で公定歩合との連動が切れ、市場金利の誘導が中心になる。 |
| 2001〜2006年 | 日銀当座預金残高 | 量的緩和政策。金利ではなく量を目標にした。 |
| 2006〜2013年 | 無担保コール翌日物金利 | 金利目標に戻る。 |
| 2013〜2024年 | マネタリーベース → 短期政策金利（マイナス）＋長期金利 | 量的・質的金融緩和、マイナス金利、イールドカーブ・コントロール。 |
| 2024年〜 | 無担保コール翌日物金利 | マイナス金利の解除で、短期金利を目標とする普通の形に戻る。 |

2006年8月に公定歩合は「基準割引率および基準貸付利率」と改称された。現在は補完貸付の金利で、コールレートが上がりすぎないように抑える上限の役割を持つ。

## 時代ごとの流れ

| 時期 | 水準 | 背景 |
| --- | --- | --- |
| 1973年 | 4.25% → 9.0% | 列島改造と第1次石油危機による狂乱物価。[[田中内閣の総需要抑制政策]]。 |
| 1975〜1978年 | 9.0% → 3.5% | 第1次石油危機後のインフレが収まり、景気を支えるため引き下げ。 |
| 1979〜1980年 | 3.5% → 9.0% | 第2次石油危機。インフレを防ぐため短期間で大幅に引き上げ。 |
| 1980〜1983年 | 9.0% → 5.0% | 物価の安定を受けて引き下げ。 |
| 1986〜1987年 | 5.0% → 2.5% | プラザ合意（1985年）後の円高不況への対応。当時の最低水準が2年あまり続き、バブルの一因とされる。 |
| 1989〜1990年 | 2.5% → 6.0% | 資産価格の高騰を抑えるため引き上げ。株価・地価の下落が始まる。 |
| 1991〜1995年 | 6.0% → 0.5% | バブル崩壊後の景気後退と金融不安への対応。 |
| 1999〜2000年 | コール 0%前後 | **ゼロ金利政策**。2000年8月に解除したが、ITバブル崩壊で景気が悪化し、のちに批判された。 |
| 2001〜2006年 | 当座預金残高目標 | **量的緩和政策**。デフレ克服を目指した。 |
| 2006〜2007年 | 0% → 0.5% | 量的緩和とゼロ金利を解除して利上げ。 |
| 2008〜2010年 | 0.5% → 0〜0.1% | リーマン・ショック後の世界金融危機への対応。2010年に包括的な金融緩和。 |
| 2013〜2016年 | 量の目標 | 黒田総裁のもとで**量的・質的金融緩和**（異次元緩和）。2%の物価目標を掲げた。 |
| 2016〜2024年 | **−0.1%** | **マイナス金利政策**。同年9月から長期金利も0%程度に誘導（イールドカーブ・コントロール）。 |
| 2024〜2026年 | 0〜0.1% → 1.25% | 植田総裁のもとでマイナス金利を解除し、17年ぶりに利上げ。以後、段階的に引き上げる。 |

## 今後の見通し（2026年10月30日時点）

ここに書くのは民間の予測と市場の見方。日銀は、会合ごとに見通しの実現度とリスクを点検して判断するとしている。

### 10月会合で示されたこと

- 1.25%で据え置き。票は8対1で、高田委員が1.5%への利上げを提案した。
- 基調的な物価上昇率が2%目標とおおむね整合する水準に達したと判断。政策の重点は「2%に近づける」から「2%程度で安定させる」へ移った。
- 植田総裁は「持続的・安定的な達成を宣言する段階には至っていない」と述べ、早期利上げの観測を抑えた。
- 保有ETFの売却ペースを年間8,600億円程度（簿価）に引き上げた。

### 予想

| 予想した機関 | 内容 |
| --- | --- |
| 市場 | 12月の利上げをかなり織り込む。日銀が様子見の姿勢を強めれば、2027年1月にずれる可能性もある。 |
| 第一生命経済研究所 | 2026年12月に1.5%、2027年3月に1.75%。 |
| 三井住友DSアセットマネジメント | 2027年1月と6月に0.25ポイントずつ利上げ。 |
| 大和総研 | 12月会合で1.5%へ。 |

大まかには、2027年にかけて1.5〜1.75%前後まで上がるという見方が多い。

### どこまで上がるか

景気を冷やしも過熱させもしない[[中立金利]]が目安になる。日銀が2026年3月に公表した再推計では、物価上昇率2%を前提に名目で1.1〜2.5%（2025年10〜12月期）と幅が広い。1.25%はこの範囲の下限付近にあるため、利上げの余地があると読まれている。

### 見通しを左右する要因

- 米国の景気と金利の動き。
- 為替。円安が進めば利上げが早まりやすく、円高なら遅れやすい。
- 2027年の春闘の賃上げ。
- 物価が2%を超えて上振れし続けるかどうか。

## 押さえどころ

- 「政策金利」が何を指すかは時代で違う。1995年ごろまでは公定歩合、以後は主にコールレート。
- ピークは公定歩合9.0%（1980年）。バブル期の最高は6.0%（1990年）。
- 0%近辺の時期は、1999年のゼロ金利から2024年のマイナス金利解除まで、四半世紀に及ぶ。
- 0.75%（2025年12月）で30年ぶり、1.0%（2026年6月）で1995年4〜9月の公定歩合と同じ水準になった。
- 2016〜2024年の −0.1% は日銀当座預金の一部（政策金利残高）にかかる金利で、預金者の預金金利がマイナスになったわけではない。
