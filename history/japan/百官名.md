# 百官名

**百官名（ひゃっかんな）**は、官職や役所の名前に由来する人の通称。式部・主水・内蔵助などがある。本人だけでなく、家や親の官名に由来する場合もある。

官名を人の呼び名として用いるもので、**その名を名乗ることが、実際にその官職に任じられていることを意味するわけではない**。

## 例

| 百官名 | 読み | 由来となる官司・官職 |
| --- | --- | --- |
| 式部 | しきぶ | 式部省 |
| 民部 | みんぶ | 民部省 |
| 刑部 | ぎょうぶ | 刑部省 |
| 主水 | もんど | 主水司 |
| 主税 | ちから | 主税寮 |
| 主計 | かずえ | 主計寮 |
| 内蔵助 | くらのすけ | 内蔵寮の次官である内蔵助 |
| 掃部 | かもん | 掃部寮 |
| 右衛門 | うえもん | 右衛門府 |
| 左近 | さこん | 左近衛府 |
| 兵衛 | ひょうえ | 左右の兵衛府・その官人 |

役所の名前を短く用いる型と、「内蔵助」のように役職名を用いる型がある。漢字だけでは読みを推測しにくい名前が多い。

## 人物名での実例

| 人物名 | 百官名の部分 | 人物・作品 |
| --- | --- | --- |
| 紫式部（むらさきしきぶ） | 式部 | 『源氏物語』の作者。「式部」は父・藤原為時の官職である式部丞に由来するとされる。本人の官職ではなく、親の官名に基づく女房名の例。 |
| 中村主水（なかむら もんど） | 主水 | 『必殺』シリーズの架空の人物。藤田まことが演じた。「主水」は主水司に由来する通称で、作中の職務を表すものではない。 |
| 大石内蔵助良雄（おおいし くらのすけ よしお） | 内蔵助 | 赤穂藩の家老で、赤穂事件の中心人物。「良雄」が諱。 |
| 大石主税良金（おおいし ちから よしかね） | 主税 | 大石内蔵助の長男で、討入りに参加した人物。「良金」が諱。 |

たとえば「中村主水」の「主水」は、現代人には普通の名前に見えるが、もとは宮中の水に関わる役所の名に由来する。時代劇の人物名にも、こうした官名由来の通称が使われている。

### 女房名の例：紫式部

百官名は男性の武士に限らない。紫式部の「式部」は、父の官職に由来するとされる呼び名で、宮仕えする女性の呼称である**女房名**として用いられた。

「紫」は『源氏物語』の登場人物・紫の上に由来すると考えられている。「紫式部」は現代の「名字＋個人名」という構成ではなく、「紫」が名字なのでもない。本人の実名は確定していない。

### 近現代の名前に残る例：大内兵衛

経済学者の**大内兵衛（おおうち ひょうえ）**も、官名と同じ形の名を持つ例。「兵衛」は、もとは天皇の身辺警護などを担った兵衛府・その官人を指す語で、百官名にも用いられた。

ただし、大内兵衛の「兵衛」は近現代の個人名であり、諱と別に使う中世・近世の通称とは区別する。ここでは**百官名にも使われた語が、近現代の名前にも見られる例**として挙げる。本人の具体的な命名事情は未確認。

「兵衛」は単独だけでなく、「○兵衛」という形でも使われる。『四季草』（1778年）には「何兵衛」なども百官名に含める説明がある（下記レファレンス協同データベース参照）。

## 名前の中での位置

武士の名では、名字と諱の間に置かれることがある。

> 大石 内蔵助 良雄
> ＝ 名字 ＋ 通称（百官名） ＋ 諱

日常の呼び名では「大石内蔵助」のように通称を用いる。「内蔵助」は現代の姓名における下の名前に似た位置に見えるが、「良雄」という諱も別にある。

## 東百官との関係

**東百官（あずまひゃっかん）**は、官名にならって作られた、実在の官職名ではない通称。伊織・数馬・左膳・頼母などが例に挙げられる。

百官名が官名に由来するのに対し、東百官は官名風に作られた呼び名として区別される。

## 肩書きを重ねる呼称との関係

[[肩書き・身分・敬称を重ねた呼称]]の「入道相国」は、出家した立場と官職に基づく呼称を組み合わせている。一方、百官名は、官名を人の通称として使う仕組みを指す。

どちらも官職に由来する語で人物を呼ぶが、「呼称の組み合わせ」と「通称の由来」という別の観点になる。
