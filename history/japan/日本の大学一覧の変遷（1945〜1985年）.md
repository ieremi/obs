# 日本の大学一覧の変遷（1945〜1985年）

前編：[[日本の大学一覧の変遷（1880〜1945年）]]

1945〜1985年の大学の変遷を、**制度変更と主要大学の新設・改組・改称**を中心に整理する。全大学の増減を網羅した一覧ではなく、掲載のない年にも大学の新設や改称はある。

## 対象と読み方

- `＋` は大学の新設・昇格、`→` は改称・改組・統合を示す。
- 新制移行は、既存の旧制大学の改組と、旧制高等学校・専門学校・師範学校などを母体とする大学設置を含む。すべてが教育機関のゼロからの創設ではない。
- 設置・認可の年を基本とする。法人設立、開校、学生受入れ、旧組織の廃止が別年の場合は区別する。
- 短期大学・高等専門学校・専門学校は、制度の変化として触れるが、四年制大学の一覧とは分ける。医学・歯学などには六年制課程がある。

## 1945〜1955年：旧制大学から新制大学へ

| 年 | 制度・大学の差分 | 意味・注意点 |
| --- | --- | --- |
| 1945 | 敗戦により、海外にあった日本側の大学が接収・閉鎖などの対象となる | 前編との接続点。終戦日と各校の廃止日は同一ではない |
| 1946 | ＋ **愛知大学**〔旧制〕 | 東亜同文書院大学など、海外の大学から引き揚げた教員・学生の受け皿となった |
| 1947 | **教育基本法・学校教育法**制定。＋ **玉川大学**〔旧制〕 | 新制大学制度の法的枠組みが成立する一方、移行期には旧制大学の設置も続いた |
| 1947 | 内地の7帝国大学から「帝国」を除く改称 | 東京・京都・東北・九州・北海道・大阪・名古屋の各大学。改称と新制移行は別の出来事 |
| 1948 | 最初の**新制大学12校**が発足 | 女子大学では**津田塾大学、東京女子大学、日本女子大学、聖心女子大学、神戸女学院大学**が含まれる |
| 1949 | **国立学校設置法**により新制国立大学69校が発足 | 原則として一府県に一国立大学を置く方針。旧制大学・高等学校・専門学校・師範学校などを再編統合 |
| 1949 | 新制国立大学の例：**東京大学、京都大学、一橋大学、東京教育大学、お茶の水女子大学、奈良女子大学、千葉大学、新潟大学、岡山大学、広島大学、神戸大学** | 旧帝国大学の移行、旧制大学の再編、専門学校などからの大学設置が並行 |
| 1949 | 公立の例：＋ **浪速大学、大阪女子大学**／私立の例：新制**愛知大学、近畿大学** | 浪速大学は後の大阪府立大学。近畿大学は大阪専門学校と大阪理工科大学を母体とする |
| 1950 | **短期大学制度**が暫定制度として発足 | 四年制大学とは異なる制度として高等教育の受け皿が増える |
| 1951 | 新制**東京医科歯科大学**を設置 | 旧制大学の設置は1946年。新制移行まで同じ年ではない |
| 1952 | ＋ **神戸商船大学** | 商船教育の大学整備。東京商船大学は1949年11月に設置 |
| 1953 | ＋ **国際基督教大学（ICU）** | 四年制教養学部を中心とする大学として発足 |
| 1955 | 浪速大学 → **大阪府立大学** | 校名変更。2005年の再編統合や2022年の大阪公立大学設置とは別 |

制度と新制移行：[文部省：新制大学の発足](https://www.mext.go.jp/b_menu/hakusho/html/others/detail/1317752.htm)、[国立大学協会：1946〜1950年の年表](https://www.janu.jp/active/activity/1950.html)。旧帝国大学の改称と新制移行の区別は、[京都大学の沿革資料](https://repository.kulib.kyoto-u.ac.jp/dspace/bitstream/2433/152988/1/general_part2_chap1.pdf)も参照。

個別校：[愛知大学の歴史](https://www.aichi-u.ac.jp/profile/flow/history)、[玉川大学の旧制大学認可](https://www.tamagawa.jp/introduction/history/detail_23546.html)、[神戸女学院大学：新制大学設置認可70周年](https://www.kobe-c.ac.jp/news/180326univ/)、[近畿大学の歴史・年表](https://www.kindai.ac.jp/about-kindai/corporation/history/)、[大阪公立大学：前身校の沿革](https://www.omu.ac.jp/about/philosophy/history/)、[ICUの使命・沿革](https://www.icu.ac.jp/about/commitments/)。東京医科歯科・商船系大学の設置は[文部科学省：国立大学の設置の経緯](https://www.mext.go.jp/b_menu/shingi/chukyo/chukyo4/006/gijiroku/010801/08.htm)による。

## 1956〜1972年：進学需要の拡大と大学の増設

| 年・時期 | 制度・大学の差分 | 意味・注意点 |
| --- | --- | --- |
| 1960年代 | 私立大学を中心に大学数が大きく増加 | 高度経済成長、理工系人材需要、進学需要の拡大に対応 |
| 1961〜1962 | 高等専門学校の制度創設と発足 | 大学とは別の、高度な実践的技術者を養成する進路を整備 |
| 1964 | **短期大学制度を恒久化** | 暫定制度から恒久的な学校種へ |
| 1965 | ＋ **宮城教育大学** | 教員養成の整備。各地の国立大学でも文理学部の分離・改組が進む |
| 1966 | ＋ **北見工業大学** | 工業短期大学を母体とする工業大学の整備 |
| 1968 | ＋ **九州芸術工科大学** | 芸術と工学を結びつける大学として設置 |
| 1971 | ＋ **創価大学** | 私立大学新設の例。経済・法・文の3学部で開学 |
| 1972 | **琉球大学が国立大学へ移管** | 大学の創設は1950年。沖縄返還に伴う1972年の国立移管と区別する |

制度・大学整備：[文部科学省：我が国高等教育のこれまでの歩み](https://www.mext.go.jp/b_menu/shingi/chukyo/chukyo0/toushin/attach/1409870.htm)、[文部省：大学制度の整備](https://www.mext.go.jp/b_menu/hakusho/html/others/detail/1317820.htm)、[文部科学省：国立大学の設置の経緯](https://www.mext.go.jp/b_menu/shingi/chukyo/chukyo4/006/gijiroku/010801/08.htm)。私立大学の例：[創価大学の沿革](https://www.soka.ac.jp/about/intro/)。

## 1973〜1985年：医科大学・新構想大学と拡大の抑制

| 年・時期 | 制度・大学の差分 | 意味・注意点 |
| --- | --- | --- |
| 1973 | ＋ **筑波大学** | 東京教育大学の移転を契機とする大学改革。単純な校名変更ではなく、新旧の大学が一時併存 |
| 1970年代 | 無医大県解消を目指し、**医科大学・医学部を増設** | 大学の新設と、既存大学への医学部新設は区別する |
| 1974 | ＋ **浜松医科大学** | 無医大県解消計画による新設の具体例 |
| 1975 | **私立学校振興助成法**制定。専修学校制度を法制化〔翌年施行〕 | 私学助成の基盤整備とともに、私立大学の量的拡大を規制。専門学校は大学とは別制度 |
| 1976 | **高等教育の計画的整備**について報告 | 大学の拡充を抑制し、量から質への転換を打ち出す。地域配置も政策課題となる |
| 1976 | ＋ **長岡技術科学大学、豊橋技術科学大学** | 高専卒業生を受け入れ、実践的・創造的な技術者を養成する新しい大学構想 |
| 1978 | **東京教育大学が閉学** | 筑波大学発足の1973年と、旧大学の閉学年を区別する |
| 1978 | ＋ **上越教育大学** | 現職教員の研究・研鑽と初等教育教員養成を組み合わせた新構想の教育大学 |
| 1979 | ＋ **図書館情報大学** | 図書館短期大学を基礎とする四年制大学への展開 |
| 1981 | ＋ **鳴門教育大学、鹿屋体育大学** | 教員の研修・養成、体育・スポーツ指導者養成のための大学整備 |
| 1983 | ＋ **放送大学**〔設置〕 | 放送を利用して高等教育の機会を広げる大学。学生受入れはまだ始まらない |
| 1985 | **放送大学が学生を受け入れ、テレビ・FMラジオによる授業を開始** | 設置年の1983年と区別。開始当初は関東地域が中心 |

筑波大学：[大学沿革](https://www.tsukuba.ac.jp/about/outline-history/)。医科大学整備：[文部科学省：医学部の定員をめぐる動向](https://www.mext.go.jp/b_menu/shingi/chousa/koutou/029/toushin/attach/1408113.htm)、[浜松医科大学：開学50周年](https://www.hama-med.ac.jp/kikin/50th/index.html)。拡大抑制：[文部省：高等教育計画の必要性](https://www.mext.go.jp/b_menu/hakusho/html/others/detail/1318378.htm)。

新構想大学の具体例：[高専機構：技術科学大学創設の趣旨](https://www.kosen-k.go.jp/Portals/0/60th/message/5/)、[上越教育大学：創設の主旨・目的](https://www.juen.ac.jp/050about/010info/010purport.html)、[鳴門教育大学：沿革](https://www.naruto-u.ac.jp/about/overview03/)、[鹿屋体育大学：沿革](https://www.nifs-k.ac.jp/aboutus/overview/history/)、[日本図書館情報学会：図書館情報学教育の調査報告書](https://jslis.jp/wp-content/uploads/2019/04/abaed91720f91a45971178033c12e50d.pdf)。放送大学：[公式Web資料館：沿革](https://oujmuseum.ouj.ac.jp/history/)。

## 大学数で見る拡大

以下は学校基本調査に基づく大学数。短期大学は含めない。年表は主要な出来事の抜粋なので、掲載した大学名の数と統計の増減は一致しない。

| 年 | 国立 | 公立 | 私立 | 合計 |
| --- | ---: | ---: | ---: | ---: |
| 1950 | 70 | 26 | 105 | 201 |
| 1960 | 72 | 33 | 140 | 245 |
| 1965 | 73 | 35 | 209 | 317 |
| 1970 | 75 | 33 | 274 | 382 |
| 1975 | 81 | 34 | 305 | 420 |
| 1980 | 93 | 34 | 319 | 446 |

1950〜1985年に大学総数は201校から460校へ増え、特に私立大学は105校から331校へ増加した。一方、1970年代後半からは高等教育計画による拡大抑制が進んだ。

出典：[日本私立大学協会附置私学高等教育研究所『私学高等教育データブック2010』基礎表1](https://www.shidaikyo.or.jp/riihe/result/pdf/2010_p03.pdf)〔原資料：各年の学校基本調査報告書〕。

## 年代を読むための要点

- **1940年代後半：制度と大学の構成を作り直す。** 旧制の多様な学校を新制大学へ再編する。
- **1960年代：進学機会を広げる。** 私立大学の新設、理工系教育の拡大、教員養成の再編が進む。
- **1970年代：分野・地域の不足に対応する。** 医科大学、技術科学大学、教育大学などを整備する一方、大学全体の量的拡大には抑制をかける。
- **1980年代前半：学ぶ機会と方法を広げる。** 放送大学の設置・授業開始がその代表例となる。
