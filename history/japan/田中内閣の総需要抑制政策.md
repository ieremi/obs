# 田中内閣の総需要抑制政策

1973年末から田中角栄内閣が採った、財政と金融の両面から需要を抑えてインフレを鎮める政策。日本列島改造論による積極財政が、過剰流動性と第1次石油危機に重なって「狂乱物価」を招いた。その後始末として、愛知揆一の急死を受けて蔵相に就いた福田赳夫が主導した。物価は鎮まったが、1974年に戦後初のマイナス成長となり、高度経済成長は終わった。

## 背景

| 要因 | 内容 |
| --- | --- |
| 過剰流動性 | 1971年のニクソン・ショック後、円の切り上げを防ぐドル買い介入と金融緩和でお金が余った。公定歩合は1972年6月に4.25%まで下がる。 |
| 日本列島改造論 | 1972年7月に田中内閣が発足。新幹線・高速道路網と地方の工業化を掲げ、積極財政を進めた。 |
| 列島改造ブーム | 開発予定地を中心に土地投機が広がり、地価と物価が上がる。 |
| 第1次石油危機 | 1973年10月の第4次中東戦争で原油価格が約4倍になる。トイレットペーパーなどの買いだめ騒ぎも起きた。 |

福田は、このときの物価高騰を「狂乱物価」と呼んだ。

## 政策の中身

| 分野 | 主な措置 |
| --- | --- |
| 金融 | 公定歩合を1973年に5回引き上げ、12月に**9.0%**。預金準備率の引き上げと窓口指導で銀行の貸出を抑えた。 |
| 財政 | 1974年度予算を緊縮型で組んだ。公共事業の契約・着工を繰り延べ、列島改造は事実上棚上げになった。 |
| 物価・物資 | 1973年12月に国民生活安定緊急措置法と石油需給適正化法を制定。生活必需品の標準価格や石油の使用規制を定めた。 |

### 1973年の公定歩合引き上げ

| 年月日 | 水準 |
| --- | --- |
| 1973年4月2日 | 5.0% |
| 1973年5月30日 | 5.5% |
| 1973年7月2日 | 6.0% |
| 1973年8月29日 | 7.0% |
| 1973年12月22日 | **9.0%** |

9.0%は1975年4月まで続いた。

## 経過と結果

| 時期 | 出来事 |
| --- | --- |
| 1973年11月 | 愛知揆一蔵相が急死し、福田赳夫が蔵相に就任。総需要抑制へ方針転換。 |
| 1974年 | 消費者物価が前年比で20%を超えて上がる。春闘の賃上げ率も30%を超えた。 |
| 1974年 | 実質経済成長率が**戦後初のマイナス**になる。物価高と不況が重なるスタグフレーション。 |
| 1974年7月 | 参院選後、田中の金権選挙を批判して福田が蔵相を辞任。大平正芳が後任になる。 |
| 1974年12月 | 金脈問題で田中内閣が総辞職。三木武夫内閣が引き締めを引き継ぐ。 |
| 1975年4月 | 公定歩合の引き下げが始まり、景気対策へ転じる。 |

## 押さえどころ

- 列島改造（拡張）から総需要抑制（引き締め）への転換は、同じ田中内閣の中で起きた。
- 原因は石油危機だけではない。石油危機の前から、過剰流動性と列島改造で物価は上がっていた。
- 結果としてインフレは収まったが、高度経済成長が終わり、安定成長期へ移る区切りになった。
- 公定歩合9.0%は、1980年の第2次石油危機の際にも再び付けた、戦後の最高水準。
