# 赤備え

**甲冑・旗指物・馬具などを、赤（朱）で統一した部隊。** 戦国時代から江戸時代にかけての軍団の編成のしかたの一つ。読みは「あかぞなえ」。

- 赤い顔料は、高価な **辰砂**（水銀の鉱物、朱）から作られた。戦場で **よく目立つ** ので、腕に自信のある武将が率いる **精鋭部隊** に多く使われた
- そのため、「**赤備え ＝ 精鋭**」というイメージが広まった
- 色で部隊をそろえることを **色備え** という。赤のほかに、黒・黄・青・白などもあった

## 主な赤備え

| 家 | 率いた人 | ことがら |
| --- | --- | --- |
| **武田氏** | **飯富虎昌** → **山県昌景** | 赤備えの始まりとされる。昌景の赤備えがとくに有名 |
| 武田氏 | 小幡信貞（上野の小幡氏）、浅利信種 | 『甲陽軍鑑』によると、これらも赤備え。武田の赤備えは合わせて千騎 |
| **井伊氏**（徳川家臣） | **井伊直政** | 武田の旧臣を引き継いで作る。「**井伊の赤鬼**」。彦根藩で幕末まで続く |
| **真田氏** | 真田信之（信幸）、**真田信繁（幸村）** | 信繁が **大坂夏の陣**（1615 年）で赤備えにして、家康の本陣に攻めこむ |
| 後北条氏 | 北条綱高 | 五色の色備えのうち、赤を受け持つ |
| 福島正則 | — | 配下の 20 騎に朱塗りの甲冑を着せ、「**赤坊主**」とよんだ |
| 江戸幕府 | 小十人組 | 将軍の外出の護衛。朱塗りの甲冑（**海老殻具足**）を幕府から借りた。武田の赤備えを手本にしたとされる |

## 武田の赤備え
- 最初に率いたのは、武田信玄の重臣 **飯富虎昌**（おぶ とらまさ）とされる
- 朱色は、多くの首を取った手柄のある者に許される色だった。虎昌は、家を継げない **武将の次男たち** を集め、赤備えの **切り込み部隊** を作った
- **1565 年**、信玄の長男 **武田義信** が父に背こうとした事件（**義信事件**）に連座して、虎昌は切腹した。部隊は **山県昌景**（やまがた まさかげ）が引き継いだ。昌景は虎昌の弟とも甥ともいわれる
- 武田氏の朱印状（1572 年・1574 年）から、武田氏が **部隊ごとに兵装の色や規格を決めていた** ことがうかがえる
- **1575 年** の [[長篠の戦い]] で、山県昌景は戦死した

## 井伊の赤備え
- **1582 年** に武田氏が滅ぶと、[[徳川家康]] は武田の旧臣を、若い家臣 **井伊直政** に付けた。その中に **山県隊の旧臣** もいたので、直政は **赤備えを受けついだ**
- **1584 年** の **小牧・長久手の戦い** で活躍し、「**井伊の赤鬼**」とおそれられた
- [[関ヶ原の戦い]]（1600 年）でも赤備えで戦った
- 直政の子孫の **彦根藩**（井伊家）では、**足軽まで赤備え** が基本とされ、幕末まで続いた。[[大坂の役]] では、直政の子 **井伊直孝** が赤備えを率いた
- いまの彦根市のキャラクター「**ひこにゃん**」の赤い兜は、井伊家に伝わる赤備えの兜がもとになっている

### 幕末の敗北
- **1853 年** の黒船来航では、彦根藩の兵が江戸湾の警備に出た
- **1866 年** の **第二次長州征討**（幕長戦争）で、彦根藩は **火縄銃と赤い鎧** で戦い、西洋式の銃をもつ長州藩の部隊に **一方的に敗れた**。目立つ赤い鎧が、かえって **よい的** になった
- 戦場で目立つことが強さのしるしだった時代から、**遠くから撃ち合う時代** に変わったことを示す出来事として語られる
- その後、彦根藩は早くから新政府に従い、鳥羽・伏見の戦いでは新政府軍として戦った
- （井伊家は、幕末に大老 [[井伊直弼]] を出した家でもある）

## 真田の赤備え
- **真田信繁（幸村）** は、**1615 年** の [[大坂夏の陣]] で部隊を赤備えにし、**天王寺口** から [[徳川家康]] の本陣に攻めこんだ。家康を追いつめたが、討ち死にした
- ただし、真田家の赤備えは信繁が最初ではない。**1593 年** に、兄の **信幸（信之）** が、家臣に赤い甲冑と指物を指示している

## 色備えのほかの例
- **伊達氏**：大将から足軽まで、**黒い仙台胴** でそろえた
- **立花宗茂**：精鋭部隊を **金備え** にすることがあった
- 中国では、三国時代の呉の **呂蒙** が兵を赤い服でそろえた。唐の末期の **李克用** の黒い服の部隊は「**鴉軍**」（からすの軍）とよばれた
- ヨーロッパでは、**イギリス陸軍の赤い軍服**（レッドコート）、イタリア統一の **ガリバルディの赤シャツ隊** がある

## なぜ赤か
- **目立つ**：敵にも味方にも、どこにいるかがすぐ分かる。精鋭であることを見せつけて、敵をおそれさせる
- **手柄の色**：朱は、多くの首を取った者に許される色だった（武田氏）
- **お金がかかる**：朱の顔料（辰砂）は高い。部隊全体をそろえられるのは、豊かで力のある家だけだった
- **まとまり**：同じ色をまとうことで、部隊の一体感が生まれる

## 押さえどころ
- 赤備えは、**甲冑などを赤でそろえた精鋭部隊**
- 流れ：**飯富虎昌 → 山県昌景（武田）→ 井伊直政（徳川）** と受けつがれた
- **真田信繁** の赤備えは、大坂夏の陣で家康の本陣を攻めたことで有名
- 井伊の赤備えは彦根藩で幕末まで続いたが、**第二次長州征討で、西洋式の銃の前に敗れた**
