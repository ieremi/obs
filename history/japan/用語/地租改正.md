# 地租改正

1873年（明治6年）から明治政府が進めた、土地と租税の制度改革。土地の価格である地価を課税の基準とし、地券所有者が貨幣で地租を納める仕組みに改めた。

## 背景と内容

旧来の年貢制度は地域ごとの違いが大きく、明治政府は全国共通の税制と安定した歳入を必要としていた。改革では土地の測量や地価の算定を行い、納税者と税額を明確にしていった。

| 観点 | 改革の主な内容 |
| --- | --- |
| 課税基準 | 石高を基礎とする方式から、地価を基準とする方式へ |
| 納付方法 | 原則として貨幣で納付 |
| 納税者 | 地券所有者 |
| 当初の税率 | 地価の3％ |
| 豊凶との関係 | 豊作・不作によって税額を増減させない |

地価は、毎年の実際の収穫額そのものではない。土地から見込まれる収益などをもとに算定された評価額である。

## 歴史的意義

### 政府の財政基盤を安定させた

貨幣による定額の税収を確保する仕組みは、政府が歳入を見通し、全国的な政策を進める基盤となった。[[廃藩置県]]による行政の統合を、財政面から支える改革として位置づけられる。

### 近代的な土地所有と課税の関係を整えた

土地の所有者を確認し、その所有に対して課税する仕組みを整備した。土地を誰が所有し、誰が納税義務を負うかを明確にすることは、近代的な土地制度の基礎となった。ただし、土地の私有が歴史上初めて生まれたという意味ではない。

### 農民に収穫・価格変動の負担を負わせた

政府にとって税収が安定する一方、納税者は不作でも原則として定額を貨幣で用意する必要があった。農産物価格が下がれば、同じ税額を納めるために、より多くの生産物を売る必要が生じる。この点からも、税制の近代化が負担の軽減と同じではないことがわかる。

## その後

農民の反対運動などを背景に、1877年には税率が地価の3％から2.5％へ引き下げられた。改革は一度の法令公布で完成したものではなく、土地の調査・評価を伴う事業として数年にわたり進められた。
