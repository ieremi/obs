# 田中角栄内閣

[[田中角栄]]を首相とする内閣。ここでは、主に1972〜1974年の経済運営について、失政と評価される点を整理する。

## 日本列島改造と地価・物価の高騰

**地方への産業分散や社会資本整備を目指した政策が、土地の値上がり期待と投機を刺激し、過熱を抑えきれなかったこと**が、代表的な批判点である。

田中は、大都市への人口・産業の集中を転換し、地方の生活環境や社会資本を整える方針を掲げた。一方、内閣府の景気循環の整理では、日本列島改造論が地価高騰を刺激し、その後の第一次石油危機による原油高も重なって「狂乱物価」に至ったと説明される。[1973年の施政方針演説](https://www.mofa.go.jp/mofaj/gaiko/bluebook/1973/s48-shiryou-1-3.htm)、[内閣府：第7循環の説明](https://www5.cao.go.jp/keizai3/2007/1214nk/07-00403-01n.html)

| 観点 | 内容 |
| --- | --- |
| 目的 | 過密・過疎の是正、産業の地方分散、社会資本・生活環境の整備。 |
| 失敗と評価される点 | 開発への期待が土地の投機的需要を刺激し、地価・物価の安定と両立しなかった。 |
| 背景 | 円切上げ後の景気対策としての金融緩和・積極財政と、過剰流動性。 |
| 外的ショック | 1973年秋の第一次石油危機による原油価格の上昇。 |
| 結果 | 物価高騰への対応として需要抑制が必要になり、景気後退へ移った。 |

### なぜ開発構想が土地投機につながるのか

次は政策の作用を理解するための整理。

1. 道路・鉄道の整備や工場進出が見込まれる地域で、土地の将来価値への期待が高まる。
2. 実際に使う目的に加え、値上がり後の転売を目的とする購入が増える。
3. 購入資金を調達しやすい状況では、期待が買いを呼び、地価が上がりやすくなる。
4. 土地取得費の上昇は、住宅取得や事業用地の確保を難しくし、開発そのものの費用も押し上げる。

問題は開発の必要性に加え、**投機を抑える土地・融資対策と、経済全体の需要管理を伴わせられたか**にある。

## 過熱への政策転換の時期

もう一つの論点は、景気刺激を重視する政策から、インフレ抑制へ転換する時期と強さである。田中自身も1973年4月の国会答弁で、内需振興に重点を置き過ぎて過剰流動性が生じた点について、前内閣以来の政策運営に改善の余地があったとの認識を示した。ただし、列島改造論が地価上昇の原因だという批判には反論していた。[1973年4月26日の国会答弁](https://kokkai.ndl.go.jp/simple/detail?minId=107105063X01119730426)

石油危機後について、日本銀行の百年史は、強力な引締め措置に至るまでの時間差と、供給制約という状況への判断の戸惑いを振り返っている。これは政府だけでなく、日銀を含めた政策対応を検討する材料となる。[日本銀行百年史：当時の金融政策](https://www.boj.or.jp/about/outline/history/hyakunen/data/hyaku6_6_1_4.pdf)

## どこまで内閣の責任といえるか

- **石油危機は内閣が引き起こしたものではない。** 原油高による供給面の物価上昇と、国内の需要刺激・投機による過熱を分けて見る。
- **金融緩和や内需拡大は前内閣からの経緯がある。** 田中内閣発足後だけを切り取って原因を説明しない。
- **地価と消費者物価は別の指標である。** 土地投機の問題と、生活物資全般の値上がりの問題を区別する。
- **地方開発の長期的な効果と、短期の過熱は別々に評価する。** 物価安定に失敗したことから、個々の交通・生活基盤整備まで一律に無価値とすることはできない。

したがって、失政としての焦点は、**列島改造を進める際の投機・過剰需要への備えと、過熱が明らかになった際の政策修正**にある。「狂乱物価のすべてが田中の責任」とする説明は、原因を単純化し過ぎる。

## 成果・成功と評価される点

### 日中国交正常化（1972年）

1972年9月29日の日中共同声明で、日本と中華人民共和国は外交関係の樹立を決定した。長年の懸案を首脳交渉と共同声明に結び付け、政府間の正式な関係や交流を進める基盤を作った点が外交上の成果である。[外務省：日中共同声明](https://www.mofa.go.jp/mofaj/gaiko/bluebook/1973/s48-shiryou-3-11.htm)

米中接近など国際環境の変化や、従来からの日中間の交流も背景にあった。国交正常化と、台湾との関係の変化やその後の日中間の個別問題は、区別して評価する。

### 高額療養費制度の創設（1973年）

1973年、まず健康保険の被扶養者について、重い医療費負担を一定限度に抑える高額療養費制度を創設した。病気になった際の家計負担を軽くする仕組みの基礎を整えた点が成果である。[厚生労働省：制度の改正経緯](https://www.mhlw.go.jp/content/12401000/0000025320.pdf)、[制度創設についての専門委員会説明](https://www.mhlw.go.jp/stf/newpage_58557.html)

現在の制度の対象や仕組みが1973年にすべて完成したわけではない。以後の対象拡大・低所得者への配慮・世帯合算などの改正を経て、医療保険のセーフティーネットとして発展した。
