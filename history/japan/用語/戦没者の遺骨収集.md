# 戦没者の遺骨収集

## 概要
- 第二次世界大戦（[[太平洋戦争]]など）で亡くなり、戦地に残されたままの日本人の遺骨を探し、掘り出して日本へ持ち帰る **国の事業**
- 担当は **厚生労働省**。1952 年（昭和 27 年）、サンフランシスコ平和条約が発効して日本が主権を回復した年に、南方地域で始まった
- 2016 年の **戦没者遺骨収集推進法** で、遺骨収集は **国の責務** と定められた

## どれだけ残っているか
厚生労働省の公表による概数（毎年更新される）。

| 区分 | 人数（概数） |
| --- | --- |
| 海外（硫黄島・沖縄を含む）での戦没者 | 約 240 万人 |
| そのうち、遺骨が帰ってきた | 約 128 万柱 |
| **まだ帰っていない** | **約 112 万柱** |
| └ 海に沈んだ（海没） | 約 30 万柱 |
| └ 相手国の事情で収集が難しい | 約 23 万柱 |
| └ それ以外（収集できる可能性がある） | 約 59 万柱 |

遺骨は「柱（はしら）」と数える。

## 歴史

| 時期 | できごと |
| --- | --- |
| 1952〜 | 南方地域で政府の遺骨収集団の派遣が始まる。戦友や遺族が多く参加した |
| 1950〜70 年代 | 計画的な収集が何度も行われる。収集した遺骨の多くは現地で焼いて（焼骨）持ち帰った |
| 1959 | 身元がわからない遺骨を納める **千鳥ケ淵戦没者墓苑**（東京都千代田区）ができる |
| 1991〜 | ソ連の崩壊前後から、旧ソ連（シベリア抑留）・モンゴルでの収集が始まる |
| 2003〜 | **DNA 鑑定** による身元の確認が始まる。はじめは遺品や記録から遺族の手がかりがある場合に限った |
| 2016 | **戦没者遺骨収集推進法** が成立（議員立法）。2016〜2024 年度を **集中実施期間** とする。日本戦没者遺骨収集推進協会を、実務を担う法人に指定 |
| 2019 | シベリアやフィリピンなどで持ち帰った遺骨に **日本人でないものが含まれていた** 疑いが明らかになり、厚生労働省が公表を遅らせていたことが問題になる |
| 2020〜 | 外国人の遺骨の混入を防ぐため、現地での鑑定や、DNA 鑑定用の検体を取る手順が見直される |
| 2021〜 | 遺族が DNA 鑑定を申し込める地域を広げる。手がかりがなくても申し込めるようになる |
| 2024 | 法改正で、集中実施期間が延長される |

## 進め方
1. **情報を集める**：戦友や遺族の証言、戦史の記録、現地の住民からの情報、米国などの公文書
2. **現地を調べる**：埋葬地や戦闘のあった場所を確かめる。土地の持ち主や相手国の政府の許可を取る
3. **掘り出す**：現地の人の協力を得て発掘する。不発弾があることも多い
4. **鑑定する**：人類学の専門家が、日本人の遺骨かどうかを見分ける
5. **DNA 鑑定の検体を取る**：身元を確かめるため、歯や骨の一部を持ち帰る
6. **日本へ持ち帰る**：身元がわかれば遺族に返す。わからなければ千鳥ケ淵戦没者墓苑に納める

## 難しさ
- **時間がたちすぎた**：戦後 80 年をこえ、場所を知る戦友や遺族がほとんどいない。遺骨も傷んでいる
- **身元がほとんどわからない**：DNA 鑑定で身元がわかったのは、帰ってきた遺骨のごく一部。遺族の側も高齢になり、比べる DNA を得にくい
- **外国人の遺骨との混同**：同じ場所で戦った相手国の兵士や現地の住民の遺骨が混じることがある
- **相手国の事情**：治安、政治的な関係、土地の所有の制度（慣習的な土地の所有など）で、調べられない場所がある
- **海に沈んだ遺骨** は、ほぼ収集できない

## ガダルカナル島では
- [[ガダルカナル作戦]]で約 2 万人が死んだとされ、その多くが島に残されたまま
- 戦後、政府の遺骨収集団が何度も派遣され、いまも調査と収集が続いている
- 島の土地の多くは、氏族などが慣習的に持つ土地で、掘るには地元の土地の持ち主の同意が要る
- 島のあちこちに不発弾が残り、発掘の妨げになる
- 激戦地だったオースチン山に、日本政府が建てた **ソロモン平和慰霊公苑** がある
- → [[ガダルカナル島]]
