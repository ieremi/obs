# 日本の大学一覧の変遷（1880〜1945年）

続編：[[日本の大学一覧の変遷（1945〜1985年）]]〔制度変更と主要大学を中心に整理〕

1880年の大学一覧を起点に、1945年までの新設・大学昇格・改称・統合を、変更のある年ごとに示す。

## 対象と読み方

- 当時の制度上の大学を対象とする。前身校の創立年や、専門学校が校名に「大学」を使い始めた年とは区別する。
- `＋` は新設・大学昇格、`→` は改称・改組・統合を表す。改組の場合、大学数が増えるとは限らない。
- 学部の増設・移管は、大学の新設・統合に関係する場合だけ記載する。
- 内地の大学を主表とし、日本統治下などの海外にあった大学は別表にする。
- 年は設置・認可を基準とし、開校・授業開始の年とは異なる場合がある。

## 起点：1880年

**東京大学の1校。** 1877年に東京開成学校と東京医学校を統合して設置された。[[工部大学校]]などは大学一覧とは別枠に扱う。[文部省：東京大学の創設](https://www.mext.go.jp/b_menu/hakusho/html/others/detail/1317599.htm)

## 年ごとの差分：内地

### 1881〜1918年：帝国大学の展開

| 年 | 大学一覧の差分 |
| --- | --- |
| 1886 | 東京大学 → **帝国大学**。工部大学校を統合 |
| 1897 | ＋ **京都帝国大学**／帝国大学 → **東京帝国大学** |
| 1907 | ＋ **東北帝国大学** |
| 1911 | ＋ **九州帝国大学** |
| 1918 | ＋ **北海道帝国大学**〔東北帝国大学農科大学が独立〕 |

出典：[文部省：帝国大学の発足と拡充](https://www.mext.go.jp/b_menu/hakusho/html/others/detail/1317632.htm)、[文部省：大学令の制定と大学の拡張](https://www.mext.go.jp/b_menu/hakusho/html/others/detail/1317663.htm)。

1918年公布・1919年施行の[[大学令]]により、官立の単科大学、公立大学、私立大学も制度上の大学として設置できるようになった。

| 年 | 大学一覧の差分 |
| --- | --- |

| 1920 | ＋ **慶應義塾大学、早稲田大学、東京商科大学、明治大学、法政大学、中央大学、日本大学、國學院大學、同志社大学、愛知医科大学**〔愛知医科大学は現在の同名大学とは別系統〕 |
| 1921 | ＋ **東京慈恵会医科大学、京都府立医科大学** |
| 1922 | ＋ **新潟医科大学、岡山医科大学、龍谷大学、大谷大学、熊本医科大学、専修大学、立教大学、立命館大学、関西大学、東洋協会大学** |
| 1923 | ＋ **千葉医科大学、金沢医科大学、長崎医科大学** |
| 1924 | ＋ **立正大学** |
| 1925 | ＋ **駒澤大学、東京農業大学** |
| 1926 | ＋ **日本医科大学、高野山大学、大正大学**／東洋協会大学 → **拓殖大学** |
| 1928 | ＋ **大阪商科大学、東洋大学、上智大学** |
| 1929 | ＋ **東京工業大学、大阪工業大学、東京文理科大学、広島文理科大学、神戸商業大学**〔大阪工業大学は現在の同名大学とは別系統〕。熊本医科大学が県立から官立へ |
| 1931 | 大阪医科大学 → **大阪帝国大学**〔官立へ移管・改組〕／愛知医科大学 → **名古屋医科大学**〔官立へ移管〕 |

| 1933 | 大阪工業大学 → **大阪帝国大学に統合** |

出典：[文部省：大学令の制定と大学の拡張](https://www.mext.go.jp/b_menu/hakusho/html/others/detail/1317663.htm)、[旧制大学：設置の歴史](https://ja.wikipedia.org/wiki/旧制大学)、[拓殖大学：沿革](https://www.takushoku-u.ac.jp/summary/history.html)。

### 1934〜1945年：戦時期の新設と再編

| 年 | 大学一覧の差分 |
| --- | --- |
| 1939 | ＋ **藤原工業大学**／名古屋医科大学 → **名古屋帝国大学**〔改組〕 |
| 1940 | ＋ **神宮皇學館大学** |
| 1942 | ＋ **興亜工業大学**〔現在の千葉工業大学〕 |

## 海外にあった大学の差分

以下には植民地の大学のほか、中国の租借地・日本の勢力下などにあった大学を含む。すべてを同一の領域・設置主体に属する大学として扱うものではない。

| 年 | 大学一覧の差分 |
| --- | --- |
| 1922 | ＋ **旅順工科大学、満洲医科大学** |
| 1924 | ＋ **京城帝国大学** |
| 1928 | ＋ **台北帝国大学** |
| 1939 | ＋ **東亜同文書院大学** |
| 1945 | 敗戦により、日本側の大学一覧からの離脱・接収・閉鎖が発生。個々の学校の法的廃止日や後継校の成立日とは区別する |

出典：[旧制大学：設置の歴史](https://ja.wikipedia.org/wiki/旧制大学)。1945年の行は終戦に伴う状況の要約であり、一律の廃止日を示すものではない。

## 校名と制度上の資格を区別する

大学の歴史には、前身校の創立、校名への「大学」の採用、大学令による昇格、新制大学への移行という異なる節目がある。

| 学校 | この一覧で追加する年 | 注意点 |
| --- | --- | --- |
| 早稲田大学 | 1920 | 1902年に東京専門学校から改称したが、大学令による昇格は1920年 |
| 立教大学 | 1922 | 1907年にも「立教大学」を称したが、当時は専門学校令による学校 |
| 日本女子大学校・東京女子大学 | 対象期間の一覧には含めない | 戦前は専門学校。校名に「大学」があっても大学令による大学ではない |
