# フランス第三共和政

フランス語：Troisième République。期間：**1870〜1940年**。

普仏戦争中に第二帝政が倒れた後、1870年に成立した共和政。議会政治を定着させたが、1940年の対独敗戦を背景に崩壊した。

## 主な出来事

| 年 | 出来事 |
| --- | --- |
| 1870年 | セダンでの敗北とナポレオン3世の捕虜化を経て、9月4日に共和政を宣言。 |
| 1871年 | パリ＝コミューン成立と鎮圧。第三共和政の政府とは別の革命的自治政権。 |
| 1875年 | 憲法的法律により、大統領と二院制を持つ制度を整備。 |
| 1890年代以降 | ドレフュス事件が政治・社会の対立を深める。 |
| 1905年 | 政教分離法。 |
| 1936年 | 人民戦線内閣。 |
| 1940年 | 対独敗戦。7月10日、議会がペタンに憲法制定の全権を委ね、ヴィシー体制へ。 |

## 政治の特徴

大統領は存在するが、政治運営では議会と内閣が大きな役割を果たした。共和政の開始は1870年、制度を固めた憲法的法律は1875年と区別する。

第三共和政の崩壊後、ヴィシー体制・自由フランスなどの戦争期と臨時政府期を経て、1946年に[[フランス第四共和政]]が成立する。
