# 南北基本合意書

**韓国と北朝鮮が、互いの体制を尊重し、武力を使わず、交流・協力を進めると約束した合意。** 1991年12月13日に署名され、1992年2月19日に発効した。正式名称は「南北間の和解と不可侵および交流・協力に関する合意書」。［1・2］

## いつ・誰が結んだ？

| 項目 | 内容 |
| --- | --- |
| 署名 | 1991年12月13日、ソウルでの第5回南北首相会談 |
| 発効 | 1992年2月19日、平壌での第6回会談 |
| 韓国側の署名者 | 国務総理の鄭元植（チョン・ウォンシク） |
| 北朝鮮側の署名者 | 政務院総理の延亨黙（ヨン・ヒョンムク） |
| 当時の最高指導者 | 韓国は盧泰愚大統領、北朝鮮は金日成主席 |
| 構成 | 前文と4章25条 |

**盧泰愚政権期の成果だが、大統領同士の首脳会談で署名した文書ではない。** 交渉と署名は首相級会談で行われた。［1〜3］

## 主な内容

| 柱 | 約束したこと | 該当条文 |
| --- | --- | --- |
| 和解 | 相手の体制を尊重し、内政干渉や体制転覆をしない。平和状態の実現に努め、それまでは休戦協定を守る。 | 第1〜8条 |
| 不可侵 | 相互に武力を使わず、紛争は対話で解決する。軍事的な信頼醸成や軍縮を協議し、偶発的衝突を防ぐ直通電話などを設ける。 | 第9〜14条 |
| 交流・協力 | 経済・文化などの交流、離散家族の再会、鉄道・道路の接続などを進める。 | 第15〜23条 |
| 修正・発効 | 双方の合意による修正と、発効の手続きを定める。 | 第24〜25条 |

これらは文書に盛り込まれた約束であり、署名と同時にすべて実現したわけではない。［1・3］

## 成立した背景と意義

冷戦終結期に、韓国は盧泰愚政権の北方外交を進めていた。南北は1990年9月から首相会談を重ね、1991年9月には国連へ同時加盟した。その流れの中で、政治・軍事・経済・人道を含む包括的な関係改善の枠組みに合意した。日本の外務省も当時、朝鮮半島の平和と安定に向けた画期的な出来事と評価した。［2］

前文では南北の関係を、通常の国家間関係ではなく、**統一を目指す途中で暫定的に形成された特殊な関係**と位置付けた。「互いの体制を尊重すること」と「互いを外国として正式に国家承認すること」を同じ意味で読むと、この位置付けを見落とす。［1・3］

## 朝鮮戦争はこれで終わった？

**この合意書によって朝鮮戦争を正式に終結させたわけではない。** 第5条は、平和状態への転換に向けて努力し、それまでは既存の休戦協定を守ると定めた。つまり、平和に向けた枠組みをつくった文書であり、休戦協定を置き換える平和条約ではない。［1］

## その後はどうなった？

1992年には履行のための協議が進んだが、核査察や米韓合同軍事演習などをめぐって対立した。1993年3月には北朝鮮が核拡散防止条約（NPT）からの脱退を表明し、南北対話も停滞した。**合意の成立と、合意を継続して履行できることは別の問題だった。**［3］

ここでは成立と初期の履行過程を扱っている。その後の南北関係や、現在の法的な効力については、この経緯だけから判断しない。

## 混同しやすい合意

| 文書 | 時期 | 区別する点 |
| --- | --- | --- |
| 南北共同声明（7・4共同声明） | 1972年7月4日 | 自主・平和・民族大団結という統一原則を示した。基本合意書の前文でも再確認された。［1］ |
| **南北基本合意書** | **1991年署名・1992年発効** | 和解・不可侵・交流協力の包括的な枠組み。 |
| 朝鮮半島の非核化に関する共同宣言 | 1992年2月19日発効 | 核兵器などを扱う別文書。基本合意書と同じ日に発効した。［2・4］ |
| 南北共同宣言（6・15共同宣言） | 2000年6月15日 | 金大中と金正日の初の南北首脳会談による宣言。1991年の首相級合意とは別。［5］ |

覚え方：**盧泰愚の時代に、首相級で「和解・不可侵・交流協力」を約束。署名は1991年、発効は1992年。**
