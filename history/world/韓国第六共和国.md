# 韓国第六共和国

期間：**1988〜**。

1987年の民主化・改憲を受け、1988年2月25日の新憲法施行と盧泰愚の大統領就任によって発足した共和国。大統領の直接選挙と任期5年・単任制を柱とする。

## 主な出来事・制度

| 年・項目 | 内容 |
| --- | --- |
| 1987年6月 | 六月民主抗争と6・29宣言。 |
| 1987年10月 | 新憲法を公布。 |
| 1987年12月 | 大統領直接選挙で盧泰愚が当選。 |
| 1988年2月25日 | 新憲法施行。盧泰愚が第13代大統領に就任。 |
| 1993年 | 金泳三が就任。軍出身ではない大統領による文民政権へ。 |
| 1998年 | 野党出身の金大中が就任。選挙を通じた与野党間の政権交代。 |

## 区分のポイント

民主化・改憲の年を基準に「1987年〜」とする資料もあるが、このページでは新憲法施行・政府発足の1988年を採る。

大統領が交代するたびに共和国の番号が増えるわけではない。大統領の代数と共和国の番号は別で、盧泰愚は「第13代大統領」かつ「第六共和国の初代大統領」。憲法上、国民の直接選挙で選ばれる大統領と、国会の同意を得て任命される首相が存在する。
