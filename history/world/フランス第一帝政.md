# フランス第一帝政

フランス語：Premier Empire。期間：**1804〜1814年、1815年**。

ナポレオン1世による帝政。1804〜1814年と、1815年の百日天下を指す。1814〜1815年の間にはブルボン朝の王政復古による中断がある。

## 主な出来事

| 年 | 出来事 |
| --- | --- |
| 1804年 | 5月18日に帝政を成立させ、12月2日に戴冠式を挙行。 |
| 1805年 | トラファルガー海戦で敗北、アウステルリッツの戦いでは勝利。 |
| 1806年 | 大陸封鎖令。 |
| 1812年 | ロシア遠征の失敗。 |
| 1813年 | ライプツィヒの戦いで敗北。 |
| 1814年 | 退位し、エルバ島へ。ブルボン朝の王政復古。 |
| 1815年 | 復帰して百日天下。ワーテルローで敗北し、再び退位。 |

## 政治の特徴

皇帝に権力を集中させ、国民投票による承認も用いた。革命期の社会変革や統領政府期の行政制度を引き継ぎながら、戦争を通じてヨーロッパへの支配を拡大した。

ナポレオン法典の制定は1804年だが、帝政成立前の統領政府期の事業。1815年の後は[[フランス第二共和政]]へ直行せず、復古王政・七月王政を挟む。
