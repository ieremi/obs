# フランスの共和政・帝政の変遷

フランスの共和政は第一〜第五、ナポレオン家の帝政は第一・第二と数える。番号はそれぞれ別で、間に王政や戦争期の体制を挟む。

## 年代と個別ページ

| 政体 | 期間 | 成立の契機 | 終焉・移行の契機 |
| --- | --- | --- | --- |
| [[フランス第一共和政]] | 1792〜1804年 | フランス革命中の王政廃止 | ナポレオンの皇帝就任 |
| [[フランス第一帝政]] | 1804〜1814年、1815年 | ナポレオン1世による帝政 | 対仏大同盟との戦争に敗北、王政復古 |
| [[フランス第二共和政]] | 1848〜1852年 | 二月革命 | ルイ＝ナポレオンのクーデタと帝政復活 |
| [[フランス第二帝政]] | 1852〜1870年 | ナポレオン3世の即位 | 普仏戦争中の敗北と共和政宣言 |
| [[フランス第三共和政]] | 1870〜1940年 | 第二帝政の崩壊 | 第二次世界大戦中の対独敗戦、ヴィシー体制へ |
| [[フランス第四共和政]] | 1946〜1958年 | 戦後の新憲法 | アルジェリア戦争を背景とする政治危機 |
| [[フランス第五共和政]] | 1958年〜 | ド＝ゴール復帰と新憲法 | — |

第一共和政は統領政府期も含む区分、第二共和政は帝政成立まで含む区分。1799年・1851年のクーデタで区切る政治史の整理もあるので、資料の区分を確認する。

## 間に入る体制も含めた順序

1. 革命前の王政 → 革命期の立憲王政。
2. **第一共和政**：国民公会 → 総裁政府 → 統領政府。
3. **第一帝政** → 1814年の第一次王政復古 → 1815年の百日天下 → 第二次王政復古。
4. 復古王政 → 1830年の七月革命 → 七月王政。
5. 1848年の二月革命 → **第二共和政** → **第二帝政**。
6. 1870年の帝政崩壊 → **第三共和政**。
7. 1940年以後のヴィシー体制・自由フランスなどの戦争期 → 解放と共和国臨時政府。
8. **第四共和政** → **第五共和政**。

戦争期には、フランスの正統な国家権力をめぐる対立がある。ヴィシー体制から第四共和政へ、一つの政府がそのまま制度変更したと捉えない。

## 混同しやすい年と番号

| 区別 | 要点 |
| --- | --- |
| 1789年と1792年 | 革命開始と第一共和政成立は別。 |
| 1799年と1804年 | ナポレオンのクーデタは統領政府の開始。帝政は1804年から。 |
| 1851年と1852年 | ルイ＝ナポレオンのクーデタの翌年に第二帝政が成立。 |
| ナポレオン1世と3世 | 第一帝政は1世、第二帝政は3世。「第二帝政＝ナポレオン2世」ではない。 |
| 1870年と1875年 | 第三共和政の開始と、憲法的法律による制度整備は別。 |
| 1944年と1946年 | 解放・臨時政府と、第四共和政の憲法成立は別。 |
| 1958年と1962年 | 第五共和政の成立と、大統領直接普通選挙の導入は別。 |
