# フランス第一共和政

フランス語：Première République。期間：**1792〜1804年**。

フランス革命の過程で成立した、フランス最初の共和政。1792年の王政廃止から1804年の帝政成立までを指す。

## 成立と変遷

| 時期 | 政治の中心・出来事 |
| --- | --- |
| 1792年9月 | 国民公会が21日に王政を廃止。翌22日が共和暦の起点となる。 |
| 1793〜1794年 | ジャコバン派の台頭と恐怖政治。1794年のテルミドールの政変でロベスピエールが失脚。 |
| 1795〜1799年 | 総裁政府。政治の不安定化と軍人の影響力拡大。 |
| 1799〜1804年 | ブリュメール18日のクーデタ後の統領政府。ナポレオンが権力を集中。 |
| 1804年 | ナポレオンの皇帝就任で[[フランス第一帝政]]へ。 |

1799年に議会政治は大きく後退するが、政体の年代区分では統領政府期まで第一共和政に含める。革命が始まった1789年にはまだ王政であり、革命開始と共和政成立は同年ではない。
