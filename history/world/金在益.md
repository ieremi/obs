# 金在益

**金在益（キム・ジェイク、김재익、1938〜1983年）**は、韓国の経済官僚・経済学者。全斗煥政権の大統領府経済首席秘書官として、1980年代初めの経済安定化や市場機能を重視する改革を推進した。[[韓国第五共和国]]の経済政策を考えるうえで重要な人物。[人物紹介](https://97imf.kr/items/show/1004)、[研究論文の概要](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART003175515)

## 経歴

| 時期 | 内容 |
| --- | --- |
| 1938年 | 生まれる。 |
| 経済官僚として | 韓国銀行、経済企画院などで勤務。米国留学で経済学を学ぶ。 |
| 1980年 | 全斗煥政権の経済首席秘書官となる。 |
| 1983年10月9日 | 大統領のビルマ（現ミャンマー）訪問に同行中、ラングーン（現ヤンゴン）のアウンサン廟爆破事件で死亡。 |

経歴は[1997外換危機アーカイブの人物紹介](https://97imf.kr/items/show/1004)、死亡日と事件は[韓国国史編纂委員会の年表](https://db.history.go.kr/id/tcct_1983_10_09_0010)による。

## 経済政策の考え方

研究では、金在益の経済哲学は**「安定・自律・開放」**と整理される。成長の量だけでなく、物価の安定や経済の質的な改善を重視した。[金承会・尹泳浩「経済首席金在益の生涯と企業家精神」概要](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART003175515)

| 考え方 | 意味 |
| --- | --- |
| 安定 | インフレの抑制を重視し、財政支出も点検する。 |
| 自律 | 政府の指示だけに頼らず、市場での競争や企業の判断が働く余地を広げる。 |
| 開放 | 輸入自由化などを通じ、国内経済と国際市場のつながりを強める。 |

ゼロベース予算による支出の見直しや、情報・通信分野の発展に関わる政策でも知られる。ゼロベース予算は、前年の予算額を当然の出発点とせず、事業の必要性や優先順位を改めて検討する考え方。[研究論文の概要](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART003175515)、[人物紹介](https://97imf.kr/items/show/1004)

## 金融実名制との関係

金在益は、金融取引を実名で行わせる**金融実名制の構想・推進に関わった人物**として挙げられる。ただし、本人の在任中に全面実施されたわけではない。[人物紹介](https://97imf.kr/items/show/1004)

1982年に実施方針が発表されたものの、反対や懸念によって実施は先送りされた。全面実施は、金在益の死後、金泳三政権による**1993年8月12日**の緊急財政経済命令で実現した。構想への関与と、制度が実際に動き始めた時期を分けて覚える。[韓国財政当局の用語解説](https://mofe.go.kr/sisa/dictionary/detail?idx=678)、[韓国国家記録院：1993年の命令](https://theme.archives.go.kr/next/chronology/archiveDetail.do?evntId=0050754025&flag=1&page=28&sort=year)

## アウンサン廟爆破事件

1983年10月9日、北朝鮮工作員が全斗煥を標的としてアウンサン廟で爆弾を爆発させた。金在益を含む韓国の閣僚・随行員らが犠牲となった。全斗煥は難を逃れ、訪問日程を打ち切って帰国した。[韓国外務省外交史料館](https://diplomaticarchives.mofa.go.kr/new/show/age_list.jsp?tagoption=5)、[国史編纂委員会の年表](https://db.history.go.kr/id/tcct_1983_10_09_0010)

## 評価を考えるときの観点

以下は人物・政策を比較するための整理。

- 経済政策の評価では、構想した政策、実施された政策、その後の結果を分けて見る。
- 物価安定や成長を、一人の官僚だけの成果とせず、他の政策担当者や国際経済環境も確かめる。
- 経済運営への評価と、全斗煥政権の権威主義・人権侵害への評価は、それぞれ検討する。
