# 韓国第五共和国

期間：**1981〜1988年**。

1980年の改憲を基礎として、1981年に新体制の政府が発足した共和国。全斗煥を中心とする権威主義体制が続き、1987年の民主化運動と改憲によって第六共和国への移行が決まった。

## 主な出来事・制度

| 年・項目 | 内容 |
| --- | --- |
| 1980年 | 光州民主化運動を弾圧。全斗煥が旧制度で大統領に就任し、10月に改憲。 |
| 1981年 | 大統領選挙人団が全斗煥を第12代大統領に選出。第五共和国の政府発足。 |
| 制度 | 大統領は間接選挙、任期7年・単任制。 |
| 1987年6月 | 六月民主抗争。6月29日の宣言で大統領直接選挙などを受け入れる。 |
| 1987年10月 | 新憲法を公布。 |
| 1988年2月25日 | 新憲法施行と盧泰愚の大統領就任により[[韓国第六共和国]]へ。 |

## 区分のポイント

このページは政府発足を基準に1981〜1988年とする。憲法改正の年で1980年から、民主化の年で1987年までとする資料もある。

任期制限が設けられていても、選挙が間接選挙で政治的自由が制限された体制だった。1987年に直接選挙を導入する改憲が行われるまで、民主的な直接選挙による政権交代は実現していない。
