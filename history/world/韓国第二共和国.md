# 韓国第二共和国

期間：**1960〜1961年**。

四月革命後の改憲によって成立した、議院内閣制の共和国。大統領は尹潽善（ユン＝ボソン）、行政の中心を担った首相は張勉（チャン＝ミョン）。

## 主な出来事・制度

| 年・項目 | 内容 |
| --- | --- |
| 1960年6月 | 改憲で議院内閣制と二院制を採用。 |
| 1960年8月 | 尹潽善を大統領に選出し、張勉内閣が成立。 |
| 1961年5月16日 | 朴正熙らの軍事クーデタで政府が倒れる。 |

## 区分のポイント

大統領と首相の役割を区別する。李承晩の大統領制から、張勉内閣を中心とする制度へ変わった。

1961〜1963年には国家再建最高会議を中心とする軍政を挟み、1963年に[[韓国第三共和国]]が発足する。クーデタ直後から第三共和国になったわけではない。
