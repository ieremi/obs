# フランス第二帝政

フランス語：Second Empire。期間：**1852〜1870年**。

ナポレオン3世による帝政。第二共和政の大統領ルイ＝ナポレオンが、1851年のクーデタと1852年の帝政復活を経て皇帝となった。

## 主な出来事

| 年 | 出来事 |
| --- | --- |
| 1852年 | 12月2日、ナポレオン3世として即位。 |
| 1853〜1856年 | クリミア戦争に参加。 |
| 1850年代以降 | オスマンによるパリ改造。鉄道・金融・産業が発展。 |
| 1859年 | イタリア統一戦争でサルデーニャ王国を支援し、オーストリアと戦う。 |
| 1860年代 | メキシコ干渉の失敗。国内では議会・言論への統制を緩める方向へ。 |
| 1870年 | 普仏戦争。セダンで皇帝が捕虜となり、9月4日に[[フランス第三共和政]]が宣言される。 |

## 政治の特徴

初期は皇帝による権威主義的統治が強く、後期には自由化が進んだ。工業化と都市改造を進める一方、対外政策の行き詰まりが体制を揺るがした。

ナポレオン1世の第一帝政と区別する。ナポレオン3世は1世の甥であり、第二帝政の「第二」と皇帝名の「3世」は別の番号。
