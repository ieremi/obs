# トルキスタン

**中央アジアの、パミール高原をはさんだ東西の地域。** ペルシア語で「**トルコ人の土地**」という意味。もとはイラン系の人びとの土地だったが、**9〜10 世紀ごろから、トルコ系の人びとが住みつき、トルコ化した** ので、この名がついた。

| | 西トルキスタン | 東トルキスタン |
| --- | --- | --- |
| 場所 | パミール高原の **西**。アム川・シル川の流域 | パミール高原の **東**。**タリム盆地** |
| いまの国 | ウズベキスタン・トルクメニスタン・タジキスタン・キルギス・カザフスタン南部 | **中国の新疆ウイグル自治区** |
| 主なオアシス都市 | **サマルカンド**・**ブハラ**・タシュケント・メルヴ | **カシュガル**・ホータン・クチャ・トルファン・敦煌（の西） |
| 古い呼び名 | ソグディアナ（アム川とシル川の間）、トランスオクシアナ、マー＝ワラー＝アンナフル（アラビア語で「川の向こう」） | 西域（中国から見て） |

- 点線（太め）：**オアシスの道**。メルヴ → ブハラ → サマルカンド → カシュガル から、**天山山脈の南のふち（クチャ・トルファン）を通る道** と、**崑崙山脈の北のふち（ホータン）を通る道** に分かれて、敦煌で合わさる
- 縦の点線：**パミール高原**。ここより西が西トルキスタン、東が東トルキスタン
- 位置はおおよそ（東経・北緯をそのまま縦横にした略図）。海・湖・川の形はおおまかで、アラル海はいまより大きかったころの形

- 雨が少なく、**砂漠と草原のあいだに、川や雪どけ水でできたオアシス** が点々とある。オアシスに **都市** ができ、その間を **隊商** が行き来した

## なぜ重要か

### 1. 東西を結ぶ交通路のまんなか（オアシスの道）
- 中国と、イラン・地中海を結ぶ **オアシスの道**（いわゆる **シルクロード**）は、ここを通る。**絹** が西へ、**銀・ガラス・馬** が東へ運ばれた
- 交易をになったのは、**ソグド人**（サマルカンドを中心とするイラン系の商人）。唐の長安にも多く住み、**安史の乱** の安禄山もソグド系とされる
- 交易の利益は大きいので、**まわりの大国が、ここを取りあった**

### 2. 遊牧民とオアシスの民が出会う場所
- 北の **草原の遊牧国家**（匈奴・突厥・ウイグル・モンゴル）は、オアシス都市を **保護し、税を取り、商人と組んだ**。遊牧の軍事力とオアシスの経済力が結びつくと、大きな帝国ができる
- 中国の王朝も、遊牧民をおさえ、交易路をにぎるために、ここへ進んだ：漢（**張騫** の派遣、**西域都護**）、唐（**安西都護府**）、清（**新疆**）

### 3. 宗教と文化の通り道
- **仏教** は、インドからここを通って中国へ伝わった（クシャーナ朝 → タリム盆地 → 中国）。クチャ出身の **鳩摩羅什**、インドへ行った **玄奘** もこの道を通った
- **ゾロアスター教**・**マニ教**・**ネストリウス派キリスト教**（→ [[ネストリウス派]]）も、ソグド人などを通じて東へ伝わった
- のちに **イスラーム** が広まり、ブハラ・サマルカンドは **イスラームの学問の中心** の一つになった
- **紙** の製法が西へ伝わったのも、ここ（**タラス河畔の戦い**、751 年、とされる）

### 4. 歴史の大きな転換が、ここで起きた
| 時代 | できごと | 意味 |
| --- | --- | --- |
| 前 2 世紀 | 漢の **張騫** の派遣、匈奴との争い | 中国が西方とつながる |
| 7〜8 世紀 | 唐の進出、**アラブ（イスラーム）** の進出 | **751 年、タラス河畔の戦い**。唐とアッバース朝がぶつかる。以後、西トルキスタンはイスラーム世界へ |
| 9〜10 世紀 | **ウイグル** の西への移動、**サーマーン朝**（イラン系）、**カラハン朝**（トルコ系で初めてイスラームを受けいれた王朝の一つ） | **トルコ化とイスラーム化**。「トルキスタン」が生まれる |
| 10〜11 世紀 | トルコ人の **マムルーク**（奴隷の軍人）、**セルジューク朝** の西への進出 | トルコ人が西アジアの主役になる（→ 十字軍） |
| 12 世紀 | **西遼**（カラ＝キタイ。遼の皇族が西へ移って建てた） | 中国の王朝の流れの国が、中央アジアを支配 |
| 13 世紀 | **モンゴル** の征服、チャガタイ＝ハン国 | ユーラシア全体がつながる（→ [[モンゴル帝国]]） |
| 14〜15 世紀 | **ティムール朝**（都サマルカンド） | トルコ＝イスラーム文化の黄金期（ウルグ＝ベクの天文台など） |
| 16 世紀 | **ウズベク**（ブハラ＝ハン国など）、**ムガル帝国** を建てたバーブルはここの出身 | ここで負けた勢力が南のインドに帝国を建てた |
| 18 世紀 | **清** がジュンガルを滅ぼし、東トルキスタンを **新疆**（「新しい領土」）とした | 東は中国の一部に |
| 19 世紀 | **ロシア** が西トルキスタンを征服（ブハラ＝ハン国・ヒヴァ＝ハン国の保護国化、コーカンド＝ハン国の併合）。**イリ事件**（ロシアと清） | **英露の「グレート＝ゲーム」**。インドを守るイギリスと、南へ進むロシアの対立 |
| 20 世紀 | ソ連の **民族境界画定**（1924 年ごろ）で 5 つの共和国に。1991 年に独立 | いまの中央アジアの国境ができる |

- **ここで勝った勢力・負けた勢力が、まわりの地域（中国・インド・西アジア）の歴史を動かした**。トルキスタンは「辺境」ではなく、**ユーラシアの歴史の「ちょうつがい」** にあたる

### 5. いまも重要
- **資源**：石油・天然ガス・ウラン、綿花（ソ連時代の綿花の単一栽培で、**アラル海** が縮んだ）
- **中国の「一帯一路」**：中国とヨーロッパを結ぶ陸路が、ふたたびここを通る
- **新疆ウイグル自治区** の、ウイグル人などの人権をめぐる問題
- ロシア・中国・アメリカ・イラン・トルコなどの影響力がぶつかる

## 入試での重要さ
- 東大の 2022 年度の大論述は、「**8 世紀から 19 世紀までのトルキスタンの歴史的展開**」（600 字）だった（→ [[東京大学世界史 大論述のテーマと字数（2007〜2026）]]）。2015 年度の「モンゴル時代の交流」、2014 年度の「ロシアの対外政策」も、ここと深くかかわる
- 教科書では、中国史・イスラーム史・ロシア史の **それぞれの章にばらばらに** 出てくるので、**一つの地域として通して整理** しておくと強い。上の表がその形
- 頻出の用語：ソグド人、タラス河畔の戦い、サーマーン朝、カラハン朝、西遼、チャガタイ＝ハン国、ティムール朝、ウズベク、ジュンガル、新疆、イリ条約、グレート＝ゲーム

## 押さえどころ
- トルキスタン＝「**トルコ人の土地**」。パミール高原の西（いまの中央アジアの 5 か国）と東（新疆）
- 重要なわけ：① **東西の交易路のまんなか**、② **遊牧民とオアシスの民の出会う場所**、③ **宗教と文化の通り道**、④ **トルコ化・イスラーム化** の舞台で、ここの勢力の動きがまわりの地域の歴史を動かした、⑤ いまも資源・一帯一路・民族問題で重要
- 大きな流れ：**イラン系の土地 → トルコ化・イスラーム化（9〜10 世紀）→ モンゴル・ティムール → 西はロシア、東は清（18〜19 世紀）→ ソ連と中国**
