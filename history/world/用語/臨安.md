# 臨安

**南宋の都。いまの浙江省の杭州。** 1129 年に杭州を **臨安府** とし、1138 年からここに朝廷を置いた。1276 年に **モンゴル（元）** に占領されるまで、約 150 年間、南宋の政治の中心だった。人口は 100 万人をこえたとされ、当時の **世界でいちばん大きな都市の一つ**。

| 項目 | 内容 |
| --- | --- |
| いまの名前 | **杭州**（浙江省の省都） |
| 臨安府 | **1129 年** に置かれる |
| 都として | **1138 年** から（高宗）。正式には「**行在**」（皇帝が一時的にいる所）とよばれた |
| 終わり | **1276 年**、元のバヤンの軍に占領される |
| 位置 | **大運河の南の端**。銭塘江の河口、**西湖** のほとり |
| 人口 | 1276 年には 100 万人をこえた、とされる |

## 都になるまで
- **1127 年**、**靖康の変** で、金が北宋の都 **開封** を落とし、徽宗と欽宗を連れ去った（北宋の滅亡）
- 欽宗の弟の **高宗** が南へのがれて宋を再建した（**南宋**）。金の軍に追われ、各地を転々とした
- 1129 年に杭州を臨安府とし、1138 年からここを落ちつき先とした
- 「臨安」は「**一時的に安んずる**」という意味をふくむ名。南宋は、**開封をとりもどすまでの仮の都** という建前をとり、臨安を「**行在**」「行都」とよびつづけた
- 1142 年、金と **紹興の和議**（淮河を国境に、南宋は金に臣下の礼をとり、銀・絹を贈る）。以後、臨安が事実上の都として定まった

## なぜ栄えたか
- **江南の経済の中心**：宋代に江南の開発が進み、「蘇湖熟すれば天下足る」といわれた（→ [[宋代の経済発展]]、[[論述例題2（宋代の経済発展）]]）。臨安はその中心にある
- **大運河の南の端**：北の物流とつながる。南宋のときは国境（淮河）で切れていたが、江南の中の水運の要だった
- **海との近さ**：近くの **明州**（寧波）や **泉州**・**広州** の **市舶司** を通じた海上交易で、財政がうるおった。南宋は **海上交易の利益** に大きく頼った国家だった
- **都市の文化**：城壁の中に **瓦子**（盛り場）があり、雑劇・講談（説話）・人形劇などの **庶民の娯楽** がさかんだった。茶館・酒楼・夜市が栄え、唐までの「市」と「坊」の区切りの規則はもうなかった

## 記録と旅行者
- 南宋の終わりごろの臨安の暮らしは、**『夢粱録』**（呉自牧）や **『武林旧事』**（周密）にくわしく書かれている。「武林」は杭州の別名
- **マルコ＝ポーロ** は、元の時代の杭州を「**キンサイ**」（Quinsay。「**行在**」がなまったもの）とよび、「**世界でいちばん豪華で美しい都市**」と書いた
- イブン＝バットゥータも、元の時代の杭州（ハンサー）について書いている

## 終わり
- 1274 年、フビライの命令で **バヤン** が南宋を攻め、1276 年に臨安を占領した。幼い **恭帝** と、太皇太后 **謝氏** が降伏した
- そのあとも、一部の臣下（**文天祥**・**陸秀夫** ら）が幼い皇族を立てて抵抗したが、**1279 年、崖山の戦い** で南宋は完全に滅んだ
- 臨安は元のもとでも、江南の大都市として栄えつづけた（→ [[元]]）

## 入試での出方
- 「南宋の都」として、**臨安** を書かせる・選ばせる。**北宋の開封** との区別が定番
- **開封**（北宋）→ **臨安**（南宋）→ **大都**（元）→ **南京** から **北京** へ（明）の、都の移り変わりの中で問う
- マルコ＝ポーロの「キンサイ」、**大運河** の南の端、**西湖**
- 「臨安」は、南宋の **金への対抗**（主戦派の **岳飛** と和平派の **秦檜**）の話とセットで出る

## 押さえどころ
- 臨安＝**南宋の都**＝いまの **杭州**。**1138 年** から都、**1276 年** に元が占領
- 建前は「**行在**」（仮の都）。北宋の都 **開封** をとりもどすつもりだった
- **江南の経済** と **海上交易** にささえられた、100 万人の大都市。庶民の文化（瓦子）がさかん
- マルコ＝ポーロは「**キンサイ**（行在）」とよんだ
