# ユーロ

## 1ユーロの価値はどのように決められたか

**導入時の1ユーロは、それ以前に使われていた欧州通貨単位「ECU（エキュ）」の1単位と同じ価値にすると決められた。** 1999年1月1日に、**1ユーロ＝1 ECU** で置き換えられた。[Eurostat：Euro/ECU exchange rates](https://ec.europa.eu/eurostat/cache/metadata/en/ert_bil_eur_esms.htm)

### 基準になったECUとは

ECUは、複数の欧州通貨を決められた数量ずつ組み合わせて価値を計算する「通貨バスケット」だった。たとえば構成通貨には、ドイツマルク0.6242、フランスフラン1.332、英ポンド0.08784などが含まれていた。これらを同じ通貨に換算して足すことで、1 ECUの価値を求められる。各国通貨を単純に1単位ずつ平均したものではない。[ECB：1998年5月2日の共同声明・付属文書](https://www.ecb.europa.eu/press/pr/date/1998/html/pr980502.en.html)

つまり、1ユーロの出発点には既存の計算単位があり、「1ドルにする」「各国の物価の平均で決める」と新しく設定したわけではなかった。

### 各国の旧通貨との交換比率

各国通貨を何単位で1ユーロに交換するかは、次の手順で確定した。

1. 参加通貨同士の比率は、欧州為替相場メカニズム（ERM）の中心相場を使う方針を事前に公表した。
2. 1998年12月31日、中央銀行が市場相場を確認し、参加通貨間の比率をその中心相場に整合させた。
3. その相場から最後の公式ECU換算率を計算し、欧州委員会の提案とECBへの諮問を経て、EU理事会がユーロへの固定換算率として採択した。1999年1月1日から発効した。

ECUには、当初ユーロに参加しなかった英国などの通貨も含まれていた。このため、参加通貨同士の比率を事前に示せても、最終的な「1ユーロ＝何マルク」などの数値は年末の計算を待つ必要があった。[ECB：共同声明](https://www.ecb.europa.eu/press/pr/date/1998/html/pr980502.en.html)、[ECB：換算率の決定](https://www.ecb.europa.eu/press/pr/date/1998/html/pr981231_2.en.html)

| 旧通貨 | 1ユーロに対する固定換算率 |
| --- | ---: |
| ドイツマルク | 1.95583マルク |
| フランスフラン | 6.55957フラン |
| イタリアリラ | 1936.27リラ |
| スペインペセタ | 166.386ペセタ |

出典：[ECB：1998年12月31日公表の換算率](https://www.ecb.europa.eu/press/pr/date/1998/html/pr981231_2.en.html)

たとえば195.583マルクは100ユーロになる。同じ比率で預金・賃金・価格を換算すれば、数字の大きさは変わっても、換算そのものによって買える量が増えるわけではない。

### 導入後の価値との違い

ここまでの話は、**新しい通貨の出発時の単位と旧通貨との換算率**の決め方である。旧通貨との比率を固定したことは、円やドルとの相場を永久に固定したという意味ではない。また、ECUのバスケットで導入後のユーロの価値を毎日計算し続ける制度でもない。導入後の対外的な為替相場と、物価に対する購買力は別の問題として考える必要がある。

ユーロへの移行それ自体でECUの対外価値を変えないという原則は、固定換算率を定めた規則にも明記されている。[EU理事会規則2866/98・前文第3項](https://eur-lex.europa.eu/legal-content/EN/ALL/?uri=CELEX%3A31998R2866)
