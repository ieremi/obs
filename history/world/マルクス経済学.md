# マルクス経済学

**マルクスの『[[資本論]]』をもとに、資本主義の経済を分析する経済学。** 略して「**マル経**」。いまの主流の経済学（新古典派、日本では「近代経済学」〈**近経**〉とよんだ）と並ぶ、もう一つの流れ。

- 大学では「**社会経済学**」「**政治経済学**」「**経済原論**」などの名前で教えられることが多い。「マルクス経済学」という名前の科目は少ない
- 主流の経済学が、市場を「人が合理的に選んで、つりあう場」とみるのに対し、マルクス経済学は、資本主義を **歴史の中で生まれ、いずれ変わる** 一つの社会のしくみとみて、そこでの **階級・搾取・恐慌** に注目する

## 主な考え方

| 考え方 | 内容 |
| --- | --- |
| **労働価値説** | 商品の価値は、それを作るのに社会的に必要な労働の量で決まる |
| **剰余価値** | 労働者は、賃金（労働力の価値）より多くの価値を生む。その差が **剰余価値** で、利潤・利子・地代のもとになる。これを資本家が受け取ることを **搾取** という |
| **商品の物神性**（物神崇拝）・**物象化** | 人と人との関係（だれがだれのために働くか）が、物と物の関係（商品の値段）のように見えてしまう |
| **資本の蓄積** | 資本は、剰余価値を資本に加えて大きくなりつづける |
| **産業予備軍** | 機械化などで、失業者（相対的過剰人口）が資本主義の中でくり返し作られる。賃金をおさえる働きをする |
| **利潤率の傾向的低下** | 機械などの割合（資本の **有機的構成**）が高まると、利潤率は下がる傾向をもつ |
| **恐慌** | 生産と消費のずれなどから、くり返し不況が起こる |
| **転形問題** | 価値（労働の量）が、実際の価格（**生産価格**）にどう変わるか。マルクス経済学の中心的な論争点の一つ |

## 日本のマルクス経済学
日本は、戦前から戦後にかけて、マルクス経済学が **世界でもとくに盛んな国** だった。東京大学・京都大学などの経済学部では、長く主流だった。

| 学派 | 考え方 | 代表的な人 |
| --- | --- | --- |
| **講座派** | 戦前の日本は、半封建的な天皇制の国。まず民主主義の革命が要る。『日本資本主義発達史講座』（1932〜33 年）から | 野呂栄太郎、山田盛太郎、平野義太郎 |
| **労農派** | 明治維新で日本はすでに資本主義の国。すぐに社会主義の革命をめざす。雑誌『労農』から | 山川均、猪俣津南雄、向坂逸郎、大内兵衛、有沢広巳 |
| **宇野学派** | 『資本論』を、純粋な資本主義の **原理論**、資本主義の発展段階の **段階論**、実際の各国の **現状分析** の 3 つに分けて読む | 宇野弘蔵、鈴木鴻一郎、伊藤誠 |
| 市民社会派 | マルクスを、市民社会の理論として読みなおす | 内田義彦、平田清明 |
| 数理マルクス経済学 | 数式を使ってマルクスの理論を厳密にする。**置塩の定理**、マルクスの基本定理 | 置塩信雄、森嶋通夫 |

- 戦後の経済政策にも関わった：**傾斜生産方式**（1946 年〜）は、労農派の有沢広巳の発案とされる
- 「日本資本主義論争」（講座派と労農派の論争）は、戦前の日本の思想史の大きなテーマ
- 冷戦が終わった 1990 年ごろから学ぶ学生が減り、多くの大学で主流の経済学に置きかわった。マルクス経済学の側は、「社会経済学」「政治経済学」に名前を変えたり、ほかの異端派（ポスト・ケインズ派、レギュラシオン学派など）と合わさったりしている
- 2020 年代には、**斎藤幸平**『人新世の「資本論」』（2020 年）が売れ、環境問題（**脱成長**）と結びつけてマルクスを読みなおす流れが話題になった

## ひとりで学ぶなら
- 入門：斎藤幸平『ゼロからの「資本論」』（NHK 出版新書、2023 年）。ZEN 大学の授業の参考書にもなっている
- 『資本論』の訳：岩波文庫（向坂逸郎訳）、新日本出版社（日本共産党中央委員会社会科学研究所監修）、筑摩書房（今村仁司ほか訳）など
- 目次は [[資本論]] のノートを参照

## 押さえどころ
- マルクス経済学は、『資本論』をもとに、資本主義を **歴史的な社会** として分析する。中心は **労働価値説・剰余価値・資本蓄積・恐慌**
- 日本では、**講座派・労農派・宇野学派** などが生まれ、戦後しばらく大学の主流だった
- いまは「**社会経済学**」「**政治経済学**」などの名前で教えられることが多い
- 2026 年に確かめられた学べるところ：**ZEN 大学**（斎藤幸平、ネット）、**立教大学**（佐々木隆治）、**京都大学**（社会経済学 I）、**東京経済大学 大学院**（政治経済学専修。一部は 2027 年度募集なし）など
