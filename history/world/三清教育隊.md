# 三清教育隊

三清教育隊（サムチョンきょういくたい、삼청교육대）は、**1980年に全斗煥らの新軍部が「社会悪一掃」を名目に、令状なしで市民を大量に検挙し、軍部隊内の施設に収容して暴力的な「純化教育」を行った事件・施設**。2022年、韓国の真実・和解のための過去事整理委員会（真実和解委）は、国家が違法な公権力を行使した**大規模人権侵害事件**と決定した。[YTN](https://www.ytn.co.kr/_ln/0103_202206091319247727)

名称は、計画を立てた国家保衛非常対策委員会（国保委）がソウルの三清洞にあったことに由来する。

## 概要

| 項目 | 内容 |
| --- | --- |
| 時期 | 1980年8月〜1981年1月（純化教育）。その後も勤労奉仕・保護監護が続いた |
| 主体 | 国家保衛非常対策委員会（委員長・全斗煥）、戒厳司令部、軍・警察 |
| 根拠 | 1980年8月4日の**戒厳布告第13号**（のちに裁判所が違法・無効と判断） |
| 検挙者 | 約6万755人（令状なし） |
| 純化教育の入所者 | 3万9742人。1980年8月4日〜1981年1月21日に11次にわたり全国の軍部隊で実施 |
| 死者 | 国の記録では54人。ほかに後遺症による死亡や多数の負傷者が報告されている |

数値の出典：[プレシアン](https://pressian.com/pages/articles/143627)、[ノーカットニュース](https://nocutnews.co.kr/news/211886)。

## 経緯

| 年月 | 出来事 |
| --- | --- |
| 1980年5月 | 新軍部が非常戒厳を全国に拡大。光州民主化運動を鎮圧し、国保委を設置 |
| 1980年8月 | 国保委が「社会悪一掃特別措置」を発表。戒厳布告第13号に基づき一斉検挙を開始 |
| 1980年8月〜1981年1月 | 検挙者を等級に分け、軍部隊で4週間程度の「純化教育」。殴打・過酷な訓練・虐待が横行 |
| 1980年12月 | 社会保護法の制定。教育後も「勤労奉仕」や「保護監護」の名目で拘束を延長された人がいた |
| 1988年 | 国会の国政監査で実態が問題化。国防部が死者数などを報告 |
| 2004年 | 「三清教育被害者の名誉回復及び補償に関する法律」制定。ただし補償対象は「負傷・死亡した者」に限定 |
| 2018年 | 大法院が戒厳布告第13号を違法・無効と判断 |
| 2022年6月 | 真実和解委が大規模人権侵害と決定。入所者全員を被害者と認定し、全員への賠償策などを政府に勧告 |
| 2024年7月 | ソウル中央地裁が被害者21人に計約17億6000万ウォンの賠償を命じる |
| 2025年9月 | 法務部が国家賠償訴訟での上訴を取り下げ・放棄する方針を決定 |

出典：[YTN](https://www.ytn.co.kr/_ln/0103_202206091319247727)、[ニューシス（2024-07-05）](https://mobile.newsis.com/view/NISX20240705_0002800474)、[京郷新聞](https://www.khan.co.kr/article/202209281639001)、[アジア経済（英語）](https://www.asiae.co.kr/en/article/2025092914464916928)。

## 論点

- **検挙の恣意性**：対象は「暴力犯・常習犯」などとされたが、警察に検挙数の割り当てがあったとされ、前科のない一般市民、学生、未成年者、労働運動の関係者なども含まれた。2026年には、未成年で連行された被害者への賠償を命じる判決も出ている。[ニューシス（2026-08-06）](https://www.newsis.com/view/NISX20260806_0003739496)
- **政治的目的**：国防部の過去事真相究明委員会は、新軍部の政権掌握の意図から生じた事件と結論づけた。社会の「浄化」を掲げて恐怖による統制と支持獲得を図ったと評価される。[ノーカットニュース](https://nocutnews.co.kr/news/211886)
- **被害者の範囲**：2004年の補償法は負傷・死亡者だけを対象にした。真実和解委は、強制入所そのものが人権侵害であり、入所者全員が被害者だとした。[YTN](https://www.ytn.co.kr/_ln/0103_202206091319247727)
- **刑務所での純化教育**：軍部隊だけでなく刑務所でも受刑者への「純化教育」が1987年ごろまで続いたことが、2025年に真実究明された。[ニューシス（2025-03-17）](https://www.newsis.com/view/NISX20250317_0003102235)
