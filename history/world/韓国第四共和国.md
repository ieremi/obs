# 韓国第四共和国

期間：**1972〜1981年**。

1972年の維新憲法によって成立した共和国。中心となるのは朴正熙の維新体制だが、1979年の暗殺後も、後継政権と第五共和国への移行期が続く。

## 主な出来事・制度

| 年・項目 | 内容 |
| --- | --- |
| 1972年 | 十月維新。12月27日に維新憲法を施行。 |
| 維新憲法下 | 統一主体国民会議による大統領間接選挙。大統領の権限を大きく強化し、長期支配を可能にする。 |
| 1979年10月26日 | 朴正熙が金載圭に暗殺される。崔圭夏が後継大統領となる。 |
| 1979年12月12日 | 全斗煥・盧泰愚らによる軍事反乱。新軍部が軍の主導権を掌握。 |
| 1980年5月 | 戒厳令の全国拡大と光州民主化運動の武力弾圧。 |
| 1980〜1981年 | 全斗煥の大統領就任、改憲、新制度による大統領選出を経て[[韓国第五共和国]]へ。 |

## 区分のポイント

期間は第五共和国の政府発足まで含めて1972〜1981年とする。朴正熙の維新支配の終焉を重視して1979年まで、1980年の改憲を境界にする整理もある。

全斗煥は1980年、旧憲法下で第11代大統領に就任した。全斗煥政権の開始と第五共和国の政府発足を同一の日付とはしない。事件と人物の関係は[[韓国現代史の人物相関図]]を参照。
