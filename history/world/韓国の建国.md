# 韓国の建国

1945年の日本の敗戦で朝鮮は植民地支配から解放されたが、北緯38度線を境に米ソが分割占領した。統一政府づくりが行き詰まり、国連監視下の選挙が南側だけで行われた結果、**1948年8月15日**に大韓民国政府が樹立された。北側では同年9月9日に朝鮮民主主義人民共和国が成立し、分断が固定化した。

## 年表

| 年月日 | 出来事 |
| --- | --- |
| 1919年4月 | 上海で**大韓民国臨時政府**が樹立。臨時憲章で国号「大韓民国」と民主共和制を掲げる。 |
| 1945年8月15日 | 日本の降伏により解放（光復）。呂運亨らが朝鮮建国準備委員会を組織。 |
| 1945年9月 | 建国準備委員会が朝鮮人民共和国を宣言。南に進駐した米軍は軍政（在朝鮮米陸軍司令部軍政庁）を敷き、これを政府として認めなかった。北はソ連軍が占領。 |
| 1945年12月 | モスクワ三国外相会議が、臨時政府の樹立と最長5年の信託統治を決定。賛託・反託をめぐり左右が激しく対立。 |
| 1946〜1947年 | 米ソ共同委員会が臨時政府の構成をめぐって決裂。 |
| 1947年11月 | 米国が朝鮮問題を国連に付託。国連総会が国連臨時朝鮮委員会（UNTCOK）の監視下での選挙を決議。ソ連は委員会の北への入域を拒否。 |
| 1948年2月 | 国連小総会が「委員会が入れる地域」での選挙実施を決定。 |
| 1948年4月 | 単独選挙に反対する済州島四・三事件が起こる。金九・金奎植は平壌での南北協商に参加し、統一政府を訴える。 |
| 1948年5月10日 | 南側で**制憲国会議員選挙**。朝鮮で初めての普通選挙。金九らは不参加。 |
| 1948年5月31日 | 制憲国会が開院し、李承晩を議長に選出。 |
| 1948年7月17日 | **大韓民国憲法**を公布（制憲節）。 |
| 1948年7月20日 | 国会の間接選挙で李承晩を大統領、李始栄を副大統領に選出。 |
| 1948年8月15日 | **大韓民国政府樹立**を宣布。米軍政が終了。 |
| 1948年9月9日 | 北で朝鮮民主主義人民共和国が成立。 |
| 1948年12月12日 | 国連総会決議195(III)が、大韓民国政府を「選挙が可能であった地域」に対し実効的支配を持つ合法政府と認める。 |

## 制憲憲法のしくみ

| 項目 | 内容 |
| --- | --- |
| 統治形態 | 大統領制を基本としつつ、国務総理を置く折衷型。 |
| 大統領の選出 | 国会による間接選挙。任期4年、1回に限り重任可。 |
| 国会 | 一院制。 |
| 前文 | 3・1運動で大韓民国を建立したとし、独立精神の継承を掲げる。 |

大統領の直接選挙は1952年の改憲から。以後の改憲と体制の移り変わりは[[韓国第一共和国]]・[[韓国の共和国の変遷]]を参照。

## 「建国」はいつか

韓国では、建国の時点をめぐって議論がある。

| 立場 | 根拠 | 論点 |
| --- | --- | --- |
| 1919年説 | 臨時政府が国号「大韓民国」と民主共和制を初めて掲げた。現行憲法前文も「臨時政府の法統」の継承をうたう。 | 臨時政府は領土・国民に対する実効的な統治を持たなかった。 |
| 1948年説 | 憲法・選挙・政府・国際承認がそろい、国家として実体を備えた。 | 臨時政府や独立運動の正統性を軽く扱うとの批判がある。 |

公式には8月15日を「光復節」とし、1945年の解放と1948年の政府樹立をあわせて記念する。「建国節」を設けるべきかどうかも政治的な争点になっている。

## 押さえどころ

- 1945年は「解放」、1948年は「政府樹立」。両方とも8月15日なので混同しやすい。
- 南北の政府はどちらも1948年に成立し、南が先（8月）、北が後（9月）。
- 国連決議195(III)の承認は「選挙が可能だった地域」に限った表現。この決議は1965年の[[日韓基本条約]]第3条で引用されている。
- 南の単独選挙には、統一を優先する金九らや左派が反対した。済州島四・三事件はその流れの中で起きた。
