# フランス第四共和政

フランス語：Quatrième République。期間：**1946〜1958年**。

第二次世界大戦後、1946年憲法によって成立した共和政。議会中心の政治のもとで戦後復興を進めたが、植民地戦争と政権の不安定化を背景に、1958年に第五共和政へ移った。

## 主な出来事

| 年 | 出来事 |
| --- | --- |
| 1946年 | 10月27日に新憲法を公布。第四共和政成立。 |
| 1954年 | ディエンビエンフーの敗北とジュネーヴ協定。同年、アルジェリア戦争が始まる。 |
| 1956年 | スエズ危機。 |
| 1957年 | ローマ条約に調印し、欧州統合を進める。 |
| 1958年 | アルジェリア問題をめぐる危機からド＝ゴールが政権に復帰。新憲法により[[フランス第五共和政]]へ。 |

## 政治の特徴

国民議会の力が強く、多党間の連立によって内閣が交代しやすかった。一方、経済復興や欧州統合も進んだ。1944年のパリ解放・臨時政府の時期と、1946年の憲法による第四共和政成立は区別する。
