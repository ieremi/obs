# ネストリウス派

**キリストの神としての性質（神性）と人としての性質（人性）を、はっきり分けて考えた** キリスト教の一派。431 年の **エフェソス公会議** で異端とされ、ローマ帝国を出て **ササン朝ペルシア** に広まり、さらに中央アジアを通って **唐** に伝わった。中国では **景教** とよばれた。

- 名前は、コンスタンティノープル総主教 **ネストリウス**（ネストリオス、381 年ごろ〜451 年ごろ）にちなむ
- ペルシアから東に広がった教会は、自分たちを「**東方教会**」とよぶ。「ネストリウス派」は、反対する側がつけた呼び名で、いまの研究ではあまり使わない
- 典礼の言葉は **シリア語**

## 世界史でのポイント

| 年 | できごと |
| --- | --- |
| 428 年 | ネストリウスがコンスタンティノープル総主教になる |
| **431 年** | **エフェソス公会議**。ネストリウスの説が異端とされ、ネストリウスは追放される |
| 451 年 | カルケドン公会議。キリストは「1 つの位格に、神性と人性の 2 つの性質」とする。単性論を退ける |
| 489 年 | ビザンツ皇帝ゼノンが、東方教会の学校（エデッサ）を閉じる。学者はペルシアの **ニシビス** に移る |
| **635 年** | **阿羅本**（アロペン）が唐の **長安** に来て、**太宗** に迎えられる |
| **781 年** | 長安に「**大秦景教流行中国碑**」が建てられる |
| 845 年 | 唐の武宗の **会昌の廃仏**。景教も禁じられ、中国では衰える |
| 13 世紀 | モンゴル帝国で、ふたたび広まる（元では **也里可温**〈エルケウン〉とよばれた） |
| 14 世紀末 | ティムールの遠征などで、中央アジア・西アジアの教会の多くが滅びる |

> 覚え方：「431 エフェソスで異端 → ペルシア → 635 唐に景教」。エフェソス＝ネストリウス派、カルケドン＝単性論、と公会議ごとに1つずつ。

## 何が問題になったか

### マリアをどうよぶか
- 当時、マリアを **「神の母」**（テオトコス）とよぶことが広まっていた
- ネストリウスは、「神が人から生まれたというのはおかしい。マリアが産んだのは **人としてのキリスト** だ」として、**「キリストの母」**（クリストトコス）とよぶべきだと主張した
- これに、アレクサンドリアの総主教 **キュリロス**（キリル）が強く反対した。「神の母」と言えないなら、キリストの中で神と人が **2 人に分かれてしまう**、というのが理由

### 学派の対立
| | アンティオキア学派（ネストリウス） | アレクサンドリア学派（キュリロス） |
| --- | --- | --- |
| 重んじること | キリストが **本当の人間** であること | キリストが **1 人の神** であること |
| 神性と人性 | **はっきり分ける**。2 つがつながっている | **1 つに結びつく** |
| 行き過ぎると | 神のキリストと人のキリストの 2 人がいることになる（ネストリウス派と批判された点） | 人性が神性に吸いこまれる（のちの単性論） |

- 背景には、教会の首位をめぐる **コンスタンティノープルとアレクサンドリアの勢力争い** もあった

### 公会議の流れ

| 公会議 | 退けられた説 | 決まったこと |
| --- | --- | --- |
| 325 年 ニケーア | アリウス派（子は父と同等の神でない） | 子は父と同一本質（[[三位一体説]]） |
| 381 年 コンスタンティノープル | | 聖霊も神 |
| **431 年 エフェソス** | **ネストリウス派**（神性と人性を分けすぎる） | マリアは「神の母」 |
| 451 年 カルケドン | **単性論**（人性が神性にのみこまれる） | キリストは 1 つの位格に 2 つの性質。「混ざらず、変わらず、分かれず、離れず」 |

- カルケドン公会議の決定は、**ネストリウス派と単性論の、ちょうど真ん中** をとったもの
- カルケドンを認めなかった教会：
  - 神性と人性を分ける側 → **東方教会**（ネストリウス派）
  - 1 つの性質とする側 → **コプト教会**（エジプト）、**アルメニア使徒教会**、**シリア正教会**、**エチオピア正教会** など（**非カルケドン派**、単性論派とよばれた）

### ネストリウス本人の考え
- 19 世紀末に、ネストリウスが追放先で書いた『ヘラクレイデスの書』が、シリア語の訳で見つかった
- それによると、ネストリウス本人の考えは、のちのカルケドン公会議の決定にかなり近く、「2 人のキリスト」を主張したわけではなかったと考える研究者が多い
- 異端とされたのは、本人の考えより、**ことばの使い方の違い** と **教会どうしの政治** によるところが大きかった、という見方がある

## 東方へ広がる

### ササン朝ペルシア
- ローマ帝国で追われた人々は、国境の外の **ササン朝ペルシア** に移った
- ペルシアの王は、ローマ帝国（ビザンツ）と対立していたので、**ローマの教会と別れたキリスト教徒** を受け入れやすかった
- ペルシアの教会は、5 世紀末に、神性と人性を分ける考えを正式に採り、西の教会と別の道を歩んだ
- 中心は、首都 **クテシフォン**（のちにはバグダード）の総主教（カトリコス）
- **ニシビス** の学校は、ギリシアの学問（アリストテレスなど）をシリア語に訳した。これが、のちに **アッバース朝** でアラビア語に訳され、イスラーム世界の学問の土台の1つになった

### 中央アジアとインド
- **ソグド人** などの商人が、シルクロードを通って広めた
- インドの南西部（ケーララ）の「**聖トマスのキリスト教徒**」も、東方教会とつながりがあった

### 唐の景教
- 635 年、ペルシアから来た **阿羅本** が長安に入り、**太宗** に迎えられた。638 年に布教を許され、寺が建てられた
- 寺ははじめ「**波斯寺**」（ペルシアの寺）とよばれ、745 年に「**大秦寺**」と改められた（大秦はローマのこと）
- 「**景教**」は「光の教え」の意味。唐の三夷教（**景教・祆教〈ゾロアスター教〉・摩尼教〈マニ教〉**）の1つ
- **大秦景教流行中国碑**（781 年）：景浄（アダム）が文を作った。漢文とシリア語で、景教の教えと、唐での150年ほどの歴史を記す。845 年ごろに埋められ、**明末の 1625 年ごろ** に西安の近くで掘り出された。いまは西安の **碑林博物館** にある
- 845 年、武宗が仏教を弾圧した **会昌の廃仏** で、景教・祆教・摩尼教も禁じられ、中国の本土ではほぼ消えた

### モンゴル帝国
- モンゴル高原の **ケレイト・ナイマン・オングト** などの部族に、東方教会の信者が多かった
- チンギス＝ハンの末子トルイの妻 **ソルコクタニ・ベキ**（ケレイト出身）は信者で、その子が **モンケ・フビライ・フレグ**
- 元の大都（北京）の近くから出た僧 **ラッバン・バール・サウマ** は、イル・ハン国の使節として、1287〜88 年に **ローマ・パリ** などを訪れ、教皇やフランス王と会った。同行した弟子は、東方教会の総主教（ヤバラーハー 3 世）になった
- ヨーロッパの「**プレスター・ジョン**」（東方にキリスト教の王がいるという伝説）は、こうした東方のキリスト教徒の話がもとになったとされる

## その後といま
- 14 世紀末の **ティムール** の遠征や、モンゴル帝国の崩壊、イスラーム化で、中央アジア・中国の教会はほぼ消えた
- イラク北部・イラン・トルコ南東部の山地に残った人々が、いまの **[[アッシリア東方教会]]** などにつながる
- 16 世紀（1553 年）に一部がローマ教皇の下に入り、**カルデア典礼カトリック教会** となった。いまは、イラクのキリスト教徒の多くがこの教会に属する
- 1960 年代に、暦の問題などで **古代東方教会** が分かれた
- 20 世紀以降、イラクやシリアの戦争・迫害で、信者の多くが欧米に移った。アッシリア東方教会の総主教座も、一時アメリカに置かれた
- **1994 年**、ローマ教皇ヨハネ・パウロ 2 世と、アッシリア東方教会の総主教マール・ディンハ 4 世が「**共同キリスト論宣言**」に署名した。キリストについての信仰は、言い方が違っても **同じ内容** だと認めあい、1500 年あまりの対立に区切りをつけた

## 押さえどころ
- ネストリウス派は、キリストの **人としての面を重んじすぎた** として退けられた。反対の極端が **単性論**
- ローマ帝国の外に出たことで、かえって **アジアの東の果てまで** 広がった。中世には、西ヨーロッパのカトリックより広い地域に信者がいた
- 「ネストリウス派」という名前は、反対者がつけたもの。本人たちは「東方教会」とよび、本人の考えも、異端とされたほど極端ではなかった可能性がある
- 世界史の試験では、**431 年エフェソス公会議 → ササン朝 → 唐の景教（大秦景教流行中国碑）** の流れと、**元の也里可温** がよく出る
