# アッシリア東方教会

**ササン朝ペルシアで育った「東方教会」の流れをくむ、いまの教会。** 世界史で「[[ネストリウス派]]」とよばれる教会の直接の子孫にあたる。信者の多くは **アッシリア人**（イラク北部・イラン北西部・トルコ南東部・シリア北東部にいた、アラム語系の言葉を話すキリスト教徒の民族）。

| 項目 | 内容 |
| --- | --- |
| 正式名 | アッシリア東方教会（Holy Apostolic Catholic Assyrian Church of the East） |
| 総主教 | **マール・アワ 3 世**（2021 年 9 月に選出。第 122 代のカトリコス総主教） |
| 本部 | イラク・クルディスタン地域の **エルビル**（アンカワ地区） |
| 信者 | 約 40〜50 万人。多くがイラク・イラン・シリアと、欧米・オーストラリアに住む |
| 典礼の言葉 | **シリア語**（古典）。信者がふだん話すのは、現代のアラム語（**スレト**、現代アッシリア語） |
| 認める公会議 | 325 年ニケーアと 381 年コンスタンティノープルだけ。431 年エフェソス・451 年カルケドンは認めない |

## 名前
- もとは単に「**東方教会**」とよんでいた。ローマ帝国の東の外、ペルシアの教会という意味
- 「**アッシリア**」を正式な名前に入れたのは **1976 年**。信者たちが、自分たちを古代アッシリアの子孫と考える民族意識が、19〜20 世紀に強まったことによる
- 「**ネストリウス派**」は、反対者や西洋の学者がつけた呼び名で、教会自身は使わない。ただし、ネストリウスを **聖人・教父として敬って** いる

## 歴史

### 古代〜中世
- 3〜5 世紀に、ササン朝ペルシアのキリスト教徒が、首都 **セレウキア・クテシフォン** の司教を長とする教会にまとまった
- 5 世紀に、ローマ帝国の教会と別れた。神学は、ネストリウスやモプスエスティアのテオドロスの考えを受けつぎ、7 世紀初めの **大ババイ** がまとめた
- アッバース朝のもとでは、総主教座は **バグダード** に置かれた。中央アジア・インド・中国（**景教**）・モンゴルまで広がった（くわしくは [[ネストリウス派]]）
- 14 世紀末の **ティムール** の遠征などで、アジアの大部分の教会が滅び、イラク北部とトルコ南東部の **ハッカリ山地** に残った

### 世襲の総主教
- 15 世紀ごろから、総主教の位が **おじから甥へ** 受けつがれるようになった（総主教は独身なので、甥が継ぐ）。この家系の総主教は、代々 **シムン**（シメオン）を名乗った
- 総主教座は、17 世紀からハッカリ山地の **コドシャニス** に置かれた
- 16 世紀（1553 年）に、世襲に反対した一派がローマ教皇の下に入った。これが、のちの **カルデア典礼カトリック教会** になった。いまはイラクのキリスト教徒の多くが、こちらに属する

### 20 世紀の受難
| 年 | できごと |
| --- | --- |
| 1914〜1920 年 | 第一次世界大戦中、オスマン帝国などによる **アッシリア人虐殺**（**サイフォ**、「剣」の意味）。アルメニア人虐殺と同じ時期 |
| 1915 年 | ハッカリ山地が攻撃され、コドシャニスの総主教座が失われる |
| 1918 年 | 総主教 **シムン 19 世ベニヤミン** が、交渉の場でクルド人の首長に殺される |
| 1933 年 | イギリスの委任統治が終わったイラクで、イラク軍がアッシリア人を虐殺した **シメレ事件**。総主教 **シムン 21 世エシャイ**（数え方によって 23 世）は国外に追放され、キプロスへ |
| 1940 年 | 総主教がアメリカの **シカゴ** に移る。その後、総主教座はアメリカに置かれた |
| 1964 年 | 総主教が、**グレゴリオ暦** の採用、典礼の改革、四旬節の短縮を決める |
| 1968 年 | 改革に反対する人々が、バグダードで別の総主教を立て、**古代東方教会** が分かれる |
| 1973 年 | 総主教が退位して結婚。教会会議が **世襲を廃止** する |
| 1975 年 | 元総主教シムン 21 世が、アメリカのサンノゼで親族に暗殺される |
| 1976 年 | **マール・ディンハ 4 世** が選ばれる（世襲でない最初の総主教）。教会の名前に「アッシリア」を入れる |
| 1980 年代 | イラン・イラク戦争で、ディンハ 4 世が亡命し、総主教座をシカゴに置く |
| 2015 年 | ディンハ 4 世が亡くなり、**マール・ゲワルギス 3 世** がエルビルで総主教になる |
| 2021 年 | ゲワルギス 3 世が退き、**マール・アワ 3 世** が選ばれる |

- イラク戦争（2003 年〜）やイスラーム国（IS、2014 年〜）の時期に、イラク・シリアのキリスト教徒の多くが国外に逃れた

## 教えと礼拝

### キリスト論
- キリストには、**神性と人性の 2 つの性質（キアナ）** と、それぞれの **2 つの「クノマ」**（個別の実体）があり、それが **1 つの「パルツォーパ」**（人格）に結びつく、とする
- 「2 つのクノマ」の言い方が、カルケドン公会議の「1 つの位格（ヒュポスタシス）」と対立するように見えたため、長く「2 人のキリストを説く異端」と誤解されてきた
- マリアは「**キリストの母**」とよぶ。「神の母」とはよばない

### 和解
- **1994 年 11 月 11 日**、総主教ディンハ 4 世とローマ教皇ヨハネ・パウロ 2 世が「**共同キリスト論宣言**」に署名した。言い方は違っても、キリストについて同じ信仰をもつと認めあい、マリアの呼び方（「神の母」「キリストの母」）も、互いに正しいと認めた
- **2001 年**、カトリック教会が、この教会の典礼「**アダイとマリの奉献文**」を **有効** と認めた。この奉献文には、ほかの教会のミサにある、キリストが最後の晩餐で言ったことば（「これはわたしのからだである」など、**制定のことば**）がまとまった形で入っていない。それでも有効と認めたことは、カトリック教会としては異例だった。これにより、事情があるときは、カルデア典礼カトリック教会の信者がこの教会で聖体を受けられるようになった
- コプト正教会が「ネストリウス派だ」と反対したため、中東教会協議会には正式に加わっていない

### 礼拝の特徴
- **イコン**（聖画像）を拝まない。教会の中は飾りが少なく簡素。家では、東の壁に **十字架**（キリストの像のないもの）をかける
- 秘跡（サクラメント）に、ほかの教会にない「**聖なるパン種**」（マルカ）と「**十字架のしるし**」を数える。聖なるパン種は、使徒の時代から受けつがれてきたとされるパン種で、聖体のパンを作るたびに少しずつ加えて、つぎに引きつぐ
- 典礼は、アダイとマリのほか、モプスエスティアのテオドロスの名とネストリウスの名がついた奉献文を、季節によって使い分ける

## 分布
- 大主教区：オーストラリア・ニュージーランド・レバノン、シリア、**インド**（ケーララ州トリシュール）
- 主教区：イラン、イラク（ドホーク・ニネヴェ、バグダード）、ロシア・ジョージア、北欧・ドイツ、西ヨーロッパ、アメリカ東部・西部・カリフォルニア、カナダ など
- インドの「カルデア・シリア教会」（トリシュール）が、いちばん大きな主教区とされる

## 押さえどころ
- アッシリア東方教会は、世界史の「ネストリウス派」「景教」の **いまの姿**。ただし、本人たちは「ネストリウス派」とよばれることを認めていない
- かつてはアジアで最も広く広がったキリスト教会だったが、いまは信者 50 万人ほどの小さな教会で、多くが **故郷を離れて** 暮らしている
- 1994 年の宣言で、カトリック教会とのあいだの 1500 年あまりの「異端」の問題に、区切りがついた
- 同じ東方教会から、**カルデア典礼カトリック教会**（16 世紀）と **古代東方教会**（1968 年）が分かれている
