# 韓国第三共和国

期間：**1963〜1972年**。

1961年の軍事クーデタ後、1963年の大統領選挙と朴正熙の就任を経て発足した共和国。制度上は民政に移行し、大統領の直接選挙を採用したが、軍出身の朴正熙が権力を握り続けた。

## 主な出来事・制度

| 年・項目 | 内容 |
| --- | --- |
| 1962年 | 軍政下の改憲で大統領制・一院制を定める。 |
| 1963年 | 大統領選挙を実施。12月に朴正熙が就任し、第三共和国が発足。 |
| 1965年 | 日韓基本条約。 |
| 1969年 | 大統領の3選を可能にする改憲。 |
| 1971年 | 朴正熙が金大中を破って大統領選挙に勝利。 |
| 1972年 | 十月維新と維新憲法により[[韓国第四共和国]]へ。 |

## 区分のポイント

輸出主導の経済開発が進む一方、反対勢力の抑圧と権力集中も進んだ。第三・第四共和国はともに朴正熙の時代だが、憲法と大統領選出制度が異なる。
