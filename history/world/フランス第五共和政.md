# フランス第五共和政

フランス語：Cinquième République。期間：**1958〜**。

アルジェリア戦争を背景とする政治危機の中で、1958年憲法によって成立した共和政。第四共和政に比べて大統領と政府の権限を強めた。

## 制度の変化

| 年 | 出来事 |
| --- | --- |
| 1958年 | 10月4日に新憲法を公布。12月、大統領選挙でド＝ゴールを選出。 |
| 1959年 | ド＝ゴールが第五共和政の初代大統領に就任。 |
| 1962年 | 憲法改正で大統領の直接普通選挙を導入。 |
| 1965年 | 改正後、初めて大統領の直接普通選挙を実施。 |

## 政治の特徴

大統領と首相の両方が存在し、政府は議会に責任を負う。大統領の権限も強いため、一般に半大統領制と説明される。大統領と議会多数派が異なる場合には、異なる政治勢力が大統領職と首相職を担うコアビタシオンが起こり得る。

1958年の成立時から大統領が直接普通選挙で選ばれていたわけではない。成立年の1958年と、ド＝ゴールの大統領就任年の1959年も区別する。
