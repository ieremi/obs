# 韓国の共和国の変遷

韓国の第一〜第六共和国は、大韓民国の憲法と政治体制の変化を区分する呼称。大統領が交代するたびに番号が増えるわけではない。

## 一覧

| 共和国 | 期間 | 主な人物 | 制度・特徴 |
| --- | --- | --- | --- |
| [[韓国第一共和国]] | 1948〜1960年 | 李承晩 | 大統領制。長期政権・権威主義化。四月革命で崩壊。 |
| [[韓国第二共和国]] | 1960〜1961年 | 尹潽善・張勉 | 議院内閣制。1961年の軍事クーデタで崩壊。 |
| 軍政期 | 1961〜1963年 | 朴正熙 | 国家再建最高会議。第二と第三の間に挟む。 |
| [[韓国第三共和国]] | 1963〜1972年 | 朴正熙 | 大統領直接選挙。民政移管後も軍出身者が支配。 |
| [[韓国第四共和国]] | 1972〜1981年 | 朴正熙、崔圭夏、全斗煥 | 維新憲法。間接選挙と強大な大統領権限。末期には新軍部が台頭。 |
| [[韓国第五共和国]] | 1981〜1988年 | 全斗煥 | 間接選挙、任期7年・単任制。権威主義体制。 |
| [[韓国第六共和国]] | 1988年〜 | 盧泰愚以降 | 1987年改憲に基づく直接選挙、任期5年・単任制。 |

この一覧は政府の発足を重視する区分。第四〜第六の境界では、憲法の改正・公布、政府発足、実質的な支配の変化のどれを採るかによって、資料の年代表記に違いがある。

## 移行の流れ

1. 1948年の政府樹立（[[韓国の建国]]） → **第一共和国**。
2. 1960年の四月革命・改憲 → **第二共和国**。
3. 1961年の5・16軍事クーデタ → 軍政 → 1963年に**第三共和国**。
4. 1972年の十月維新・維新憲法 → **第四共和国**。
5. 1979年の朴正熙暗殺と12・12軍事反乱 → 1980年の新軍部による権力掌握・改憲 → 1981年に**第五共和国**の政府発足。
6. 1987年の六月民主抗争・6・29宣言・改憲 → 1988年に**第六共和国**発足。

## 人物と制度を区別する

| 混同しやすい点 | 整理 |
| --- | --- |
| 朴正熙政権と第三共和国 | 朴正熙は軍政期・第三共和国・第四共和国にまたがる。 |
| 朴正熙暗殺と全斗煥の権力掌握 | 1979年10月の暗殺、12月の軍事反乱、1980年の支配強化は別の段階。 |
| 全斗煥の就任と第五共和国 | 1980年に旧憲法下で第11代大統領、1981年に新制度で第12代大統領となる。 |
| 1987年と1988年 | 民主化運動・改憲・大統領選挙は1987年、新憲法施行と盧泰愚就任は1988年。 |
| 共和国の番号と大統領の代数 | 盧泰愚は第六共和国の初代だが、大統領としては第13代。 |
| 「共和制」と「民主主義」 | 君主を置かない体制であっても、政治的自由や公正な選挙が保障されるとは限らない。 |

## 年代の別表記

米国議会図書館の年表では第四共和国を1972〜1979年、第五を1980〜1987年、第六を1987年以降としている。これは、上の政府発足を重視する区分と同じ境界を採った表ではない。資料を比べるときは、1979年の維新体制の動揺、1980年の改憲、1987年の民主化・改憲、1988年の新憲法施行をそれぞれ確認する。
