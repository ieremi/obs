## A 大航海時代と文明の接触

### 問1 ディアスの航路：④

バルトロメウ＝ディアスは、1488年にアフリカ南端の喜望峰へ到達した。原問の地図では、アフリカ西岸を南下して南端を回る**④**を選ぶ。

コロンブスの大西洋横断、ヴァスコ＝ダ＝ガマのインド到達とは区別する。ディアス自身がインドへ到達したわけではない。

### 問2 大航海時代後の変化：③

アメリカ大陸原産のジャガイモなどがヨーロッパへ伝わった。

誤りを直すと、ルネサンスはアメリカとの接触以前にイタリアで始まっている。アメリカ植民地では先住民の強制労働などが行われ、近代中国の制度である軍管区制とは関係しない。商人ギルドも中世ヨーロッパに存在していた。

### 問3 中国のイエズス会士：②

**ジュゼッペ＝カスティリオーネ（郎世寧）と西洋画法**の組合せが正しい。清の宮廷で画家として活動した。

| 人物 | 押さえる活動 |
| --- | --- |
| マテオ＝リッチ（利瑪竇） | 明末に活動。徐光啓と『幾何原本』を翻訳し、『坤輿万国全図』を作成 |
| アダム＝シャール（湯若望） | 明末・清初に暦法の整備に関わる |
| フェルビースト（南懐仁） | 清で天文・暦法や大砲鋳造に関わる |
| カスティリオーネ（郎世寧） | 清で西洋画法を伝える |

『幾何原本』とカスティリオーネ、イグナティウス＝ロヨラと大砲鋳造、リッチと『皇輿全覧図』を結びつけた選択肢は誤り。ロヨラはイエズス会の創設者で、『皇輿全覧図』は康熙帝の時代の測量事業による。

### 問4 文明の接触：②が誤り

732年のトゥール・ポワティエ間の戦いでは、フランク王国のカール＝マルテルがウマイヤ朝軍を退けた。**西ヨーロッパのキリスト教勢力とイスラーム勢力の戦い**であり、選択肢では両者が逆になっている。

ほかの選択肢は、西域経営とビザンツへの使節、クシャーナ朝のガンダーラ美術とヘレニズム文化、唐代中国への祆教の伝来を扱う。ガンダーラ美術の仏像にはギリシア系美術の影響が見られ、祆教はゾロアスター教を指す。

## B 交通手段の発達と戦争・国際関係

### 問5 蒸気機関と交通：③

**ニューコメン → ワット → フルトン／スティーヴンソン**の順で整理する。

| 人物 | 業績 |
| --- | --- |
| ニューコメン | 実用的な蒸気機関を考案 |
| ワット | 蒸気機関を改良 |
| フルトン | 蒸気船を実用化 |
| スティーヴンソン | 蒸気機関車の発展・実用化に貢献 |

### 問6 イギリスとアジア・アフリカ：②

1898年の**ファショダ事件**の翌年、1899年にイギリスは**南アフリカ戦争（ブール戦争）**を開始した。地図のbは南アフリカなので、②が正しい。

地図のaはエジプト、bは南アフリカ、cはインド、dはオーストラリア。

- スエズ運河会社の株式をイギリスが買った相手は、フランスではなく**エジプトの支配者**。
- **1935年の新インド統治法**は自治の拡大を定めたが、**独立の約束ではない**。インドの独立は1947年。
- オーストラリア連邦の成立は**1901年**。第一次世界大戦後ではない。

### 問7 航空機を用いた戦争：②

1942年の**ミッドウェー海戦**で、日本は主要な空母を失った。アメリカが太平洋戦争の主導権を握る転機となった。

| 誤った組合せ | 訂正 |
| --- | --- |
| ゲルニカをフランスの町とする | **スペイン**の町。ピカソの絵画は1937年の爆撃を題材とする |
| ケネディ政権が北爆を開始 | 本格的・継続的な北爆開始は1965年、**ジョンソン政権** |
| 第4次中東戦争で先制攻撃しゴラン高原を占領 | イスラエルの先制攻撃とゴラン高原占領は1967年の**第3次中東戦争** |

### 問8 冷戦と宇宙開発：②

ソ連は1957年に世界初の人工衛星**スプートニク1号**を打ち上げた。1962年にはキューバへのソ連のミサイル配備をめぐり、**キューバ危機**が起こった。選択肢②の順序は正しい。

ほかの選択肢は次のように直す。

- 朝鮮戦争の国連軍は**アメリカ軍が中心**。
- 1969年、初の有人月面着陸に成功したのは**アメリカのアポロ11号**。
- 1989年のマルタ会談は、1990年のイラクのクウェート侵攻と1991年の湾岸戦争より**前**。

## C 現代の国際関係と社会問題

### 問9 国際金融：④が誤り

国際復興開発銀行（IBRD）は、**第二次世界大戦後**の復興・開発を目的として、1944年のブレトンウッズ会議で設立が決められた。第一次世界大戦後の復興機関とする点が誤り。

ほかの選択肢で押さえる点は、1973年の主要国の変動相場制移行、第一次世界大戦後のニューヨークの国際金融上の地位向上、1931年のイギリスの金本位制停止。

ニクソン政権による1971年の金・ドル交換停止と、1973年の変動相場制への移行は、段階を分けて覚える。

### 問10 国家の形成：③

**アラブ首長国連邦は1971年に成立**した。

ほかの選択肢は、年代・宗主国・国名が取り違えられている。

| 対象 | 正しい整理 |
| --- | --- |
| 中華人民共和国 | 1949年成立。文化大革命の開始は1966年 |
| イラク | フランスではなく、イギリスの委任統治から1932年に独立 |
| ベトナム民主共和国 | ホー＝チ＝ミンが1945年に独立を宣言。アメリカ軍撤退後の成立ではない |
| ベトナム社会主義共和国 | 南北統一により1976年成立 |

### 問11 労働組合運動：③

アメリカの**ワグナー法（1935年）**が、労働者の団結権・団体交渉権を保護した。

ほかの選択肢は、産業革命の先駆国をイギリス、第一次世界大戦直前の組織を第2インターナショナル、人民戦線の目的を反ファシズムに直す。
