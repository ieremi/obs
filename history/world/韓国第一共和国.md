# 韓国第一共和国

期間：**1948〜1960年**。

1948年の大韓民国政府樹立から、1960年の四月革命による李承晩政権の崩壊までの共和国。大統領制のもとで、李承晩の長期政権と権威主義化が進んだ。

## 主な出来事・制度

| 年・項目 | 内容 |
| --- | --- |
| 1948年 | 7月17日に憲法を公布。8月15日に大韓民国政府が発足。 |
| 1950〜1953年 | 朝鮮戦争。1953年に休戦協定。 |
| 1952年 | 改憲で大統領を国会による間接選挙から直接選挙へ変更。 |
| 1954年 | 初代大統領の重任制限を撤廃する改憲。採決をめぐり「四捨五入改憲」と呼ばれる。 |
| 1960年 | 3月の不正選挙への抗議から四月革命が広がり、李承晩が退陣。 |

## 区分のポイント

建国時から大統領を直接選挙で選んだわけではない。李承晩退陣後、過渡政府と改憲を経て[[韓国第二共和国]]へ移る。
