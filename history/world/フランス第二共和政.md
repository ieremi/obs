# フランス第二共和政

フランス語：Deuxième République。期間：**1848〜1852年**。

1848年の二月革命で七月王政が倒れた後に成立した共和政。大統領となったルイ＝ナポレオンがクーデタを経て皇帝となり、第二帝政へ移った。

## 成立と終焉

| 年月 | 出来事 |
| --- | --- |
| 1848年2月 | 二月革命でルイ＝フィリップが退位。臨時政府が成立。 |
| 1848年3月 | 男子普通選挙を導入。女性の選挙権は含まれない。 |
| 1848年4月 | 植民地の奴隷制廃止を決定。 |
| 1848年6月 | 国立作業場の閉鎖を契機に六月蜂起。労働者と保守的な共和派の対立が激化。 |
| 1848年12月 | ルイ＝ナポレオンが大統領に当選。 |
| 1851年12月2日 | 大統領がクーデタを起こす。 |
| 1852年12月2日 | ナポレオン3世として即位。[[フランス第二帝政]]へ。 |

議会制の実質的な崩壊を重視して「1848〜1851年」とする区分もある。このページは帝政成立までの1848〜1852年とする。第二共和政の大統領と第二帝政の皇帝は同一人物。
