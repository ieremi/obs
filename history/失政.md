# 失政

**政治の運営や政策の選択・実施を誤り、社会に損失をもたらしたと評価されること。** 単に評判が悪い政策や、政権に不利な結果を生んだ政策だけを指すのではない。

以下は、政策の失敗として検討できる日本・外国の事例。何を失敗と評価するかを、政策の目的、実際の結果、損失に至る仕組みに分けて記す。

## 日本の例

### 上知令の撤回（1843年）

| 観点 | 内容 |
| --- | --- |
| 政策 | 水野忠邦が天保の改革で進めた、江戸・大坂周辺の大名・旗本領を幕府の直轄地へ組み替える政策。 |
| 目的 | 幕府の財政・支配基盤の強化など。 |
| 結果 | 大名・旗本や幕閣内部から強い反対を受け、江戸・大坂に関しては実施されないまま撤回。 |
| 失敗の論点 | 利害関係者の反発と実施の政治的条件を十分に処理できず、改革を実現できなかった。 |

これは主に**実施可能性・合意形成の失敗**。未実施なので、「実施した結果、経済が崩壊した」事例としては扱わない。また、上知令の失敗だけで天保の改革の全施策を同一評価にはできない。[日本大百科全書など「上知令」（コトバンク）](https://kotobank.jp/word/上知令-79542)

関連：[[天保の改革]]

### 金解禁とデフレ政策（1930〜1931年）

| 観点 | 内容 |
| --- | --- |
| 政策 | 浜口雄幸内閣・井上準之助蔵相による旧平価での金本位制復帰と緊縮政策。 |
| 目的 | 為替の安定、国際金融秩序への復帰、経済の整理による競争力の強化。 |
| 結果 | 世界恐慌と重なり、物価下落と景気悪化が進行。1931年12月には金輸出を再禁止。 |
| 失敗の論点 | 固定相場への復帰と緊縮を、不況の深刻化する環境で続けたことが、デフレ圧力を強めた。 |

**政策目的と実施時期・外部環境の不整合**の例。昭和恐慌のすべてを金解禁だけで説明するのではなく、世界恐慌の影響と、国内政策が不況を増幅した経路を分けて考える。[財務省『大蔵省百年史』第5期](https://www.mof.go.jp/pri/publication/mof_100history/5ki_c1.pdf)、[内閣府：デフレの進行と金融政策](https://www5.cao.go.jp/j-j/wp/wp-je01/wp-je01-00102.html)

関連：[[昭和恐慌]]

## 戦後日本の例

### ハンセン病の隔離政策の継続（戦後〜1996年）

| 観点 | 内容 |
| --- | --- |
| 政策 | 戦前からの隔離政策を、戦後の1953年「らい予防法」でも維持した。 |
| 掲げられた目的 | 感染拡大の防止。ただし、感染性や隔離の必要性についての認識自体が問われる。 |
| 結果 | 医学的知見や治療の進歩に対応した政策転換が遅れ、患者・回復者の社会生活を長く制限。家族との関係の断絶や、偏見・差別をもたらした。法律の廃止は1996年。 |
| 失敗の論点 | 隔離を必要としないという知見を政策に反映せず、人権を侵害する制度を長期間存続させた。 |

**知見の更新に対応しない政策の固定化と、国家による人権侵害**の例。2001年の熊本地裁判決後、政府は控訴せず、謝罪と補償を進めた。2008年の「ハンセン病問題の解決の促進に関する法律」も、国の隔離政策による人権上の制限・差別等を明記している。

これは単に「成果が期待に届かなかった」事例ではない。患者本人だけでなく、家族への差別や、長期隔離によって社会復帰が困難になったことも被害として記録する。[厚生労働省：ハンセン病に関する主な出来事](https://www.mhlw.go.jp/houdou/2003/01/h0131-5/dekigoto.html)、[ハンセン病問題の解決の促進に関する法律・前文](https://www.mhlw.go.jp/web/t_doc?dataId=80ab0034&dataType=0&pageNo=1)、[法務省：隔離政策と人権問題の整理](https://www.moj.go.jp/JINKEN/public_jinken07_refer04.html)

### 水俣病の被害拡大を防げなかった行政対応（1956年の公式確認以降）

| 観点 | 内容 |
| --- | --- |
| 政策上の課題 | 工場排水による健康被害の疑いに対して、原因究明と被害防止をどう並行して進めるか。 |
| 必要だった対応 | 汚染源への対策、汚染された魚介類を通じた曝露の防止、被害の把握と住民への情報提供。 |
| 結果 | 1956年の公式確認後も、長期間にわたり適切な対応ができず、被害の拡大を防止できなかった。政府が原因に関する統一見解を示したのは1968年。 |
| 失敗の論点 | 科学的な不確実性や経済・社会的利害のある中で、被害防止へ十分早く動けなかった。 |

**対策を実施したことだけでなく、必要な規制・予防措置を遅らせたことも失政の対象となる**例。環境省自身が、企業に長期間適切に対応できず、被害拡大を防げなかった経験から、初期対応と予防的な取組の重要性を教訓としている。

汚染を発生させた企業の責任と、被害防止に当たる国・自治体の対応の問題は区別して検討する。また、1968年に原因が公表されたことを、それ以前には対策を検討できる情報が全くなかったという意味にしない。[環境省『水俣病の教訓と日本の水銀対策』](https://www.env.go.jp/chemi/tmms/pr-m/mat01/ja_full.pdf)、[国立水俣病総合研究センター：社会科学的研究会報告書](https://nimd.env.go.jp/research/result/study_group_report/)

### バブル期・崩壊初期の金融政策（1980年代後半〜1991年）

| 観点 | 内容 |
| --- | --- |
| 政策 | 1980年代後半の金融緩和の長期化と、その後の引締め・緩和への転換のタイミング。 |
| 目的 | 円高への対応や内需拡大、その後は景気過熱・物価上昇の抑制。 |
| 結果・検証 | 資産価格と信用の膨張、バブル崩壊後の調整が深刻化。日本銀行のアーカイブ研究は、崩壊によるバランスシート調整の潜在的影響を十分深刻に受け止められず、1991年前半まで引締めを続けたと指摘する。 |
| 失敗の論点 | 消費者物価や足元の景気だけでなく、金融の不均衡と、崩壊後の債務・資産価値の調整を判断に十分取り込めたか。 |

**金融リスクの把握と政策転換のタイミング**を検討する例。バブルの生成・崩壊には金融機関の融資行動や制度なども関わるため、「金利政策だけが原因」とはしない。また、緩和が長すぎたという批判と、崩壊後の緩和が遅かったという批判は、異なる局面への評価。[日本銀行金融研究所「1980年代における金融政策運営について」](https://www.imes.boj.or.jp/research/papers/japanese/kk34-2-3.pdf)

### 消費税率引上げなどの負担増と景気後退（1997〜1998年）

| 観点 | 内容 |
| --- | --- |
| 政策 | 1997年4月の消費税率3%から5%への引上げ、特別減税の終了など。財政構造改革も推進。 |
| 目的 | 財政再建や税制の見直し。 |
| 結果 | 駆け込み需要の反動減と家計の実質可処分所得の減少が消費に影響。さらにアジア通貨危機や国内金融機関の破綻が重なり、景気が悪化した。 |
| 失敗の論点 | 民間需要の回復が十分強くない段階での負担増や財政引締めが、需要の弱さを増幅しなかったか。 |

**財政再建の必要性と、実施時期・速度の適切さを分ける**例。財政再建という目的への賛否と、1997年の政策の組合せが適切だったかは別の問いとなる。

この例は評価が分かれる。消費税引上げ等が需要を抑えたことと、1997〜1998年の景気後退の主因が何だったかは同じ問題ではない。増税だけで景気後退全体を説明せず、金融危機・信用収縮やアジア通貨危機の寄与も検討する。[内閣府『平成10年経済白書』はじめに](https://www5.cao.go.jp/keizai3/keizaiwp/wp-je98/wp-je98-000h1.html)、[同・財政政策と経済対策](https://www5.cao.go.jp/keizai3/keizaiwp/wp-je98/wp-je98-00110.html)、[同・おわりに](https://www5.cao.go.jp/keizai3/keizaiwp/wp-je98/wp-je98-00307.html)

### ゼロ金利政策の解除（2000年）

| 観点 | 内容 |
| --- | --- |
| 政策 | 日本銀行が2000年8月にゼロ金利政策を解除。 |
| 目的・判断 | 景気改善を踏まえ、極端な金融緩和から金利を引き上げる判断。 |
| 結果 | その後景気が悪化し、2001年には再び緩和を進め、3月に量的緩和を導入。 |
| 失敗の論点 | デフレ懸念や下振れリスクが残る中で、解除が早すぎなかったか。 |

**不確実な回復局面での引締め判断**の例。当時から政府は解除を時期尚早として採決延期を求めており、政策判断に対立があった。ただし、後に緩和へ戻ったという事実だけで解除が景気悪化の全原因だったとは証明できない。外部環境の変化と、解除しなかった場合の見通しも比較する。[日本銀行：2000年の政策判断・政府の延期請求](https://www.boj.or.jp/mopo/diet/d_report_2000/semi0012b.pdf)、[日本銀行：非伝統的金融政策の年表](https://www.boj.or.jp/mopo/outline/bpreview/ref.htm)

## 戦後日本の産業政策の例

産業政策は、特定産業の育成・技術開発・設備投資・再編などを支援・誘導する政策。景気全体を調整する財政・金融政策とは区別する。以下では、政府の狙いと企業の行動が食い違った例、評価軸によって判断が分かれる例を取り上げる。

### 石油化学のエチレン年産30万トン基準（1960年代後半以降）

| 観点 | 内容 |
| --- | --- |
| 政策 | エチレン設備の大型化を基準として、石油化学の設備投資を誘導。 |
| 目的 | 規模の経済を生かし、国際競争力のある生産体制を育てる。 |
| 結果・研究上の評価 | 企業が基準に対応して参入・投資を進め、集約化の狙いに反して能力増強が重なった。過剰能力と構造不況につながったとする研究がある。 |
| 失敗の論点 | 個々の設備を大きくする条件が、産業全体の投資過剰を防ぐ条件にはならなかった。 |

**規模の経済を求める基準が、投資競争を促す逆効果**の例。企業は政策に受動的に従うだけでなく、事業を維持・拡大するために制度へ戦略的に対応する。石油化学産業の発展全体を失敗とするのではなく、設備投資の調整方法を評価する。[島本実「産業政策の意図せざる結果」第III節](https://www.jstage.jst.go.jp/article/jrbh/38/0/38_6/_html/-char/en)

### YS-11と日本航空機製造による民間航空機育成（1950〜1970年代）

| 観点 | 内容 |
| --- | --- |
| 政策 | 官民共同の日本航空機製造（NAMC）を通じて、国産旅客機YS-11の開発・生産・販売を進めた。 |
| 目的 | 国内の技術・資金を集め、民間航空機産業を育成する。 |
| 結果 | 機体の開発と実際の運航は実現したが、事業の採算確保には失敗。 |
| 失敗の論点 | 開発の達成だけでなく、参加企業の責任・誘因、販売を含む事業運営をどう設計したか。 |

**技術的達成と事業・政策の成果を分けて評価する**例。島本の研究は、国策会社への集約が参加企業に十分な事業上の誘因を与えなかった点を論じる。「飛行機を作れなかった」という失敗ではない。[同論文・第II節](https://www.jstage.jst.go.jp/article/jrbh/38/0/38_6/_html/-char/en)

### 第五世代コンピュータ・プロジェクト（1982〜1992年度）

| 観点 | 内容 |
| --- | --- |
| 政策 | 通商産業省主導で、並列処理・知識情報処理を中心とする新しいコンピュータ技術を共同研究。 |
| 目的 | 従来方式の技術的限界に対応する、新たな技術体系の確立。 |
| 失敗とされる論点 | 製品化・産業的な普及という観点から、期待した成果に結び付かなかったとの批判。 |
| 評価上の争点 | 基礎研究や国際貢献を重視した計画を、短期的な製品化だけで判定してよいか。 |

これは**失政と断定するより、成功・失敗の評価軸が争われる例**。通産省の研究資料は、製品化そのものが目的ではなかったとして、超LSIプロジェクトなどとの単純比較を戒めている。研究政策では、当初の目標、知識・人材への波及、費用、他の選択肢を併せて評価する。[産総研所蔵・MITI Research Review No.5、113ページ](https://www.airc.aist.go.jp/aitec-icot/ICOT/Museum/MITIrr/doc113.html)、[科学技術政策研究の評価報告](https://cir.nii.ac.jp/crid/1390282681106489984)

### 産業政策を評価する際の問い

- 支援がなければ実現しにくい技術・投資だったか。民間投資を単に置き換えていないか。
- 企業が制度にどう反応するか。補助金・認可の条件が過剰投資や責任の分散を招かないか。
- 技術開発、事業採算、知識の波及、雇用など、どの成果を目標としていたか。
- 中間評価、方針変更、事業からの退出の条件を設けていたか。

以上は事例を読むための整理。政府介入がすべて失敗、あるいは成長産業への支援ならすべて成功という結論にはしない。[経済企画庁『平成4年経済白書』企業・市場と政府の関係](https://www5.cao.go.jp/keizai3/keizaiwp/wp-je92/wp-je92-00306.html)

## 外国の例

### アメリカの禁酒政策（全国的禁酒：1920〜1933年）

| 観点 | 内容 |
| --- | --- |
| 政策 | 憲法修正第18条と施行法により、飲用酒の製造・販売・輸送などを禁止。 |
| 目的 | 飲酒に伴う社会問題の抑制。 |
| 結果 | 密造・密輸などの非合法市場が拡大し、犯罪組織の収益源となった。取締りも司法の大きな負担となり、1933年に修正第21条で全国的禁酒を撤廃。 |
| 失敗の論点 | 需要が残る中で合法供給を禁じ、非合法市場と執行費用を膨らませた。 |

**規制の副作用と執行可能性**の例。禁酒期にも、飲酒量や健康への影響と犯罪・行政負担とは評価軸が異なる。「飲酒自体がすべて禁止された」「消費は全く減らなかった」とは単純化しない。[米連邦司法センター：禁酒政策の年表](https://www.fjc.gov/history/exhibits/prohibition-in-federal-courts-timeline)、[FBI：禁酒期と犯罪組織](https://www.fbi.gov/history/history-of-the-fbi/the-fbi-and-the-american-gangster)

### 中国の大躍進政策と大飢饉（1958年以降）

| 観点 | 内容 |
| --- | --- |
| 政策 | 毛沢東指導下で、集団化・大衆動員を通じて農工業の生産を急増させようとした。 |
| 目的 | 急速な経済発展と工業化。 |
| 結果 | 農業生産の落ち込みと深刻な食糧不足が起こり、1959〜1961年を中心に大規模な飢饉が発生。 |
| 失敗の論点 | 農業からの資源転用、過大な生産報告、実情に対応できない食糧徴発などが被害を増幅した。 |

**非現実的な目標、情報の歪み、修正の遅れ**が重なった例。研究は、農村の食糧確保を損なう徴発制度など、政策・制度上の要因を示している。死者数の推計には幅があり、一つの確定値として扱わない。天候だけ、あるいは単一の政策だけで被害全体を説明しない。[Meng・Qian・Yared「中国大飢饉の制度的原因」](https://business.columbia.edu/faculty/research/institutional-causes-chinas-great-famine-1959-1961)、[Li・Yang「大躍進：中央計画の災厄の分析」](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=772079)

### イギリスのコミュニティー・チャージ（人頭税、1989〜1993年）

| 観点 | 内容 |
| --- | --- |
| 政策 | サッチャー政権が、住宅資産に基づく地方税に代えて、原則として成人個人に定額を課す方式を導入。1989年にスコットランド、1990年にイングランド・ウェールズで実施。 |
| 目的 | 地方行政の費用負担を住民に広げ、支出と納税者の負担の関係を明確にすること。 |
| 結果 | 負担の公平性などをめぐる強い反発を受け、1993年にカウンシル・タックスへ置き換えられた。 |
| 失敗の論点 | 所得・負担能力に比べた逆進性への批判と、社会的受容を得られなかった制度設計。 |

**負担配分と制度への納得の不足**の例。減免などもあったため、全員が例外なく同額を払ったという意味ではない。失政と評価する際は、不人気だったことだけでなく、負担の設計や徴税への影響を見る。[英国議会：戦後の税制](https://www.parliament.uk/about/living-heritage/transformingsociety/private-lives/taxation/overview/postwar/)、[英国財政研究所：税制の歴史と仕組み](https://ifs.org.uk/media/331/download)

## 事例から見る失敗の仕組み

以下は、上の事例を比較するための整理。

| 仕組み | 事例 | 確認する問い |
| --- | --- | --- |
| 実施条件の不足 | 上知令 | 誰の協力・負担が必要で、反対にどう対応したか。 |
| 環境変化への対応不足 | 金解禁 | 当初の前提が崩れたときに修正できたか。 |
| 意図しない行動を誘発 | 禁酒政策 | 規制によって代替市場や抜け道が生まれなかったか。 |
| 情報の歪みと修正の抑圧 | 大躍進 | 悪い結果を正確に報告できたか。政策を止められたか。 |
| 負担配分・正統性の問題 | コミュニティー・チャージ | 誰がどれだけ負担し、その理由を説明できたか。 |

## 評価するときの注意

1. **当時の目的と情報を確認する。** 後知恵だけで、失敗が最初から自明だったと決め付けない。
2. **悪い結果と政策の効果を区別する。** 外的ショックや、政策がなかった場合の結果とも比較する。
3. **平均だけでなく負担の分布を見る。** 一部の利益と、別の人々の被害が併存することがある。
4. **撤回と失敗を同一視しない。** 撤回は実施困難の表れの場合も、被害を抑えた適切な修正の場合もある。
5. **政策の失敗と人権侵害を区別して記録する。** 強制や弾圧を伴う事例は、効率・成果だけの問題に還元しない。
