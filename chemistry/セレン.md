# セレン

**原子番号 34、元素記号 Se。硫黄の仲間（16 族、カルコゲン）の元素。** 銅を精錬するときの副産物としてとれる。生き物に欠かせない微量元素だが、少し多すぎるだけで毒になる。土の中のセレンの量は地域によって大きくちがい、足りない地域と多すぎる地域の両方に病気がある。

### 発見と名前

- **1817 年**、スウェーデンの **ベルセリウス** と **ガーン** が発見した
- 硫酸工場（鉛室法）で、ファールン鉱山の黄鉄鉱を燃やしたところ、赤い沈殿ができた。燃やすとダイコンのようなにおいがし、テルルの化合物に似ていた
- ベルセリウスははじめテルルの化合物と考えたが、調べ直して新しい元素とわかった
- 名前はギリシャ語の **セレーネー（σελήνη、月）** から。似た元素の **テルル** が「地球」（ラテン語 tellus）から名づけられていたので、それに合わせた

### 同素体

| 同素体 | 見た目・性質 |
| --- | --- |
| **灰色セレン**（三方晶） | **いちばん安定**。原子がらせん状の鎖につながる。**半導体** で、光が当たると電気を通しやすくなる（**光伝導性**）。同素体のうち、光伝導性がはっきりあるのはこれだけ |
| 赤色セレン | 化学反応で作ると、ふつうは赤れんが色の粉（無定形）になる。Se₈ の環でできた結晶（単斜晶）もある |
| 黒色セレン（ガラス状） | 溶かして急に冷やすとできる。50 ℃でやわらかくなり、180 ℃で灰色セレンに変わる |

### 硫黄の仲間として

16 族は下へ行くほど金属に近くなる。セレンは非金属と金属の中間の性質をもつ。

| | 酸素 O | 硫黄 S | **セレン Se** | テルル Te |
| --- | --- | --- | --- | --- |
| 水素化合物 | H₂O | H₂S | **H₂Se** | H₂Te |
| 二酸化物 | — | SO₂ | **SeO₂** | TeO₂ |
| 酸 | — | 硫酸 H₂SO₄ | **セレン酸 H₂SeO₄** | テルル酸 |

| 化合物 | 性質・使い道 |

### 作り方

セレンだけを掘る鉱山はほとんどない。セレンは **硫化物の鉱石**（とくに **銅** の硫化物）の中で、硫黄の一部と入れかわって少しふくまれる。

1. 銅を **電解精錬** すると、陽極の下に泥がたまる（**陽極泥**、アノードスライム）。ここにセレンが集まる
2. 陽極泥を炭酸ナトリウムと酸化して、二酸化セレン SeO₂ にする
3. 水に溶かして酸性にし、亜セレン酸 H₂SeO₃ にする
4. **二酸化硫黄 SO₂** を吹きこむと、セレンが単体になって沈殿する

$$\mathrm{H_2SeO_3 + 2SO_2 + H_2O \rightarrow Se + 2H_2SO_4}$$

昔は、硫酸工場（鉛室法）の泥からもとった（発見のきっかけもこれ）。

### 使い道

2010 年の消費の内訳は、冶金 30%、ガラス 30%、農業 10%、化学品・顔料 10%、電子機器 10%。

| 分野 | 使い道 |
| --- | --- |
| **冶金** | **マンガンの電解精錬**：二酸化セレンを加えると、必要な電力が減る。マンガン 1 トンあたり約 2 kg の酸化セレンを使う。**中国が最大の消費国**。鋼や銅合金に少し加えて削りやすくする。黄銅の鉛の代わり |
| **ガラス** | 鉄のせいでガラスが緑や黄色を帯びるのを、セレンの赤で打ち消す（**消色**）。セレンで赤いガラスも作る |
| 農業 | 家畜のえさ・肥料に加えて、セレン不足を補う（下の「地理」） |
| **光・電子** | **光伝導性** を使う。昔のコピー機の感光ドラム（1980 年代に有機感光体へ）、露出計、X 線の平面検出器（アモルファスセレン）、整流器。1876 年には最初の固体の太陽電池に使われた |

## 体の中のセレン

**少なすぎても、多すぎても病気になる。** 必要な量と毒になる量の差が小さい元素。

- 動物に欠かせない微量元素であることは **1957 年** にわかった。体全体で 13〜20 mg ふくまれる
- **セレノシステイン**（セレンをふくむアミノ酸）として、酵素に組みこまれて働く
  - **グルタチオンペルオキシダーゼ**：過酸化水素などを分解して、細胞を傷つける物質を除く
  - **甲状腺ホルモンの脱ヨウ素酵素**：4 種類のうち 3 種類がセレンを必要とする
- **摂取量の目安（米国）**：推奨量は成人 1 日 **55 µg**。耐容上限量は **400 µg**
- **とりすぎ（セレン中毒）**：息がニンニクのようなにおいになる、髪が抜ける、爪がはがれる、胃腸の症状、疲れ、神経の障害。ひどいと肝硬変・肺水腫で死ぬこともある
- **多くふくむ食べ物**：ブラジルナッツ（とれた土地の土で量が変わる）、腎臓、マグロ、カニ、ロブスター

## 地理

### どこでとれるか（精錬の生産量）

セレンは銅の精錬の副産物なので、**銅の鉱山がある国ではなく、銅を精錬する国** で多く作られる。

| 順位 | 国 | 生産量（2023 年） | 世界の割合 |
| --- | --- | --- | --- |
| 1 | **中国** | 約 1,780 t | 約 50% |
| 2 | **日本** | 約 680 t | 約 19% |
| 3 | ロシア | 約 350 t | 約 10% |
| 4 | ベルギー | 約 200 t | 約 6% |
| 5 | カナダ | 約 130 t | 約 4% |
| 6 | フィンランド | 約 122 t | 約 3% |
| | 世界 | 約 3,530 t | |

- 数字は推定をふくむ。米国は企業の秘密のため公表されず、合計に入っていない。チリ・オーストラリア・韓国などは、情報が足りず表にない
- **日本が 2 位** なのは、銅の鉱石（精鉱）を海外から輸入して、国内で大量に精錬しているため。日本にはほとんど銅の鉱山がない。原料のある場所ではなく、加工する場所に副産物ができる例（[[産業立地]]）
- ベルギーにも鉱山はないが、非鉄金属の精錬会社があり、セレンを作っている
- 2011 年の資料では、1 位ドイツ（650 t）、2 位日本（630 t）。ただしこの数字には米国と中国が入っていない

### 土の中のセレン

地殻にふくまれる量は平均 0.05〜0.09 mg/kg とわずか。土の中の量は、もとの岩石や雨の量などで地域によって大きくちがう。作物のセレンは土で決まり、人や家畜のセレンは作物で決まる。

| 地域 | 土のセレン | 起こったこと |
| --- | --- | --- |
| **中国の低セレン地帯**（北東の黒竜江省から南西の雲南省まで、帯のように続く） | 少ない | **克山病**：心臓の筋肉が傷む風土病。1959〜1970 年には 10 万人あたり 40 人を超えたが、いまは 5 人未満に減った |
| **中国・湖北省恩施** | とても多い | **セレン中毒**。セレンを非常に多くふくむ石炭（最大 9.1%）が風化して土に入った。石灰を肥料にする習慣があり、作物がセレンを吸いやすくなった |
| **フィンランド** | 少ない（植物が吸いにくい） | **1984 年から、肥料にセレンを加えている**。国全体の摂取量を上げた |
| 北米の一部 | 少ない | 牛・羊など反すう動物がセレン不足になりやすい |
| 北米の一部（セレンの多い土） | 多い | ゲンゲ属（*Astragalus*、ロコ草の一部）など、セレンをためる植物が生える。これらの植物は、セレンの多い土の目印になる |
| 米国カリフォルニア州・ケスタソン野生生物保護区 | 農地の排水で多くなった | 排水にふくまれたセレンで、何千もの魚と水鳥が死んだ |
| 米国ノースカロライナ州・ビューズ湖 | 石炭火力発電所の排水 | 1974〜1986 年に、魚 19 種がいなくなった |

- 中国の低セレン地帯では、ほかに **カシン・ベック病**（骨・関節の病気）もある。ただし、セレン不足がどのくらい関係しているかは、はっきりしていない
- 水の中では、プランクトンがセレンを何千倍にも濃縮し、食物連鎖で魚や鳥にたまる。そのため、水の中のセレンは少しでも生き物に害になる
