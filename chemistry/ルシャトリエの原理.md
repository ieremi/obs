# ルシャトリエの原理

**平衡**（右向きと左向きの反応が同時に起きて、つり合っている状態）にある反応に外から変化を加えると、**その変化をやわらげる向き**に平衡が移る、という原理。

## 変化と平衡の移る向き

| 加える変化 | 平衡が移る向き |
|---|---|
| ある物質を増やす | その物質が減る向き |
| ある物質を減らす（取り除く） | その物質が増える向き |
| 圧力を上げる（気体の反応） | 気体の分子の数が減る向き |
| 圧力を下げる（気体の反応） | 気体の分子の数が増える向き |
| 温度を上げる | 熱を吸収する向き（吸熱反応の向き） |
| 温度を下げる | 熱を出す向き（発熱反応の向き） |
| 触媒を加える | 移らない（平衡に達するまでの時間が短くなるだけ） |

以下の反応式で、ΔH は右向きに進んだときの反応熱。ΔH < 0 なら右向きが発熱、ΔH > 0 なら右向きが吸熱。

## 水垢まわりの例

### 加熱すると水垢ができる
$$\mathrm{Ca(HCO_3)_2 \rightleftharpoons CaCO_3 + H_2O + CO_2}$$

加熱すると CO₂ が水から逃げる。**CO₂ が減る → CO₂ が増える向き（右）に移る** → [[炭酸カルシウム]]ができる。[[電気ケトル]]に水垢が付きやすい理由。

### 炭酸カルシウムは熱い水ほど溶けにくい
$$\mathrm{CaCO_3 \rightleftharpoons Ca^{2+} + CO_3^{2-}} \qquad \Delta H < 0$$

炭酸カルシウムが水に溶けるときは、わずかに熱を出す。**温度を上げる → 熱を吸収する向き（左）に移る** → 溶けていたものが固体にもどる。砂糖や塩は溶けるときに熱を吸収するので、反対に熱い水ほどよく溶ける。

### 鍾乳洞と鍾乳石
$$\mathrm{CaCO_3 + H_2O + CO_2 \rightleftharpoons Ca(HCO_3)_2}$$

- 地下で：CO₂ を多く含む雨水が石灰岩に触れる。**CO₂ が多い → 右に移る** → 石灰岩が溶けて鍾乳洞ができる
- 洞窟の天井で：しみ出した水から CO₂ が空気中に逃げる。**CO₂ が減る → 左に移る** → 炭酸カルシウムが固まって鍾乳石になる

水垢ができるしくみと同じ反応を、逆向きに見たもの。

### 酸で水垢が溶ける
$$\mathrm{CaCO_3 \rightleftharpoons Ca^{2+} + CO_3^{2-}}$$
$$\mathrm{CO_3^{2-} + 2H^+ \rightarrow H_2O + CO_2}$$

[[クエン酸]]や[[酢]]の H⁺ が CO₃²⁻ と反応して、CO₃²⁻ を取り除く。**CO₃²⁻ が減る → CO₃²⁻ が増える向き（右）に移る** → 炭酸カルシウムがどんどん溶ける。

### 尿石ができる
$$\mathrm{CO(NH_2)_2 + H_2O \rightarrow 2NH_3 + CO_2}$$
$$\mathrm{NH_3 + H_2O \rightleftharpoons NH_4^+ + OH^-}$$
$$\mathrm{HPO_4^{2-} \rightleftharpoons H^+ + PO_4^{3-}}$$
$$\mathrm{3Ca^{2+} + 2PO_4^{3-} \rightarrow Ca_3(PO_4)_2}$$

細菌が尿素を分解してアンモニアができ、OH⁻ が増える（アルカリ性になる）。OH⁻ は H⁺ と反応して水になるので、**H⁺ が減る → H⁺ が増える向き（右）に移る** → PO₄³⁻ が増え、カルシウムと結びついて溶けないリン酸カルシウムになる。→ [[尿石]]

### 塩素系と酸性の洗剤をまぜると塩素ガスが出る
$$\mathrm{ClO^- + Cl^- + 2H^+ \rightleftharpoons Cl_2 + H_2O}$$

塩素系の洗剤には次亜塩素酸ナトリウム（ClO⁻）と塩化ナトリウム（Cl⁻）が入っていて、ふだんはアルカリ性に保たれ、H⁺ がほとんどないので左に片寄っている。酸性の洗剤を加えると、**H⁺ が増える → H⁺ が減る向き（右）に移る** → 塩素ガスが出る。→ [[まぜるな危険]]

## ほかの例

### 炭酸飲料の気が抜ける
$$\mathrm{CO_2(気体) \rightleftharpoons CO_2(水に溶けた状態)} \qquad \Delta H < 0$$

- ふたを開ける：容器の中の圧力が下がる。**圧力を下げる → 気体が増える向き（左）に移る** → 泡が出る
- 温まる：CO₂ が水に溶けるときは熱を出す。**温度を上げる → 熱を吸収する向き（左）に移る** → 気が抜ける

### アンモニアをつくる（ハーバー・ボッシュ法）
$$\mathrm{N_2 + 3H_2 \rightleftharpoons 2NH_3} \qquad \Delta H < 0$$

- 圧力を上げる：左は分子4個、右は2個。**圧力を上げる → 分子が減る向き（右）に移る** → アンモニアが増える
- 温度：低いほうが右に移るが、低すぎると反応がおそくなる。そこで 400〜500 ℃ くらいにして、触媒で反応を速くする

### 二酸化窒素の色が変わる
$$\mathrm{2NO_2(赤褐色) \rightleftharpoons N_2O_4(無色)} \qquad \Delta H < 0$$

- 温める：**熱を吸収する向き（左）に移る** → 赤褐色が濃くなる
- 冷やす：**熱を出す向き（右）に移る** → 色がうすくなる

### 食塩水に塩酸を加えると食塩が出てくる（共通イオン効果）
$$\mathrm{NaCl(固体) \rightleftharpoons Na^+ + Cl^-}$$

飽和した食塩水に塩酸（HCl）を加える。**Cl⁻ が増える → Cl⁻ が減る向き（左）に移る** → 溶けていた食塩が固体になって出てくる。
