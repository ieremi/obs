# 回転行列とクォータニオンの対応

**回転行列はベクトルへの作用を、単位クォータニオンは回転軸と角度を表しやすい。** 両者は同じ3次元回転を表現できる。

ここでは右手系・能動回転・列ベクトル・Hamilton積を用い、四元数の成分を $q=(w,x,y,z)$ の順で書く。$w^2+x^2+y^2+z^2=1$ とする。[[クォータニオン]]と同じ約束。

## 回転を作用させる

ベクトル $\boldsymbol v$ を純虚四元数 $p=(0,\boldsymbol v)$ にすると、

$$
p'=qpq^{-1}
$$

のベクトル部が回転後の $\boldsymbol v'$ になる。単位四元数では $q^{-1}=\bar q$。

これを成分で展開し、$\boldsymbol v'=R\boldsymbol v$ の形にまとめると、

$$
\boxed{R=\begin{pmatrix}
1-2(y^2+z^2)&2(xy-wz)&2(xz+wy)\\
2(xy+wz)&1-2(x^2+z^2)&2(yz-wx)\\
2(xz-wy)&2(yz+wx)&1-2(x^2+y^2)
\end{pmatrix}}
$$

この $R$ は $R^TR=I$、$\det R=1$ を満たし、長さと向きを保つ。

## 例：$z$ 軸の周りに90度

回転軸が $(0,0,1)$、角度が $\theta=\pi/2$ なら、

$$
q=\left(\cos\frac\theta2,0,0,\sin\frac\theta2\right)
=\left(\frac{\sqrt2}{2},0,0,\frac{\sqrt2}{2}\right)
$$

行列へ変換すると、

$$
R=\begin{pmatrix}0&-1&0\\1&0&0\\0&0&1\end{pmatrix},
\qquad R\begin{pmatrix}1\\0\\0\end{pmatrix}
=\begin{pmatrix}0\\1\\0\end{pmatrix}
$$

$x$ 軸方向が $y$ 軸方向へ回ることを確認できる。

## 合成と表現上の注意

先に $q_1$、次に $q_2$ で回すと、合成は $q_2q_1$。対応する行列も $R_2R_1$ になる。順序を逆にすると一般に違う回転になる。

$q$ と $-q$ は同じ行列を与える。四元数は符号が違っても同じ姿勢を表すため、補間や値の比較ではこの重複を考える。

[[pitch・yaw・roll]]は3角で表すが、回転順序の指定が必要で、特定の姿勢で[[ジンバルロック]]が生じる。四元数からオイラー角に戻すと、その角度表現の特異性は再び現れる。

## 実装で確認する

SciPyは既定で $(x,y,z,w)$ 順。ここでの順序を使うには `scalar_first=True` を指定する。

```python
import numpy as np
from scipy.spatial.transform import Rotation
q = [np.sqrt(0.5), 0, 0, np.sqrt(0.5)]
r = Rotation.from_quat(q, scalar_first=True)
print(r.as_matrix())
print(r.apply([1, 0, 0]))  # およそ [0, 1, 0]
```
