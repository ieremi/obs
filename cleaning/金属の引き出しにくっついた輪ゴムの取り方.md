# 金属の引き出しにくっついた輪ゴムの取り方

**まずプラスチックのヘラなどで取れる分をそっと取り、残りは表面の仕上げに合わせて落とす。アルコールが使える面なら、布に少量付けて少しずつ拭く方法がある。**

金属の引き出しでも、表面に塗装や透明なコーティングがあることが多い。「金属だから溶剤を使ってよい」とは判断せず、取扱説明書のお手入れ方法を優先する。

## 作業手順

以下は、輪ゴムメーカーの除去方法と家具メーカーの手入れ方法を組み合わせた、表面を傷めにくくするための手順。

1. **中身を出し、塊を取る。** プラスチックのヘラや不要なプラスチックカードを寝かせ、軽い力で少しずつすくう。引っかかる場合は無理に削らない。ベタつきを広げないよう、取れたゴムはその都度紙に移す。
2. **薄めた中性洗剤で拭く。** 柔らかい布を浸して固く絞り、残りを軽く拭く。これだけでは劣化したゴムが落ちない場合もある。
3. **残ったら、アルコールの使用可否を確認する。** 家具の説明書で禁止されている場合や、塗装の種類が不明な場合は、ここで止めてメーカーに相談する。
4. **使用可能な面でのみ、目立たない場所で試す。** エタノールを使い捨ての布や綿棒に少量付けて軽く拭き、乾いてから変色・つやの変化・塗装の軟化がないか確認する。布に塗装の色が付いたら中止する。
5. **異常がなければ、ゴムの部分を少しずつ拭き取る。** 引き出しに直接液を注がず、布のきれいな面に替えながら作業する。換気し、火気を避ける。
6. **仕上げに固く絞った布で水拭きし、乾拭きする。** 洗剤や水分を残さず、隅や継ぎ目も乾かす。

輪ゴムメーカーの共和は、劣化して付着した輪ゴムにアルコールなどの溶剤を案内しているが、対象物の変色のおそれがあるため少量での事前確認を求めている。[出典：オーバンド公式 Q4](https://oband.jp/post-2047)

家具の日常清掃では、薄めた中性洗剤・水拭き・乾拭きが案内されている。ただし製品や仕上げによって使える薬剤は異なる。[出典：コクヨ取扱説明書・お手入れ](https://www.kokuyo.com/sites/default/files/assets/pdf/support/manual-furniture/ing.pdf)

## 避けたい方法

- **カッター・金属ヘラで削る**：塗装や金属表面を傷つけやすい。
- **除光液・アセトン・シンナーを最初から使う**：ゴムだけでなく塗装を傷めるおそれがある。輪ゴムに効くことと、引き出しに使えることは別。
- **シールはがしを無条件で使う**：塗装された金属面を傷める製品もある。使用できる素材と注意書きを確認する。

オカムラは家具の手入れでシンナー・ベンジン等の有機溶剤を避けるよう案内している。セメダインも、シールはがしが塗装金属面などの下地を傷める場合があると説明している。[出典：オカムラ](https://www.okamura.com/daily-care-instructions/)、[セメダイン](https://www.cemedine.co.jp/home/products/remover/sticker_remover.html)

## ベタつきは取れたのに跡が残る場合

ゴムの残りではなく、表面の変色や塗装の損傷の可能性もある。手触りがさらさらになっているなら、強くこすったり溶剤を追加したりせず、表面の状態を確認する。

## 化学的機序

**輪ゴムがベタつく過程は主に高分子の酸化劣化、引き出しへの付着は界面での接着、拭き取りは溶媒の作用と機械的な除去として分けると理解しやすい。** 以下は一般的な天然ゴム製の輪ゴムを想定した説明で、今回の付着物を分析して原因を確定したものではない。

### 1. なぜ「溶けた」ようになるのか

天然ゴムの主成分は **cis-1,4-ポリイソプレン**。長い分子鎖を硫黄などで架橋し、網目状にすることで、伸ばしても戻るゴムの性質を持たせている。

空気中の酸素と熱・光などの影響で酸化が進むと、分子鎖の切断と、新たな架橋の形成などが競合する。**鎖の切断や有効な網目の減少が優勢なら、弾性や凝集力が低下し、軟化して粘つく方向に進む。** 逆に架橋の増加などが優勢なら、硬化・ひび割れが起こり得る。「劣化したゴムは必ず液状になる」わけではない。

これは、氷が水になるような単純な融解とは違い、**分子構造が変わる不可逆な劣化**である。また、天然ゴムのこの現象を、ウレタン樹脂などで起こる加水分解と一律に同じ機序と考えない。[出典：労働安全衛生総合研究所・天然ゴム絶縁材料の熱劣化](https://www.jniosh.johas.go.jp/publication/doc/rr/RR-91-11.pdf)、[ポリイソプレン加硫ゴムの酸化実験](https://doi.org/10.2324/gomu.42.199)

酸化の代表的なラジカル連鎖を簡略化すると、次のように表せる。`RH` はゴム鎖中の水素を持つ部位、`・` は不対電子を表す。

```text
開始：        RH → R・                  （開始過程を簡略化）
酸素の付加：  R・ + O₂ → ROO・
連鎖の進行：  ROO・ + RH → ROOH + R・
過酸化物分解：ROOH → ラジカル生成 → 鎖切断・架橋など
```

二重結合に隣接する部位などで反応が進み、ヒドロペルオキシド（ROOH）を経て、鎖切断やカルボニル基などの酸化生成物の形成につながる。上式は反応全体の概略であり、単一の反応経路ではない。[出典：日本ゴム協会誌「各種ゴムの劣化機構」](https://www.jstage.jst.go.jp/article/gomu1944/68/5/68_5_284/_pdf)

### 2. なぜ金属にくっつくのか

軟らかくなった残留物は、接触面の細かい凹凸に沿って広がりやすくなる。表面に十分接近すると、ファンデルワールス力などの分子間相互作用が働く。実際に接している相手は、裸の金属ではなく塗装や酸化皮膜の場合もある。

この付着は、**柔らかい残留物が表面を濡らして密着する**という接着の一般論で説明できる。「金属とゴムが化学反応して一体化した」と断定する必要はない。ただし今回の表面状態を測定していないため、どの相互作用が支配的かは不明。[出典：日本接着学会・物理的相互作用](https://www.adhesion.or.jp/plaza/plaza_992.html)

### 3. なぜアルコールで拭き取れる場合があるのか

共和は、付着した劣化輪ゴムをアルコールなどで除去する方法を案内している。ただし、**この案内は、エタノールが健全な加硫ゴム全体を完全に溶かすことや、化学分解することを示すものではない。** メーカーの案内には、除去の分子レベルの機序までは示されていない。[出典：オーバンド公式 Q4](https://oband.jp/post-2047)

一般に架橋された高分子は、相性のよい溶媒を吸って膨潤しても、網目全体がそのまま溶けて分散するとは限らない。一方、劣化残留物には、網目から外れた低分子成分や添加剤などが含まれ得る。

したがって拭き取りについては、**溶媒になじむ成分の溶出、表面・残留物への濡れ、布による剥離・回収が組み合わさる可能性がある**、という説明にとどめる。どの寄与が大きいかは、輪ゴムの配合・劣化状態・アルコール濃度によって変わり、今回の条件では未確認。溶媒による膨潤・抽出が材料ごとに異なることは、エラストマーの実験でも示されている。[出典：エラストマーの膨潤・抽出成分に関する研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7835956/)

中性洗剤は界面活性剤によって汚れの濡れや分散を助けるが、ゴム鎖を短時間で分解する薬剤ではない。ヘラや布は物理的に残留物を取り去る。溶剤が塗装樹脂にも作用すると、ゴムと一緒に塗膜を傷めることがあるため、除去力だけで薬剤を選ばない。

### 4. シンナーやアセトンで取れる機序

**主な作用は、残留物に溶媒が入り込み、可溶成分を溶かしたり、残ったゴムを膨潤させたりして、布で回収しやすくすること。通常の短時間の拭き取りで、ゴムの共有結合を切って分解する作用が中心とは考えない。** ただしアセトンとシンナーは、同じ組成・同じ溶解力の液体ではない。

#### 溶解と膨潤の違い

| 現象 | 分子レベルで起こること | 拭き取りとの関係 |
| --- | --- | --- |
| 溶解・抽出 | 残留物中の可溶な分子が溶媒に取り囲まれ、液中へ移る | 液を布に吸わせて回収できる |
| 膨潤 | 溶媒が架橋網目の中に入り、網目を広げる | 軟化・変形して、すくい取りや拭き取りがしやすくなる場合がある |
| 化学分解 | 主鎖や架橋の共有結合が切れ、別の分子構造になる | 経年劣化では重要だが、溶剤洗浄の説明とは区別する |

架橋が残る部分は、良溶媒でも網目に束縛されるため、全体が自由な分子として溶け出すことはできない。一方、劣化で網目から切り離された鎖や添加剤は、溶媒との相性に応じて液中へ移り得る。天然ゴム加硫物の研究でも、**アセトンによる配合剤等の抽出**と、**トルエンによる網目の膨潤**は異なる操作として用いられている。[出典：天然ゴム加硫物の精製・膨潤測定](https://doi.org/10.1016/j.polymer.2021.124271)

#### シンナー：配合された溶剤が、それぞれの成分に作用する

「シンナー」は特定の一つの化合物名ではなく、塗料の希釈などに使う溶剤製品の呼び名。例えばトルエン・酢酸エチルを含むラッカー用シンナーがある一方、トルエンを配合しない製品もある。**シンナーという名称だけでは、何がどれほど溶けるかは決められない。** [出典：東工薬・製品成分](https://www.toukouyaku.co.jp/product-list/%E3%83%A9%E3%83%83%E3%82%AB%E3%83%BC%E7%94%A8%E3%82%B7%E3%83%B3%E3%83%8A%E3%83%BC%E3%80%90%E7%89%B9%E5%AE%9A%E8%A3%BD%E5%93%81%E3%80%91)、[アサヒペン・うすめ液一覧](https://www.asahipen.jp/products/category/genre/1/large/21)

トルエンのように天然ゴムと相性のよい溶媒は、ゴム鎖の間へ入り込む。未架橋の可溶な鎖なら溶解し、架橋された部分なら膨潤する。実際に天然ゴムの架橋密度の評価にはトルエンでの膨潤が利用される。[出典：天然ゴムの膨潤測定](https://journal.polymer-korea.or.kr/journal/pdf/04404/PK_2020_044_04_519.pdf)

分子間力の観点では、ゴム同士・溶媒同士の接触の一部を、ゴムと溶媒の接触に置き換えてもエネルギー的に不利になりにくい組合せほど混ざりやすい。「似たものは溶けやすい」という目安は、この相互作用の相性を簡略化したもの。架橋ゴムでは、混ざろうとする作用に網目の弾性的な復元力が対抗し、有限の膨潤にとどまる。

#### アセトン：天然ゴム全体をよく溶かす、と説明しない

アセトンはカルボニル基を持つ極性溶媒。**炭化水素主体の天然ゴム本体に対する作用を、トルエンと同一視しない。** 研究では、アセトンを用いて未反応配合剤やその断片を抽出した後も天然ゴムの架橋試料が残り、別途トルエンで膨潤測定されている。[出典：天然ゴム加硫物の精製](https://doi.org/10.1016/j.polymer.2021.124271)

劣化した輪ゴムの除去では、**アセトンに溶ける添加剤や劣化生成物などを溶出させ、残留物を拭き取りやすくする寄与**が考えられる。酸化で極性基が増えた成分は、未劣化のゴムと溶媒への親和性が異なる可能性もある。ただし、これは一般的な性質からの推論で、今回の残留物で主成分や作用を測定した結果ではない。共和の除去案内はアセトンの使用例を示すが、効く分子成分までは特定していない。[出典：オーバンド公式 Q4](https://oband.jp/post-2047)

#### なぜ塗装まで取れるのか

引き出しの塗膜も高分子を含むため、その樹脂と溶媒の相性がよければ、溶解・膨潤・成分の抽出が起こり得る。その結果、軟化、つやの変化、色移り、剥離につながる。**溶媒は「輪ゴムだけ」を選んで作用するわけではない。** ラッカーうすめ液メーカーも、拭き取り時に素材を傷める場合があると注意している。[出典：アサヒペン・ラッカーうすめ液](https://www.asahipen.jp/products/view/02993)
