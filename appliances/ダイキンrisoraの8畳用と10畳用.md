# ダイキンrisoraの8畳用と10畳用

確認日：**2026年11月20日**。2026年モデルのSXシリーズ、**8畳用 S256ATSSと10畳用 S286ATSS**を比較する。色・パネルの仕様によって末尾の型番が変わる。

**10畳用は定格能力が大きいが、最大能力の差は冷房・暖房とも0.2 kWにとどまる。8畳用で必要な冷暖房負荷を満たせるなら、10畳用へ上げたときの最大能力の上積みは小さい。** ただし、最大能力が近いことだけで、どちらでも同じ部屋に適するとは判断しない。

## 公式仕様の比較

| 項目 | 8畳用 S256ATSS | 10畳用 S286ATSS |
| --- | ---: | ---: |
| 定格冷房能力 | 2.5 kW | 2.8 kW |
| 冷房能力の範囲 | 0.6〜3.1 kW | 0.6〜3.3 kW |
| 定格冷房消費電力 | 650 W | 730 W |
| 冷房消費電力の範囲 | 130〜910 W | 130〜940 W |
| 定格暖房能力 | 2.8 kW | 3.6 kW |
| 暖房能力の範囲 | 0.7〜4.6 kW | 0.7〜4.8 kW |
| 定格暖房消費電力 | 590 W | 870 W |
| 暖房消費電力の範囲 | 130〜1,360 W | 140〜1,410 W |
| 通年エネルギー消費効率（APF） | 5.9 | 5.7 |
| 2027年度目標省エネ基準達成率 | 89% | 86% |

出典：[ダイキン公式・risoraスペック表（2026年3月25日表記）](https://www.ac.daikin.co.jp/-/media/Project/Daikin/ac_daikin_co_jp/theartline/spec/assets/pdf/202603/risora_spec-pdf.pdf)。括弧内に掲載されている最小〜最大値を、上表では範囲として分けて記載した。

## 能力差をどう読むか

公式値から差を計算すると、次のようになる。

| 比較 | 8畳用 → 10畳用の増加 |
| --- | ---: |
| 定格冷房能力 | 0.3 kW、12% |
| 最大冷房能力 | 0.2 kW、約6.5% |
| 定格暖房能力 | 0.8 kW、約29% |
| 最大暖房能力 | 0.2 kW、約4.3% |

**特に暖房は、定格値の差ほど最大値の差は大きくない。** 「8畳から10畳だから、どの条件でも能力が25%増える」という関係ではない。

一方、最大能力は所定の試験条件での数値であり、冬の低外気温時や霜取りを含む運転のすべてを表すものではない。暖房を重視するなら、低温暖房能力も含めて設置店に確認する。能力の範囲が近いことから、コンプレッサーや熱交換器などの内部部品が完全に同じとも断定できない。

畳数表示についても、ダイキンは部屋の条件を考慮した冷暖房負荷計算が必要と案内している。[出典：公式仕様ページの注記](https://www.ac.daikin.co.jp/kabekake/products/sx_series/feature/spec)

## 電気代はどちらが安いか

APFは8畳用が5.9、10畳用が5.7。ただし、**定格消費電力の差を、そのまま同じ部屋で使ったときの電気代差にはできない。** インバーター機は必要な能力に応じて出力を変えるため、部屋の断熱・日射・設定温度・運転時間で実際の消費電力が変わる。

APFも各機種の所定の条件で算出される指標で、同じ部屋の年間電気代がこの比率どおりになるとは限らない。見方は [[APF]] を参照。

## 選び方

- **8畳用で負荷を満たせる部屋**：価格差と能力差を考え、8畳用を候補にする。
- **10畳程度の部屋や、西日・最上階・大きな窓などで負荷が大きい部屋**：10畳用を含めて必要能力を確認する。畳数だけで機種を決めない。
- **8畳用では冷房能力が大幅に不足しそうな部屋**：10畳用でも最大冷房能力は約6.5%増なので、それだけで不足を解消できるか負荷計算で確認する。

設置寸法については、既存の [[エアコン8畳用4機種のサイズ比較]] に8畳用の寸法を記載している。買い替え時は本体サイズに加え、吸排気・配管・施工に必要な空間を施工店に確認する。
