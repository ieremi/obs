# 青空文庫への参加方法

青空文庫は、著作権の切れた作品などを、ボランティアがテキストにして無料で公開するインターネットの電子図書館。作業するボランティアを **工作員** と呼ぶ。

参加のしかたは大きく 4 つある。

| 方法 | 内容 |
| --- | --- |
| **入力** | 本を見て本文をテキストにする |
| **校正** | 入力されたテキストを底本と照らし合わせて直す |
| **寄付** | 運営を支える |
| **作品の提供** | 著作権者や翻訳者が、自分の作品の収録を申し込む |

1 つの作品を公開するまでに、入力者と校正者の **少なくとも 2 人** が関わる。

## 収録できる作品
- 原則は **著作権の切れた作品**
- 著作権の保護期間は、2018 年末まで **死後 50 年**、いまは **死後 70 年**。2018 年末までに切れたものは、そのまま切れている
- 著作者の没年が **1967 年（昭和 42 年）以前** なら、著作権は切れている
- 1968 年以降に亡くなった著作者の作品は、延長のため切れるのが 20 年遅くなった。たとえば 1968 年没なら 2039 年に切れる
- **翻訳** には、翻訳者に別の著作権がある。原作者の著作権が切れていても、訳者の著作権が残っていれば収録できない
- 挿絵は、描いた人の没年が 1967 年以前なら切れているとみる。写真は、1956 年 12 月 31 日までに発行されたものは権利が消えている
- 著作権が残っている作品は、著作権者から自分で申し出がない限り収録しない。青空文庫から著作権者に公開を頼むこともしない

参考：[著作権が消滅した作家一覧](https://www.aozora.gr.jp/siryo1.html)

## 入力

### 流れ
1. **作品を選ぶ**：作者の没年を確かめる。総合インデックスの「公開中の作品」と「作業中の作品」を見て、ほかの人と重なっていないか確かめる
2. **底本を用意する**：手元の本でも、図書館の本でもよい
3. **入力を申し込む**：[作業着手連絡システム](https://reception.aozora.gr.jp)の [入力受付](https://reception.aozora.gr.jp/accept.php) から申し込む。点検の担当が、著作権の状況と底本を確かめる
4. **入力する**：下の「ファイルの形式」と「注記の規則」に従う
5. **自分で校正する**：原稿（底本）と突き合わせる校正と、素読み（文章だけを読む）の 2 段階
6. **送る**：ファイルを zip などに圧縮して、`reception@aozora.gr.jp` へメールで送る。件名と本文に著者と作品名を書く

### 注意
- 1 人が同時に作業中にできる作品は **200 以下**
- 作業を続けられなくなったら、`reception@aozora.gr.jp` に連絡する
- 長く止まったままの作業中の作品を引き継ぎたいときも、同じあてに申し出る

### ファイルの形式
- 文字コードは **Shift_JIS**、改行は **CR+LF**
- 使える文字は JIS X 0201 と JIS X 0208 の範囲だけ
- ファイル名は作品名をローマ字（小文字）にしたもの＋ `.txt`
- 1 行目に作品名、2 行目に著者名、必要なら訳者名など。空行のあとに本文
- 本文のあと 3 行あけて、**底本の正式な書名・出版社・発行年月日** と **入力者名** を書く
- 範囲外の文字が混ざっていないかを、「チェッカー君」で確かめる

## 校正

### 流れ
1. **作品を選んで申し込む**：作業着手連絡システムの [校正受付](https://reception.aozora.gr.jp/at_work.html) から申し込む
2. **底本を用意する**：なるべく自分で用意する。入力に使った底本と同じ版か、それより後の刷りがよい
3. **校正する**：基本は **底本どおり**。目安は、底本との突き合わせ 2 回と素読み 1 回。終わったら一晩おいて見直すとよい
4. **送る**：直したファイルと、どこをどう直したかを書いた **作業履歴**（形式は自由）を圧縮して、`reception@aozora.gr.jp` へ送る。直すところがなかったときも、そう書いて送る

- 1 人が同時に校正中にできる作品は **100 以下**
- 道具として、新字・旧字の混在などを調べる「校閲君」がある

## 注記の規則
青空文庫のテキストは、ふつうの文字だけで書く。ルビや字下げなどは記号で表す。

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `《》` | ルビ | `学校《がっこう》` |
| `｜` | ルビをふる範囲の始まり | `｜青空文庫《あおぞらぶんこ》` |
| `［＃…］` | 注記 | `［＃３字下げ］` |
| `［＃「…」は中見出し］` | 見出し（大・中・小） | `［＃「第一章」は中見出し］` |
| `［＃改ページ］` | 改ページ | |
| `［＃「…」に傍点］` | 傍点 | |
| `※［＃…］` | JIS X 0208 にない字（外字） | |
| `［＃「…」は底本では「…」］` | 底本の誤りを直した | |
| `［＃「…」はママ］` | 誤りに見えるが底本のまま | |

- ルビの小さい「ゃ・ゅ・っ」などは、原則として小書きする。ただし旧かなの作品では小書きしない
- **旧字・旧かな** は原則として底本どおりにする。新字・新かなに直すのは、決められた作業指針に沿う場合だけ
- 外字の書き方は、外字注記辞書で調べる

## 寄付
青空文庫のトップページから、寄付の受付先（本の未来基金）へ進める。

## 著作権者が作品を提供する
- **著作者・著作権を継いだ人**：すでに本として出た作品に限り、収録を申し込める。書き下ろしは受け付けない
- **翻訳者**：自分の翻訳の収録や、リンクの登録を申し込める
- いずれも **クリエイティブ・コモンズ・ライセンス** を付ける必要がある。ファイルは原則として申し込む人が用意する
- 連絡先は `reception@aozora.gr.jp`

## はじめるには
1. [作業マニュアル](https://www.aozora.gr.jp/aozora-manual/)の入力編と校正編を読む
2. まず **校正** から入るとやりやすい。注記の規則に慣れられ、すでにあるファイルを直すだけで済む
3. 短い作品を 1 つ選んで申し込む
