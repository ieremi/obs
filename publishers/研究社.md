# 研究社

英語の辞書・参考書・英語学・英米文学の出版社。

## 会社概要

| 項目 | 内容 |
|---|---|
| 社名 | 株式会社研究社 |
| 創業 | 1907年。創業時は「英語研究社」、創業者は小酒井五一郎 |
| 所在地 | 東京都千代田区富士見2-11-3 |
| 代表者 | 吉田尚志 |
| 資本金 | 100,000,000 JPY |
| 事業 | 英和・和英辞典、英語学・英語教育、英米文学、実用英語、日本語教材。電子書籍・オンライン辞書 |

## 沿革

| 年 | 出来事 |
|---|---|
| 1907 | 英語研究社として創業 |
| 1916 | 研究社に改称 |
| 1927 | 新英和大辞典 |
| 1967 | 新英和中辞典 初版 |
