# 囲碁用語のカタカナ表記

囲碁の用語は、**セキ・コウ・アタリ・ハネ・ツケ・ケイマ** のように、カタカナで書くのがふつう。一方で、**布石・定石・手筋・死活・地・目・星・先手** のように、漢字で書く用語もある。

カタカナ書きの理由を、はっきり定めた規則や公式の説明は見つからなかった。以下は、**表記の傾向から考えられる理由**の整理で、確かめられた定説ではない。

## カタカナで書く用語と漢字で書く用語

| カタカナで書く | もとの言葉・あてうる漢字 | 種類 |
| --- | --- | --- |
| ハネ・ツケ・ノビ・キリ・ツギ・オサエ・トビ・ノゾキ・ワタリ | 跳ね・付け・伸び・切り・継ぎ・押さえ・飛び・覗き・渡り | 和語の動詞の名詞形（手の名前） |
| カカリ・シマリ・ハサミ | 掛かり・締まり・挟み | 同上 |
| アタリ・ダメ | 当たり・駄目 | 和語・ふつうの言葉と同じ形 |
| ケイマ | 桂馬 | 将棋の駒の名前の借用 |
| シチョウ | 征・四丁・止長など、あて字がまちまち | 語源がはっきりしない |
| セキ | 関・持 | |
| コウ | 劫 | 仏教の言葉（きわめて長い時間）の借用 |

| 漢字で書く | 種類 |
| --- | --- |
| 布石・定石・手筋・死活・形勢・終局・整地 | 漢語 |
| 地・目・星・小目・三々・天元 | 盤の点や数え方の名前 |
| 先手・後手・手抜き・置き碁・互先 | 対局のしかた |

**傾向**：**漢語や盤の点の名前は漢字**、**石の打ち方（手）の名前になる和語はカタカナ**。

## 考えられる理由

### 1. ふつうの言葉と区別する
- 手の名前の多くは、「はねる」「つける」「のびる」「きる」といった **ふつうの動詞** の名詞形。漢字で「切り」「付け」と書くと、文の中で、ふつうの意味なのか、囲碁の手の名前なのか、区別がつきにくい
- カタカナで書くと、**「ここは囲碁の専門用語」** と目で分かる。動植物の名前を学術的な文ではカタカナで書く（イヌ、サクラ）のと似た使い方
- 例：「黒が切りにくる」より「黒がキリにくる」のほうが、手の名前だとはっきりする

### 2. 決まった漢字がない・漢字が難しい
- **シチョウ** にはいくつものあて字があり、どれが正しいとも言えない
- **セキ** は「関」とも「持」とも書かれてきた
- **コウ** の「劫」は、ふだん使わない字で、読みにくい。戦後の当用漢字表（1946 年）や、いまの常用漢字表にも入っていない。新聞では、表にない字はかなで書くのがふつうなので、カタカナが定着しやすかったと考えられる（ただし、囲碁用語が新聞の用字の規則でカタカナになったという記録は確認できなかった）
- 漢字を決めにくい言葉は、音だけを表すカタカナで書くのがいちばん無難

### 3. 盤の上の動きを短く書く
- 棋譜の解説では、「黒 1 のハネに白 2 とノビ、黒 3 とキリ…」のように、手の名前が次々に出てくる。カタカナは画数が少なく、ひらがなの文の中で **区切りが目立つ** ので読みやすい

### 4. 中国・韓国と用語が違う
- 漢字で書いても、中国語の囲碁用語とは一致しない。たとえば、
  - コウ → 中国語でも「劫」
  - セキ → 中国語では「双活」
  - シチョウ → 中国語では「征子」
  - アタリ → 中国語では「打吃」
- 日本の用語の多くは、日本で生まれた和語なので、漢字で書く利点が小さい

## 囲碁から広まった言葉

囲碁の用語がふつうの日本語になったものは、カタカナ書きをやめて、ひらがなや漢字で書かれる。

| 囲碁の用語 | ふつうの言葉 |
| --- | --- |
| ダメ（どちらの地にもならない点） | 駄目・だめ |
| 布石 | 布石を打つ（将来のための準備） |
| 定石 | 定石どおり（決まったやり方） |
| 一目置く | 一目置く（相手を認める） |
| 駄目押し | 駄目押し（念を入れる） |
| 八百長 | 八百長（囲碁の相手をした八百屋の長兵衛から、という説がある） |

## 押さえどころ
- 囲碁用語のカタカナ書きは **慣習** で、規則で決まっているわけではない。日本棋院の出版物や新聞の囲碁欄の書き方が、事実上の基準になっている
- 和語の手の名前はカタカナ、漢語や点の名前は漢字、という使い分けが基本
- はっきりした歴史（いつから、なぜカタカナになったか）は、調べた範囲では見つからなかった。江戸時代の棋書の書き方を調べれば分かる可能性がある
