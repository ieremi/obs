# 囲碁の定石のリスト

**定石** は、隅（すみ）の打ち方で、**双方にとって損のない、決まった手順**。長い間に打ち比べられて、互角とされてきた。ただし、定石どおりに打っても、周りの石の配置によっては片方が悪くなるので、**盤全体に合わせて選ぶ** のが大事。

隅の最初の石の位置で分ける。位置は「辺から何本目の線か」を2つ並べてよぶ（例：3 の 4 は、片方の辺から 3 本目、もう片方から 4 本目）。

| 位置 | 名前 | 性格 |
| --- | --- | --- |
| 3 の 3 | **三々** | 1 手で隅の地を確保する。外への働きは小さい |
| 3 の 4 | **小目** | 地と外の両方にバランスがよい。昔からの主流 |
| 4 の 4 | **星** | 外への働きが大きく、速い。隅の地は三々に入られうる |
| 3 の 5 | **目外し** | 辺を重視。相手に小目へかからせて外を取る |
| 4 の 5 | **高目** | 中央を重視 |
| 5 の 5 | **五の五** | さらに中央向き。まれ |

## 用語

| 用語 | 意味 |
| --- | --- |
| **カカリ** | 相手の隅の石に、近づいて打つ手。隅を独り占めさせない |
| **シマリ** | 自分の隅の石に、もう 1 手加えて隅を固める手 |
| **ハサミ** | 相手のカカリの石を、辺の側からはさむ手 |
| **受け** | カカリに対して、自分の隅を守る手 |
| **ツケ** | 相手の石にくっつけて打つ手 |
| **ハネ** | 相手の石の斜め先に打って、行く手をさえぎる手 |
| 小ゲイマ・一間・大ゲイマ・二間 | 石と石の距離。将棋の桂馬の動き（小ゲイマ）、1 つあけて一直線（一間）、など |
| 高・低 | 4 線（高い）か 3 線（低い）か |

用語をカタカナで書くわけは、[[囲碁用語のカタカナ表記]]。

## 星の定石

### カカリへの受け
- **小ゲイマガカリ → 一間トビ受け**：もっとも基本。カカった側は三々にスベるか、辺に開く
- **小ゲイマガカリ → 小ゲイマ受け**：地に辛い
- **小ゲイマガカリ → 大ゲイマ受け**：広いが、隙もある
- **小ゲイマガカリ → コスミ**：AI 以降によく打たれる。カカリの石を辺へ追いやる
- **ツケノビ定石**：カカリの石の上にツケて、ハネにノビる。簡明に隅の地を確保する
- **一間高ガカリ**・**大ゲイマガカリ**：カカリの別の形

### ハサミ
- 小ゲイマガカリに対して、**一間高・一間低・二間高・二間低・三間高・三間低** バサミ
- ハサまれた側は、**三々に入る**、**両ガカリ**（反対側にもカカる）、**トビ** で中央へ出る、などで応じる

### 三々入り
- 星の隅に、相手が **直接三々に入る** 手。隅の地を取る代わりに、星の側に外の厚みを与える
- かつては、序盤の早い三々入りは「相手を厚くするだけ」と嫌われた
- **AI（2016 年以降の囲碁 AI）が序盤から早い三々入りを打ち**、評価が一変した。いまはプロの対局でも、序盤の数手目で三々に入るのがふつう
- 受け方（どちらからオサエるか、ハネを続けるか）で、多くの変化がある

### 両ガカリ
- 星の両側からカカる。隅の石は、どちらか片方にツケるなどして対応する

## 小目の定石

### 小ゲイマガカリ
- **一間低バサミ・一間高バサミ・二間高バサミ・三間バサミ**：ハサミの定石
- **下ツケ（ツケ引き）**：カカリの石の下にツケて、引く。簡明
- **ケイマに受ける**・**一間に受ける**：隅を守る
- **大斜**（たいしゃ）：小ゲイマガカリの石に、**大ゲイマにカケる** 手から始まる。19 世紀前半から打たれ、変化が数百あるといわれる（**大斜百変**）。シチョウの有無で結論が変わる
- **なだれ**：小ゲイマガカリから、ツケ・ハネのあと、相手の 2 つの石に沿って押していく形。石が雪崩のように並ぶのが名前の由来。**大なだれ**・**小なだれ** がある。1927 年に木谷實が研究を始め、1957 年に呉清源が高川格との対局で打った新手から、研究が一気に進んだ

### 一間高ガカリ
- **下ツケ（ツケ引き）**：もっとも基本
- **一間低バサミ・二間高バサミ** など
- **村正の妖刀**：一間高ガカリに **二間高バサミ** した形から生じる。変化が多く、うかつに使うと自分が斬られる（妖刀村正）のが名前の由来。1928 年に久保松勝喜代が初めて打ったとされる

### 大ゲイマガカリ
- 小目に、大ゲイマの位置からカカる。辺を重視したカカリ

### シマリ
- **小ゲイマシマリ**：もっとも固い
- **一間シマリ**：中央にやや強い
- **大ゲイマシマリ**：広いが、隅の守りが薄い

## そのほかの隅

| 隅の石 | 主な定石 |
| --- | --- |
| **三々** | **肩ツキ**（三々の石の斜め上に打ち、低くおさえこむ）、カカリ |
| **目外し** | 相手が **小目にカカる** のが基本。目外しの側は、カケて外の厚みを取るか、大ゲイマに受けて辺を取る。**高目にカカる** 手もある |
| **高目** | 相手が **小目にカカる**、**三々に入る** のが基本。高目の側は、ツケて外を取る |
| **五の五** | 定石はあまり決まっていない。三々や小目に入られる |

## 三大難解定石

| 定石 | 起こる形 | 特徴 |
| --- | --- | --- |
| **大斜** | 小目の小ゲイマガカリに、大ゲイマにカケる | もっとも古い。変化が数百（大斜百変） |
| **なだれ** | 小目の小ゲイマガカリから、ツケ・ハネのあと押していく | 20 世紀に研究が進み、大斜と並ぶ複雑さ |
| **村正の妖刀** | 小目の一間高ガカリに、二間高バサミ | 変化が多く、読み切りにくい |

どれも、シチョウやコウの有無で結論が変わり、手順の途中でまちがえると大きく損をする。

## 定石の移り変わり
- **江戸時代**：小目が中心。本因坊秀策の「秀策のコスミ」（小目の隅で打つコスミ）などが有名（定石というより布石の一手）
- **1930 年代**：木谷實と呉清源の **新布石** で、星・三々・五の五など、中央を重んじる打ち方が広まった
- **2016 年以降**：囲碁 AI（AlphaGo など）の登場で、定石が大きく変わった
  - 星への **早い三々入り**、小ゲイマガカリへの **コスミ** など、かつて悪いとされた手がふつうになった
  - ハサミは減り、カカられたら手を抜いて別の場所に打つ（**手抜き**）ことも増えた
  - 大斜・なだれ・村正の妖刀のような複雑な定石は、AI の評価で「ほかの手のほうがよい」とされる場面が多く、打たれることが減った
