# 許文道

許文道（ホ・ムンド、허문도）は、韓国のジャーナリスト・政治家。全斗煥政権の有力者で、**1980 年の言論統廃合を主導した人物**として知られる。文化公報部次官、国土統一院長官などを歴任した。[東亜日報](https://www.donga.com/news/Politics/article/all/20160305/76830302/1)

## 経歴

| 年 | 出来事 |
| --- | --- |
| 1940 | 慶尚南道固城に生まれる。釜山高校・ソウル大学で学び、朝鮮日報の記者になる |
| 1979 | 駐日韓国大使館の公報官に就任 |
| 1980 | 新軍部に登用され、中央情報部や大統領秘書室などで活動。言論統廃合の計画を推進 |
| 1981 | 大規模な文化行事「国風81」を企画 |
| 1982 | 文化公報部次官に就任 |
| 1986 | 国土統一院長官に就任 |
| 1989 | 第五共和国の不正を調べる国会聴聞会で、言論統廃合について追及される |
| 2016 | 3 月 5 日、76 歳で死去 |

経歴は[東亜日報の訃報](https://www.donga.com/news/Politics/article/all/20160305/76830302/1)に基づく。

## 言論統廃合

1980 年、新軍部による新聞・放送・通信各社の強制的な再編を主導した。言論人の大量解職にも関与し、全斗煥政権の言論統制を担った。この役割から「全斗煥政権のゲッベルス」と批判された。[東亜日報](https://www.donga.com/news/Politics/article/all/20160305/76830302/1)

国会聴聞会でも、言論統廃合は正しい措置だったという立場を維持した。[聯合ニュース](https://www.yna.co.kr/view/AKR20211123082500001)

## 国風81と「三許」

- **国風81**：1981 年に企画した文化行事。聯合ニュースは、光州民主化運動の 1 周年をめぐる世論を鎮める意図があったと説明している。
- **三許（쓰리 허）**：[[許和平]]・[[許三守]]・許文道の 3 人を指す呼称。全斗煥政権の実力者として知られた。許文道は記者出身で、軍人出身の他の 2 人とは経歴が異なる。
