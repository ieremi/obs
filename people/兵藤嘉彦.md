# 兵藤嘉彦

**兵藤嘉彦**（ひょうどう よしひこ、ハンドル名 **c.mos**）は、日本のプログラマー。MS-DOS 用テキストエディタ **VZ Editor** の開発者として知られる。[インタビュー](https://retropcnews.com/archives/5700)

## EZ Editor と VZ Editor

- **EZ Editor**：自身の開発に使うエディタとして作り始めた製品。1987年に PCワールド・ジャパンから発売された。[インタビュー](https://retropcnews.com/archives/5700)、[＠IT](https://atmarkit.itmedia.co.jp/ait/spv/2510/23/news005.html)
- **VZ Editor**：EZ を発展させ、1989年にビレッジセンターから発売された MS-DOS 用エディタ。高速な動作、常駐機能、キーカスタマイズ、マクロなどで知られる。[VZ の年表](https://mezala.la.coocan.jp/vz/history/chrono.html)、[＠IT](https://atmarkit.itmedia.co.jp/ait/spv/2510/23/news005.html)

VZ は当時の代表的な日本語対応エディタである MIFES と比較され、ユーザーによるマクロや解説書も数多く作られた。2024年には VZ Editor 1.6 のソースコードが公開された。[VZ Editor リポジトリ](https://github.com/vcraftjp/VZEditor)、[公開時の報道](https://www.itmedia.co.jp/pcuser/articles/2411/26/news198.html)
