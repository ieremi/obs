# Paul Adrien Maurice Dirac

イギリスの理論物理学者。量子力学の建設者の一人。

## 経歴

| 年 | 出来事 |
|---|---|
| 1902 | ブリストル生まれ |
| 1928 | Dirac 方程式（量子力学と特殊相対論を合わせた電子の波動方程式）を発表 |
| 1930 | 『量子力学の原理』（The Principles of Quantum Mechanics） |
| 1931 | 磁気単極子（モノポール）の理論。反電子（陽電子）の存在を予言 |
| 1932 | ケンブリッジ大学ルーカス教授（〜1969） |
| 1933 | ノーベル物理学賞（Schrödinger と共同受賞） |
| 1937 | 巨大数仮説 |
| 1971 | フロリダ州立大学へ。晩年をアメリカで過ごす |
| 1984 | タラハシーで死去 |

## 本

- [[ディラック現代物理学講義]]（訳：[[岡村浩]]、ちくま学芸文庫、2008）
- 一般相対性理論（訳：江沢洋、ちくま学芸文庫、2005）
- 物理学に生きて（Heisenberg、Bethe らとの共著、ちくま学芸文庫、2008）
