# 盧信永

盧信永（ノ・シニョン、노신영）は、韓国の外交官・政治家。全斗煥政権で**外務部長官・国家安全企画部長・国務総理**を歴任した。軍人が政権中枢を占めた第五共和国において、外交官出身の有力者だった。[朝鮮日報](https://www.chosun.com/site/data/html_dir/2019/10/22/2019102200258.html)

## 経歴

| 年 | 出来事 |
| --- | --- |
| 1930 | 平安南道江西に生まれる。のちに南へ移り、ソウル大学法学部で学ぶ |
| 1953 | 高等考試行政科に合格 |
| 1955 | 外務部に入り、外交官として活動 |
| 1980〜1982 | 外務部長官。日韓経済協力交渉などを担当 |
| 1982〜1985 | 国家安全企画部長 |
| 1985〜1987 | 国務総理 |
| 1987 | 朴鍾哲拷問致死事件の責任を受け、総理を辞任 |
| 1994〜2012 | ロッテ福祉財団理事長 |
| 2019 | 10 月 21 日に死去 |

出典：[聯合ニュース](https://www.yna.co.kr/view/AKR20191022002351001)、[朝鮮日報](https://www.chosun.com/site/data/html_dir/2019/10/22/2019102200258.html)。

## 外交・情報機関での活動

国家安全企画部長時代には、中国旅客機の韓国への不時着、大韓航空機撃墜事件、ラングーン爆弾テロ事件などに対応した。外交官として潘基文を引き立て、国務総理時代には儀典秘書官に登用したことでも知られる。[聯合ニュース](https://www.yna.co.kr/view/AKR20191022002351001)
