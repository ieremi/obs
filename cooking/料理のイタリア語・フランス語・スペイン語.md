# 料理のイタリア語・フランス語・スペイン語

日本のレストランやレシピでよく見る料理のことばを、言語ごとに、**つづり・読み・もとの意味** でまとめる。3 つともラテン語から生まれた言語（ロマンス語）なので、食材の名前がよく似ている。

- カタカナは、日本でよく書かれる形。もとの発音とちがうものは、（ ）に近い読みを書いた
- 名詞の **性**（男性・女性）は、イタリア語・スペイン語は語尾でだいたい分かる（-o は男性、-a は女性）。フランス語は覚えるしかない

- **イタリア語の latte は「牛乳」**。イタリアで「ラッテ」と頼むと、コーヒーではなく牛乳が出てくる。コーヒー入りは caffè latte（カッフェ・ラッテ）
- **pomodoro** は「金のりんご」（pomo d'oro）、**pomme de terre** は「大地のりんご」が語源
- **aceite**（油）・**azúcar**（砂糖）など、スペイン語には **アラビア語から来た語**（a- で始まるものが多い）がある。イスラーム支配の時代のなごり

### 料理のしかた

| 日本語 | イタリア語 | フランス語 | スペイン語 |

| 網焼き | alla griglia（アッラ・グリッリャ） | grillé（グリエ） | a la parrilla（ア・ラ・パリージャ） |
| 鉄板焼き | alla piastra | à la plancha | **a la plancha**（ア・ラ・プランチャ） |
| 揚げる | fritto（フリット） | frit（フリ） | frito（フリト） |

- 「〜風」の後ろは、女性名詞の「やり方」（maniera・mode・manera）が省かれた形なので、3 つとも女性の冠詞（la）を使う
- イタリア語の **ragù**（ミートソース）は、フランス語の **ragoût**（煮込み）から来た

### パスタの形と名前のもと

| **penne**（ペンネ） | 羽ペン |
| **farfalle**（ファルファッレ） | 蝶 |
| **orecchiette**（オレッキエッテ） | 小さな耳 |
| **vermicelli**（ヴェルミチェッリ） | 小さな虫 |

| **fusilli**（フジッリ） | 小さな紡錘（糸をつむぐ道具） |
| tagliatelle（タリアテッレ） | 切ったもの（tagliare ＝ 切る） |

- イタリア語の名詞は、複数形が -i・-e で終わる。spaghetti・penne・gnocchi は、もともと **複数形**

## フランス語

### コースの順
| 順 | フランス語 | 意味 |
| --- | --- | --- |
| 0 | **amuse-bouche**（アミューズ・ブーシュ） | 「口を楽しませるもの」。最初に出る一口の料理 |
| 1 | **hors-d'œuvre**（オードブル） | 前菜。「作品（œuvre）の外（hors）」。本来の料理の外のもの |
| 1 | **entrée**（アントレ） | **フランスでは前菜**（「入口」）。**アメリカ英語では主菜** の意味になるので注意 |
| 2 | **potage**（ポタージュ） | スープ全般。とろみのあるものに限らない |
| 3 | poisson（ポワソン） | 魚料理 |
| 4 | **plat principal**（プラ・プランシパル） | 主菜。viande（肉料理） |
| 5 | fromage（フロマージュ） | チーズ |
| 6 | **dessert**（デセール） | デザート。「食卓を片づける（desservir）」から |
| 7 | café（カフェ）、mignardises（ミニャルディーズ） | コーヒーと小さな菓子 |

- **menu**（ムニュ）は、フランスでは「**決まった値段のコース（定食）**」。料理の一覧表は **carte**（カルト）。「ア・ラ・カルト」（à la carte）は、一覧から 1 品ずつ選ぶこと
- **prix fixe**（プリ・フィクス）：「決まった値段」のコース

## 押さえどころ
- 3 つの言語は、どれもラテン語から生まれたので、**食材の名前がよく似ている**（vino・vin・vino、carne・viande・carne など）
- 「〜風」は、イタリア語 **alla**、フランス語 **à la**、スペイン語 **a la**
- イタリア語の **-ini・-etti・-elle** は「小さな」。パスタの名前の多くは、形にちなむ
- フランス語は、**コースの順** と **調理のことば**（ソテー、ムニエル、コンソメなど）が、日本の西洋料理にたくさん入っている
- スペイン語には、**アラビア語**（aceite・azúcar）や **ナワトル語**（tomate・chocolate）から来た食べもののことばがある
