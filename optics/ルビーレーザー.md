# ルビーレーザー

**人工のルビーを光らせて赤い光を出すレーザー。** 世界で最初に作られたレーザーでもある。

| 項目 | 内容 |
| --- | --- |
| 発明 | 1960 年 5 月 16 日、**セオドア・メイマン**（米国・ヒューズ研究所） |
| 光を出す物質 | 人工ルビー：**酸化アルミニウム（Al₂O₃）** に **クロムイオン（Cr³⁺）** を 0.05% ほど混ぜた結晶 |
| 波長 | **694.3 nm**（深い赤色） |
| 光らせ方 | **キセノンのフラッシュランプ** の強い光を当てる（メイマンの装置ではルビー棒にらせん状のランプを巻いた） |
| 発振のしかた | **パルス**（一瞬ずつ光る）。連続して光らせるのはむずかしい |
| 仕組み | **3 準位レーザー** |
| 効率 | ほかのレーザーよりかなり低い |

## 仕組み

1. フラッシュランプの光で、クロムイオンの電子が高いエネルギーの状態に上がる
2. 電子はすぐに、少し低くて長く留まれる状態（**準安定準位**）に移る
3. その状態の電子が、いちばん低い状態（**基底状態**）の電子より多くなる（**反転分布**）と、694.3 nm の光が増幅されてレーザー光になる

- 3 準位レーザーでは、光を出したあとの行き先が **基底状態**
- そのため、基底状態にある電子の **半分以上** を上の状態に上げないとレーザーにならない
- 強い光で光らせる必要があり、効率が低いのはこのため

## Q スイッチ

- 光を一気に出させて、とても短く強いパルスにする方法
- 1961 年に **ロバート・ヘルワース** が考え出した。それまでのルビーレーザーは、不規則なパルスがばらばらに出ていた
- Q スイッチを使うと、**ナノ秒**（10 億分の 1 秒）単位のパルスになる

## 使い道

### 皮膚科

**Q スイッチルビーレーザー** を使う。赤い光は **メラニン** によく吸収されるので、皮膚の色素だけを壊せる。

- **保険が使える病気**：
  - **太田母斑**
  - **異所性蒙古斑**
  - **外傷性色素沈着症**
  - **扁平母斑**
- **保険が使えないもの**：しみ（老人性色素斑）、入れ墨、アートメイク
- **主な合併症**：色素が抜けること（色素脱失）

### そのほか

- **ホログラフィー**：大きな肖像のホログラムを撮るのに使われる
- **距離計（レンジファインダー）**：1964 年ごろには軍用の距離計の標準になった。その後 10 年ほどで Nd:YAG レーザーに置きかわった
- **脱毛・入れ墨の除去**：広く使われたが、アレキサンドライトレーザーや Nd:YAG レーザーに置きかわりつつある

効率が低く、パルスをくり返す速さも遅いので、工業ではあまり使われない。
