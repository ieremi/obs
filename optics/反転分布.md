# 反転分布

**エネルギーの高い状態にある原子・分子の数が、低い状態にある数より多くなっていること。** ふつうの状態（熱平衡）とは上下の数が逆になっているので「反転」という。レーザーが光を増幅するには、反転分布が必要。

## ふつうの状態：ボルツマン分布

熱平衡では、高い状態（E₂）にある数 N₂ と低い状態（E₁）にある数 N₁ の比は次の式で決まる（**ボルツマン分布**）。

$$\frac{N_2}{N_1} = \frac{g_2}{g_1}\exp\left(-\frac{E_2-E_1}{kT}\right)$$

- k はボルツマン定数、T は温度、g₁・g₂ はそれぞれの状態の数（縮退度）
- 右辺の exp の部分はいつも 1 より小さいので、熱平衡では **上の状態のほうが少ない**
- 温度を上げると N₂ は増えるが、無限大の温度でようやく N₁ と同じになる。**熱平衡では反転しない**

### 数の例

| | 値 |
| --- | --- |
| 室温 | T ≈ 300 K、kT ≈ **0.026 eV** |
| 可視光（ν ≈ 5×10¹⁴ Hz）の光 1 個のエネルギー | ΔE ≈ **2.07 eV** |

ΔE が kT の 80 倍ほどもあるので、N₂/N₁ は e⁻⁸⁰ ≈ 10⁻³⁵ ほどになり、室温では上の状態にほとんど何もいない。

## なぜ反転分布が必要か

光が物質を通るとき、2 つのことが同時に起こる。

| 現象 | 何が起こるか | 起こる量 |
| --- | --- | --- |
| **吸収** | E₁ の原子が光を 1 個吸って E₂ に上がる。光が **減る** | N₁ に比例 |
| **誘導放出** | E₂ の原子が光に刺激されて、同じ向き・同じ位相の光をもう 1 個出して E₁ に落ちる。光が **増える** | N₂ に比例 |

アインシュタインは、1 個あたりの吸収と誘導放出の起こりやすさが同じであることを示した。そのため、光が増えるか減るかは N₁ と N₂ のどちらが多いかだけで決まる。

| 上下の数 | 光は |
| --- | --- |
| N₁ > N₂（ふつう） | 減る（吸収される） |
| N₁ = N₂ | 変わらない（透明） |
| **N₂ > N₁（反転分布）** | **増える（増幅）** |

このほか、E₂ の原子は刺激がなくても勝手に光を出す（**自然放出**）。自然放出の光は向きも位相もばらばらなので、レーザー光にはならない。

## 2 準位では反転しない

E₁ と E₂ の 2 つだけの物質に、E₂−E₁ に合う光を当てて上げようとしても、反転分布にはならない。

- 上の数が増えるにつれて、当てた光による誘導放出も増える
- その結果、**N₁ = N₂ = N/2** で釣り合ってしまう。透明になるだけで、増幅はしない

そこで、**3 つ以上の準位** を使い、ポンプで上げる準位と、光を出す準位を分ける。

| | 3 準位 | 4 準位 |
| --- | --- | --- |
| 光を出す遷移 | E₂ → **E₁（基底状態）** | E₃ → **E₂**（基底状態より上） |
| 反転に必要なこと | 基底状態の原子の **半分以上** を上げる | E₂ がほぼ空なので、**少し上げるだけ** でよい |
| 条件 | E₂ に長く留まる（E₂ の寿命 ≫ E₃ の寿命） | E₃ に長く留まり、E₂ からはすぐ落ちる |
| 効率 | 低い。とても強く光らせる必要がある | 高い。**実用のレーザーの多くはこの型** |
| 例 | [[ルビーレーザー]]（1960 年、メイマン） | Nd:YAG レーザー |

[[炭酸ガスレーザー]] では、原子の電子の状態ではなく **分子の振動** の状態を使う。光を出したあとの下の振動状態は、ヘリウムとぶつかってすぐ空になる。

## 反転分布の作り方（ポンプ）

| 方法 | 例 |
| --- | --- |
| **光** を当てる | フラッシュランプ（ルビー）、半導体レーザーの光（Nd:YAG など） |
| **放電**（気体に電流を流す） | 炭酸ガス、ヘリウム・ネオン |
| **化学反応** | 化学レーザー |

- ポンプに使う光は、出てくるレーザー光より **エネルギーが大きい**（波長が短い）

## 関連する話題

- **負の温度**：ボルツマン分布の式に反転分布（N₂ > N₁）をあてはめると、T が負になる。反転分布を「負の温度」の状態ということがある
- **メーザー**：マイクロ波で同じことを行う装置。室温ではマイクロ波の 2 つの状態はほとんど同じ数になっている。水素メーザーでは、強い不均一な磁場で上の状態の原子をより分けて反転分布を作る
- **反転分布なしのレーザー**：量子のコヒーレンスを使って、反転分布なしで増幅する研究もある
