# 炭酸ガスレーザー

**二酸化炭素（炭酸ガス）をふくむ気体に放電して、目に見えない赤外線を出すレーザー。** 強い光を連続して出せて効率もよいので、工業の切断・溶接や、医療の手術に広く使われる。

| 項目 | 内容 |
| --- | --- |
| 発明 | 1964 年、**クマール・パテル**（米国・ベル研究所） |
| 光を出す物質 | **二酸化炭素（CO₂）** の分子。窒素とヘリウムを混ぜた気体で使う |
| 波長 | おもに **10.6 µm** と **9.6 µm**（遠赤外線。目に見えない） |
| 光らせ方 | 気体の中で **放電** する（電流を流す） |
| 発振のしかた | **連続**（ずっと光り続ける）でも **パルス** でもよい |
| 効率 | 最大で **20%** ほど。レーザーとしてはかなり高い |
| 出力 | 連続でミリワットから **数百キロワット**。いま手に入る連続発振レーザーで最も強い部類 |

## 気体の中身

封じ切りの管の場合、だいたい次のように混ぜる。流しながら使う型では割合がちがう。

| 気体 | 割合 | 役目 |
| --- | --- | --- |
| **二酸化炭素（CO₂）** | 10〜20% | レーザー光を出す |
| **窒素（N₂）** | 10〜20% | 放電のエネルギーを受け取って、CO₂ に渡す |
| **ヘリウム（He）** | 残り | 光を出したあとの CO₂ を元の状態に戻す。気体を冷やす |
| 水素・キセノン | 数% | — |

## 仕組み

ルビーレーザーでは電子のエネルギーの状態を使うが、炭酸ガスレーザーでは **分子の振動** のエネルギーを使う。

1. 放電の電子がぶつかって、**窒素分子** が振動する
2. 窒素分子は同じ原子 2 つでできているので、光を出してエネルギーを捨てられない。そのため振動したまま長く留まる
3. 窒素分子の振動のエネルギーは、CO₂ の **非対称伸縮振動**（O=C=O の両端が交互に伸び縮みする振動）のエネルギーとほぼ同じ。窒素が CO₂ にぶつかると、エネルギーがそのまま CO₂ に移る
4. CO₂ が低い振動の状態に落ちるときに光を出す
   - **対称伸縮振動**（両端が同時に伸び縮みする）に落ちる → **10.6 µm**
   - **変角振動**（分子が折れ曲がる）に落ちる → **9.6 µm**
5. 落ちた CO₂ は **冷たいヘリウム** にぶつかって基底状態に戻る。下の状態がすぐ空になるので、**[[反転分布]]** が保たれる

## レンズや窓の材料

10.6 µm の赤外線は **ふつうのガラスを通らない**。そのため特別な材料を使う。

- レンズ・窓：**セレン化亜鉛（ZnSe）**、**ゲルマニウム（Ge）**
- 高価だが **ダイヤモンド** も使う。熱をよく伝え、かたい
- 昔は **食塩（塩化ナトリウム）** や塩化カリウムを使った。空気中の湿気で少しずつ傷んだ
- 鏡：銀めっき。強い出力では **金** の鏡を使う

### 材料に求められること

炭酸ガスレーザーに使える材料はわずかしかない。光を通すことのほかに、光学的な性質と熱の性質を考えなければならないため。

| 要件 | わけ | 例 |
| --- | --- | --- |
| **10.6 µm の光を通す** | 通さない材料は光を吸ってしまい、レンズにならない | ふつうのガラスは通さないので使えない |
| **吸収がとても小さい** | 強い光が通るので、わずかな吸収でも熱くなる。熱くなると、ふくらんで形が変わり、屈折率も上がって、**焦点がずれる**（熱レンズ）。ひどいと割れる | 加工用の ZnSe レンズの吸収は 0.25% 未満、低吸収品は 0.15% 未満。吸収の多くは、表面のコーティングと汚れで起こる |
| **熱くなっても吸収が増えない** | 温度で吸収が増えると、熱くなる → もっと吸う → もっと熱くなる、とくり返す（**熱暴走**） | **ゲルマニウム** は熱くなると自由に動く電子が増え、10.6 µm をより多く吸う。そのため強い出力には向かない |
| **熱をよく逃がす** | 熱がこもらず、熱レンズになりにくい | **ダイヤモンド** は熱をとてもよく伝える |
| **反射の損失を減らせる** | 屈折率が大きい材料は、表面での反射が大きい。表面に **反射防止コーティング** をつける | コーティングなしの ZnSe は透過率が約 70%。両面にコーティングすると 99.4% より上になる |
| **湿気に強い** | 水を吸って曇ったり溶けたりすると使えない | 食塩（NaCl）・塩化カリウム（KCl）は湿気で傷むので、いまはほとんど使わない |
| **かたく、傷つきにくい** | 加工ヘッドのレンズは、飛び散った金属や煙で汚れ、ふいて掃除する | ダイヤモンドは砂を吹きつけても性能が落ちない |
| （あると便利）**目に見える光も通す** | 見える光のガイドレーザーで、光の通り道を合わせられる | ZnSe は黄色く透けて見え、赤い光を通す |

#### 強い出力の場合

- レンズのような **光を通す部品**（透過光学系）は、どうしても少し吸収して熱くなる
- そのため、とても強い出力では **鏡**（反射光学系）で光を集めることがある。鏡は光を中まで入れないので、熱で傷みにくい
- ある特許は、ZnSe レンズは 5 kW を超える出力には使えないとしている。一方で、レーザー用の高品質な ZnSe は kW 級でも使えるとするメーカーもある

#### 材料の比べ方

| 材料 | 長所 | 短所 |
| --- | --- | --- |
| **ZnSe**（セレン化亜鉛） | 吸収が小さい。目に見える光も少し通す。**レンズ・窓の標準** | やわらかく傷つきやすい。壊れたり燃えたりすると有毒な物質が出る |
| **Ge**（ゲルマニウム） | かたい。屈折率が大きい | 熱暴走する。目に見える光を通さない |
| **GaAs**（ヒ化ガリウム） | ZnSe よりかたい | ヒ素をふくみ有毒 |
| **ダイヤモンド** | 熱をとてもよく伝える。とてもかたい | とても高い |
| **NaCl・KCl**（塩） | 安い。吸収が小さい | 湿気で傷む |

## 使い道

### 医療

10.6 µm の光は **水によく吸収される**。体の組織はほとんど水なので、当てたところの水が一瞬で熱くなり、組織が **蒸発** する。

- 光が奥まで届かず、表面だけを削れる（光が届く深さは数十 µm ほどとされる）
- 切ると同時に熱で血管がふさがるので、**出血が少ない**
- 手術時間が短く、感染や手術後の腫れも少ないとされる
- 軟らかい組織の手術では、いまでも **最良の手術用レーザー** とされる

| 分野 | 例 |
| --- | --- |
| **皮膚科** | ほくろ・いぼなどの皮膚の盛り上がりを削る。汗管腫、眼瞼黄色腫、表皮母斑など |
| **美容** | **リサーフェシング**：皮膚の表面を蒸発させて、コラーゲンができるのをうながす。しわ・ニキビの跡など |
| 耳鼻科 | 声帯の病変（のう胞など） |
| 婦人科・歯科・口腔外科 | 軟らかい組織の切除。9.25〜9.6 µm の歯科用レーザーは歯などのかたい組織も削れる |
| 獣医 | 軟らかい組織の手術 |

- **保険**：病気によって保険が使える。東北大学病院皮膚科では、汗管腫・眼瞼黄色腫・表皮母斑などの小さな腫瘍に、主に保険が使える病気で行っている
- いぼ（老人性疣贅）・ほくろを美容目的で取る場合は、**自費** の医療機関が多い

### 工業

- **切断・溶接**：強い出力が安く得られる
- **彫刻・マーキング**：弱い出力で木・アクリル・革などに刻む
- **3D プリンター**：樹脂の粉を焼き固める（選択的レーザー焼結）
- **半導体**：極端紫外線（EUV）を作るのに使う
- そのほか、分光、軍用の距離計（ライダー）、ウラン濃縮の研究

## ルビーレーザーとのちがい

| | [[ルビーレーザー]] | 炭酸ガスレーザー |
| --- | --- | --- |
| 光を出す物質 | 固体（ルビーの結晶） | 気体（CO₂） |
| 波長 | 694.3 nm（赤い光） | 10.6 µm（遠赤外線） |
| よく吸収するもの | メラニン（色素） | 水 |
| 皮膚での働き | 色素だけを壊す（しみ・あざ） | 組織そのものを削る（いぼ・ほくろ） |
| 効率 | 低い | 高い（最大 20% ほど） |
| 発振 | パルス | 連続もパルスもできる |
