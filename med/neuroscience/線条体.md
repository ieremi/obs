# 線条体

## 概要
- 大脳の深いところにある神経核の集まり（**大脳基底核**）のうち、**入り口** にあたる部分
- **尾状核** と **被殻** からなる。腹側の **側坐核** を含めて「腹側線条体」とよぶこともある
- 尾状核と被殻のあいだを内包の線維が通り、その間に灰白質が橋のようにつながって **縞（すじ）模様** に見えることから名づけられた
- 被殻と淡蒼球をあわせて **レンズ核** という（[[ウィルソン病]]の別名「肝レンズ核変性症」の由来）

## 入力と出力

| 方向 | 相手 | 伝達物質 |
| --- | --- | --- |
| 入力 | 大脳皮質のほぼ全体 | グルタミン酸（興奮） |
| 入力 | 視床 | グルタミン酸 |
| 入力 | **黒質緻密部**（黒質線条体路） | **ドパミン** |
| 出力 | 淡蒼球、黒質網様部 | GABA（抑制） |

## 細胞
- **中型有棘ニューロン**（medium spiny neuron）：線条体の神経細胞の **約 95%**。GABA を出す
- 介在ニューロン：**コリン作動性介在ニューロン**（アセチルコリンを出す）、GABA 作動性介在ニューロンなど

## 直接路と間接路
中型有棘ニューロンは 2 つのグループに分かれ、反対の働きをする。

| | 直接路 | 間接路 |
| --- | --- | --- |
| ドパミン受容体 | **D₁** | **D₂** |
| 行き先 | 淡蒼球内節・黒質網様部へ直接 | 淡蒼球外節 → 視床下核 → 淡蒼球内節・黒質網様部 |
| 結果 | 視床・脳幹への抑えを **外す** → 運動を **起こす** | 視床・脳幹への抑えを **強める** → 運動を **止める** |
| ドパミンの作用 | 興奮させる（D₁） | 抑える（D₂） |

**ドパミンは、どちらの経路を通しても「運動を起こしやすくする」方向に働く**。

出力核（淡蒼球内節・黒質網様部）は、ふだんは視床や[[上丘]]を抑え続けている。直接路はこの抑えを一時的に外し、必要な運動だけを通す。

## ドパミンとアセチルコリンのつり合い
- コリン作動性介在ニューロンは、D₂ 受容体をもち、ドパミンで **抑えられている**
- ドパミンが減ったり、D₂ 受容体が遮断されたりすると、アセチルコリンが **相対的に優位** になる
- パーキンソン病や薬剤性の錐体外路症状に **抗コリン薬**（トリヘキシフェニジル、ビペリデン）が効くのはこのため

## 働き
- **運動の選択・開始**：いくつもある運動の候補から、ひとつを選んで実行する
- **習慣・手続き記憶**：くり返して身についた動作（自転車に乗るなど）。→ [[エピソード記憶]]の「記憶の分類」
- **報酬と学習**：側坐核（腹側線条体）は、報酬を予測し、やる気や依存にかかわる

## 線条体がかかわる病気

| 病気 | 線条体で起こること | 症状 |
| --- | --- | --- |
| パーキンソン病 | 黒質の神経細胞が死に、ドパミンが減る | 動きが遅い、ふるえ、筋肉のこわばり |
| 薬剤性の錐体外路症状 | D₂ 受容体の遮断（[[ハロペリドール]]、[[リスペリドン]]、[[メトクロプラミド]]） | パーキンソン症状、急性[[ジストニア]]、アカシジア |
| [[瀬川病]] | ドパミンを作る材料（[[テトラヒドロビオプテリン\|BH₄]]）が足りない | 足から始まるジストニア |
| ハンチントン病 | 尾状核の中型有棘ニューロン（とくに間接路）が死ぬ | 舞踏運動（踊るような不随意運動）、認知症 |
| [[ウィルソン病]] | 被殻に銅がたまる | ふるえ、ジストニア、パーキンソン症状 |
| 脳梗塞・脳出血 | 被殻は高血圧性脳出血の最も多い部位 | 反対側の麻痺 |
