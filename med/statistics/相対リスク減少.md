# 相対リスク減少

悪い転帰が、対照群のリスクに対して相対的にどれだけ減ったか。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $R_c$ | 対照群の、指定期間内の悪い転帰のリスク。 |
| $R_t$ | 治療群の、同じ期間内の同じ転帰のリスク。 |
| $RR$ | 治療群を分子とするリスク比。$R_t/R_c$。 |
| $RRR$ | 相対リスク減少。$1-RR$。 |
| $ARR$ | 絶対リスク減少。$R_c-R_t$。 |

## 計算式

$$
RRR=\frac{R_c-R_t}{R_c}=1-RR
$$

## 具体例

10%から6%ならRRR＝40%。1%から0.6%でもRRRは40%だが、絶対差はそれぞれ4と0.4パーセントポイント。

## 解釈・注意点

相対的な減少だけでは治療の絶対的な利益は分からない。基準となるリスクとARRを一緒に示す。
