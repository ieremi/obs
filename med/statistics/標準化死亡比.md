# 標準化死亡比

標準集団の死亡率を対象集団に当てはめたときの期待死亡数に対する、観察死亡数の比。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $O$ | 対象集団で実際に観察された死亡数。 |
| $E$ | 標準集団の死亡率を当てはめて計算する期待死亡数。 |
| $i$ | 年齢階級などの層の番号。 |
| $N_i$ | 対象集団の層 $i$ における総人時間。標準死亡率と時間単位をそろえる。 |
| $m_i^{std}$ | 標準集団の層 $i$ における死亡率。 |
| $SMR$ | 標準化死亡比。$O/E$。 |
| $\sum_i$ | 層 $i$ ごとに計算した値を合計する記号。 |

## 計算式

$$
SMR=\frac{O}{E},\qquad E=\sum_i N_i m_i^{std}
$$

## 具体例

年齢構成を踏まえた期待死亡20人に対して観察死亡30人なら、SMR＝1.5（100を基準とする表記なら150）。

## 解釈・注意点

Nは対象集団の年齢別人時間、標準死亡率mとの積を合計する。年齢などの間接調整であり、SMRが1.5だから曝露の因果効果が1.5倍とは限らない。異なる集団のSMR同士の比較にも注意する。
