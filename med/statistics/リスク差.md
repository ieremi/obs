# リスク差

曝露群と非曝露群の発症リスクの絶対的な差。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $R_e$ | 曝露群の、指定期間内の発症リスク。 |
| $R_u$ | 非曝露群の、同じ期間内の発症リスク。 |
| $RD$ | リスク差。小数の差、またはパーセントポイントで表す。 |

## 計算式

$$
RD=R_e-R_u
$$

## 具体例

20%−5%＝15パーセントポイント。100人当たり発症15人分の差。

## 解釈・注意点

15%の相対増加ではない。0が差のない値で、向きを逆にすれば符号も逆になる。因果解釈のもとで過剰分を論じる場合には寄与危険と呼ぶ。
