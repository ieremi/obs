# 人口寄与割合

集団全体で起きた発症のうち、曝露がなければ防げたと考えられる部分の割合。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $R_e$ | 曝露群の、指定期間内の発症リスク。 |
| $R_u$ | 非曝露群の、同じ期間内の発症リスク。 |
| $R_p$ | 曝露群・非曝露群を合わせた集団全体の、同じ期間内の発症リスク。 |
| $P_e$ | 集団全体のうち曝露を受けている人の割合。 |
| $RR$ | リスク比。$R_e/R_u$。 |
| $PAF$ | 人口寄与割合。集団全体の発症に占める過剰部分の割合。 |
| $AF$ | 曝露群寄与割合。曝露群の発症だけを分母にする。 |

## 計算式

$$
PAF=\frac{R_p-R_u}{R_p}
$$

## 具体例

曝露群100人中20人、非曝露群100人中5人が発症した例では、集団全体25人のうち過剰15人分なのでPAF＝60%。曝露群だけを分母とするAFは75%。

## 解釈・注意点

単純な二群モデルでは、曝露割合Peを用いてPAF＝Pe(RR−1)／{1＋Pe(RR−1)}。調整済みRRをこの単純式へ代入するだけで適切になるとは限らない。因果的解釈には交絡・バイアス等への対応が必要。
