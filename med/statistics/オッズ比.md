# オッズ比

二群のオッズの比。2×2表で曝露群の発症・非発症をa・b、非曝露群をc・dとする。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $a$ | 曝露あり・発症ありの人数。 |
| $b$ | 曝露あり・発症なしの人数。 |
| $c$ | 曝露なし・発症ありの人数。 |
| $d$ | 曝露なし・発症なしの人数。 |
| $OR$ | オッズ比。$(a/b)/(c/d)$。 |
| $RR$ | リスク比。$\{a/(a+b)\}/\{c/(c+d)\}$。 |

## 計算式

$$
OR=\frac{a/b}{c/d}=\frac{ad}{bc}
$$

## 具体例

発症リスク40%と20%ならRR＝2だが、OR＝(0.4／0.6)／(0.2／0.8)≒2.67。

## 解釈・注意点

症例対照研究では症例と対照の曝露オッズを比較する。通常、その標本から母集団のリスクは直接計算しない。ORの推定対象は対照抽出法によるため、「常にRRを近似する」とはしない。
