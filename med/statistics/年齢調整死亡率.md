# 年齢調整死亡率

集団間の年齢構成の違いをそろえた死亡率。直接法では、各年齢階級の死亡率を同じ標準人口構成で平均する。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $i$ | 年齢階級の番号。 |
| $m_i$ | 対象集団の年齢階級 $i$ における死亡率。 |
| $w_i$ | 標準人口に占める年齢階級 $i$ の割合。全階級の合計が1。 |
| $M_{std}$ | 標準人口の年齢構成で重み付けした死亡率。 |
| $\sum_i$ | すべての年齢階級 $i$ について足し合わせる記号。 |

## 計算式

$$
M_{std}=\sum_i w_i m_i,\qquad\sum_i w_i=1
$$

## 具体例

若年層の死亡率1／1,000人年、高齢層10／1,000人年を、標準人口の比率80%・20%で加重すると2.8／1,000人年。

## 解釈・注意点

wは標準人口の構成比、mは対象集団の年齢別死亡率。比較には同じ標準人口を使う。対象集団で実際に観測された粗死亡率とは異なる仮想的な指標。
