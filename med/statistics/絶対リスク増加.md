# 絶対リスク増加

悪い転帰について、治療・曝露群で対照群より増えたリスクの絶対差。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $R_c$ | 対照群の、指定期間内の悪い転帰のリスク。 |
| $R_t$ | 治療群の、同じ期間内の同じ転帰のリスク。 |
| $ARI$ | 絶対リスク増加。$R_t-R_c$。 |
| $ARR$ | 絶対リスク減少。$R_c-R_t$。 |

## 計算式

$$
ARI=R_t-R_c
$$

## 具体例

有害事象が対照群1%、治療群3%ならARI＝0.02＝2パーセントポイント。

## 解釈・注意点

害の転帰を何としたかを明示する。利益の転帰のARRと、別の有害事象のARIを混同しない。

関連：[[害必要数]]、[[絶対リスク減少]]。一覧：[[疫学指標]]。
