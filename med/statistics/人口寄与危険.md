# 人口寄与危険

集団全体の発症リスクと、曝露がない場合のリスクの絶対差。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $R_e$ | 曝露群の、指定期間内の発症リスク。 |
| $R_u$ | 非曝露群の、同じ期間内の発症リスク。 |
| $R_p$ | 曝露群・非曝露群を合わせた集団全体の、同じ期間内の発症リスク。 |
| $P_e$ | 集団全体のうち曝露を受けている人の割合。 |
| $RR$ | リスク比。$R_e/R_u$。 |
| $PAR$ | 人口寄与危険。$R_p-R_u$。 |

## 計算式

$$
PAR=R_p-R_u
$$

## 具体例

曝露群100人で20人、非曝露群100人で5人が発症した例では、集団全体は25／200＝12.5%。PAR＝12.5%−5%＝7.5パーセントポイント。

## 解釈・注意点

全200人が非曝露群と同じリスクなら発症は10人と期待され、実際の25人との差は15人。因果的にこう読むには、非曝露群のリスクを集団の反実仮想として使える条件が必要。
