# 絶対リスク減少

悪い転帰について、対照群より治療群でどれだけリスクが小さいかを絶対差で示す。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $R_c$ | 対照群の、指定期間内の悪い転帰のリスク。 |
| $R_t$ | 治療群の、同じ期間内の同じ転帰のリスク。 |
| $ARR$ | 絶対リスク減少。$R_c-R_t$。 |
| $NNT$ | 治療必要数。$ARR>0$ のとき $1/ARR$。 |

## 計算式

$$
ARR=R_c-R_t
$$

## 具体例

対照群10%、治療群6%ならARR＝0.04＝4パーセントポイント。

## 解釈・注意点

対照群から治療群を引く向きに注意。NNTには0.04を代入し、4を代入しない。転帰・比較対象・期間を併記する。
