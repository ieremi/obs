# 害必要数

指定期間に有害事象が1件余分に起きる治療・曝露人数。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $R_c$ | 対照群の、指定期間内の悪い転帰のリスク。 |
| $R_t$ | 治療群の、同じ期間内の同じ転帰のリスク。 |
| $ARI$ | 絶対リスク増加。$R_t-R_c$。式には小数を入れる。 |
| $NNH$ | 害必要数。$1/ARI$。 |
| $NNT$ | 治療必要数。利益を測る別の指標。 |

## 計算式

$$
NNH=\frac{1}{ARI}\quad(ARI>0)
$$

## 具体例

有害事象が1%から3%ならNNH＝1／0.02＝50。

## 解釈・注意点

同じ転帰・期間で比較する。NNTとNNHの大小だけで利益と害の釣り合いは決められず、転帰の重さや不確実性も必要。
