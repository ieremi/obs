# 疫学指標

疫学指標は、**疾病の頻度、集団間の関連・差、介入の効果**を数で表す。検査を評価する指標も併せて整理する。読むときは、分子・分母・対象集団・観察期間を確認する。

人数の同時条件は $n(E\cap D)$、条件付き確率は $P(E\mid D)$ と区別する。$n(E\cap D)/n(D)$ は「疾患ありの人のうち陽性の割合」であり、感度の標本上の計算になる。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $n(A)$ | 同じ対象集団で、事象 $A$ に該当する人数。 |
| $A\cap B$ | $A$ と $B$ の両方に該当すること（積事象）。 |
| $E,\neg E$ | 検査陽性、検査陰性という事象。 |
| $D,\neg D$ | 疾患あり、疾患なしという事象。 |
| $R_e$ | 曝露群の、指定期間内の発症リスク。 |
| $R_u$ | 非曝露群の、同じ期間内の発症リスク。 |
| $R_p$ | 曝露群・非曝露群を合わせた集団全体の、同じ期間内の発症リスク。 |
| $P_e$ | 集団全体のうち曝露を受けている人の割合。 |
| $RR$ | リスク比。$R_e/R_u$。 |
| $R_c$ | 対照群の、指定期間内の悪い転帰のリスク。 |
| $R_t$ | 治療群の、同じ期間内の同じ転帰のリスク。 |
| $n(E\cap D)$ | 真陽性数。疾患があり、検査が陽性だった人数。 |
| $n(\neg E\cap D)$ | 偽陰性数。疾患があり、検査が陰性だった人数。 |
| $n(E\cap\neg D)$ | 偽陽性数。疾患がなく、検査が陽性だった人数。 |
| $n(\neg E\cap\neg D)$ | 真陰性数。疾患がなく、検査が陰性だった人数。 |
| $Se$ | 感度。$P(E\mid D)$。 |
| $Sp$ | 特異度。$P(\neg E\mid\neg D)$。 |
| $a,b$ | 曝露ありの発症者数・非発症者数。 |
| $c,d$ | 曝露なしの発症者数・非発症者数。 |
| $p$ | 事象が起こる確率。 |
| $h_e(t),h_u(t)$ | 時刻 $t$ での曝露群・非曝露群のハザード。 |
| $t$ | 観察開始からの時刻。 |
| $ARR,RRR$ | 絶対リスク減少 $R_c-R_t$、相対リスク減少 $(R_c-R_t)/R_c$。 |
| $ARI$ | 絶対リスク増加 $R_t-R_c$。 |
| $NNT,NNH$ | 治療必要数 $1/ARR$、害必要数 $1/ARI$。 |
| $LR$ | 得られた検査結果に対応する尤度比。 |

## 比・割合・率

| 区分 | 定義 | 例 |
| --- | --- | --- |
| 比（ratio） | 二つの量の比較。分子が分母に含まれるとは限らない。 | オッズ、リスク比。 |
| 割合（proportion） | 全体のうちの部分。0〜1、または0〜100%。 | 有病割合、累積罹患割合。 |
| 率（rate） | 単位時間当たりの発生の速さ。人時間などを分母にする。 | 罹患率。 |

日本語の「〜率」には割合も含まれる。「有病率」「致命率」は通常、時間当たりの率ではなく割合。[CDC：疫学指標の概要](https://archive.cdc.gov/www_cdc_gov/csels/dsepd/ss1978/lesson3/)

## 疾病の頻度

| 指標 | 計算 | 読み方・注意 |
| --- | --- | --- |
| [[有病率|時点有病率（prevalence）]] | ある時点の患者数 ÷ 同時点の対象人口 | 現在どれだけ患者がいるか。新規発症の頻度ではない。 |
| [[累積罹患割合|累積罹患割合・リスク（incidence proportion）]] | 一定期間の新規発症者数 ÷ 開始時の発症リスク集団 | その期間に発症する確率。単純式では追跡が完全な閉鎖集団を想定する。 |
| [[罹患率|罹患率・罹患密度（incidence rate）]] | 新規発症数 ÷ 発症リスク下の総人時間 | 発症の速さ。単位は人年当たりなど。確率とは異なる。 |
| [[発病割合|発病割合（attack rate）]] | 流行期間の発症者数 ÷ 発症リスク集団 | アウトブレイクで用いる累積罹患割合。 |

例えば100人を1年間完全追跡して新規発症が5人なら、1年リスクは5%。一方、合計200人年の観察で5件発症したなら罹患率は0.025／人年、すなわち25／1,000人年。

人時間は、発症・死亡・追跡終了などまで、各人が発症リスク下にいた時間を合計する。全員が同じ時間だけ追跡されたとは限らない。

有病率は発症だけでなく罹病期間にも左右される。まれな疾患で集団・発症率・罹病期間が安定しているなどの条件下では、

$$
\text{有病割合}\approx\text{罹患率}\times\text{平均罹病期間}
$$

と近似できる。常に成立する恒等式ではない。[CDC：疾病頻度のまとめ](https://archive.cdc.gov/www_cdc_gov/csels/dsepd/ss1978/lesson3/summary.html)、[CDC：疫学の原則・第3課](https://stacks.cdc.gov/view/cdc/6914/cdc_6914_DS1.pdf)

## 2×2表と関連の指標

同じ期間について、曝露の有無と発症を次のように集計する。

|  | 発症あり | 発症なし | 計 |
| --- | ---: | ---: | ---: |
| 曝露あり | $a$ | $b$ | $a+b$ |
| 曝露なし | $c$ | $d$ | $c+d$ |

$$
R_e=\frac{a}{a+b},\qquad R_u=\frac{c}{c+d}
$$

ここで $R_e,R_u$ は曝露群・非曝露群の期間内リスク。以下の比は分母が0でない場合に定義される。

| 指標 | 式 | 意味 |
| --- | --- | --- |
| [[リスク比|リスク比・相対危険度（RR）]] | $R_e/R_u$ | 発症リスクが何倍か。 |
| [[リスク差|リスク差（RD）]] | $R_e-R_u$ | 発症リスクが絶対値でどれだけ違うか。 |
| [[オッズ比|オッズ比（OR）]] | $(a/b)/(c/d)=ad/(bc)$ | 発症オッズの比。症例対照研究では曝露オッズの比として計算できる。 |
| [[罹患率比|罹患率比（IRR）]] | 曝露群の罹患率 ÷ 非曝露群の罹患率 | 人時間に基づく発症の速さの比。 |
| [[ハザード比|ハザード比（HR）]] | $h_e(t)/h_u(t)$ | その時点までイベント未発生の人における瞬間的な率の比。詳細は[[ハザード比]]。 |

**比は1、差は0が「両群で等しい」ことを表す値。** リスク比・罹患率比・ハザード比は同じものではない。[CDC：関連の指標](https://archive.cdc.gov/www_cdc_gov/csels/dsepd/ss1978/lesson3/section5.html)

### オッズと確率

個別ページ：[[オッズ]]。

確率 $p$ に対するオッズは、

$$
\text{odds}=\frac{p}{1-p},\qquad
p=\frac{\text{odds}}{1+\text{odds}}.
$$

曝露群40%、非曝露群20%ならRRは2だが、ORは $(0.4/0.6)/(0.2/0.8)\approx2.67$。「ORが2だからリスクが2倍」とは限らない。

通常の症例対照研究では症例と対照の人数を研究者が設定するため、この標本の列合計・行合計から母集団の発症リスクを直接計算しない。対照の抽出法に応じてORの推定対象も変わる。累積発症に基づく症例対照研究では、疾患がまれな場合にORをRRの近似として扱える。[CDC：データの解析と解釈](https://www.cdc.gov/field-epi-manual/php/chapters/analyze-interpret-data.html)

## 寄与危険・集団への影響

有害な曝露を想定し、集団全体のリスクを $R_p$、集団の曝露割合を $P_e$ とする。

| 指標 | 式 | 解釈 |
| --- | --- | --- |
| [[寄与危険|寄与危険（AR）]] | $R_e-R_u$ | 曝露群での絶対的な過剰リスク。リスク差と同じ形。 |
| [[曝露群寄与割合|曝露群寄与割合（AF）]] | $(R_e-R_u)/R_e=(RR-1)/RR$ | 曝露群の発症のうち、曝露がなければ防げたと考える部分の割合。20%対5%の例では75%。 |
| [[人口寄与危険|人口寄与危険（PAR）]] | $R_p-R_u$ | 集団全体の絶対的な過剰リスク。 |
| [[人口寄与割合|人口寄与割合（PAF）]] | $(R_p-R_u)/R_p$ | 集団全体の発症のうち、曝露に寄与すると考える割合。 |

単純な二群モデルでは、

$$
PAF=\frac{P_e(RR-1)}{1+P_e(RR-1)}.
$$

**「曝露をなくせば防げる」と因果的に解釈するには、交絡やバイアスなどへの対応が必要。** 調整済みRRを上の単純式に代入するだけでは、適切なPAFにならない場合がある。「寄与危険」が差を指すか割合を指すかは資料の定義を確認する。[CDC：関連・影響の指標](https://www.cdc.gov/field-epi-manual/php/chapters/analyze-interpret-data.html)

## 介入効果：ARR・RRR・NNT

個別ページ：[[絶対リスク減少]]（ARR）、[[相対リスク減少]]（RRR）、[[治療必要数]]（NNT）、[[絶対リスク増加]]（ARI）、[[害必要数]]（NNH）。

悪い転帰のリスクを、対照群で $R_c$、治療群で $R_t$ とする。治療が有益で $R_t<R_c$ の場合、

$$
RR=\frac{R_t}{R_c},\qquad
ARR=R_c-R_t,\qquad
RRR=\frac{R_c-R_t}{R_c}=1-RR,
$$

$$
NNT=\frac{1}{ARR}.
$$

NNT（治療必要数）は、指定した期間に悪い転帰を1件余分に防ぐための治療人数。ARRは百分率の数値ではなく小数で代入する。人数として示す場合は通常切り上げる。

例えば1年リスクが対照群10%、治療群6%なら、RR＝0.6、RRR＝40%、ARR＝4パーセントポイント、NNT＝25人。「リスクを40%減らす」だけでは絶対的な利益は分からない。

害が増える場合は $ARI=R_t-R_c>0$ として $NNH=1/ARI$（害必要数）。NNT・NNHは転帰・期間・比較対象を併記する。[Oxford CEBM：EBM tools（NNT）](https://www.cebm.ox.ac.uk/resources/ebm-tools)

## 死亡の指標

| 指標 | 分子／分母 | 注意 |
| --- | --- | --- |
| [[粗死亡率]] | 期間中の死亡数／人口の人時間（年単位の統計では年央人口で近似） | 集団の年齢構成に影響される。 |
| [[死因別死亡率]] | 特定死因による死亡数／対象人口の人時間 | 分母はその病気の患者数ではない。 |
| [[致命率|致命率（CFR）]] | その病気による死亡者数／その病気の患者数 | 患者のうち死亡に至る割合。十分な追跡と対応する患者集団が必要。 |
| [[比例死亡割合]] | 特定死因の死亡数／全死亡数 | 全死亡の内訳。人口当たりの死亡リスクではない。 |
| [[年齢調整死亡率]] | 年齢別死亡率を標準人口の構成で加重平均 | 年齢構成の違いをそろえて比較するための指標。 |
| [[標準化死亡比|標準化死亡比（SMR）]] | 観察死亡数／期待死亡数 | 期待死亡数は標準集団の年齢別死亡率などから計算。1を基準とする表記と、100倍して100を基準とする表記がある。 |

致命率の分母は「患者」、死亡率の分母は「人口・人時間」。粗死亡率が高いだけでは、年齢構成が異なる集団の健康状態を単純には比較できない。[CDC：死亡頻度の指標](https://archive.cdc.gov/www_cdc_gov/csels/dsepd/ss1978/lesson3/section3.html)

## 検査の評価指標

ここでは別の2×2表を使う。疾患の有無は参照基準で判定する。

|  | 疾患あり | 疾患なし |
| --- | ---: | ---: |
| 検査陽性 | 真陽性（$n(E\cap D)$） | 偽陽性（$n(E\cap\neg D)$） |
| 検査陰性 | 偽陰性（$n(\neg E\cap D)$） | 真陰性（$n(\neg E\cap\neg D)$） |

| 指標 | 式 | 条件にしているもの |
| --- | --- | --- |
| [[感度|感度（Se）]] | $n(E\cap D)/n(D)$ | 疾患ありの人が陽性となる確率。 |
| [[特異度|特異度（Sp）]] | $n(\neg E\cap\neg D)/n(\neg D)$ | 疾患なしの人が陰性となる確率。 |
| [[陽性的中率|陽性的中率（PPV）]] | $n(E\cap D)/n(E)$ | 陽性者に疾患がある確率。 |
| [[陰性的中率|陰性的中率（NPV）]] | $n(\neg E\cap\neg D)/n(\neg E)$ | 陰性者に疾患がない確率。 |
| [[陽性尤度比|陽性尤度比（LR＋）]] | $Se/(1-Sp)$ | 陽性結果による疾患オッズの更新倍率。 |
| [[陰性尤度比|陰性尤度比（LR−）]] | $(1-Se)/Sp$ | 陰性結果による疾患オッズの更新倍率。 |

$$
\text{検査後オッズ}=\text{検査前オッズ}\times LR.
$$

感度とPPVは逆向きの条件付き確率。PPV・NPVは有病割合や検査前確率に左右される。感度・特異度もカットオフ、患者の重症度、対象集団などで変わり得るため、普遍的な定数ではない。[Clinical Methods：感度・特異度・的中率](https://www.ncbi.nlm.nih.gov/books/NBK383/)、[Oxford CEBM：尤度比](https://www.cebm.ox.ac.uk/resources/ebm-tools/likelihood-ratios)

## 読むときの確認事項

- 観察期間と、分母が人数か人時間かを確認する。
- 比だけでなく、ベースラインリスクと絶対差も見る。
- 95%信頼区間、交絡調整、脱落、選択・情報バイアスを確認する。
- 95%信頼区間が比の1、差の0を含むかだけで、効果の重要性や因果関係を決めない。
- 横断研究の有病割合の比較を、新規発症リスクの比較に読み替えない。
