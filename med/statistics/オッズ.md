# オッズ

ある事象が起こる確率と、起こらない確率の比。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $p$ | ある事象の確率。検査の節では検査前の疾患確率。 |
| $O$ | その事象のオッズ。$p/(1-p)$。 |
| $D,\neg D$ | 疾患あり、疾患なしという事象。 |
| $E$ | 観察された検査結果という事象。陽性・陰性のいずれも表せる。 |
| $P(A),P(A\mid B)$ | 事象 $A$ の確率、および $B$ を条件とする $A$ の確率。 |
| $L$ | 観察結果 $E$ の尤度比。$P(E\mid D)/P(E\mid\neg D)$。 |
| $O_{\mathrm{前}},O_{\mathrm{後}}$ | 検査前・検査後の疾患オッズ。 |
| $p_{\mathrm{後}}$ | 検査後の疾患確率。 |
| $Se,Sp$ | 感度、特異度。ともに0〜1の小数で代入する。 |
| $x_j$ | ロジスティック回帰の第 $j$ 説明変数。$j=1,\ldots,k$。 |
| $k$ | 回帰式で用いる説明変数の数。 |
| $\beta_0$ | 回帰式の切片。 |
| $\beta_j$ | 説明変数 $x_j$ の回帰係数。 |
| $\eta$ | 回帰式の右辺 $\beta_0+\sum_{j=1}^k\beta_jx_j$。予測する対数オッズ。 |
| $\log,e$ | 自然対数と、その底であるネイピア数。 |
| $\operatorname{logit}(p)$ | 対数オッズ。$\log\{p/(1-p)\}$。 |

## 計算式

$$
O=\frac{p}{1-p},\qquad p=\frac{O}{1+O}
$$

## 具体例

発症確率20%なら、オッズは0.2／0.8＝0.25（1対4）。

## 確率より扱いやすいところ

確率とオッズは一対一に変換できるので、持っている情報は同じ。オッズの利点は、**証拠による更新を掛け算にでき、対数を取ると統計モデルで扱いやすくなること**にある。

### 1．検査結果による更新が掛け算になる

#### 記号：何を知る前・後なのか

疾患があることを $D$、疾患がないことを $\neg D$、得られた検査結果を $E$ とする。$E$ は、陽性でも陰性でもよい。

| 記号 | 意味 |
| --- | --- |
| $P(D)$ | 検査結果を知る前の、疾患がある確率。検査前確率。 |
| $P(D\mid E)$ | 結果 $E$ を知った後の、疾患がある確率。検査後確率。 |
| $P(E\mid D)$ | 疾患がある人に、その結果が出る確率。 |
| $P(E\mid\neg D)$ | 疾患がない人に、その結果が出る確率。 |

**$P(D\mid E)$ と $P(E\mid D)$ は逆向きの条件付き確率で、一般には等しくない。** ベイズの定理は、この向きをつなぐ。

#### 二つのベイズの式を割る

通常の[[ベイズの定理]]を、疾患あり・なしの両方に使うと、

$$
P(D\mid E)=\frac{P(E\mid D)P(D)}{P(E)},
$$

$$
P(\neg D\mid E)=\frac{P(E\mid\neg D)P(\neg D)}{P(E)}.
$$

この二式を割る。**共通の分母 $P(E)$ が消える**のがポイント。

$$
\begin{aligned}
\frac{P(D\mid E)}{P(\neg D\mid E)}
&=\frac{P(E\mid D)P(D)/P(E)}
{P(E\mid\neg D)P(\neg D)/P(E)}\\
&=\underbrace{\frac{P(D)}{P(\neg D)}}_{\text{検査前オッズ}}
\times\underbrace{\frac{P(E\mid D)}{P(E\mid\neg D)}}_{\text{結果Eの尤度比}}.
\end{aligned}
$$

左辺も、検査後に「疾患あり」と「疾患なし」を比べた**オッズ**である。$P(\neg D\mid E)=1-P(D\mid E)$ だから、オッズの定義そのものになる。

したがって、ベイズの定理をオッズで書くと、

$$
\boxed{\text{検査後オッズ}=\text{検査前オッズ}\times\text{尤度比}}
$$

となる。ここでは、条件付き確率が定義でき、各分母が0でない場合を扱っている。

#### 尤度比は「この結果が、どちらで出やすいか」

$$
L=\frac{P(E\mid D)}{P(E\mid\neg D)}.
$$

- $L=4$：この結果は、疾患なしの人より、疾患ありの人で4倍出やすい。疾患あり対なしのオッズを4倍にする。
- $L=1$：両者で同じくらい出やすい結果なので、オッズは変わらない。
- $L=0.1$：疾患ありの人では出にくい結果なので、疾患あり対なしのオッズを10分の1にする。

結果が陽性なら[[陽性尤度比]] $Se/(1-Sp)$、陰性なら[[陰性尤度比]] $(1-Se)/Sp$ を使う。**尤度比そのものは「検査後に疾患がある確率」ではない。** 検査前の見込みと組み合わせて初めて、検査後確率が決まる。

#### 確率へ戻す

検査前確率を $p$、結果に対応する尤度比を $L$ とすると、検査後オッズは、

$$
O_{\mathrm{後}}=\frac{p}{1-p}L.
$$

これを $p_{\mathrm{後}}=O_{\mathrm{後}}/(1+O_{\mathrm{後}})$ に代入すれば、

$$
p_{\mathrm{後}}=\frac{pL}{1-p+pL}.
$$

つまり、オッズに直すと分母を含む更新を、単純な倍率として扱える。

例えば検査前確率20%、陽性尤度比4なら、

$$
20\%\ \longrightarrow\ O_{\mathrm{前}}=\frac{0.2}{0.8}=0.25
\ \longrightarrow\ O_{\mathrm{後}}=0.25\times4=1
\ \longrightarrow\ p_{\mathrm{後}}=\frac{1}{1+1}=50\%.
$$

確率20%を直接4倍して80%とするのは誤り。複数の検査結果も、疾患あり・なしのそれぞれの条件下で検査同士が独立なら、各尤度比を順に掛けられる。依存する検査では、先行結果を条件にした尤度比が必要。[Oxford CEBM：尤度比](https://www.cebm.ox.ac.uk/resources/ebm-tools/likelihood-ratios)

#### 人数で同じ計算を確かめる

検査前確率20%の集団1,000人で、感度80%、特異度80%の検査を考える。期待人数は次のようになる。

|  | 疾患あり | 疾患なし |
| --- | ---: | ---: |
| 検査前 | 200人 | 800人 |
| 陽性となる割合 | 80% | 20% |
| 陽性者 | 160人 | 160人 |

検査前の「疾患あり：なし」は200：800＝1：4。陽性になる割合が80%：20%＝4：1なので、陽性者の中では160：160＝1：1へ変わる。これが**オッズに尤度比4を掛ける**ことの人数による説明。

陽性者320人のうち疾患ありは160人だから、検査後確率は50%。上のオッズによる計算と一致する。

### 2．対数オッズなら、実数全体を使ってモデル化できる

確率 $p$ は0〜1に制限される。これをそのまま線形式で予測すると、予測値が範囲外に出る場合がある。一方、$0<p<1$ に対して、対数オッズ（ロジット）は、

$$
\operatorname{logit}(p)=\log\frac{p}{1-p}
$$

であり、$-\infty$ から $+\infty$ までの値を取れる。ロジスティック回帰では、これを

$$
\log\frac{p}{1-p}=\beta_0+\beta_1x_1+\cdots+\beta_kx_k
$$

とモデル化する。右辺を $\eta$ とすると、確率に戻す式は、

$$
p=\frac{e^\eta}{1+e^\eta}.
$$

どんな有限の $\eta$ からも、0と1の間の予測確率が得られる。交互作用などがない上のモデルでは、他の変数を固定して $x_j$ が1増えると、オッズは $e^{\beta_j}$ 倍になる。**対数上の足し算が、オッズ上の掛け算として読める。** この性質はモデル化の利便性であり、モデルがデータに適合することを自動的に保証しない。[UCLA OARC：ロジスティック回帰とオッズ比](https://stats.oarc.ucla.edu/other/mult-pkg/faq/general/faq-how-do-i-interpret-odds-ratios-in-logistic-regression/)

### 3．起こる／起こらないの入れ替えが逆数になる

事象の確率が $p$ なら、起こらない確率は $1-p$。そのオッズは、

$$
\frac{1-p}{p}=\frac1O.
$$

したがって、対数オッズでは符号を反転するだけ。確率20%と80%はオッズ0.25と4、対数オッズは $-\log4$ と $+\log4$ になる。二値の結果を対称に扱える。

### 4．症例対照研究で比較できる

症例対照研究では、研究者が症例数と対照数を決めるため、その標本の発症割合を母集団の発症確率とはみなせない。一方、適切な対照抽出のもとで、症例と対照の曝露オッズを比較する[[オッズ比]]は推定できる。

曝露ありの発症・非発症を $a,b$、曝露なしを $c,d$ とすると、

$$
\underbrace{\frac{a/b}{c/d}}_{\text{発症オッズの比}}
=\frac{ad}{bc}
=\underbrace{\frac{a/c}{b/d}}_{\text{曝露オッズの比}}.
$$

行と列を入れ替えても同じ交差積比になることが、この解析を支える。何の関連を推定するかは対照の抽出法などに依存し、母集団の絶対リスクまで分かるわけではない。[CDC：関連の指標・オッズ比](https://archive.cdc.gov/www_cdc_gov/csels/dsepd/ss1978/lesson3/section5.html)

## 確率との使い分け

| 目的 | 適した表し方 |
| --- | --- |
| 患者に「何人に起きるか」を伝える | 確率・絶対リスク。 |
| 検査結果を受けて見込みを更新する | オッズに尤度比を掛け、最後に確率へ戻す。 |
| 二値の転帰を複数の要因でモデル化する | 対数オッズを使うロジスティック回帰など。 |
| 症例対照研究で関連を比較する | オッズ比。 |

オッズが確率より常に分かりやすいわけではない。計算や解析にはオッズを使い、結果の説明には確率へ戻すと理解しやすい。

## 解釈・注意点

確率は0〜1だがオッズは1を超える。確率50%はオッズ1。確率1では有限のオッズは定義できない。
