# 治療必要数

指定期間に悪い転帰を1件余分に防ぐため、対照治療に代えて治療する必要のある人数。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $R_c$ | 対照群の、指定期間内の悪い転帰のリスク。 |
| $R_t$ | 治療群の、同じ期間内の同じ転帰のリスク。 |
| $ARR$ | 絶対リスク減少。$R_c-R_t$。式には百分率の数値でなく小数を入れる。 |
| $NNT$ | 治療必要数。$1/ARR$。 |

## 計算式

$$
NNT=\frac{1}{ARR}\quad(ARR>0)
$$

## 具体例

1年のリスクが10%から6%へ下がるなら、NNT＝1／0.04＝25。「1年間25人治療して平均的に1件余分に防ぐ」。

## 解釈・注意点

個人の治療成功確率や、25人目だけに利益があるという意味ではない。人数として示す場合は通常切り上げる。ARR＝0なら有限のNNTはなく、信頼区間が0をまたぐと解釈も複雑になる。
