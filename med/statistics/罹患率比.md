# 罹患率比

二群の人時間当たりの罹患率の比。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $I_e,I_u$ | 曝露群・非曝露群の罹患率。 |
| $D_e,D_u$ | 曝露群・非曝露群の新規発症数。 |
| $T_e,T_u$ | 曝露群・非曝露群の発症リスク下の総人時間。 |
| $IRR$ | 罹患率比。$I_e/I_u$。 |
| $RR$ | リスク比。指定期間内の発症確率を比べる指標。 |

## 計算式

$$
IRR=\frac{I_e}{I_u}=\frac{D_e/T_e}{D_u/T_u}
$$

## 具体例

曝露群が20／1,000人年、非曝露群が5／1,000人年ならIRR＝4。

## 解釈・注意点

Dは発症数、Tはリスク下の人時間。各群の人数や観察期間が違っても人時間で集計できる。一定期間内の確率の比であるRRとは別。
