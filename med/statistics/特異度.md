# 特異度

参照基準で疾患なしとされた人のうち、検査が陰性となる割合。

人数の同時条件は $n(E\cap D)$、条件付き確率は $P(E\mid D)$ と区別する。$n(E\cap D)/n(D)$ は「疾患ありの人のうち陽性の割合」であり、感度の標本上の計算になる。

## 変数・記号の定義

| 記号 | 定義 |
| --- | --- |
| $n(A)$ | 同じ対象集団で、事象 $A$ に該当する人数。 |
| $A\cap B$ | $A$ と $B$ の両方に該当すること（積事象）。 |
| $n(E\cap D)$ | 真陽性数。疾患があり、検査が陽性だった人数。 |
| $n(\neg E\cap D)$ | 偽陰性数。疾患があり、検査が陰性だった人数。 |
| $n(E\cap\neg D)$ | 偽陽性数。疾患がなく、検査が陽性だった人数。 |
| $n(\neg E\cap\neg D)$ | 真陰性数。疾患がなく、検査が陰性だった人数。 |
| $P(A)$ | 事象 $A$ の確率。 |
| $P(A\mid B)$ | 事象 $B$ が起きたという条件のもとでの、$A$ の確率。表中の $A,B$ は一般的な事象の記号。 |
| $D,\neg D$ | 疾患あり、疾患なしという事象。$\neg$ は否定。 |
| $E,\neg E$ | 検査陽性、検査陰性という事象。 |
| $Sp$ | 特異度。疾患なしの人を分母とする陰性割合。 |

## 計算式

$$
Sp=\frac{n(\neg E\cap\neg D)}{n(\neg D)}=P(\neg E\mid\neg D)
$$

## 具体例

疾患なし100人中95人が陰性なら特異度95%、偽陽性割合は5%。

## 解釈・注意点

$n(\neg E\cap\neg D)$ は真陰性数、$n(E\cap\neg D)$ は偽陽性数。陰性者の95%が非患者だという意味ではない。通常、検査の閾値を変えると感度との釣り合いが変わる。
