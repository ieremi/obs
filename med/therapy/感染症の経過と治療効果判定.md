# 感染症の経過と治療効果判定

## どういう説か
**急性の細菌感染症は、ほぼ一方向に経過する。治療が合っていればよくなり、合っていなければ悪くなる。** よくなったり悪くなったりを繰り返したり、ずっと変わらなかったりすることは少ない。

日本の感染症診療の教育で、よく言われる経験則。青木眞の講義では、次のように説明されている。

- 細菌感染症の治療は、改善か悪化しかない
- ずっと変化がないなら、それはもう感染症の問題ではない

厳密な法則ではなく、**経過がおかしいと気づくための目安**。

## なぜそう言えるか
- 急性の細菌感染症では、菌が増えれば症状は進み、抗菌薬などで菌が減れば症状はおさまる。菌の量と症状が、おおむね同じ向きに動く
- そのため、治療を始めてから数日の経過は、**その治療が合っているかどうか** をよく表す

## 経過から考えること

| 経過 | 考えること |
| --- | --- |
| 一方向によくなる | 治療が効いている。そのまま続け、予定の期間で終える |
| 一方向に悪くなる | 診断・抗菌薬・量が合っていない。耐性菌、膿瘍などの **ドレナージが要る病変**、抗菌薬が届きにくい場所の感染を考える |
| よくなったり悪くなったり | 元の感染症とは **別の問題** が重なっていないかを考える（→ 下） |
| 変わらない | **そもそも感染症ではない** 可能性を考える（膠原病、腫瘍、薬の副作用など） |

### よくなったり悪くなったりするとき
いったんよくなったあと、また熱が出るなどしたら、次のことを考える。

- **新しい感染症**：カテーテル関連の血流感染症、尿路感染症、院内肺炎、*Clostridioides difficile* 感染症
- **感染症ではない発熱**：薬剤熱、偽痛風・痛風、深部静脈血栓症・肺塞栓症、輸血の反応
- **元の感染症の取り残し**：膿瘍、膿胸、人工物の感染など、抗菌薬だけでは治りきらない病変

## 何を見て判断するか
熱・CRP・白血球数だけで判断しない。

- **熱・CRP・白血球数** は、感染症以外でも上がり、よくなるときは遅れて下がる。重症度とも、必ずしも一致しない。重い敗血症では、かえって熱が出ないこともある
- **その臓器に合った指標** を見る

| 感染症 | 見る指標 |
| --- | --- |
| 肺炎 | 呼吸数、酸素飽和度・必要な酸素の量、痰の量と性状、痰のグラム染色 |
| 尿路感染症 | 排尿時の痛み、尿の所見、腰の痛み |
| 髄膜炎 | 意識、頭痛、髄液の所見 |
| 敗血症 | 血圧、脈拍、意識、尿量、乳酸値 |

- **バイタルサイン**（血圧、脈拍、呼吸数、意識）がよくなっていれば、熱が残っていてもよい方向とみてよい
- **グラム染色** は、効いていればすぐに菌が見えなくなり、効いていなければすぐにわかる
- **胸部 X 線写真** は、悪くなったことを見るのには使えるが、よくなったことを見るのには向かない。肺炎が治っても、影が消えるまでに数週間かかる

## 例外：正しく治療してもいったん悪くなるもの
次のものは、適切に治療しても、はじめの数日はかえって悪くなることがある。これを治療の失敗と取り違えないようにする。

- **レジオネラ肺炎**
- **ノカルジア症**
- **ニューモシスチス肺炎**
- **肺炎球菌性肺炎**
- **ヤーリッシュ・ヘルクスハイマー反応**（梅毒などのスピロヘータ感染症）
- **免疫再構築症候群・結核の逆説的反応**

### いったん悪くなるわけ

#### 共通のしくみ
抗菌薬が効いて **菌が減りはじめても、炎症や症状はすぐにはおさまらない**。数日遅れてピークを迎え、それから下がる。治療を始めてからこのピークまでが、「かえって悪くなる」ように見える時期になる。

遅れる理由は大きく 3 つある。

1. **壊れた菌から出る物質が炎症を強める**
   - 菌が死んで壊れると、細胞壁の成分、毒素、リポたんぱく質などが一度にばらまかれる
   - 体の免疫は、生きた菌だけでなく、これらの「菌の部品」にも反応する。そのため、サイトカイン（TNF-α、IL-1、IL-6 など）がかえって増える
   - 細胞壁を壊して殺す β ラクタム系抗菌薬（ペニシリンなど）で目立ちやすい
2. **すでに起きた組織の傷は、菌がいなくなっても続く**
   - 炎症は一度始まると、白血球が集まる、血管から水が漏れる、といった反応が連鎖して、しばらく自分で進む
   - 肺炎なら肺胞に水や白血球がたまったまま。抗菌薬は菌を殺すが、傷んだ組織を直すわけではない
3. **薬が効くまでに時間がかかる菌がある**
   - 細胞の中に住む菌、ゆっくり増える菌、膿瘍の中の菌には、薬が届いて効くまでに時間がかかる。その間は病気が進む

#### 病原体ごとのわけ

| 病原体・病態 | いったん悪くなるわけ |
| --- | --- |
| **ニューモシスチス肺炎** | 死んだ菌に対する体の炎症反応で、肺の傷みがかえって強くなる。治療開始から 3〜5 日ごろに呼吸が悪くなりやすい。このため、HIV 感染者で酸素化が悪い場合は、炎症をおさえる **副腎皮質ステロイド** を抗菌薬と一緒に使う |
| **肺炎球菌** | ペニシリンなどで溶けた菌から、細胞壁の成分や毒素（ニューモリシン）が出て炎症が強まる。重い肺炎球菌性肺炎では、ペニシリンを使っても、はじめの数日の死亡は減らなかったという古典的な報告がある（Austrian と Gold、1964 年）。**肺炎球菌性髄膜炎** では、同じ理由で、抗菌薬の直前か同時にデキサメタゾンを使う |
| **レジオネラ** | 肺胞マクロファージなど **細胞の中** で増える菌で、菌が減るのに時間がかかる。適切な抗菌薬を使っていても、はじめの数日は胸部 X 線の影が広がることが多く、熱もなかなか下がらない |
| **ノカルジア** | ゆっくり増える菌で、膿瘍を作りやすい。よく使う ST 合剤は菌を殺すより増えるのをおさえる薬で、効きはじめるのが遅い。そのため、はじめは病変が大きくなって見えることがある |
| **ヤーリッシュ・ヘルクスハイマー反応** | 梅毒、回帰熱、レプトスピラ症、ライム病など、スピロヘータの感染症で起こる。最初の抗菌薬を使ってから **数時間以内** に、死んだ菌から出るリポたんぱく質に反応して、熱、悪寒、血圧の低下が出る。多くは 1 日以内におさまる |
| **免疫再構築症候群（IRIS）・結核の逆説的反応** | 治療で体の免疫が回復すると、残っている菌や菌の成分に強く反応するようになる。結核の治療中や、HIV 感染者で抗 HIV 薬を始めたあとに、リンパ節が腫れる、影が広がるなどが起こる |

#### 治療の失敗との見分け方
- **起こる時期** が決まっている。上の病態は治療開始から数時間〜数日のうち。それより後に悪くなるなら、治療の失敗や別の問題を考える
- 多くは **一時的** で、そのまま治療を続ければよくなる。むやみに抗菌薬を変えない
- ただし、悪くなっている間に命にかかわることもある。呼吸や血圧は注意して見て、必要なら集中治療を行う
- 「いったん悪くなることがある病気」でも、診断や薬が合っていない可能性は、ほかの場合と同じように考える

### よくなるまで時間がかかるもの
また、次のような場合は、よくなるまでに時間がかかる。「よくなるのが遅い」ことと「よくならない」ことを区別する。

- 腎盂腎炎は、効いていても熱が数日続くことがある
- 膿瘍は、ドレナージをしないと熱が下がりにくい
- 結核、感染性心内膜炎、骨髄炎などは、経過が月単位
- 高齢者や免疫が落ちている人は、症状が出にくく、よくなるのもゆっくり

## この説の限界
- 急性の **細菌感染症** を念頭においた経験則。ウイルス感染症、慢性の感染症、免疫が落ちている人では当てはまりにくい
- 症状には日内変動がある。1 日の中の上下ではなく、**日ごとの流れ** で見る
- 経過がおかしいと気づくきっかけにすぎない。その先は、診察と検査で原因をはっきりさせる
