# 介護医療院のⅠ型・Ⅱ型

**Ⅰ型は重篤な身体疾患や身体合併症を有する認知症高齢者等を主な対象とし、Ⅱ型はそれ以外の長期療養が必要な者を対象とする。** どちらも医療と介護を提供し、長期療養と日常生活を支える介護保険施設である。

## 対象者の違い

| 項目 | Ⅰ型 | Ⅱ型 |
| --- | --- | --- |
| 主な対象 | 長期療養が必要で、重篤な身体疾患を有する者、身体合併症を有する認知症高齢者等 | Ⅰ型療養床以外。Ⅰ型と比べて容体が比較的安定した者を想定 |
| 制度上の位置づけ | 介護療養病床の療養機能強化型相当のサービス | 老人保健施設相当以上のサービス |
| 共通する役割 | 医療・看護・介護、生活支援、看取り・ターミナルケア | 同左 |

Ⅰ型・Ⅱ型は要介護度だけで決まる区分ではない。Ⅱ型も長期療養・生活のための介護医療院であり、老健そのものではない。[厚生労働省：介護医療院とは](https://www.mhlw.go.jp/kaigoiryouin/about/)

## Ⅰ型の対象疾患・状態

**Ⅰ型への入所を、特定の病名の一覧だけで判断する仕組みではない。** 長期療養の必要性や病状、必要な医療・介護、施設の対応力を踏まえて判断する。一方、報酬上の施設基準で「重篤な身体疾患を有する者」「身体合併症を有する認知症高齢者」として数える際には、具体的な状態・疾病の定義がある。

### 重篤な身体疾患を有する者

病名だけでなく、重症度・継続期間・治療内容などで判定する。以下は通知に示される状態の例であり、全項目の一覧ではない。

| 疾患・領域 | 判定に用いる状態の例 |
| --- | --- |
| 慢性心不全 | NYHA分類Ⅲ以上 |
| 呼吸障害 | Hugh-Jones分類Ⅳ以上の呼吸困難、または連続1週間以上人工呼吸器が必要 |
| 腎不全・透析 | 各週2日以上の人工腎臓が必要で、所定の合併症がある状態。透析を受けているだけではこの条件を満たさない |
| 肝機能障害 | Child-Pugh分類C以上 |
| 意識障害 | 連続3日以上、JCS100以上が継続 |

透析の所定の合併症には、常時低血圧（収縮期血圧90mmHg以下）、運動機能障害等を伴う透析アミロイド症、出血性消化器病変、骨折を伴う二次性副甲状腺機能亢進症が挙げられる。

根拠：[厚生労働省：介護医療院ハンドブック・報酬関係資料](https://www.mhlw.go.jp/kaigoiryouin/assets/docs/kaigoiryouin_3.pdf)、[前橋市：介護医療院自主点検表（2025年3月版）](https://www.city.maebashi.gunma.jp/material/files/group/40/R703zisyutenkenhyou26iryouinp.pdf)。実際の人数集計には、通知の全項目と各条件を照合する。

### 身体合併症を有する認知症高齢者

通知では、次のいずれかに該当する者を挙げている。

| 区分 | 疾患・状態 |
| --- | --- |
| 認知症＋悪性腫瘍 | 認知症で、悪性腫瘍と診断されている |
| 認知症＋所定の神経疾患等 | 下記のいずれかの疾病と診断されている |
| 認知症の日常生活自立度 | ランクⅢb・Ⅳ・Mのいずれかに該当 |

「認知症＋所定の神経疾患等」の疾病は次のとおり。

- パーキンソン病関連疾患：進行性核上性麻痺、大脳皮質基底核変性症、パーキンソン病。
- 多系統萎縮症：線条体黒質変性症、オリーブ橋小脳萎縮症、シャイ・ドレーガー症候群。
- 筋萎縮性側索硬化症（ALS）。
- 脊髄小脳変性症。
- 広範脊柱管狭窄症。
- 後縦靱帯骨化症。
- 黄色靱帯骨化症。
- 悪性関節リウマチ。

**この疾病リストの区分は「認知症があること」が前提。** たとえばパーキンソン病の診断だけで、この区分の人数に数えられるわけではない。別の重篤な身体疾患の状態等に当てはまるかは別に判定する。

根拠：[前橋市：介護医療院自主点検表](https://www.city.maebashi.gunma.jp/material/files/group/40/R703zisyutenkenhyou26iryouinp.pdf)、[川口市：介護医療院自主点検表](https://www.city.kawaguchi.lg.jp/material/files/group/39/R7iryouP.pdf)。

### 入所対象と「重度者割合50％以上」は別

通常規模のⅠ型の報酬上の施設基準では、前3月間の入所者等のうち、上記の重篤な身体疾患を有する者と身体合併症を有する認知症高齢者の割合が50％以上であること等を求める。同一人が両方に当てはまる場合は二重計上しない。

これは施設の報酬算定の要件であり、**Ⅰ型の入所者全員が、上記のいずれかに該当しなければならないという意味ではない。** また、これだけで基本報酬の全要件を満たすわけではなく、医療処置・ターミナルケア等の基準も区分ごとに確認する。

根拠：[厚生労働大臣が定める施設基準・介護医療院サービス](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4585&dataType=0&pageNo=2)。

## 法令上の定義

介護医療院基準第3条は、療養床を次のように区分する。

> 二　Ⅰ型療養床　療養床のうち、主として長期にわたり療養が必要である者であって、重篤な身体疾患を有する者、身体合併症を有する認知症高齢者等を入所させるためのものをいう。
>
> 三　Ⅱ型療養床　療養床のうち、Ⅰ型療養床以外のものをいう。

療養床とは、療養室のうち入所者1人当たりの寝台等の部分。同じ施設にⅠ型・Ⅱ型の療養床がある場合も、区分ごとの入所者数に応じて必要人員を計算する。[介護医療院基準第3条・第4条](https://www.mhlw.go.jp/web/t_doc?dataId=82ab6230)

## 基本的な人員配置の違い

比率は入所者数対職員数で、下表の医師・薬剤師・看護・介護職員は常勤換算による。常時その人数が同時に勤務するという意味ではない。

| 職種 | Ⅰ型 | Ⅱ型 |
| --- | --- | --- |
| 医師 | 48対1を計算基礎とする | 100対1を計算基礎とする |
| 薬剤師 | 150対1 | 300対1 |
| 看護師・准看護師 | 6対1 | 6対1 |
| 介護職員 | 5対1 | 6対1 |
| 理学療法士・作業療法士・言語聴覚士 | 実情に応じた適当数 | 同左 |
| 栄養士・管理栄養士 | 定員100人以上で1人以上 | 同左 |
| 介護支援専門員 | 常勤1人以上。入所者100人またはその端数ごとに1人を標準 | 同左 |
| 診療放射線技師 | 実情に応じた適当数 | 同左 |

**医師数は比率だけで確定しない。** 原則は「Ⅰ型入所者数÷48＋Ⅱ型入所者数÷100」で、合計が3未満なら3、1未満の端数は切上げ。ただし、宿直医を置かないことが認められる場合、医療機関併設型、定員19人以下の併設型小規模には別の取扱いがある。

人員基準・例外の詳細は[[介護医療院・特養・老健の人員配置基準]]を参照。[介護医療院基準第4条](https://www.mhlw.go.jp/web/t_doc?dataId=82ab6230)

## 医師の宿直

基準第27条第3項は次のように定める。

> ３　介護医療院の管理者は、介護医療院に医師を宿直させなければならない。ただし、当該介護医療院の入所者に対するサービスの提供に支障がない場合にあっては、この限りではない。

Ⅱ型療養床のみの施設など、解釈通知の条件に該当し、サービス提供に支障がない場合には宿直を要しない取扱いがある。Ⅰ型・Ⅱ型の名称だけで、個々の施設の宿直体制を判断しない。

**宿直体制の確保と、医師の常勤換算への勤務時間の算入は別に確認する。** 宿直の待機・睡眠を含む全時間を当然に算入できるとする根拠は、このページでは確認できていない。算入の可否は勤務の実態・勤務表・併設医療機関との兼務状況に基づいて許可権者に確認する。

根拠：[介護医療院基準第27条](https://www.mhlw.go.jp/web/t_doc?dataId=82ab6230)、[厚生労働省：介護医療院開設に向けたハンドブック・夜間の職員配置](https://www.mhlw.go.jp/kaigoiryouin/assets/docs/kaigoiryouin_3.pdf)。

## 報酬の「Ⅰ・Ⅱ・Ⅲ」との区別

**「Ⅰ型・Ⅱ型」は療養床の類型。「サービス費（Ⅰ）・（Ⅱ）・（Ⅲ）」は介護報酬の区分で、別の分類。**

たとえば「Ⅰ型介護医療院サービス費（Ⅱ）」は、Ⅰ型の療養床について、サービス費の区分（Ⅱ）を算定するという意味。Ⅱ型になったという意味ではない。

報酬は類型だけでなく、サービス費の区分、要介護度、個室・多床室、ユニット型、加算・減算等で変わる。基本人員を満たしても、希望する報酬区分や加算の要件をすべて満たすとは限らない。[報酬告示・別表4](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)
