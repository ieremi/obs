# *Moraxella*（モラクセラ属）

**グラム陰性の球菌・短桿菌を含む属。** 臨床では *M. catarrhalis* の呼吸器感染を中心に学ぶ。双球菌という見た目だけでNeisseriaと同定しない。

## 名前の由来とラテン語

研究者 **V. Morax** にちなむ *Morax* ＋ラテン語の指小辞 *-ella*。新ラテン語の女性名詞。形や感染部位を直訳した名前ではない。

属名の出典：[LPSN：Moraxella](https://lpsn.dsmz.de/genus/moraxella)。語源は命名の由来であり、全菌種・全菌株の性状を保証するものではない。

## 代表種と性状

| 項目 | 主に *M. catarrhalis* の特徴 |
| --- | --- |
| 形 | グラム陰性双球菌 |
| オキシダーゼ | 陽性 |
| カタラーゼ | 陽性 |
| 糖の利用 | 非糖分解性 |
| 主な病気 | 中耳炎、副鼻腔炎、慢性呼吸器疾患の増悪など |

上気道に保菌されることがあり、検出だけで症状の原因と断定しない。属内には *M. lacunata* など別菌種もあり、*M. catarrhalis* の特徴をすべてに当てはめない。

## 耐性と検査の意味

*M. catarrhalis* はβ-ラクタマーゼ産生が多いため、アンピシリンなどの単剤が使えると決めつけない。治療は感染部位・感受性で判断する。
