# *Helicobacter* (ヘリコバクター)

## 概要
- **グラム陰性の微好気性らせん菌**。臨床で重要なのは ***Helicobacter pylori***(ヘリコバクター・ピロリ、ピロリ菌)
- **ヒトの胃の粘膜にすみつく**。強い酸の中で生きられる数少ない細菌
- 多くは幼児期に感染し、除菌しなければ一生続く。日本では高齢の世代ほど感染率が高く、若い世代では低くなっている
- 慢性胃炎、**消化性潰瘍、胃癌**、胃 MALT リンパ腫、免疫性血小板減少症の原因になる。国際がん研究機関 (IARC) は 1994 年に確実な発がん因子(グループ 1)とした
- 1982 年にマーシャルとウォレン (Marshall & Warren) が培養に成功し、2005 年にノーベル生理学・医学賞を受賞した
- 日本では、除菌は [[アモキシシリン]] + クラリスロマイシン + 酸分泌抑制薬(ボノプラザンまたはプロトンポンプ阻害薬)の 3 剤併用が一次除菌

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Helicobacter* | ギリシア語 ἕλιξ (hélix)「らせん」+ *-bacter* | らせん形の桿菌 |
| *-bacter* | ギリシア語 βακτήριον (baktḗrion)「小さな杖」から作った新ラテン語 | 桿菌 |
| *pylori* | ラテン語 *pylōrus*「幽門」の属格 | 幽門の |
| *pylōrus* | ギリシア語 πυλωρός (pylōrós)「門番」。πύλη (pýlē)「門」+ οὖρος (oûros)「見張り」 | 胃の出口の門番 |

- 幽門(胃の出口)近くの胃粘膜(前庭部)で見つかったことから名付けられた
- 英語の helix(らせん)、helicopter(らせん + 翼)と同じ語根

### 名前の変遷
| 年 | 学名 | 理由 |
| --- | --- | --- |
| 1984〜85 年 | *Campylobacter pyloridis* | 形が[[Campylobacter\|カンピロバクター]]に似ていたため同じ属に入れられた |
| 1987 年 | *Campylobacter pylori* | 種小名の属格の形を正しく直した(下の文法を参照) |
| 1989 年 | *Helicobacter pylori* | 鞭毛の構造や遺伝子がカンピロバクターと違うことがわかり、新しい属が立てられた |

### ラテン語文法
- *Helicobacter* は男性名詞
- *pylori* は名詞 *pylōrus*(第 2 変化・男性)の**属格**

| 格 | 単数 |
| --- | --- |
| 主格 | pylōrus |
| 属格 | **pylōrī** |
| 与格 | pylōrō |
| 対格 | pylōrum |
| 奪格 | pylōrō |

- 最初の *pyloridis* は、*pylorus* を第 3 変化の名詞(主格 *-us*、属格 *-idis* の型)のように扱った形で、正しくないとされた。第 2 変化なので属格は *pylori* になる
- [[Escherichia_coli|*Escherichia coli*]] の *coli*「大腸の」と同じく、臓器の名前の属格を種小名にしたもの

## 性状
| 項目 | 内容 |
| --- | --- |
| 形 | らせん状(S 字状)の桿菌。長さ約 2.5〜5 µm |
| 運動性 | 片方の端に**鞘に包まれた鞭毛**が数本あり、粘液の中をよく動く |
| 酸素 | 微好気性(酸素 5% 前後を好む) |
| ウレアーゼ | **強陽性** |
| [[oxidase#オキシダーゼ試験\|オキシダーゼ]]、カタラーゼ | 陽性 |

## 胃の中で生きるしくみ
- **ウレアーゼ**: 尿素をアンモニアと二酸化炭素に分解する。アンモニアで菌のまわりの酸を中和する
  - $\mathrm{CO(NH_2)_2 + H_2O \rightarrow 2NH_3 + CO_2}$
  - このしくみを診断に使う(尿素呼気試験、迅速ウレアーゼ試験)
- **鞭毛**: 胃酸の強い内腔から、pH が中性に近い粘液層の奥(上皮の表面)へ泳いでいく
- **付着因子**: 胃の上皮細胞に付着する

## 病気を起こすしくみ
- **CagA**: IV 型分泌装置で胃の上皮細胞に注入される蛋白質。細胞の増殖や形の異常を起こし、胃癌のリスクを上げる。東アジアの株の CagA は作用が強い
- **VacA**: 上皮細胞に空胞を作り、免疫細胞の働きも抑える毒素
- 慢性炎症が続き、萎縮性胃炎 → 腸上皮化生 → 胃癌と進むことがある

## 起こす病気
| 病気 | ポイント |
| --- | --- |
| 慢性胃炎(ヘリコバクター・ピロリ感染胃炎) | ほぼ全員に起こる。日本では 2013 年から、内視鏡で確認した感染胃炎の除菌に保険が適用された |
| 胃潰瘍・十二指腸潰瘍 | 除菌で再発がとても少なくなる。もう一つの主な原因は NSAIDs([[ロキソプロフェン]]など)で、[[プロスタグランジン]]の減少による |
| 胃癌 | 除菌で減らせる(とくに早い時期の除菌) |
| 胃 MALT リンパ腫 | 早期のものは除菌だけで治ることが多い |
| 免疫性血小板減少症 | 除菌で血小板が増えることがある |

## 診断
- 内視鏡を使う検査: 迅速ウレアーゼ試験、組織の鏡検、培養(薬剤感受性がわかる)
- 内視鏡を使わない検査: **尿素呼気試験**、便中抗原、血清・尿中抗体
- 酸分泌抑制薬や抗菌薬を使っていると偽陰性になりやすい

## 除菌(日本)
| | 組み合わせ(いずれも 1 日 2 回、7 日間) |
| --- | --- |
| 一次除菌 | [[アモキシシリン]] 750 mg + クラリスロマイシン 200 mg(最大 400 mg) + 酸分泌抑制薬 |
| 二次除菌 | [[アモキシシリン]] 750 mg + **メトロニダゾール** 250 mg + 酸分泌抑制薬 |

- 酸分泌抑制薬は、ボノプラザン(カリウムイオン競合型アシッドブロッカー、P-CAB)またはプロトンポンプ阻害薬
- 胃の pH を上げると、アモキシシリンとクラリスロマイシンが安定して効きやすくなる。ボノプラザンは酸をより強く、速く抑えるので除菌率が高い
- **クラリスロマイシン耐性**(23S rRNA の点変異)が増えていて、一次除菌が失敗する主な原因になっている
- 除菌の判定は、治療終了から 4 週以降に尿素呼気試験などで行う(一般的な知識)

## エビデンス
- **発見 (Lancet 1984)**: 胃炎と消化性潰瘍の患者の胃に、らせん状の桿菌がいることを報告した
  - Marshall BJ, Warren JR. Lancet. 1984;323(8390):1311-1315. [doi:10.1016/S0140-6736(84)91816-6](https://doi.org/10.1016/S0140-6736(84)91816-6)
- **除菌と胃癌 (Lancet 2008)**: 日本で、早期胃癌を内視鏡で切除した患者に除菌すると、新たな胃癌(異時性胃癌)ができる割合が約 3 分の 1 に減った
  - Fukase K, et al. Lancet. 2008;372(9636):392-397. [doi:10.1016/S0140-6736(08)61159-9](https://doi.org/10.1016/S0140-6736(08)61159-9)
- **ボノプラザンを使った 3 剤併用 (Gut 2016)**: 日本の第 III 相試験で、一次除菌の成功率がランソプラゾールより高かった(非劣性を示し、優越性も認められた)
  - Murakami K, et al. Gut. 2016;65(9):1439-1446. [doi:10.1136/gutjnl-2015-311304](https://doi.org/10.1136/gutjnl-2015-311304)

この内容は一般的な微生物学・消化器病学の知識と、サワシリンの添付文書による。
