# *Klebsiella*（クレブシエラ）

**グラム陰性の通性嫌気性桿菌の属**。[[Escherichia|大腸菌]]や[[Enterobacter|エンテロバクター]]と同じ腸内細菌目に属する。

代表的な菌種は ***Klebsiella pneumoniae*（肺炎桿菌）**。腸内に保菌されることがあり、肺炎、尿路感染症、血流感染症などの原因になる。[CDC](https://www.cdc.gov/klebsiella/about/)


## 名前の由来とラテン語

細菌学者 **Edwin Klebs** にちなみ、*Klebs* にラテン語化した接尾辞 *-iella* を付けた名前。属名は文法上女性。

*pneumoniae* は「肺炎の」を表す名詞の属格で、女性形容詞ではない。名前が肺炎に由来していても、感染部位を肺に限定するものではない。

属名の出典：[LPSN：Klebsiella](https://lpsn.dsmz.de/genus/klebsiella)。語源は命名の由来であり、全菌種・全菌株の性状を保証するものではない。

## 主な菌種

| 菌種 | 臨床上の特徴 |
| --- | --- |
| *K. pneumoniae*（肺炎桿菌） | 肺炎や血流感染症などの原因。ESBLやカルバペネマーゼを産生する株がある |
| *K. oxytoca* | ESBL産生菌としても問題になる菌種 |
| *K. aerogenes* | 旧名 *Enterobacter aerogenes*。誘導型AmpCによる耐性が重要 |

属名だけで抗菌薬への反応を一括りにせず、**菌種と薬剤感受性**を確認する。[IDSA 2026](https://www.idsociety.org/practice-guideline/amr-guidance/)

## 性状

以下は主に *K. pneumoniae* の特徴。

| 項目 | 内容 |
| --- | --- |
| グラム染色・形 | グラム陰性桿菌 |
| 酸素 | 通性嫌気性 |
| 莢膜 | 多糖の莢膜を持ち、粘液性のコロニーを形成する |
| 運動性 | 非運動性 |
| 乳糖分解 | 陽性 |
| [[oxidase#オキシダーゼ試験|オキシダーゼ]] | 陰性 |

莢膜は宿主の防御を回避するうえで重要。[Medical Microbiology](https://www.ncbi.nlm.nih.gov/books/NBK8035/)

## 肺炎との関係

肺炎桿菌は肺炎の原因菌の一つだが、**肺炎のすべてがこの菌によるものではない**。肺以外の感染症も起こす。

院内感染では、人工呼吸器や静脈カテーテルを使用している患者、長期間抗菌薬を使用している患者などで問題になる。[CDC](https://www.cdc.gov/klebsiella/about/)

喀痰で検出されても、原因菌とは限らない。気道への定着や検体の汚染もあり、症状、胸部画像、酸素化、検体の質を合わせて判断する。[ATS/IDSA：院内肺炎ガイドライン](https://www.idsociety.org/practice-guideline/hap_vap/)

## ESBLと薬剤耐性

- **[[ESBL]]産生株**：多くのペニシリン系、セファロスポリン系、アズトレオナムを不活化する。[[セフトリアキソン]]などが効きにくくなる。
- **カルバペネマーゼ産生株**：カルバペネム系にも耐性を示しうる。ESBLとは別の耐性機構。
- ***K. aerogenes***：誘導型AmpCが重要。第3世代セファロスポリンで治療中に耐性化することがある。

**すべてのKlebsiellaがESBL産生菌やカルバペネム耐性菌というわけではない**。[IDSA 2026](https://www.idsociety.org/practice-guideline/amr-guidance/)

## 高病原性株

*K. pneumoniae* の一部には **高病原性株（hypervirulent K. pneumoniae：hvKp）**がある。肝膿瘍や、眼・中枢神経などへの播種性感染が問題になる。

**病原性の強さと薬剤耐性は別の性質**だが、高病原性とカルバペネム耐性を併せ持つ株も報告されている。[ECDC：高病原性K. pneumoniaeのリスク評価](https://www.ecdc.europa.eu/en/publications-data/risk-assessment-emergence-hypervirulent-klebsiella-pneumoniae-eu-eea)

## 治療の考え方

感染部位、重症度、薬剤感受性で選択する。保菌・定着と、治療が必要な感染症を区別する。

ESBL産生菌による肺炎など尿路外の感染では、カルバペネム系が優先選択。カルバペネム耐性の場合は、耐性機構に応じた別の治療選択が必要になる。[IDSA 2026](https://www.idsociety.org/practice-guideline/amr-guidance/)
