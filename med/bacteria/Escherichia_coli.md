# *Escherichia coli* (大腸菌)

## 概要
- **グラム陰性の通性嫌気性桿菌**。腸内細菌目細菌 (*Enterobacterales*) の代表
- ヒトや温血動物の大腸にいる常在菌。ただし腸内細菌叢の中では少数派で、大部分は嫌気性菌が占める
- 腸管の外に出ると病気を起こす。**尿路感染症の原因菌として最も多い**ほか、菌血症・胆道感染・腹膜炎などの原因になる
- 一部の株は腸管に病気を起こす(下痢原性大腸菌)。腸管出血性大腸菌 O157 など
- 名前は 1885 年に最初に報告したテオドール・エシェリヒ (Theodor Escherich) に由来する → [[#名前の由来とラテン語]]
- 分子生物学のモデル生物として最もよく使われる細菌でもある

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Escherichia* | 人名 Escherich + 接尾辞 *-ia* | 「エシェリヒの(菌)」 |
| *coli* | ラテン語 *cōlon*「大腸・結腸」の属格 | 「大腸の」 |

- **Escherichia**: ドイツ出身の小児科医テオドール・エシェリヒ (Theodor Escherich, 1857–1911) の名前に、属名をつくる接尾辞 *-ia* を付けたもの
  - 人名から属名をつくる例はほかにも多い: *Salmonella*(サーモン Salmon + 指小辞 *-ella*)、*Shigella*(志賀潔 + *-ella*)、*Klebsiella*(クレープス Klebs + *-ella*)、*Yersinia*(イェルサン Yersin + *-ia*)、*Listeria*(リスター Lister + *-ia*)
- **coli**: ラテン語 *cōlon*(大腸・結腸)の属格(「〜の」の形)。*cōlon* はギリシア語 κόλον (kólon)「大腸」を借りた語。英語の colon や、医学用語の colitis(大腸炎)、colonoscopy(大腸内視鏡)と同じ語
- 和名の「大腸菌」は *coli*「大腸の」とほぼ同じ意味になっている

### 名前の歴史
- 1885 年: エシェリヒが乳児の便から見つけ、*Bacterium coli commune*「大腸のありふれた細菌」と名付けた
  - *Bacterium*(細菌、中性名詞)+ *coli*(大腸の、属格)+ *commune*(ありふれた、*Bacterium* に合わせた中性形の形容詞)
- 1919 年: カステラーニとチャーマーズ (Castellani & Chalmers) が、エシェリヒにちなむ属 *Escherichia* を立て、*Escherichia coli* となった

### ラテン語文法
#### 二名法
学名は「**属名 + 種小名**」の 2 語でできている(リンネの二名法)。
- **属名** (*Escherichia*): 名詞。主格(文の主語の形)。最初の文字は大文字
- **種小名** (*coli*): 属名を説明する語。すべて小文字
- どちらもイタリック体で書く。2 回目からは *E. coli* と属名を略してよい

#### 属名 *Escherichia* の変化
第 1 変化の女性名詞。
| 格 | 単数 | 複数 |
| --- | --- | --- |
| 主格(〜が) | Escherichia | Escherichiae |
| 属格(〜の) | Escherichiae | Escherichiārum |
| 与格(〜に) | Escherichiae | Escherichiīs |
| 対格(〜を) | Escherichiam | Escherichiās |
| 奪格(〜で・〜から) | Escherichiā | Escherichiīs |

#### 種小名 *coli* は名詞の属格
*cōlon* は第 2 変化の中性名詞(ギリシア語から来た語なので、主格が *-um* ではなく *-on* で終わる)。
| 格 | 単数 |
| --- | --- |
| 主格 | cōlon |
| 属格 | **cōlī** |
| 与格 | cōlō |
| 対格 | cōlon |
| 奪格 | cōlō |

種小名 *coli* はこの属格なので、*Escherichia coli* は「大腸の、エシェリヒの菌」という意味になる。

#### 種小名の型
種小名は、名詞の属格か、属名を修飾する形容詞であることが多い。名詞の属格は属名の性と関係なく形が決まるが、形容詞は属名の性(男性・女性・中性)に語尾を合わせる。

| 型 | 例 | 意味 | 文法 |
| --- | --- | --- | --- |
| 名詞の属格 | *Escherichia **coli*** | 大腸の | *cōlon* の属格。属名の性とは関係ない |
| 名詞の属格 | *Klebsiella **pneumoniae*** | 肺炎の | *pneumonia*(第 1 変化・女性)の属格 |
| 形容詞 | *Staphylococcus **aureus*** | 金色の | *aureus, -a, -um*。男性名詞 *coccus* に合わせて男性形 |
| 形容詞 | *Pseudomonas **aeruginosa*** | 緑青(銅のさび)色の | *aerūginōsus, -a, -um*。女性名詞 *Pseudomonas* に合わせて女性形 |
| 形容詞 | *Proteus **mirabilis*** | 驚くべき | 第 3 変化の形容詞 *mīrābilis*(男性・女性で同じ形) |
| 名詞の属格 | *Bacillus **anthracis*** | 炭疽の | *anthrax*(第 3 変化・男性)の属格 |

- 種が性の違う属に移されると、形容詞の種小名は新しい属の性に合わせて語尾を変えるのが原則。名詞の属格(*coli* など)は変わらない

#### 読み方
- 日本語: エシェリキア・コリ(エシェリヒア・コリとも)
- 英語: /ˌɛʃəˈrɪkiə ˈkoʊlaɪ/(エシェリキア・コウライ)
- 古典ラテン語の発音にならえば *cōlī* は「コーリー」。学名の読み方には決まった規則がなく、国や分野で慣用が違う

## 性状
| 項目 | 内容 |
| --- | --- |
| 大きさ | 長さ約 2 µm、幅約 0.5〜1 µm |
| 運動性 | 多くは周毛性の鞭毛で運動する |
| 至適温度 | 37 ℃ 前後 |
| 分裂時間 | 条件がよければ約 20 分 |
| 乳糖分解 | 陽性(マッコンキー寒天でピンクの集落、EMB 寒天で金属光沢のある緑色の集落) |
| オキシダーゼ | 陰性 |
| カタラーゼ | 陽性 |
| IMViC | インドール +、メチルレッド +、VP −、クエン酸 − |
| ゲノム | 約 4.6 Mb の環状染色体 1 本(K-12 株 MG1655)。遺伝子は約 4,300 個 |

## 抗原
血清型は 3 種類の抗原の組み合わせで表す(例: O157:H7)。
- **O 抗原**: 外膜のリポ多糖 (LPS) の糖鎖部分
- **H 抗原**: 鞭毛
- **K 抗原**: 莢膜。K1 莢膜は新生児髄膜炎の原因株に多い

## 腸管外の感染症
| 感染症 | ポイント |
| --- | --- |
| 尿路感染症(膀胱炎・腎盂腎炎) | 最も多い原因菌。尿路病原性大腸菌 (UPEC) は線毛(1 型線毛の FimH、P 線毛)で尿路の上皮に付着する |
| 菌血症・敗血症 | 尿路・胆道・腹腔からの侵入が多い |
| 胆嚢炎・胆管炎 | 腸内細菌目細菌の代表的な原因菌 |
| 腹膜炎・腹腔内膿瘍 | 嫌気性菌との混合感染が多い |
| 新生児髄膜炎 | B 群レンサ球菌 (*Streptococcus agalactiae*) と並ぶ主な原因菌。K1 莢膜をもつ株が多い |
| 院内肺炎 | 人工呼吸器関連肺炎などの原因になる |

## 下痢原性大腸菌
日本では次の 5 つに分けることが多い。

| 種類 | 略称 | しくみ | 特徴 |
| --- | --- | --- | --- |
| 腸管出血性大腸菌 | EHEC (STEC) | 志賀毒素 (Stx1、Stx2) | 血便。溶血性尿毒症症候群 (HUS) を起こすことがある。O157、O26、O111 など。少ない菌量(100 個程度)でも感染する |
| 腸管毒素原性大腸菌 | ETEC | 易熱性毒素 (LT)、耐熱性毒素 (ST) | 水様性の下痢。旅行者下痢症の主な原因 |
| 腸管病原性大腸菌 | EPEC | 腸の上皮に付着し、微絨毛を壊す (attaching and effacing) | 乳幼児の下痢 |
| 腸管侵入性大腸菌 | EIEC | 腸の上皮の細胞に侵入する | 赤痢に似た症状 |
| 腸管凝集付着性大腸菌 | EAEC | 腸の上皮に凝集して付着する | 長引く下痢 |

- EHEC 感染症は感染症法の**三類感染症**で、診断したら直ちに届け出る
- EHEC で止痢薬(腸の動きを止める薬)を使うと、毒素が腸にとどまり HUS のリスクが上がるおそれがあるため避ける。抗菌薬を使うかどうかは意見が分かれている

## 抗菌薬への耐性
### もともとの性質
- 染色体に AmpC 型の β-ラクタマーゼ遺伝子をもつが、発現を誘導するしくみ (AmpR) がなく、作る量はとても少ない。そのため、[[Enterobacter|エンテロバクター属]] (*Enterobacter* spp.) などと違い、耐性遺伝子を獲得していなければ[[アンピシリン]]や第 1 世代セフェムにも感性
- グラム陽性菌用の薬(バンコマイシンなど)は外膜を通れないので効かない

### 獲得耐性
| 耐性 | しくみ | 影響 |
| --- | --- | --- |
| アンピシリン耐性 | プラスミド上の TEM-1 などの狭域 β-ラクタマーゼ | アンピシリンが効かない。TEM-1 を大量に作る株では [[セファゾリン]] も効かなくなる |
| ESBL 産生 | CTX-M 型などの基質特異性拡張型 β-ラクタマーゼ | 第 3 世代セフェム([[セフトリアキソン]]、[[セフカペン]]など)が効かない。[[セフメタゾール]](セファマイシン系)やカルバペネムは分解されにくい |
| AmpC 過剰産生 | 染色体の AmpC のプロモーター変異、またはプラスミド性 AmpC の獲得 | セファマイシン系も分解される |
| カルバペネマーゼ産生 | IMP 型(日本で多い)、KPC 型、NDM 型、OXA-48 型など | カルバペネムを含むほとんどの β-ラクタムが効かない |
| フルオロキノロン耐性 | DNA ジャイレース・トポイソメラーゼ IV の変異、排出ポンプ | レボフロキサシンなどが効かない |
| コリスチン耐性 | プラスミド上の *mcr-1* など | 最後の手段の薬が効かなくなる |

- **ST131**: ESBL(とくに CTX-M-15、CTX-M-27)とフルオロキノロン耐性をあわせもつことが多い流行クローン。世界中に広がっている

## 治療薬の選び方
感受性試験の結果で決めるのが基本。

- **感性株**: アンピシリン、[[セファゾリン]]などの狭い範囲の薬で治療できる
- **ESBL 産生株**: カルバペネムが標準。日本では [[セフメタゾール]] が代わりに使われることがある
- **第 3 世代セフェム耐性株の菌血症で、ピペラシリン・タゾバクタムはメロペネムより劣る**: [[ピペラシリン]]・[[タゾバクタム]]。MERINO 試験で 30 日死亡率がピペラシリン・タゾバクタム群で高かった

## 常在菌としての役割
- 腸内でビタミン K₂(メナキノン)を作る。抗菌薬で腸内細菌が減るとビタミン K が不足し、ワルファリンの作用が強まることがある([[セファゾリン]]の相互作用を参照)
- 水が糞便で汚れているかどうかの指標に使われる。日本の水道水質基準では「大腸菌は検出されないこと」と決められている

## モデル生物として
- **K-12 株**: 1922 年に分離された株。病原性がなく、O 抗原を作れない。多くの研究の基準株
- **B 株**: 派生株の BL21 は、組換えタンパク質を作らせるのによく使われる
- 大腸菌で見つかったことの例
  - 接合による遺伝子の受け渡し(レーダーバーグとテータム、1946 年)
  - DNA が半保存的に複製されること(メセルソンとスタール、1958 年)
  - *lac* オペロンによる遺伝子発現の調節(ジャコブとモノー、1961 年)
  - 組換え DNA 技術(コーエンとボイヤー、1973 年)
- 遺伝子組換えでヒト[[インスリン]]を作らせ、1982 年に医薬品として承認された(最初の組換え DNA 医薬品)

このノートの内容は一般的な微生物学・感染症学の知識による。

## エビデンス
- **MERINO 試験**: セフトリアキソン耐性の大腸菌・肺炎桿菌 (*Klebsiella pneumoniae*) の菌血症で、ピペラシリン・タゾバクタムはメロペネムに対する非劣性を示せなかった(30 日死亡率 12.3% vs 3.7%)
  - Harris PNA, et al. JAMA. 2018;320(10):984-994. [doi:10.1001/jama.2018.12163](https://doi.org/10.1001/jama.2018.12163)
- **全ゲノム配列**: K-12 株 MG1655 のゲノムが決定された
  - Blattner FR, et al. Science. 1997;277(5331):1453-1462. [doi:10.1126/science.277.5331.1453](https://doi.org/10.1126/science.277.5331.1453)
