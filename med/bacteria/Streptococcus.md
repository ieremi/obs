# *Streptococcus*（レンサ球菌属）

**主に連鎖状・双球状に見えるグラム陽性球菌の属。** 溶血性、群抗原、菌種を分けて整理する。

| 代表種 | 呼び名 | 典型的な性状・臨床 |
| --- | --- | --- |
| *S. pneumoniae* | 肺炎球菌 | α溶血・双球状。肺炎、髄膜炎 |
| *S. pyogenes* | A群レンサ球菌 | β溶血。咽頭炎、侵襲性感染 |
| *S. agalactiae* | B群レンサ球菌 | 通常β溶血。周産期・新生児感染 |

この3種だけが属の全体ではない。溶血性の例外もある。腸球菌は現在は別属の[[Enterococcus]]として扱う。

## 名前の由来とラテン語

ギリシア語 *streptos* と、新ラテン語 *coccus*「球菌」の組み合わせ。LPSNは *streptos* を「しなやかな・曲がる」と説明する。連なった球菌の像と結びつけると和名を覚えやすいが、「連鎖状」という臨床での覚え方と語の逐語訳は分ける。属名は男性。

| 種小名 | 意味 | 文法上の型 |
| --- | --- | --- |
| *pneumoniae* | 肺炎の | 名詞の属格 |
| *pyogenes* | 膿を作る | ギリシア語由来の形容詞 |
| *agalactiae* | 無乳症の | 名詞の属格 |

*agalactiae* は *a-*「ない」＋乳を表す語に由来する「無乳症」に関わる名前で、新生児だけを意味する名前ではない。

出典：[pneumoniae](https://lpsn.dsmz.de/species/streptococcus-pneumoniae)、[pyogenes](https://lpsn.dsmz.de/species/streptococcus-pyogenes)、[agalactiae](https://lpsn.dsmz.de/species/streptococcus-agalactiae)。

属名の出典：[LPSN：Streptococcus](https://lpsn.dsmz.de/genus/streptococcus)。語源は命名の由来であり、全菌種・全菌株の性状を保証するものではない。

## 肺炎球菌

**莢膜を持つグラム陽性球菌で、肺炎・中耳炎から菌血症・髄膜炎まで起こす。** 鼻咽頭に保菌されることもある。

### 性状

| 項目 | 特徴 |
| --- | --- |
| 形・配列 | ランセット状の双球菌が典型 |
| 溶血 | α溶血 |
| カタラーゼ | 陰性 |
| 古典的な鑑別 | オプトヒン感受性、胆汁溶解性 |
| 莢膜 | 多数の血清型があり、病原性・ワクチンと関係 |

α溶血だけでは他のレンサ球菌と区別できない。形態と検査結果を合わせる。[CDC：肺炎球菌同定資料](https://stacks.cdc.gov/view/cdc/11632/cdc_11632_DS1.pdf)

### 感染部位で整理する

| 部位 | 病気 |
| --- | --- |
| 耳・副鼻腔 | 中耳炎、副鼻腔炎 |
| 肺 | 肺炎。膿胸を伴うことがある |
| 血液 | 菌血症 |
| 中枢神経 | 髄膜炎 |

通常は無菌である部位から菌が検出される感染を、侵襲性肺炎球菌感染症として扱う。肺炎でも、菌血症を伴うかで侵襲性の分類が変わる。[CDC：Clinical Overview](https://www.cdc.gov/pneumococcal/hcp/clinical-overview/index.html)

### 肺炎桿菌との違い

| 肺炎球菌 | 肺炎桿菌 |
| --- | --- |
| *Streptococcus pneumoniae* | *Klebsiella pneumoniae* |
| グラム陽性球菌 | グラム陰性桿菌 |
| レンサ球菌の一種 | 腸内細菌目細菌の一種 |

名前に「肺炎」があるが別の菌。どちらも肺以外の感染を起こす。[[Klebsiella]]を参照。

### 治療・予防の考え方

治療は感染部位と薬剤感受性で選ぶ。特に髄膜炎では、中枢神経への薬剤移行と感染部位に対応した感受性判定が重要になる。

莢膜の血清型に対応したワクチンがある。対象年齢・製剤・接種間隔は国や制度、既接種歴で異なるため、最新の国内案内で確認する。[CDC：Clinical Overview](https://www.cdc.gov/pneumococcal/hcp/clinical-overview/index.html)

## A群レンサ球菌

**A群レンサ球菌（GAS）として知られるグラム陽性球菌。** 咽頭炎や皮膚感染に加え、侵襲性感染や感染後の免疫反応による病気を起こす。

### 性状

連鎖状に並び、通常はβ溶血を示す。カタラーゼ陰性。Lancefield分類のA群に属する。「A群」は血清学的な群、「β溶血」は培地上の性状で、違う分類軸である。[CDC：Clinical Considerations](https://www.cdc.gov/group-a-strep/hcp/clinical-guidance/index.html)

### 病気を三つに分ける

| 型 | 主な例 |
| --- | --- |
| 局所の感染 | 咽頭炎、膿痂疹、蜂窩織炎 |
| 侵襲性・重症感染 | 壊死性筋膜炎、菌血症、レンサ球菌性毒素性ショック症候群 |
| 感染後の合併症 | 急性リウマチ熱、溶連菌感染後糸球体腎炎 |

侵襲性感染については[CDC：医療従事者向け感染管理資料](https://www.cdc.gov/infection-control/hcp/healthcare-personnel-epidemiology-control/group-a-streptococcus.html)、咽頭炎後の合併症については[CDC：咽頭炎ガイダンス](https://www.cdc.gov/group-a-strep/hcp/clinical-guidance/strep-throat.html)を参照。

### 咽頭炎の検査と治療

のどが赤いだけでは原因菌は決まらない。迅速抗原検査や咽頭培養を、症状・年齢・流行状況と合わせて解釈する。保菌者に別の原因の咽頭炎が重なることもある。

確認されたGAS咽頭炎では、ペニシリン系や[[アモキシシリン]]が基本的な選択肢。マクロライド系・クリンダマイシンには耐性があり、地域・時期で状況が変わる。重症の侵襲性感染は、通常の咽頭炎と同じ扱いにはしない。[CDC：咽頭炎ガイダンス](https://www.cdc.gov/group-a-strep/hcp/clinical-guidance/strep-throat.html)

### 既存ノートとのつながり

[[溶連菌感染症]]は病気のページ、このページは菌のページ。B群の[[Streptococcus#B群レンサ球菌|B群レンサ球菌]]やα溶血の[[Streptococcus#肺炎球菌|肺炎球菌]]とは区別する。

## B群レンサ球菌

**B群レンサ球菌（GBS）。消化管・生殖器に無症状で保菌されることがあり、新生児の重症感染で重要。** 高齢者や基礎疾患のある成人にも感染を起こす。

### 性状と鑑別

グラム陽性の連鎖球菌で、カタラーゼ陰性。通常はβ溶血を示すが、非溶血株もある。CAMP試験や群抗原の検査などが同定の手がかりになる。溶血の有無だけでは除外しない。[UK SMI ID 4](https://www.rcpath.org/asset/33A8F14A-992D-467D-8F87BA4BAF4CD6CF/)

### 誰にどのような感染を起こすか

| 対象 | 主な病気・背景 |
| --- | --- |
| 新生児・乳児 | 敗血症、肺炎、髄膜炎 |
| 妊婦・産褥期 | 周産期の感染 |
| 成人 | 菌血症、皮膚・軟部組織感染など。高齢・糖尿病などがリスク |

保菌されていることと、感染症を発症していることは別。[CDC：GBS Clinical Overview](https://www.cdc.gov/group-b-strep/hcp/clinical-overview/index.html)

### 早発型と遅発型

乳児のGBS感染は、生後7日未満の**早発型**と、生後7〜89日の**遅発型**に分けられる。

分娩時の抗菌薬予防投与は早発型の予防に重要だが、遅発型まで同じように防げるわけではない。妊娠中の検査、分娩時の予防投与、新生児の感染治療を分けて理解する。[CDC：GBS Clinical Overview](https://www.cdc.gov/group-b-strep/hcp/clinical-overview/index.html)

### 治療・予防を読むとき

ペニシリン系が中心になるが、感染部位、薬剤アレルギー、感受性によって対応が変わる。妊婦のスクリーニング時期や予防投与の適応は、国内の産科指針で確認する。海外資料の手順をそのまま国内制度として扱わない。

[[Streptococcus#A群レンサ球菌|A群レンサ球菌]]の咽頭炎とは、患者背景も予防の考え方も異なる。新生児感染では[[Escherichia|大腸菌]]との比較も役立つ。
