# *Citrobacter* (シトロバクター)

## 概要
- **グラム陰性の通性嫌気性桿菌**。[[Escherichia_coli|大腸菌]]・[[Enterobacter|エンテロバクター]]と同じ腸内細菌目細菌 (*Enterobacterales*)
- ヒトや動物の腸内、水、土にいる。主に尿路感染、菌血症、腹腔内感染などの院内感染・日和見感染の原因になる
- 臨床で重要な 2 種は性質がかなり違う

| | *Citrobacter freundii*(フロインディ) | *Citrobacter koseri*(コセリ) |
| --- | --- | --- |
| 旧名 | — | *Citrobacter diversus* |
| β-ラクタマーゼ | **誘導型の染色体性 AmpC**([[Enterobacter]]と同じ) | 染色体性のクラス A β-ラクタマーゼ。誘導型 AmpC はない |
| 第 3 世代セフェム | 治療中に耐性になることがある | ふつうは効く |
| 特徴的な病気 | 院内感染。カルバペネマーゼをもつ株も多い | **新生児の髄膜炎と脳膿瘍** |
| 硫化水素 (H₂S) | 多くは陽性(サルモネラとまちがえやすい) | 陰性 |

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Citrobacter* | ラテン語 *citrus*(柑橘)に由来する citrate(クエン酸塩)+ *-bacter* | クエン酸を利用する桿菌 |
| *-bacter* | ギリシア語 βακτήριον (baktḗrion)「小さな杖」から作った新ラテン語 | 桿菌 |
| *freundii* | 人名 Freund の属格 | フロイントの |
| *koseri* | 人名 Koser の属格 | コーザーの |
| *diversus*(旧名) | ラテン語 *dīversus*「異なる、さまざまな」 | 異なる |

- **クエン酸塩を唯一の炭素源として育つ**性質から名付けられた(1932 年、ワークマンとギレン Werkman & Gillen)。英語の citric acid(クエン酸)、citron(シトロン)と同じ語根。[[クエン酸]]もこの性質の検査に使われる物質
- *freundii* は、19 世紀にこの菌がグリセリンからトリメチレングリコールを作ることを報告したフロイント (Freund) にちなむ
- *koseri* は、クエン酸利用試験の培地(コーザーのクエン酸培地)を考案した米国の細菌学者スチュアート・コーザー (Stewart A. Koser) にちなむ。属名も種小名も、クエン酸を使う性質に関係している

### ラテン語文法
- *Citrobacter* は男性名詞(*-bacter* で終わる属名)
- 種小名はどちらも**人名の属格**で、名前の終わり方で付け方が違う
  - 子音で終わる名前 → *-ii*: Freund → *freundii*([[Acinetobacter]] の *baumannii* と同じ)
  - *-er* で終わる名前 → *-i* だけ: Koser → *koseri*
  - 母音で終わる名前 → *-i*: Hormaeche → *hormaechei*([[Enterobacter]] を参照)
- 旧名の *diversus* は形容詞で、男性名詞 *Citrobacter* に合わせて男性形 *-us* になっている(女性形なら *diversa*、中性形なら *diversum*)。名詞の属格(*coli*、*pylori*、*cloacae*)と違い、形容詞は属名の性に合わせる

## 起こす病気
- **尿路感染症**: 最も多い。カテーテル関連が多い
- **菌血症**: 尿路・胆道・腹腔から
- **腹腔内感染、創部感染、肺炎**
- ***C. koseri* の新生児髄膜炎**: 髄膜炎を起こした新生児の多く(報告では 7〜8 割)に**脳膿瘍**ができる。脳の組織に入り込み、マクロファージの中で生き残る性質があるとされる。後遺症や死亡が多い

## 抗菌薬への耐性
### *C. freundii*
- 誘導型 AmpC をもつので、[[アンピシリン]]、[[アモキシシリン]]、[[セファゾリン]]、[[セフメタゾール]]にもともと耐性
- 第 3 世代セフェム([[セフトリアキソン]]など)は感性でも、治療中に AmpC を大量に作る変異株が選ばれて耐性になることがある。しくみは [[Enterobacter#AmpC と耐性]] と同じ
- 重い感染ではセフェピムやカルバペネムを使うことが多い
- カルバペネマーゼ(KPC 型、NDM 型、OXA-48 型、IMP 型など)をもつ株が増えている

### *C. koseri*
- 染色体性のクラス A β-ラクタマーゼをもつので、アンピシリン・アモキシシリンには耐性
- 誘導型 AmpC がないので、セファロスポリンにはふつう感性
- 髄膜炎・脳膿瘍では、髄液と脳によく移行する第 3 世代セフェム([[セフトリアキソン]]など)やカルバペネムを使い、膿瘍はドレナージを考える

この項目は一般的な微生物学・感染症学の知識による。

## エビデンス
- **小児のシトロバクター感染症の総説 (Clin Infect Dis 1999)**: 新生児の *C. koseri*(*C. diversus*)髄膜炎では、脳膿瘍を高い割合で伴い、死亡や神経学的後遺症が多いことをまとめた
  - Doran TI. Clin Infect Dis. 1999;28(2):384-394. [doi:10.1086/515106](https://doi.org/10.1086/515106)
- **新生児の脳膿瘍と髄膜炎 (JAMA 1981)**: *C. diversus* による新生児髄膜炎と脳膿瘍の症例を報告した
  - Graham DR, Band JD. JAMA. 1981;245(19):1923-1925. [doi:10.1001/jama.1981.03310440023017](https://doi.org/10.1001/jama.1981.03310440023017)
