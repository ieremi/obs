# *Proteus*（プロテウス）

**腸内細菌目に属するグラム陰性桿菌の属。** 特に *Proteus mirabilis* は尿路感染と、ウレアーゼによる尿のアルカリ化を結びつけて理解すると覚えやすい。


## 名前の由来とラテン語

### 属名は「変身する海神」の名前

*Proteus* は、ギリシア神話の海神 **プローテウス**（ギリシア語 Πρωτεύς、ラテン文字転写 *Prōteus*）に由来する。姿を自在に変える神の固有名を、細菌の属名に用いたもの。

命名者は **Gustav Hauser（グスタフ・ハウザー）**。1885年の著作 *Über Fäulnissbakterien und deren Beziehungen zur Septicämie. Ein Beitrag zur Morphologie der Spaltpilze* で属名を提唱した。題名はおおよそ「腐敗細菌と敗血症との関係――細菌の形態学への一寄与」という意味。

命名者・年・原著の書誌と、変身する海神という語源は[LPSN：Proteus](https://lpsn.dsmz.de/genus/proteus)で確認できる。

### 神話では何に変身するのか

ホメロス『オデュッセイア』第4歌では、メネラオスが帰還の手がかりを得るため、海の老人プローテウスを捕らえる。プローテウスは逃れるために、**ライオン、蛇、豹、猪、水、木**へと次々に姿を変える。それでもメネラオスたちが手を離さずにいると、元の姿へ戻って問いに答える。

「同じ存在が、いくつもの姿を取る」という物語が、この名の中心にある。[『オデュッセイア』第4歌、特に454〜461行付近（Perseus）](https://www.perseus.tufts.edu/hopper/text?doc=Perseus%3Atext%3A1999.01.0136%3Abook%3D4)

### 細菌のどの性質と結びつくのか

名前を理解する手がかりは、Proteusの**形態の変化と遊走性**。特に *P. mirabilis* では、短い遊泳細胞と、表面を集団で移動する細長い遊走細胞という、異なる状態が見られる。

| 状態 | 形・動きの特徴 |
| --- | --- |
| 遊泳細胞（swimmer cell） | 短い桿菌。液体中を泳ぐ |
| 遊走細胞（swarmer cell） | 長く伸び、鞭毛が増える。表面を集団で移動する |

表面での遊走細胞への分化は、変異株を用いた研究でも調べられている。[Belas et al., 1991：遊走細胞への分化と集団行動](https://pubmed.ncbi.nlm.nih.gov/1917860/)

神話との対応は、**「同じ菌が状態によって姿や振る舞いを変える」**と捉えると分かりやすい。別の菌種へ変身するという意味ではない。

ここでの細胞分化の説明は現代の研究による。Hauserの1885年原著本文を今回直接確認できていないため、現代の分化機構まで当時の命名理由として述べたとは扱わない。

### ラテン語ではどう扱うか

属名 *Proteus* は文法上**男性**。学名は「属名＋種小名」の二名法なので、*Proteus mirabilis* では神話由来の属名に、性質を表す形容詞が続く。

| 部分 | 意味 | 文法上の型 |
| --- | --- | --- |
| *Proteus* | プローテウスという海神 | 男性の固有名詞に由来する属名 |
| *mirabilis* | 驚くべき・すばらしい | ラテン語形容詞の男性形 |
| *vulgaris* | 普通の・よくある | ラテン語形容詞の男性形 |

したがって *P. mirabilis* は語を直訳すれば「驚くべきプローテウス」、*P. vulgaris* は「普通のプローテウス」という組み合わせ。種小名の辞書的な意味であり、病原性の強弱や現在の頻度を示すものではない。

出典：[LPSN：mirabilis](https://lpsn.dsmz.de/species/proteus-mirabilis)、[LPSN：vulgaris](https://lpsn.dsmz.de/species/proteus-vulgaris)。

## 主な菌種と性状

| 項目 | 内容 |
| --- | --- |
| 代表種 | *P. mirabilis*、*P. vulgaris* |
| 乳糖分解 | 通常陰性 |
| オキシダーゼ | 陰性 |
| ウレアーゼ | 陽性 |
| 運動性 | 遊走（swarming）が特徴的 |
| インドール | *P. mirabilis* は通常陰性、*P. vulgaris* は通常陽性 |

性状は同定の手がかりで、一項目だけで菌種を決めない。[UK SMI ID 16](https://www.rcpath.org/asset/28C29E82-88C1-4DD3-8F73BA01FA251D49/)（2015年版。基本性状の参照であり、現在の分類・治療は別に確認）

## ウレアーゼから結石へ

ウレアーゼは尿素を分解し、アンモニアを生じさせる。尿がアルカリ性に傾くと、ストルバイトなどの感染結石やカテーテルへの析出物が問題になる。

```text
尿素の分解 → アンモニア生成 → 尿pH上昇
                              ↓
                  結石・カテーテルの析出物
```

ウレアーゼ遺伝子の研究：[Jones & Mobley, 1988](https://pmc.ncbi.nlm.nih.gov/articles/PMC211300/)。尿路感染由来菌のウレアーゼ研究：[Mobley et al., 1987](https://pubmed.ncbi.nlm.nih.gov/3623698/)。

## 臨床で見る点

膀胱炎・腎盂腎炎に加え、尿路閉塞、結石、留置カテーテルの有無を見る。抗菌薬への感受性だけでなく、感染が続く背景となる尿路の問題も重要。

尿のpHが高いことだけではProteus感染と確定できず、培養と症状を合わせる。ほかにもウレアーゼ産生菌はいる。

## 耐性

ESBLなどを獲得する株があり、菌名だけで薬剤は決まらない。*P. mirabilis* と *P. vulgaris* の性質も一括りにしない。「インドール陽性Proteusなら一律にAmpC高リスク」とする古い語呂合わせにも注意する。[IDSA 2026 AMR Guidance](https://www.idsociety.org/practice-guideline/amr-guidance/)
