# *Treponema* (トレポネーマ)

## 概要
- **細いらせん状の細菌（スピロヘータ）**。臨床でいちばん大事なのは ***Treponema pallidum* subsp. *pallidum***（梅毒トレポネーマ）で、**[[梅毒]]** の原因
- ヒトだけが宿主。性的な接触でうつり、妊婦から胎児にもうつる。病気の経過・検査・治療は [[梅毒]] を参照
- とても細く、グラム染色では見えない。**人工の培地では増やせない**（2018 年にウサギの細胞といっしょに長期間培養する方法がやっと報告された）ので、診断はおもに **血液の抗体検査** で行う
- **ペニシリンがずっと効く**。耐性株は見つかっていない。一方、マクロライド（アジスロマイシン）には耐性が広がっている
- そのほかの *Treponema*
  - *T. pallidum* の別の亜種：**フランベジア**（subsp. *pertenue*、熱帯の皮膚の病気）、**ベジェル**（subsp. *endemicum*、乾燥地帯の風土性梅毒）。どちらも性感染ではなく、子どもの皮膚や口の接触でうつる
  - ***T. carateum***：ピンタ（中南米の皮膚の病気）
  - ***T. denticola***：口の中にいて、**歯周病** に関わる

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Treponema* | ギリシア語 τρέπω (trépō)「回す、向きを変える」+ νῆμα (nêma)「糸」 | ねじれた糸 |
| τρέπω (trépō) | 「向きを変える、回す」。名詞形は τροπή (tropḗ)「回転、変化」、τρόπος (trópos)「向き、やり方」 | 回す |
| νῆμα (nêma) | νέω (néō)「糸を紡ぐ」+ 結果を表す名詞語尾 -μα (-ma) | 紡いだもの、糸 |
| *Spirochaeta* | ギリシア語 σπεῖρα (speîra)「巻いたもの、らせん」+ χαίτη (chaítē)「長い髪」 | らせん状の髪の毛 |
| *pallidum* | ラテン語 *pallidus*「青白い、淡い」 | 青白い（染まりにくい） |
| *pertenue* | ラテン語 *per-*「とても」+ *tenuis*「細い」 | とても細い |
| *endemicum* | ギリシア語 ἔνδημος (éndēmos)「その土地の」 | 風土性の |
| *carateum* | スペイン語 *carate*（ピンタの現地での呼び名） | カラテ（ピンタ）の |
| *denticola* | ラテン語 *dens*「歯」（属格 *dentis*）+ *-cola*「住むもの」 | 歯に住むもの |

- *Treponema* は **「ねじれた糸」**。細い糸のような体が、コルク栓抜きのようにねじれていることから
- 1905 年、ドイツのフリッツ・シャウディン（Fritz Schaudinn）とエーリッヒ・ホフマン（Erich Hoffmann）が見つけ、まず *Spirochaeta pallida* と名づけた。薄くしか染まらないことから「青白い」。同じ年のうちに、シャウディンがほかのスピロヘータと区別して新しい属 *Treponema* を立てた
- 同じ語根の言葉
  - τρέπω・τροπή：**entropy**（エントロピー。クラウジウス〈Rudolf Clausius〉が τροπή「変化」から作った語、→ [[熱力学#エントロピー]]）、**tropic**（回帰線。太陽が向きを変える所）、**-tropic**（向性、親和性。*psychotropic* 向精神性の）、**trophy**（トロフィー。敵が向きを変えて逃げた所に立てた記念物 τρόπαιον から）
  - νῆμα：**nematode**（線虫、「糸のような」）、chromonema（染色糸）
- τρέπω（e）と τροπή・τρόπος（o）のように、ギリシア語では同じ語根の母音が e と o で入れかわる（**母音交替**）
- 病名「梅毒」「syphilis」の由来は [[梅毒#名前の由来]] を参照

### ラテン語文法
- ***Treponema* は中性名詞**。ギリシア語の *-μα*（*-ma*）で終わる名詞（νῆμα、属格 νήματος）は中性で、ラテン語に入っても中性の第 3 変化名詞になる（*nema*、属格 *nematis*。英語の nematode〈線虫〉も同じ語根）
  - そのため形容詞の種小名は中性形：***pallidum***（男性 *pallidus*、女性 *pallida*）
  - 最初の名前 *Spirochaeta pallida* では、*Spirochaeta*（女性名詞）に合わせて *pallida* だった。属が変わって語尾も変わった（[[Aeromonas]] の *hydrophila* と同じ現象）
  - *pertenue* は第 3 変化の形容詞 *tenuis* の中性形（男性・女性は *-is*、中性は *-e*）
- ***denticola*** は「〜に住むもの」という **名詞の同格**。*-cola* は第 1 変化で、属の性にかかわらず *-cola* のまま（*agricola*「農夫」と同じ形）
- *-ma* で終わるギリシア語由来の中性名詞は、医学用語に多い：*carcinoma*、*stoma*、*trauma* など

## 性状
| 項目 | 内容 |
| --- | --- |
| 形 | らせん状。太さ 0.1〜0.2 µm、長さ 6〜15 µm |
| グラム染色 | 細すぎて見えない。外膜をもつ点ではグラム陰性菌に近いが、**リポ多糖（LPS）をもたない** |
| 運動 | 外膜と細胞壁の間にある **ペリプラズム鞭毛（軸糸）** で、コルク栓抜きのように回って進む。粘り気のある組織の中でも動ける |
| 酸素 | 微好気性 |
| 培養 | 人工培地では増えない。ウサギの精巣に植えて増やしてきた |
| 増える速さ | とても遅く、分裂に約 30 時間かかる |
| 見る方法 | **暗視野顕微鏡**（病変の液を見る）、銀染色、PCR |

- 外膜の表面に出ている蛋白質がとても少ない。抗体の標的になりにくく、免疫から隠れて長く感染し続ける（「ステルス病原体」とよばれる）
- ゲノムは約 114 万塩基対と小さく（1998 年に解読）、代謝の遺伝子の多くを失っている。宿主から栄養をもらわないと生きられないので、人工培地で育たない

## エビデンス
- **梅毒トレポネーマのゲノム (Science 1998)**：約 114 万塩基対のゲノムを解読し、多くの代謝経路を欠くこと、外膜蛋白質が少ないことなどを示した
  - Fraser CM, et al. Science. 1998;281(5375):375-388. [doi:10.1126/science.281.5375.375](https://doi.org/10.1126/science.281.5375.375)
- **長期間の試験管内培養 (mBio 2018)**：ウサギの上皮細胞といっしょに培養し、梅毒トレポネーマを長期間増やし続けることに初めて成功した
  - Edmondson DG, et al. mBio. 2018;9(3):e01153-18. [doi:10.1128/mBio.01153-18](https://doi.org/10.1128/mBio.01153-18)
