# *Aeromonas* (エロモナス)

## 概要
- **グラム陰性の通性嫌気性桿菌**。ブドウ糖を発酵し、**[[oxidase#オキシダーゼ試験|オキシダーゼ]]陽性**。ビブリオ属に近い
- **淡水** (川・湖・池・水道水) と汽水に広くいる。魚・カエル・カメなどにもいて、魚の病原菌としても重要
- ヒトでは、**下痢 (胃腸炎)** と、**淡水でできた傷の感染** (重いと壊死性筋膜炎) が多い。肝硬変や悪性腫瘍のある人では菌血症を起こす
- 臨床で多いのは ***A. hydrophila***、***A. caviae***、***A. veronii*** (biovar sobria) と、最近区別された ***A. dhakensis***。*A. dhakensis* は以前 *A. hydrophila* と同定されていたことが多く、病原性が最も強いとされる
- 日本では、*A. hydrophila* と *A. sobria* が食中毒の原因菌に指定されている
- 魚の病気を起こす *A. salmonicida* (サケのせっそう病) は低温を好み、鞭毛がなく、ヒトにはふつう病気を起こさない

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Aeromonas* | ギリシア語 ἀήρ (aḗr)「空気、気体」+ μονάς (monás)「単位、1 つのもの」 | 気体を作る単体 (の菌) |
| *hydrophila* | ギリシア語 ὕδωρ (hýdōr)「水」+ φίλος (phílos)「好む」 | 水を好む |
| *caviae* | 新ラテン語 *Cavia*「モルモット」の属格 | モルモットの |
| *veronii* | 人名 Véron のラテン語化 *Veronius* の属格 | ヴェロンの |
| *salmonicida* | ラテン語 *salmo*「サケ」+ *-cida*「殺すもの」 | サケを殺すもの |

- ブドウ糖を発酵するときに **気体 (二酸化炭素と水素) を出す** ことから名付けられた (1936 年、クライフェルとファン・ニール Kluyver & van Niel)
- *-monas* は、[[Acinetobacter]] と同じ環境菌の緑膿菌 *Pseudomonas* (「にせの単体」) と同じ語尾。英語の monad、mono- と同じ語根
- *caviae* は、モルモットから分けられたことによる
- *veronii* は、フランスの細菌学者ミシェル・ヴェロン (Michel Véron) にちなむ

### ラテン語文法
- ***-monas* で終わる属名は女性名詞** (ギリシア語 μονάς が女性名詞のため)。そのため、形容詞の種小名は女性形になる
  - ギリシア語の -φιλος → ラテン語の形容詞 *-philus* (男性) / ***-phila*** (女性) / *-philum* (中性)
  - *Aeromonas* は女性なので ***hydrophila***。もとは *Bacillus hydrophilus* (*Bacillus* は男性) とよばれていて、属が変わったときに語尾も変わった
  - 同じように *Pseudomonas aeruginosa* (女性形 -a、「緑青色の」)
- *caviae* は**名詞の属格** (*Cavia* は第 1 変化名詞、属格 *-ae*)。[[Escherichia_coli|*Escherichia coli*]] の *coli* (「結腸の」) と同じく、属名の性に合わせて変えない
- *veronii* は人名の属格 (*-ius* → *-ii*)。[[Acinetobacter]] の *baumannii* と同じ
- *salmonicida* は「サケを殺すもの」という**名詞の同格**。*-cida* (英語の -cide) は性にかかわらず *-a* のまま

## 性状
| 項目 | 内容 |
| --- | --- |
| 形 | まっすぐな桿菌 |
| グラム染色 | 陰性 |
| 酸素 | 通性嫌気性 |
| 運動性 | 陽性 (極に 1 本の鞭毛)。*A. salmonicida* は陰性 |
| [[oxidase#オキシダーゼ試験\|オキシダーゼ]] | **陽性** (腸内細菌目との区別に使う) |
| カタラーゼ | 陽性 |
| ブドウ糖 | 発酵する。多くは気体も出す |
| 血液寒天 | 多くは β 溶血 |
| マッコンキー寒天 | 発育する。乳糖は分解するものとしないものがある |
| 食塩 | なくても育つ (多くのビブリオは食塩が要る) |
| O/129 (ビブリオを止める薬剤) | 耐性 (ビブリオは多くが感性) |

- **マッコンキー寒天では腸内細菌に見えるが、オキシダーゼ陽性** という組み合わせが手がかり。便の検査では見落とされやすい
- 市販の同定キットでは、種まで正しく分けられないことが多い (*A. dhakensis* はとくに)

## 起こす病気
- **胃腸炎**: 水のような下痢が多く、ときに血便。小児と免疫の落ちた人に多い。ほかの原因菌と同時に見つかることも多く、本当に原因かどうか判断しにくい場合がある
- **創部・軟部組織感染**: 川・湖での外傷、釣り、魚の処理などのあと。**蜂窩織炎から壊死性筋膜炎・筋壊死** まで進むことがある
  - 2004 年のスマトラ島沖地震の津波のあと、タイの生存者の皮膚・軟部組織感染で最も多く分けられた菌だった
- **医療用ヒル** (ヒルド *Hirudo*) の使用後の感染: ヒルは消化を助けるエロモナスを腸にもつ。形成外科などでヒルを使うときは予防の抗菌薬を使う
- **菌血症**: 肝硬変・悪性腫瘍・好中球減少の人に多い。肝硬変では特発性細菌性腹膜炎も起こす。死亡率が高い
- 胆道感染、尿路感染、溺水のあとの肺炎、角膜炎など

## 抗菌薬への耐性
### もともとの耐性
種によって、染色体に次の β-ラクタマーゼをもつ。
| 酵素 | クラス | 分解するもの | 主にもつ種 |
| --- | --- | --- | --- |
| ペニシリナーゼ (OXA 型など) | D | ペニシリン | ほとんどの種 |
| **AmpC 型セファロスポリナーゼ** (誘導型) | C | セファマイシン、第 3 世代セフェムまで | *A. caviae*、*A. hydrophila*、*A. dhakensis* |
| **CphA** (メタロ-β-ラクタマーゼ) | B | **カルバペネムをほぼ選んで分解** | *A. hydrophila*、*A. veronii*、*A. dhakensis* |

- そのため、**アンピシリン ([[アンピシリン]]、[[アモキシシリン]]) にはもともと耐性**。[[セファゾリン]]も効かないことが多い
- AmpC をもつ種では、第 3 世代セフェム ([[セフトリアキソン]]など) で治療中に、AmpC を大量に作る変異株が選ばれて耐性になることがある。しくみは [[Enterobacter#AmpC と耐性]] と同じ
- **CphA は、ふつうの感受性試験 (少ない菌量) ではカルバペネム感性に見えることがある**。菌量が多い感染 (膿瘍など) では効かないおそれがあるので、カルバペネムを第一選択にしない
- [[ピペラシリン]]・[[タゾバクタム]]は効くことが多いが、CphA はタゾバクタムでおさえられない

### 獲得耐性
- プラスミドの ESBL や、KPC 型・NDM 型・VIM 型のカルバペネマーゼをもつ株もある。水の環境で耐性遺伝子をやりとりする「耐性遺伝子の貯蔵庫」としても注目されている

## 治療
感受性試験で決めるのが基本。
- **胃腸炎**: ふつうは補液だけで治る。長引くときや重いときは、フルオロキノロンや ST 合剤
- **創部・軟部組織感染、菌血症**: フルオロキノロン (シプロフロキサシン、レボフロキサシン)、**セフェピム**、ST 合剤、アミノグリコシドなど。重いときは 2 剤を組み合わせることもある
  - 壊死性筋膜炎では、抗菌薬に加えてすぐに外科的デブリードマンをする
  - 淡水での外傷のあとの重い軟部組織感染では、エロモナスに効く抗菌薬を初めから入れておく
- **医療用ヒルの予防**: フルオロキノロンや ST 合剤 (ヒルのエロモナスにフルオロキノロン耐性が出てきている)

この項目は一般的な微生物学・感染症学の知識による。
