# *Enterobacter* (エンテロバクター)

## 概要
- **グラム陰性の通性嫌気性桿菌**。[[Escherichia_coli|大腸菌]]と同じ腸内細菌目細菌 (*Enterobacterales*)
- 臨床で最も多いのは ***Enterobacter cloacae* complex**(エンテロバクター・クロアカ複合体)。*E. cloacae*、*E. hormaechei* など、互いによく似た数種をまとめてこう呼ぶ
- 腸内や環境(水、土、植物)にいる。主に**院内感染**(菌血症、肺炎、尿路感染、術後感染)の原因になる
- **染色体に誘導型の AmpC β-ラクタマーゼ**をもつのが最大の特徴。そのため、
  - アンピシリン、第 1 世代セフェム、セファマイシンにもともと耐性
  - 第 3 世代セフェムで治療していると、AmpC を大量に作る変異株が選ばれて**治療中に耐性になる**ことがある
- 以前 *Enterobacter aerogenes* と呼ばれていた菌は、2017 年に *Klebsiella aerogenes* に移された
- 日本のカルバペネム耐性腸内細菌目細菌 (CRE) 感染症の届出では、エンテロバクター属と *Klebsiella aerogenes* が多いとされる(一般的な知識)

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Enterobacter* | ギリシア語 ἔντερον (énteron)「腸」+ *-bacter* | 腸の桿菌 |
| *-bacter* | ギリシア語 βακτήριον (baktḗrion)「小さな杖」から作った新ラテン語 | 桿菌 |
| *cloacae* | ラテン語 *cloāca*「下水溝」の属格 | 下水の |
| *hormaechei* | 人名 Hormaeche のラテン語化の属格 | オルマエチェの |

- *Enterobacter* 属は 1960 年にオルマエチェとエドワーズ (Hormaeche & Edwards) が立てた
- *cloacae* は、下水から見つかったことにちなむ。古代ローマの大下水道 *Cloaca Maxima*(クロアカ・マクシマ)と同じ語。動物学では、鳥類などの排泄と生殖の出口(総排出腔)も cloaca という
- 英語の enteric(腸の)、医学用語の enteritis(腸炎)と同じ語根。腸内細菌目 *Enterobacterales* も同じ

### ラテン語文法
- *Enterobacter* は男性名詞
- *cloacae* は名詞 *cloāca*(第 1 変化・女性)の**属格**

| 格 | 単数 | 複数 |
| --- | --- | --- |
| 主格 | cloāca | cloācae |
| 属格 | **cloācae** | cloācārum |
| 与格 | cloācae | cloācīs |
| 対格 | cloācam | cloācās |
| 奪格 | cloācā | cloācīs |

- 第 1 変化では、単数属格と複数主格が同じ *-ae* になる。種小名の *cloacae* は「下水の」(単数属格)
- 名詞の属格なので、男性名詞の属名 *Enterobacter* に合わせて形を変える必要はない([[Escherichia_coli|*Escherichia coli*]] の *coli* と同じ)
- 人名の *hormaechei* は、名前が母音 -e で終わるので *-i* だけを付けている(子音で終わる名前なら *baumannii* のように *-ii*)

## AmpC と耐性
### 誘導型 AmpC のしくみ
1. ふだんは調節遺伝子 AmpR によって AmpC はほとんど作られていない
2. β-ラクタムで細胞壁が壊されると、壊れた細胞壁の断片が AmpR に結合し、AmpC が大量に作られる(**誘導**)
3. 細胞壁の断片を処理する AmpD などに変異がおきると、薬がなくても AmpC を常に大量に作るようになる(**脱抑制変異株**)

### 薬ごとの影響
| 薬 | AmpC との関係 | エンテロバクターへの効き目 |
| --- | --- | --- |
| [[アンピシリン]]、[[アモキシシリン]] | 強く誘導し、よく分解される | もともと耐性 |
| [[セファゾリン]](第 1 世代) | よく分解される | もともと耐性 |
| [[セフメタゾール]](セファマイシン) | 強く誘導し、分解される | もともと耐性 |
| [[セフトリアキソン]]、[[セフカペン]](第 3 世代) | 誘導は弱いが、脱抑制変異株には分解される | 感性でも**治療中に耐性になる**ことがある |
| [[ピペラシリン]]・[[タゾバクタム]] | タゾバクタムは AmpC を阻害しにくい | 第 3 世代セフェムと同じく注意が必要 |
| セフェピム(第 4 世代) | 誘導が弱く、AmpC に分解されにくい | 重い感染でよく使われる |
| カルバペネム | AmpC に分解されない | 確実に効く(カルバペネマーゼがなければ) |

- 同じように誘導型 AmpC をもつ菌として、[[Citrobacter|シトロバクター・フロインディ]] (*Citrobacter freundii*)、*Klebsiella aerogenes*、セラチア属 (*Serratia* spp.)、モルガネラ (*Morganella*) などがある。まとめて「SPACE」「HECK-Yes」などの覚え方がある
- [[Escherichia_coli|大腸菌]]も染色体に AmpC をもつが、AmpR がなく誘導されない

### そのほかの耐性
- ESBL、プラスミド性の AmpC
- **カルバペネマーゼ**: 日本では **IMP 型**(メタロ-β-ラクタマーゼ)が多い

この項目は一般的な微生物学・感染症学の知識による。

## 治療
- 感受性試験で決めるのが基本
- 重い感染では、感受性があっても第 3 世代セフェムを避け、**セフェピム**やカルバペネムを使うことが多い(米国感染症学会のガイダンスなど、一般的な知識)
- 尿路感染など軽い感染では、第 3 世代セフェムやキノロン、ST 合剤で治療できることも多い

## エビデンス
- **治療中の耐性化 (Ann Intern Med 1991)**: エンテロバクター菌血症の前向き研究で、第 3 世代セフェムで治療した患者の一部で治療中に多剤耐性の株が出てきて、死亡が多かった
  - Chow JW, et al. Ann Intern Med. 1991;115(8):585-590. [doi:10.7326/0003-4819-115-8-585](https://doi.org/10.7326/0003-4819-115-8-585)
