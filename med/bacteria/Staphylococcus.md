# *Staphylococcus*（ブドウ球菌属）

**房状に集まるグラム陽性球菌の属。** 皮膚・粘膜に常在する菌を含み、菌種によって病原性・耐性・検出時の意味が異なる。

| 代表種 | 和名 | 主な比較点 |
| --- | --- | --- |
| *S. aureus* | 黄色ブドウ球菌 | 通常コアグラーゼ陽性。菌血症・深部感染に注意 |
| *S. epidermidis* | 表皮ブドウ球菌 | コアグラーゼ陰性。混入と器材関連感染を区別 |

## 名前の由来とラテン語

ギリシア語 *staphylē*「ブドウの房」＋ *kokkos*「粒・種」に由来する新ラテン語 *coccus*「球菌」。つまり「ブドウの房のような球菌」。属名は文法上男性として扱う。

| 種小名 | 語源・文法 | 意味 |
| --- | --- | --- |
| *aureus* | ラテン語の男性形容詞 | 金色の |
| *epidermidis* | 「表皮」を表す名詞の属格 | 表皮の |

種小名の出典：[aureus](https://lpsn.dsmz.de/species/staphylococcus-aureus)、[epidermidis](https://lpsn.dsmz.de/species/staphylococcus-epidermidis)。*aureus* は属名の性に合わせた形容詞、*epidermidis* は「〜の」を表す名詞で、文法上の型が違う。

属名の出典：[LPSN：Staphylococcus](https://lpsn.dsmz.de/genus/staphylococcus)。語源は命名の由来であり、全菌種・全菌株の性状を保証するものではない。

## 黄色ブドウ球菌

**グラム陽性の球菌。鼻腔・皮膚に保菌される一方、膿瘍や菌血症などを起こす。** MRSAは別の菌種ではなく、この菌のメチシリン耐性株を指す。

### 性状と感染症

| 項目 | 特徴 |
| --- | --- |
| 配列 | ブドウの房状の集まり |
| カタラーゼ／コアグラーゼ | 通常は両方陽性 |
| 局所感染 | 皮膚・軟部組織感染、創感染、膿瘍 |
| 深部・全身感染 | 菌血症、感染性心内膜炎、骨・関節感染、肺炎 |
| 毒素による病気 | 食中毒、毒素性ショック症候群など |

菌株ごとに毒素や耐性は異なる。すべての株がすべての毒素を持つわけではない。[UK SMI ID 7](https://www.rcpath.org/asset/DB5F13CB-53CA-4E9E-A0937B78B610D0AC/)

### MSSAとMRSA

- **MSSA**：メチシリン感受性黄色ブドウ球菌。
- **MRSA**：メチシリン耐性黄色ブドウ球菌。通常の抗ブドウ球菌用β-ラクタム薬が使えないため、選択肢が変わる。

耐性は病原性の強さそのものではない。MSSAも重い感染症を起こす。MRSAの保菌と、治療が必要な感染症も区別する。[CDC：MRSA](https://www.cdc.gov/mrsa/about/index.html)

### 血液培養で検出されたら

皮膚にいる菌だからといって、血液培養陽性を単なる混入と即断しない。感染源、血液培養の陰性化、心内膜炎や遠隔部位への感染を評価することが重要。

2026年のIDSA/ESCMID文書は、黄色ブドウ球菌菌血症をリスク評価・診断・感染源対策を含めて扱っている。[IDSA/ESCMID 2026](https://www.idsociety.org/practice-guideline/staphylococcus-aureus-bacteremia/)

### 治療を理解する軸

MSSAかMRSAか、感染部位、感受性で選ぶ。MSSAでは[[セファゾリン]]などが候補になる。膿瘍や感染した器材では、排膿・器材への対応も検討する。薬剤名だけで治療を完結させない。

## 表皮ブドウ球菌

**皮膚の常在菌であると同時に、カテーテルや人工物の感染で重要な菌。** 血液培養では、採血時の混入と真の菌血症を区別する必要がある。

### 性状

| 項目 | 特徴 |
| --- | --- |
| グラム染色 | 房状に集まるグラム陽性球菌 |
| カタラーゼ | 通常陽性 |
| コアグラーゼ | 陰性 |
| 分類上のまとまり | コアグラーゼ陰性ブドウ球菌（CoNS）の一種 |

CoNSは菌種名ではなく複数菌種の総称。「CoNS」とだけ報告されている段階で、表皮ブドウ球菌と断定しない。[UK SMI ID 7](https://www.rcpath.org/asset/DB5F13CB-53CA-4E9E-A0937B78B610D0AC/)

### バイオフィルムと人工物

器材表面に付着し、細菌が集まって形成する**バイオフィルム**が感染の持続に関わる。血管内カテーテル、人工弁、人工関節などが背景になる。

菌が浮遊している状態の感受性だけで、感染した人工物ごと治療できるとは限らない。器材の温存・交換・除去は、感染部位や患者の状態から判断する。[IDSA：カテーテル関連感染ガイドライン](https://www.idsociety.org/practice-guideline/iv-catheter)

### 混入か、感染か

| 確認する情報 | 考えること |
| --- | --- |
| 別々の採血で同じ菌が出るか | 複数セットの結果を合わせて評価 |
| 発熱・循環動態・局所所見 | 感染症を支持する所見があるか |
| カテーテル・人工物 | 感染源になりうるか |
| 採血部位・陽性化時間 | 末梢血とカテーテル血の関係 |

「1本だけなら必ず混入」「複数本なら必ず感染」という単独の基準では決めない。古典的なIDSA 2009文書も、単回のCoNS陽性では追加培養による確認を重視している。これは旧版の診断原則の参照であり、現在の施設手順に合わせる。

### 耐性・関連

メチシリン耐性株があり、[[Staphylococcus#黄色ブドウ球菌|黄色ブドウ球菌]]と同じ薬剤がそのまま使えるとは限らない。菌種同定と感受性を分けて確認する。
