# *Campylobacter* (カンピロバクター)

## 概要
- **グラム陰性の微好気性らせん菌**。S 字やカモメの翼のように曲がった形。[[Helicobacter]] と同じカンピロバクター目
- ***C. jejuni*** (ジェジュニ) と ***C. coli*** (コリ) が **細菌性の胃腸炎の原因として世界で最も多いものの一つ**。日本でも、細菌による食中毒の件数で毎年上位 (多くの年で 1 位)
- 鳥類 (とくに **ニワトリ**)、ウシ、ブタの腸に病気を起こさずにすんでいる。**生や加熱の足りない鶏肉** (鶏刺し、鶏わさ、たたき、バーベキュー) と、そこからの二次汚染で感染する
- **ギラン・バレー症候群** の最も多い先行感染
- ***C. fetus*** (フィータス) は胃腸炎よりも、免疫の落ちた人での **菌血症・血管の感染** を起こす

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Campylobacter* | ギリシア語 καμπύλος (kampýlos)「曲がった」+ *-bacter* | 曲がった桿菌 |
| *-bacter* | ギリシア語 βακτήριον (baktḗrion)「小さな杖」から作った新ラテン語 | 桿菌 |
| *jejuni* | ラテン語 *jejunum*「空腸」の属格 | 空腸の |
| *jejunum* | ラテン語 *jejunus*「空腹の、空の」 | (死体で) 空になっている腸 |
| *coli* | ラテン語 *colon*「結腸」の属格 | 結腸の |
| *fetus* | ラテン語 *fetus*「胎児、子」 | 胎児 |
| *upsaliensis* | *Upsalia*「ウプサラ (スウェーデンの町)」+ *-ensis* | ウプサラの |

- 1963 年、セバルドとヴェロン (Sebald & Véron) が、それまで *Vibrio fetus* とよばれていた菌などをまとめて新しい属にした。[[Aeromonas]] の *veronii* のヴェロンと同じ人
- *fetus* は、ヒツジ・ウシの **流産した胎児** から分けられたことによる
- 空腸 (jejunum) は、解剖すると中が空になっていることが多いのでこうよばれた

### ラテン語文法
- *Campylobacter* は男性名詞 (*-bacter* で終わる属名は男性)。[[Acinetobacter]] と同じ
- ***jejuni*** と ***coli*** は **名詞の属格** (第 2 変化の中性名詞 *jejunum* → *jejuni*、*colon* → *coli*)。名詞なので属の性に合わせない。[[Escherichia_coli|*Escherichia coli*]] の *coli* とまったく同じ
- ***fetus*** は **名詞の同格** (主格のまま)。第 4 変化の名詞で、属が変わっても形は変わらない
- ***upsaliensis*** は *-ensis* の形容詞 (「〜の土地の」)。第 3 変化で、男性・女性は *-ensis*、中性は *-ense*。*Campylobacter* は男性なので *upsaliensis*
- [[Helicobacter]] の *pylori* (「幽門の」) も同じく名詞の属格で、カンピロバクター属にいたころに *pyloridis* から *pylori* に直された

## 性状
| 項目 | 内容 |
| --- | --- |
| 形 | 曲がった〜らせん状の細い桿菌 (S 字、カモメの翼の形)。古い培養では球状になる |
| グラム染色 | 陰性 (薄く染まる) |
| 酸素 | **微好気性** (酸素 5% 前後、二酸化炭素 10% 前後でよく育つ。大気中でも嫌気でも育ちにくい) |
| 発育温度 | *C. jejuni*・*C. coli* は **42 ℃ でよく育つ** (鳥の体温に近い)。*C. fetus* は 42 ℃ で育ちにくく、25 ℃ で育つ |
| 運動性 | 陽性。両端に 1 本ずつの鞭毛で、**コルク栓抜きのように速く動く** |
| [[oxidase#オキシダーゼ試験\|オキシダーゼ]] | **陽性** |
| カタラーゼ | 陽性 |
| 糖 | 分解しない (アミノ酸などからエネルギーを得る) |
| 馬尿酸の加水分解 | *C. jejuni* は陽性、*C. coli* は陰性 (2 つを分ける) |

- 便からは、ほかの菌をおさえる **選択培地** (スキロー培地、CCDA 培地など) で、42 ℃・微好気の条件で 2 日ほど培養する
- 便のグラム染色で、細いらせん菌がたくさん見えると診断の手がかりになる

## 起こす病気
### 胃腸炎
- 潜伏期は **2〜5 日** (1〜7 日) と、ほかの細菌性食中毒より長い。そのため、何を食べたか思い出しにくい
- **数百個の菌で感染する** ほど少ない菌数で発病する
- 発熱、腹痛、下痢 (水様から **血便** まで)、吐き気。腹痛が強く、右下腹部が痛むと **虫垂炎とまちがえられる** ことがある (回腸末端炎、腸間膜リンパ節炎)
- 多くは 1 週間ほどで自然に治る

### 合併症
- **ギラン・バレー症候群** (GBS): 感染から 1〜3 週後に、手足の力が急に入らなくなる。*C. jejuni* の感染およそ 1,000 人に 1 人
  - しくみは **分子相同性** (molecular mimicry)。菌の表面のリポオリゴ糖が、神経 (軸索) の膜にある **ガングリオシド** (GM1、GD1a) と同じ形をしている。菌に対して作られた抗体が神経も攻撃する
  - カンピロバクターのあとの GBS は、**軸索型** (急性運動性軸索型ニューロパチー、AMAN) が多く、回復が遅いことがある
  - 似た病気の **フィッシャー症候群** (眼のまひ・運動失調・反射の消失) では、ガングリオシド GQ1b に対する抗体が出る
  - 治療は免疫グロブリン大量療法や血漿交換。ステロイドは効かない
- **反応性関節炎**、過敏性腸症候群 (感染のあと)

### *C. fetus*
- 高齢者、肝硬変、糖尿病、悪性腫瘍の人で **菌血症** を起こす。下痢はないことも多い
- **血管内の感染** (感染性大動脈瘤、心内膜炎、血栓性静脈炎) を起こしやすい
- 菌の表面に蛋白質の層 (S 層) をもち、補体による殺菌を逃れるので、血液中で生き残りやすい
- 家畜では流産を起こす

## 抗菌薬
- 胃腸炎の多くは **抗菌薬なしで治る**。補液が中心
- 高熱・血便・長引く・免疫が落ちている・妊娠中などでは抗菌薬を使う。**第一選択はマクロライド** (アジスロマイシン、エリスロマイシン)
- **フルオロキノロン耐性がとても多い** (日本でも半数前後)。家畜へのフルオロキノロンの使用が関係するとされる。旅行者下痢症でフルオロキノロンを経験的に使うときに注意する
- もともと **トリメトプリム** (ST 合剤)、バンコマイシン、多くのセファロスポリンに耐性。*C. jejuni*・*C. coli* は第 3 世代セフェムにもほとんど効かない
- *C. fetus* の菌血症・血管内感染では、カルバペネムやアミノグリコシドなどを使い、感染した血管の手術が要ることもある

この項目は一般的な微生物学・感染症学の知識による。

## 予防
- 鶏肉は **中心まで十分に加熱する** (中心部 75 ℃ で 1 分以上)。「新鮮だから生で食べられる」わけではない。市販の鶏肉の多くから菌が見つかる
- 生の鶏肉を切ったまな板・包丁・手から、生で食べるサラダなどへの **二次汚染** を防ぐ
- 乾燥と熱に弱いが、低温 (冷蔵) では長く生き残る

## 歴史
- 1886 年、エシェリヒ (Escherich、ドイツ、[[Escherichia_coli|大腸菌]] の名の由来) が、下痢で死んだ乳児の腸にらせん菌を見たが、培養できなかった
- 1913 年、イギリスでヒツジの流産胎児から分けられ、*Vibrio fetus* とよばれた
- 1972 年、ベルギーのデケイゼルとブツラー (Dekeyser & Butzler) が、フィルターで便から小さな菌をこし分けて培養した。1977 年、イギリスのスキロー (Skirrow) が選択培地を作り、ふつうの検査室でも培養できるようになって、**下痢の主な原因の一つ** だとわかった
- 1990 年代〜2000 年代、日本の結城伸泰らが、*C. jejuni* のリポオリゴ糖とガングリオシドの分子相同性を示し、GBS を起こすしくみを明らかにした
