# *Corynebacterium* (コリネバクテリウム)

## 概要
- **グラム陽性の桿菌**。一方の端がふくらんだ **こん棒の形** で、芽胞を作らず、動かない
- 細胞壁に短い **ミコール酸** をもち、結核菌 (*Mycobacterium*) やノカルジアに近い
- 臨床では 2 つに分けて考える
  - ***C. diphtheriae*** (**ジフテリア菌**) と、同じ毒素を作ることがある ***C. ulcerans***：**ジフテリア毒素** で、のどの偽膜・心筋炎・神経障害を起こす
  - それ以外 (**ジフテロイド**)：皮膚・粘膜の常在菌。血液培養では汚染菌のことが多いが、カテーテル・人工物の感染や免疫の落ちた人の感染を起こす。***C. jeikeium***、***C. striatum*** は多くの抗菌薬に耐性
- ジフテリアは日本では **二類感染症**。ワクチン (トキソイド) が広まり、日本では 1999 年を最後に報告がない。世界ではいまも流行がある
- 産業では、***C. glutamicum*** が **グルタミン酸 (うま味調味料)** やリシンの発酵生産に使われる。1956 年に日本 (協和発酵、木下祝郎ら) で見つかった

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Corynebacterium* | ギリシア語 κορύνη (korýnē)「こん棒」+ *bacterium* | こん棒の形の桿菌 |
| *bacterium* | ギリシア語 βακτήριον (baktḗrion)「小さな杖」 | 桿菌 |
| *diphtheriae* | 新ラテン語 *diphtheria* の属格。ギリシア語 διφθέρα (diphthérā)「なめし革」から | ジフテリアの |
| *ulcerans* | ラテン語 *ulcerare*「潰瘍を作る」の現在分詞 | 潰瘍を作る |
| *striatum* | ラテン語 *striatus*「すじのある」 | すじのある |
| *urealyticum* | *urea*「尿素」+ ギリシア語 λυτικός (lytikós)「分解する」 | 尿素を分解する |
| *jeikeium* | 米国 CDC の分類グループ「JK」を読んだもの (jei-kei) + *-ium* | JK 群の |
| *glutamicum* | *glutamicus*「グルタミン酸の」 | グルタミン酸の |

- 1896 年、レーマンとノイマン (Lehmann & Neumann) が命名
- **ジフテリア** は、のどにできる灰白色の偽膜が **なめし革** のように厚くて丈夫なことから。フランスのブルトノー (Bretonneau) が 1826 年に diphthérite と名づけ、のちにトルソー (Trousseau) が diphthérie とした

### ラテン語文法
- ***-bacterium* で終わる属名は中性名詞** (第 2 変化、*-um*)。そのため、形容詞の種小名は中性形 ***-um*** になる
  - *striatus* (男) / *striata* (女) / ***striatum*** (中)
  - 同じく *urealyticum*、*glutamicum*、*amycolatum* (「ミコール酸のない」)、*minutissimum* (「とても小さい」、*minutus* の最上級)
  - 女性名詞の属 [[Aeromonas]] では *hydrophila* (女性形) になるのと比べるとわかりやすい
- *diphtheriae* は **名詞の属格** (*diphtheria* は第 1 変化、属格 *-ae*)。名詞なので属の性に合わせない。[[Aeromonas]] の *caviae* と同じ
- *ulcerans* は **現在分詞**。第 3 変化の形容詞と同じく、男・女・中性で同じ形 (*-ans*) なので、どの属にも *ulcerans* のままつく

## 性状
| 項目 | 内容 |
| --- | --- |
| 形 | こん棒状の桿菌。分裂のあとに折れ曲がって残るので、**V・L 字や柵のように並ぶ** (「漢字のような配列」とよばれる) |
| グラム染色 | 陽性 (染まり方にむらがある) |
| 酸素 | 好気性〜通性嫌気性 |
| 運動性 | なし |
| 芽胞 | 作らない |
| カタラーゼ | 陽性 (レンサ球菌・リステリアなどとの区別の手がかりの一つ) |
| 異染小体 | ジフテリア菌はリン酸の重合体 (ポリリン酸) の粒をもち、ナイサー染色やレフレルのメチレンブルー染色で濃く染まる |
| 培地 | ジフテリア菌はレフレル血清培地でよく育つ。亜テルル酸塩を含む培地では **黒い集落** になる |

- ジフテロイドは形だけでは種まで分けられない。MALDI-TOF 質量分析や 16S rRNA 遺伝子の配列で同定する

## ジフテリア
### 毒素のしくみ
- ジフテリア毒素の遺伝子 (*tox*) は、菌のものではなく、菌に入り込んだ **β ファージ** (バクテリオファージ) がもつ。ファージをもつ株だけが毒素を作る (溶原変換)
- 毒素は **鉄が少ないとき** に作られる。鉄が十分あるときは、菌の調節蛋白質 DtxR が *tox* の発現を止める
- 毒素は A・B の 2 つの部分からなる
  - **B 部分** が細胞の受容体 (ヘパリン結合 EGF 様増殖因子の前駆体) に結合し、毒素が細胞に取り込まれる
  - **A 部分** が細胞質で、蛋白質合成に必要な **伸長因子 EF-2** を ADP リボシル化して働かなくする。蛋白質が作れなくなり、細胞が死ぬ
  - A 部分は酵素なので、**1 分子で細胞を殺せる** ほど強い
- 毒素を作るかどうかは **エレク試験** (寒天の中で毒素と抗毒素が出会うと沈降線ができる) や PCR で調べる

### 症状
- **咽頭ジフテリア**: 発熱、のどの痛み。扁桃・咽頭に **灰白色の偽膜** ができ、はがすと出血する。首のリンパ節が大きく腫れると **牛の首 (bull neck)** のようになる。偽膜が喉頭・気管に広がると窒息する
- 毒素が全身に回ると
  - **心筋炎**：発症から 1〜2 週ごろ。不整脈・心不全で、主な死因
  - **神経障害**：軟口蓋のまひ (鼻声、飲み物が鼻に逆流する)、眼の調節のまひ、のちに手足のまひ
- **皮膚ジフテリア**: 治りにくい潰瘍。熱帯に多い。周りへの感染源になる

### 治療と予防
- **ジフテリア抗毒素** (ウマの血清) をできるだけ早く。すでに細胞に入った毒素は中和できないので、疑ったら検査結果を待たずに使う
- 抗菌薬 (エリスロマイシンやペニシリン) で菌を除き、ほかの人へ広がるのを止める
- 予防は **ジフテリアトキソイド** (毒素をホルマリンで無毒にしたもの)。日本では、百日咳・破傷風などとの混合ワクチン (DPT-IPV、DPT-IPV-Hib) で乳児期にうつ。効果は年とともに落ちるので、11〜12 歳で DT (ジフテリア・破傷風) の追加接種をする

### *C. ulcerans*
- ジフテリア毒素を作る株があり、ジフテリアと同じような症状を起こす
- **イヌやネコなどの動物からうつる人獣共通感染症**。日本でもペットからの感染と死亡例が報告されている

## ジフテロイドが起こす病気
| 種 | 主な病気・特徴 |
| --- | --- |
| *C. jeikeium* | 好中球減少の人のカテーテル関連菌血症、人工物の感染。**多剤耐性** |
| *C. striatum* | 院内の人工呼吸器関連肺炎、菌血症、人工物・デバイスの感染。**多剤耐性** |
| *C. urealyticum* | **ウレアーゼで尿をアルカリ性にし、膀胱にストルバイト (リン酸マグネシウムアンモニウム) がこびりつく膀胱炎** (アルカリ性被包性膀胱炎)、尿路結石 |
| *C. amycolatum* | 皮膚の常在菌で最も多いものの一つ。人工物の感染 |
| *C. kroppenstedtii* | 脂質を好む。**肉芽腫性乳腺炎** |
| *C. minutissimum* | **紅色陰癬** (わきの下・股の赤茶色の斑)。ポルフィリンを作るので、ウッド灯で **さんご色に光る** |
| *C. pseudotuberculosis* | ヒツジ・ヤギの乾酪性リンパ節炎。ヒトではまれ |

- 血液培養で 1 セットだけから出たときは汚染のことが多い。**複数のセットから出る、人工物がある、好中球減少がある** ときは本当の感染と考える

## 抗菌薬
- **ジフテリア菌**: ペニシリン、エリスロマイシンに感性
- **ジフテロイド** (とくに *C. jeikeium*、*C. striatum*): β-ラクタム、マクロライド、フルオロキノロン、アミノグリコシドなどに耐性のことが多い。**バンコマイシン** はほぼすべての株に効くので、重い感染での経験的治療の基本になる
  - リネゾリドも多くは感性
  - *C. striatum* では、ダプトマイシンで治療中に高度耐性になることがある
- 人工物の感染では、取り除くことを考える

この項目は一般的な微生物学・感染症学の知識による。

## 歴史
- 1883 年、クレープス (Klebs、ドイツ) がジフテリアの偽膜の中に菌を見つけ、1884 年、レフラー (Löffler、ドイツ) が培養した (クレープス・レフラー菌)。レフラーは、菌がのどにとどまるのに全身の症状が出ることから、毒素があると考えた
- 1888 年、ルーとイェルサン (Roux & Yersin、フランス) が、菌を除いた培養液だけで動物に症状が出ることを示し、**毒素** を見つけた
- 1890 年、**ベーリング (Behring、ドイツ) と北里柴三郎 (日本)** が、毒素で免疫した動物の血清が毒素を中和すること (**抗毒素**) を発表し、血清療法が始まった。ベーリングは 1901 年、最初のノーベル生理学・医学賞を受けた
- 1923 年、ラモン (Ramon、フランス) が、ホルマリンで無毒にした毒素 (トキソイド) を作り、予防接種に使われるようになった
