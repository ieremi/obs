# *Acinetobacter* (アシネトバクター)

## 概要
- **グラム陰性の偏性好気性球桿菌**。ブドウ糖を発酵しない「ブドウ糖非発酵菌」の一つで、緑膿菌 (*Pseudomonas aeruginosa*) と並ぶ院内感染の原因菌
- 臨床で最も重要なのは ***Acinetobacter baumannii***(アシネトバクター・バウマニ)
- 土や水など環境に広くいる。**乾いた表面でも数週間〜数か月生き残る**ので、病院の環境(ベッド柵、人工呼吸器など)や医療者の手を介して広がる
- 健康な人に病気を起こすことは少ないが、ICU の重症患者で人工呼吸器関連肺炎・菌血症・創部感染を起こす
- 耐性をとても獲得しやすい。**カルバペネム耐性 *A. baumannii* (CRAB)** は、WHO が最も優先度の高い耐性菌の一つに挙げている
- 日本では、カルバペネム・アミノグリコシド・フルオロキノロンのすべてに耐性のものを「薬剤耐性アシネトバクター感染症」として、感染症法の五類感染症(全数把握)に指定している

## 名前の由来とラテン語
### 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| *Acinetobacter* | ギリシア語 ἀκίνητος (akínētos)「動かない」+ *-bacter* | 動かない桿菌 |
| ἀκίνητος | 否定の *a-* + κινητός (kinētós)「動く」 | 動かない |
| *-bacter* | ギリシア語 βακτήριον (baktḗrion)「小さな杖」から作った新ラテン語 | 桿菌(棒の形の菌) |
| *baumannii* | 人名 Baumann のラテン語化 *Baumannius* の属格 | バウマンの |

- 鞭毛がなく泳がないことから名付けられた(1954 年、ブリスーとプレヴォ Brisou & Prévot)。実際には線毛を使って表面をはうように動く(けいれん運動、twitching motility)ことがある
- 英語の kinetic(運動の)、cinema(映画、動く絵)と同じ語根
- *baumannii* は、アシネトバクターの研究者ポール・バウマン (Paul Baumann) にちなむ(1986 年、ブーヴェとグリモン Bouvet & Grimont が命名)

### ラテン語文法
- *Acinetobacter* は男性名詞(*-bacter* で終わる属名は男性として扱う)
- *baumannii* は**人名の属格**。人名を種小名にするときは、名前をラテン語の第 2 変化名詞 *-ius* にして、その属格 *-ii* を付けるのが一般的(男性の人名の場合)
  - Baumann → *Baumannius* → 属格 *Baumannii* → 種小名 *baumannii*(小文字)
- [[Escherichia_coli|*Escherichia coli*]] の *coli* と同じく名詞の属格なので、属名の性に合わせて形を変える必要がない

## 性状
| 項目 | 内容 |
| --- | --- |
| 形 | 短い桿菌〜球菌に近い形(球桿菌)。2 つ並ぶことが多い |
| グラム染色 | 陰性。ただし脱色されにくく、陽性に見えることがある |
| 酸素 | 偏性好気性 |
| 運動性 | 鞭毛による運動はない |
| オキシダーゼ | **陰性**(緑膿菌・モラクセラとの区別に使う) |
| カタラーゼ | 陽性 |
| ブドウ糖 | 発酵しない |

## 起こす病気
- **人工呼吸器関連肺炎・院内肺炎**: 最も多い
- **菌血症**: 中心静脈カテーテルからなど
- **創部・軟部組織感染**: 外傷・熱傷。戦傷者の感染で問題になった
- 尿路感染(カテーテル関連)、術後髄膜炎

## 抗菌薬への耐性
### もともとの耐性
- アンピシリン([[アンピシリン]]、[[アモキシシリン]])、第 1・第 2 世代セフェム([[セファゾリン]]など)、エルタペネムなど、多くの β-ラクタムにもともと効きにくい
- 外膜の透過性が低く、排出ポンプが多い
- 染色体に AmpC 型 β-ラクタマーゼ (ADC) と、OXA-51 系のオキサシリナーゼをもつ

### 獲得耐性
| 耐性 | しくみ |
| --- | --- |
| カルバペネム耐性 | **OXA-23 型**などのカルバペネム分解酵素(クラス D)の獲得が最も多い。OXA-51 系の過剰発現、IMP 型・NDM 型(メタロ-β-ラクタマーゼ)、ポーリンの減少もある |
| アミノグリコシド耐性 | アミノグリコシド修飾酵素、16S rRNA メチラーゼ |
| フルオロキノロン耐性 | DNA ジャイレース・トポイソメラーゼ IV の変異 |
| コリスチン耐性 | リピド A の修飾、リポ多糖の欠損 |

## 治療
感受性試験で決めるのが基本。
- **感性株**: カルバペネム、[[ピペラシリン]]・[[タゾバクタム]]、セフェピム、アンピシリン・[[スルバクタム]]など
- **[[スルバクタム]]はそれ自身がアシネトバクターに効く**(PBP1・PBP3 を阻害)。CRAB では、高用量のアンピシリン・スルバクタムが治療の中心の一つになる。海外では、スルバクタムを OXA 型の分解から守るデュルロバクタムとの配合剤が承認されている
- **カルバペネム耐性株 (CRAB)**: コリスチン、セフィデロコル、チゲサイクリン、ミノサイクリン、高用量スルバクタムなどを組み合わせることが多い。どれも決定的ではない
- 日本の適応菌種に「アシネトバクター属」を含むものの例: ゾシン([[タゾバクタム]])、スルペラゾン([[スルバクタム]])

この項目は一般的な微生物学・感染症学の知識による(適応菌種は各添付文書による)。

## エビデンス
- **CRAB を含む *A. baumannii* 感染症 (ATTACK、Lancet Infect Dis 2023)**: スルバクタム・デュルロバクタムは、コリスチンと比べて 28 日死亡率が非劣性で、腎毒性が少なかった → [[スルバクタム#エビデンス]]
