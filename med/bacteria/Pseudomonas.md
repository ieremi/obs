# *Pseudomonas*（シュードモナス属）

**グラム陰性の非発酵性桿菌を含む属。** 代表的な臨床菌種は緑膿菌 *P. aeruginosa*。以下の臨床・耐性の説明は主に緑膿菌についてのもの。

## 名前の由来とラテン語

ギリシア語 *pseudēs*「偽の」＋ *monas*「単位・モナド」から「偽のモナド」。属名は女性。これは歴史的な命名で、緑色色素や薬剤耐性を表す語ではない。

*aeruginosa* はラテン語 *aeruginosus, -a, -um*「緑青を帯びた・銅のさびに満ちた」の女性形。属名に合わせた語尾で、和名「緑膿菌」と色のイメージを結びつけられる。[LPSN：aeruginosa](https://lpsn.dsmz.de/species/pseudomonas-aeruginosa)

属名の出典：[LPSN：Pseudomonas](https://lpsn.dsmz.de/genus/pseudomonas)。語源は命名の由来であり、全菌種・全菌株の性状を保証するものではない。

## 緑膿菌

**グラム陰性のブドウ糖非発酵桿菌。** 水や湿潤環境に存在し、医療関連感染で重要になる。腸内細菌目の大腸菌・肺炎桿菌とは別のまとまり。

### 性状

| 項目 | 特徴 |
| --- | --- |
| 代謝 | ブドウ糖を発酵しない |
| 酸素 | 主に好気性 |
| オキシダーゼ | 通常陽性 |
| 色素 | ピオシアニンなどを作る株がある |
| 運動性 | 鞭毛による運動 |

緑色の色素を作らない株もあり、色だけでは同定できない。「非発酵」は糖をまったく利用できないという意味ではない。[UK SMI ID 17](https://www.rcpath.org/asset/BFD560D2-EB3A-4260-BF1F63FEEE21325A/)

### 主な感染と患者背景

肺炎、血流感染、尿路感染、創部感染などの原因になる。人工呼吸器・カテーテルの使用、熱傷、手術などが背景になることがある。汚染された水や器材、手指を介した医療現場での伝播が問題になる。[CDC：About P. aeruginosa](https://www.cdc.gov/pseudomonas-aeruginosa/about/index.html)

### 定着と感染

喀痰や創から検出されても、必ず現在の症状の原因とは限らない。採取部位、検体の質、局所所見、全身状態を合わせて考える。慢性の気道疾患では持続的に検出されることもある。

### 抗菌薬の違い

**抗緑膿菌活性のある薬と、ない薬を区別する。** [[セフトリアキソン]]や[[セファゾリン]]は、緑膿菌を狙う薬ではない。

[[ピペラシリン]]・[[タゾバクタム]]配合剤、セフェピム、セフタジジムなどは候補となるが、耐性株もある。カルバペネム系でも一律ではなく、エルタペネムには抗緑膿菌活性がない。耐性機構・感染部位・感受性から選択する。[IDSA 2026 AMR Guidance、Section 4](https://www.idsociety.org/practice-guideline/amr-guidance/)
