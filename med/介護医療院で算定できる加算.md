# 介護医療院で算定できる加算

**介護医療院の入所サービスで算定対象となる加算と関連費用の一覧。** 2026年6月1日適用の介護報酬算定構造を基に整理した。短期入所療養介護・介護予防短期入所療養介護は別の報酬表となる。

以下は制度上の算定候補であり、個々の施設が取得できるかは、基本サービス費の区分、人員配置、研修、実施記録、入所者の状態、体制届等で決まる。各表の「確認する内容」は要件の概要であり、算定要件の全文ではない。

## 算定要件

以下は主な要件の整理。告示の「別に定める基準」には、人員・対象者・施設区分などの追加条件があるため、各項目の根拠資料も併せて確認する。

### 共通する手続き・記録

- 体制届が必要な加算は、指定権者に届け出た区分と算定開始日を確認する。要件を満たさなくなった場合も届出が必要。
- 対象者の評価、医師等の指示、計画、本人・家族への説明や同意、実施内容、会議、再評価を、各加算で求められる形で記録する。
- 職員の割合は、単日の勤務表の人数だけで判定せず、告示・留意事項が定める算出期間と常勤換算等の方法で計算する。
- LIFE関連の加算は、情報の提出だけでなく、提出情報やフィードバックを使ったケア・計画の見直しが必要。

根拠：[報酬告示・介護医療院サービス](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)、[大臣基準告示](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0&pageNo=3)。

### 入所・退所に関する加算

| 加算 | 主な算定要件 |
| --- | --- |
| 初期加算 | 入所日から起算して30日以内。再入所等の扱いは留意事項に従う |
| 若年性認知症入所者受入加算 | 若年性認知症の対象者を受け入れ、個別の担当者を定めて特性・ニーズに応じたサービスを提供する。体制届が必要。認知症行動・心理症状緊急対応加算との併算定は不可 |
| 退所時栄養情報連携加算 | 告示上の特別食が必要な者、または医師が低栄養と判断した者が対象。本人の同意を得て管理栄養士が情報提供する。在宅への退所では主治医の医療機関と介護支援専門員へ、入院・他施設入所ではその医療機関等へ提供。栄養マネジメント強化加算・栄養管理の減算を算定している場合は不可 |
| 再入所時栄養連携加算 | 退所して病院・診療所に入院した者が同じ介護医療院に再入所し、所定の特別食等を必要とすること。施設と入院先の管理栄養士が連携して栄養ケア計画を作成。栄養管理の減算時は不可 |
| 退所前訪問指導加算 | 入所期間が1月を超える見込みの者について、退所後の居宅を訪問し、本人・家族等へ療養上の指導。原則入所中1回、入所後早期の訪問が必要と認められる場合は2回まで |
| 退所後訪問指導加算 | 退所後30日以内に居宅を訪問し、本人・家族等へ療養上の指導。退所後1回まで |
| 退所時指導加算 | 入所期間が1月を超え、退所後に居宅で療養を継続する者へ、退所時に本人・家族等への療養上の指導を実施。1人1回まで |
| 退所時情報提供加算Ⅰ | 居宅で療養を継続する退所者について、本人の同意を得て、退所後の主治医へ診療状況・心身の状況・生活歴等を提供して紹介。社会福祉施設等への退所にも所定の取扱いあり。1人1回まで |
| 退所時情報提供加算Ⅱ | 医療機関に入院する退所者について、本人の同意を得て、入院先へ心身の状況・生活歴等を提供して紹介。1人1回まで |
| 退所前連携加算 | 入所期間が1月を超え、退所後に居宅サービスを利用する者。本人の同意を得て、希望する居宅介護支援事業者へ診療状況を示す文書等を提供し、退所後のサービス利用を調整。1人1回まで |
| 訪問看護指示加算 | 退所時に施設の医師が診療に基づき訪問看護等を必要と判断。本人の同意を得て、本人が選定する訪問看護ステーション等に訪問看護指示書を交付。1人1回まで |
| 在宅復帰支援機能加算 | 前6月の退所者のうち、入所期間が1月を超え在宅で介護を受けることになった者の割合が30％を超えること。退所後30日以内の訪問またはケアマネジャーからの情報で、在宅生活が1月以上継続する見込みを確認・記録。家族との連絡調整と、居宅介護支援事業者への情報提供・サービス調整も実施 |

退所前・退所後訪問指導では、社会福祉施設等への退所についても、本人の同意を得て訪問し連絡調整・情報提供等を行った場合の取扱いがある。

根拠：[報酬告示「4 介護医療院サービス」ト～ヌ・レ](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)、[大臣基準告示第64号・第65号の2・第91号](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0&pageNo=3)。

### 栄養・口腔に関する加算

**栄養マネジメント強化加算**では、次を満たす。

- 管理栄養士を常勤換算で「入所者数÷50」以上配置。常勤栄養士1人以上が給食管理を担う場合は「入所者数÷70」以上。
- 低栄養またはそのおそれがある者に、多職種で作成した栄養ケア計画に沿って定期的な食事観察・食事調整等を実施。
- その他の入所者も変化を把握し、問題があれば早期に対応。
- 栄養状態等をLIFEに提出し、継続的な栄養管理に活用。
- 所定の定員・人員等の基準を満たし、体制届を行う。栄養管理の減算時は算定不可。

**経口移行加算**は、現在経管栄養の者が対象。医師の指示の下、多職種で経口移行計画を作成し、管理栄養士・栄養士による栄養管理と、言語聴覚士・看護職員による支援を行う。原則として計画作成から180日以内。180日を超えても、一部経口摂取が可能で医師が継続支援を必要とする場合には例外がある。栄養管理の減算時は不可。

**経口維持加算Ⅰ**は、経口摂取中で摂食機能障害があり誤嚥が認められる者が対象。医師・歯科医師の指示、多職種での食事観察・会議、経口維持計画、管理栄養士・栄養士の栄養管理が必要。摂食・嚥下機能の評価、誤嚥時の管理体制、食形態への配慮も必要。栄養管理の減算時や経口移行加算との併算定は不可。

**経口維持加算Ⅱ**は、Ⅰの算定と協力歯科医療機関の確保が前提。食事観察・会議等に、施設の配置医師以外の医師、歯科医師、歯科衛生士または言語聴覚士が参加する。

**口腔衛生管理加算Ⅰ**では、歯科医師・歯科衛生士の助言に基づく個別の管理計画を作成。歯科医師の指示を受けた歯科衛生士が月2回以上管理を行い、介護職員へ具体的な技術的助言・指導をし、相談にも対応する。**Ⅱ**は、Ⅰの要件に加え、LIFEへの情報提出・活用が必要。所定の定員・人員等の基準も満たすこと。

**療養食加算**は、管理栄養士または栄養士が管理し、年齢・心身の状態に合う食事を提供する施設が体制届を行い、告示で定める療養食を提供した場合に算定。単に食べやすくした刻み食・ミキサー食であることだけでは、対象の療養食とはならない。

根拠：[報酬告示ヲ～タ](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)、[大臣基準告示第65号の3・第66号・第67号・第69号・第100号の4](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0&pageNo=3)。

### 認知症に関する加算

| 加算 | 主な算定要件 |
| --- | --- |
| 認知症専門ケア加算 | 所定の認知症の対象者割合を満たし、認知症介護の専門研修修了者を対象者数に応じて配置してチームケアを実施。職員への情報伝達・技術指導の会議を開催。Ⅱには指導に係る研修修了者等の追加条件がある |
| 認知症チームケア推進加算 | 所定の対象者割合を満たし、所定研修の修了者を含む複数職種のチームを編成。BPSDの評価、予防・軽減に向けた個別のケア、定期的な評価・見直しを実施。Ⅰ・Ⅱで研修修了者の要件が異なる |
| 認知症行動・心理症状緊急対応加算 | 医師が、BPSDにより在宅生活が困難で緊急入所が適当と判断した者へのサービス。体制届が必要。入所日から7日まで |
| 重度認知症疾患療養体制加算 | 所定の施設基準に適合する療養棟で、告示に定める重度認知症の対象者を受け入れる。Ⅰ・Ⅱ別の精神科医・看護職員・作業療法士等の配置、療養環境等の施設基準を満たして届け出る。認知症の診断があるだけでは算定できない |

認知症専門ケア加算と認知症チームケア推進加算は併算定不可。各加算のⅠ・Ⅱも同時には算定しない。重度認知症疾患療養体制加算等の具体的な対象者・配置人数は、下記の施設基準・対象者告示の該当区分で照合する。

根拠：[報酬告示ネ～ム](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)、[大臣基準告示](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0)、[施設基準告示](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4585)。

### 排せつ支援・自立支援・LIFE

| 加算・区分 | 主な算定要件 |
| --- | --- |
| 排せつ支援加算Ⅰ | 入所時と少なくとも3月に1回、医師または医師と連携した看護師が軽減の見込みを評価。改善が見込まれる者について多職種で原因分析・支援計画を作成し継続支援。少なくとも3月に1回計画を見直し、LIFEへの提出・活用を行う |
| 排せつ支援加算Ⅱ | Ⅰの要件に加え、改善が見込まれる対象者について、排尿・排便の少なくとも一方が改善し両方とも悪化なし、またはおむつが不要となる、または尿道カテーテルが抜去されるなど、告示に定める改善要件を満たす |
| 排せつ支援加算Ⅲ | Ⅰの要件に加え、排尿・排便の少なくとも一方が改善し両方とも悪化がなく、かつ、おむつを使用しなくなった対象者 |
| 自立支援促進加算 | 医師が入所時と少なくとも3月に1回医学的評価を行い、多職種で支援計画を作成してケアを実施。医師が計画策定等に参加し、少なくとも3月に1回見直す。LIFEへの評価情報提出・活用が必要 |
| 科学的介護推進体制加算Ⅰ | ADL、栄養、口腔、認知症等の基本情報をLIFEに提出し、その情報を使って施設サービス計画・ケアを見直す |
| 科学的介護推進体制加算Ⅱ | Ⅰの基本情報に加えて疾病の状況等を提出し、情報を活用してサービスを見直す |

根拠：[大臣基準告示第71号の3～第71号の5等](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0&pageNo=3)。提出対象・提出月・期限はLIFE関係通知による。

### 職員体制・感染対策・安全管理

**夜間勤務等看護加算**は、夜勤を行う看護・介護職員の配置と勤務条件について、Ⅰ～Ⅳの基準に適合し、体制届を行った場合に算定。人数の判定には、入所者数、夜勤時間帯、勤務時間、施設・療養棟の区分等を用いる。夜勤勤務条件の減算が適用される場合は不可。具体的な配置人数・看護職員の条件は[夜勤勤務条件告示の第7号ハが準用する第2号ハ(3)](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0263)で確認する。

**協力医療機関連携加算**は、入所者の同意を得て、病歴等の情報を協力医療機関と共有する会議を定期的に開催する。相談対応・診療を常時行える体制と、入院が必要な場合の原則受入体制を満たす協力医療機関との連携が50単位、それ以外は5単位。会議の開催記録と共有内容を残す。[報酬告示ル](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)

**安全対策体制加算**は、安全対策担当者が外部の安全対策研修を受け、施設内に安全対策部門を設け、組織的に安全対策を実施する体制を整備する。[施設基準告示](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4585)

**高齢者施設等感染対策向上加算Ⅰ**では、以下のすべてを満たす。

- 第二種協定指定医療機関と新興感染症発生時等の対応体制を確保。
- 協力医療機関等と、それ以外の感染症の発生時対応も取り決め、連携して対応。
- 感染対策向上加算・外来感染対策向上加算の届出医療機関等の研修・訓練に年1回以上参加。

**Ⅱ**は、感染対策向上加算の届出医療機関から、感染者発生時の対応について3年に1回以上、施設内で実地指導を受ける。[大臣基準告示第100号の5](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0&pageNo=3)

**生産性向上推進体制加算**は、利用者の安全、ケアの質、職員負担軽減を検討する委員会を設置し、見守り機器等のテクノロジーを用いた継続的な業務改善と実績データ報告を行う。ⅠはⅡよりも導入機器・職員間の役割分担・効果の確認等の条件が加わる。機器を導入するだけでは算定できない。[大臣基準告示第37号の3・第100号の5の2](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0)

**サービス提供体制強化加算**の職員構成要件は次のとおり。

| 区分 | 職員構成の要件 |
| --- | --- |
| Ⅰ | 介護職員中の介護福祉士が80％以上、または勤続10年以上の介護福祉士が35％以上。加えてサービスの質向上の取組を実施 |
| Ⅱ | 介護職員中の介護福祉士が60％以上 |
| Ⅲ | 介護職員中の介護福祉士が50％以上、看護・介護職員中の常勤職員が75％以上、または直接サービスを提供する職員中の勤続7年以上が30％以上のいずれか |

各区分とも所定の定員・人員等の基準を満たし、体制届を行う。割合の算出期間・勤続年数・兼務者の数え方は留意事項に従う。[大臣基準告示第93号を準用する第100号の6](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0&pageNo=3)

## 算定時に確認する組合せ・制限

- **特別介護医療院サービス費・ユニット型特別介護医療院サービス費**では、通常のⅠ型・Ⅱ型と同じように全加算を算定できない。算定構造で「※2」とされた栄養・退所支援・LIFE関連などの項目には適用除外がある。
- 夜勤勤務条件の減算が適用される場合、夜間勤務等看護加算は算定できない。
- 栄養管理の基準を満たさない場合、栄養マネジメント強化加算や経口移行加算など、算定できなくなる項目がある。
- 認知症専門ケア加算と認知症チームケア推進加算は併算定できない。
- 経口維持加算Ⅰと経口移行加算は併算定できない。経口維持加算ⅡはⅠの算定が前提となる。
- 退所時栄養情報連携加算と栄養マネジメント強化加算など、別途併算定制限のある組合せを確認する。

施設ごとの取得可否を絞るには、Ⅰ型・Ⅱ型・特別の別、基本サービス費の区分、職員配置、現在の届出加算、LIFEの運用状況が必要となる。
