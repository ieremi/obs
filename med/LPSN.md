# LPSN

**LPSNは、細菌・古細菌の学名と命名の履歴を調べるデータベース。** 正式名称は *List of Prokaryotic names with Standing in Nomenclature*。日本語では「命名法上の地位を持つ原核生物名の一覧」という意味になる。

ドイツの **Leibniz Institute DSMZ（ドイツ微生物・細胞培養コレクション）**が運営する。[LPSN公式サイト](https://lpsn.dsmz.de/)、[DSMZによる説明](https://www.dsmz.de/de/collection/digital-collection/prokaryotic-names)

## 何を確認できるか

| 項目 | 分かること |
| --- | --- |
| 属名・種名 | 学名の綴りと分類上の位置 |
| Etymology | 名前の語源、構成要素、ラテン語の文法上の性など |
| 命名者・発表年 | 誰が、いつ、その名前を発表したか |
| 原著の書誌 | 命名や分類変更の根拠となる論文・著作 |
| 命名上の地位 | 国際原核生物命名規約（ICNP）に沿って有効に発表された名前かなど |
| 同義名・旧名 | 改名や別名との関係 |
| タイプ種・タイプ株 | 属や種の名前を結びつける基準 |

出典：[LPSN：Introduction](https://www.lpsn.dsmz.de/text/introduction)、[Glossary](https://www.lpsn.dsmz.de/text/glossary)。タイプ株は種名の基準であり、その種の全菌株の性質を代表する「平均的な菌株」という意味ではない。

## 属と種のページを使い分ける

属名の由来は属ページ、種小名の由来は種ページで確認する。

| 調べたいこと | 参照するページ | ノートでの使用例 |
| --- | --- | --- |
| *Proteus* の由来 | [属ページ](https://lpsn.dsmz.de/genus/proteus) | [[Proteus]]：変身する海神プローテウス |
| *mirabilis* の意味 | [種ページ](https://lpsn.dsmz.de/species/proteus-mirabilis) | 「驚くべき」という形容詞 |
| *agalactiae* の意味 | [種ページ](https://lpsn.dsmz.de/species/streptococcus-agalactiae) | [[無乳症]]：「無乳症の」を表す属格 |

二名法の学名では、例えば *Proteus mirabilis* の前半が属名、後半が種小名。ページの **Etymology** 欄を見ると、語根だけでなく形容詞・属格などの区別も確認できる。

## 命名と分類を分ける

**命名法**は名前を付けたり適用したりする規則、**分類**は生物をどのまとまりに置くかについての判断。

LPSNの「有効に発表された名前」と「正名（correct name）」は同じ意味ではない。規約に沿う名前が複数ある場合、正名の選択には採用する分類学的見解も関わる。[LPSN：Glossary](https://www.lpsn.dsmz.de/text/glossary)

名前の語源も、現在の生態・感染部位・全菌株の性質を保証するものではない。例えば *agalactiae* という名前だけで、ヒトの感染症を無乳症に限定することはできない。

## ノートでの使い方

学名・語源・旧名の確認に使い、参照したページと確認日を記録する。命名当時の説明を詳しく扱う場合は、LPSNに記載された原著も確認する。

治療・薬剤感受性・感染対策は、それぞれの診療ガイドラインや公的機関の資料も参照する。
