# テトラヒドロビオプテリン (tetrahydrobiopterin, BH₄)

## 構造式
```smiles
C[C@@H]([C@@H]([C@H]1CNC2=C(N1)C(=O)NC(=N2)N)O)O
```

- [PubChem CID 135398654](https://pubchem.ncbi.nlm.nih.gov/compound/135398654)（天然型の (6R)-BH₄。医薬品名 **サプロプテリン**）
- 分子式 C₉H₁₅N₅O₃、分子量 241.25
- **プテリン**（プテリジン環をもつ化合物）の一種。プテリンの名は、ギリシャ語の pteron（翼）から。最初にチョウの翅の色素から見つかったため
- 「テトラヒドロ」は、プテリジン環に水素が 4 つ付いた（還元された）形であることを表す。この形でないと補酵素として働かない

## 働き
**芳香族アミノ酸を水酸化する酵素** と **一酸化窒素合成酵素** の補酵素。神経伝達物質と一酸化窒素を作るのに欠かせない。

| 酵素 | 反応 | できるもの |
| --- | --- | --- |
| **フェニルアラニン水酸化酵素**（PAH） | フェニルアラニン → チロシン | フェニルアラニンの分解（肝臓） |
| **チロシン水酸化酵素**（TH） | チロシン → L-ドパ | **ドパミン**・ノルアドレナリン・アドレナリン（[[カテコールアミン]]）。この反応が律速段階 |
| **トリプトファン水酸化酵素**（TPH） | トリプトファン → 5-ヒドロキシトリプトファン | **セロトニン**・メラトニン |
| **一酸化窒素合成酵素**（NOS） | アルギニン → 一酸化窒素（NO）＋シトルリン | 血管の拡張、神経伝達、免疫 |
| アルキルグリセロールモノオキシゲナーゼ | エーテル脂質の分解 | — |

どの反応でも、酸素分子（O₂）の酸素原子 1 つを基質に付け、もう 1 つを水にする。BH₄ はそのための電子を渡す。

## 合成（新しく作る経路）
GTP から 3 段階で作られる。

```
GTP
 │ GTP シクロヒドロラーゼ I（GCH1）  ← 律速段階
 ▼
7,8-ジヒドロネオプテリン三リン酸
 │ 6-ピルボイルテトラヒドロプテリン合成酵素（PTPS）
 ▼
6-ピルボイルテトラヒドロプテリン
 │ セピアプテリン還元酵素（SR）
 ▼
BH₄
```

- GCH1 の量が、BH₄ を作る量を決める。BH₄ がたまると GCH1 は抑えられ、フェニルアラニンが増えると強められる
- GCH1 の片方の遺伝子の変異で、[[瀬川病]]（ドパ反応性ジストニア）が起こる

## 再生（リサイクル）
水酸化の反応で使われた BH₄ は、2 段階で元に戻る。

```
BH₄ ──(水酸化の反応)──→ 4a-ヒドロキシ-BH₄
                            │ プテリン-4a-カルビノールアミン脱水酵素（PCD）
                            ▼
                         キノイド型ジヒドロビオプテリン（qBH₂）
                            │ ジヒドロプテリジン還元酵素（DHPR）＋NADH
                            ▼
                           BH₄
```

- 酸化されてできた 7,8-ジヒドロビオプテリン（BH₂）は、**ジヒドロ葉酸還元酵素**（DHFR）でも BH₄ に戻せる（サルベージ経路）。メトトレキサートは DHFR を阻害する

## BH₄ がかかわる病気

### BH₄ 欠乏症
BH₄ を作る酵素や再生する酵素が、両方の遺伝子で働かない病気（常染色体潜性遺伝）。

| 欠損する酵素 | 高フェニルアラニン血症 | 特徴 |
| --- | --- | --- |
| PTPS | あり | BH₄ 欠乏症で最も多い |
| DHPR | あり | 葉酸の代謝も乱れる |
| GCH1（両方の遺伝子） | あり | 重い。片方だけなら[[瀬川病]] |
| PCD | あり（一時的） | 神経症状は軽いことが多い |
| SR | **なし** | 肝臓ではほかの酵素が代わりに働くため |

- **フェニルアラニンが分解できない**（高フェニルアラニン血症）だけでなく、**ドパミン・セロトニンも作れない**
- そのため、フェニルアラニンを減らす食事だけでは神経症状（筋緊張の異常、けいれん、発達の遅れ）を防げない。フェニルケトン尿症と違う点
- 治療：BH₄（サプロプテリン）、**L-ドパ**（カルビドパとの合剤）、**5-ヒドロキシトリプトファン**。DHPR 欠損症では葉酸（ホリナート）も補う
- 新生児マススクリーニングで高フェニルアラニン血症として見つかり、尿中プテリン分析、DHPR 活性、BH₄ 負荷試験でフェニルケトン尿症と見分ける

### フェニルケトン尿症（PAH 欠損症）
- フェニルアラニン水酸化酵素そのものが働きにくい病気
- 一部の人では、**BH₄ を飲むと酵素が働きやすくなり、血中フェニルアラニンが下がる**（BH₄ 反応性フェニルケトン尿症）。BH₄ が酵素の形を安定させるためと考えられている

### 一酸化窒素合成酵素の「脱共役」
- BH₄ が足りない、または酸化されて BH₂ になると、NOS は NO を作らず、代わりに **スーパーオキシド**（活性酸素）を作る（NOS の脱共役）
- 血管の内皮で起こると、血管が広がりにくくなり、酸化ストレスがさらに BH₄ を壊す悪循環になる
- 糖尿病、高血圧、脂質異常症などの血管障害で起こっていると考えられている。→ [[糖尿病性末梢神経障害]]（原因のしくみ：酸化ストレス、微小血管障害）

## 薬としての BH₄
- **サプロプテリン塩酸塩**（日本：ビオプテン、海外：Kuvan）
- 適応：BH₄ 欠乏症、BH₄ 反応性の高フェニルアラニン血症
- 飲み薬（顆粒・錠剤）
