# カテコールアミン (catecholamine)

## 構造
カテコール(ベンゼン環に隣り合った 2 つの水酸基)とアミノ基をもつ化合物の総称。

## 概要
- **ドパミン、ノルアドレナリン、アドレナリン**の 3 つ。アミノ酸のチロシンから作られる
- ノルアドレナリンは主に交感神経の終末から出る**神経伝達物質**、アドレナリンは主に副腎髄質から血中に出る**ホルモン**(副腎髄質の分泌の約 80% がアドレナリン)
- 「闘争か逃走か」の反応を起こす: 心拍数・血圧・血糖を上げ、気管支を広げる
- 血中の半減期は約 2 分と短い
- アドレナリン(英国式)とエピネフリン(米国式)、ノルアドレナリンとノルエピネフリンは同じ物質。日本の医療ではアドレナリンと呼ぶ

## 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| catechol | カテキュー (catechu) + *-ol*。catechu はマレー語 *kachu*、アセンヤクノキなどの植物の抽出物 | カテキューから取れるアルコール(フェノール) |
| amine | ammonia(アンモニア)から | アンモニアの仲間 |
| adrenaline | ラテン語 *ad*「そばに」+ *rēn*「腎臓」+ *-ine* | 腎臓のそばの物質(副腎の物質) |
| epinephrine | ギリシア語 *epi-*「上に」+ νεφρός (nephrós)「腎臓」+ *-ine* | 腎臓の上の物質 |
| noradrenaline | *nor-* + adrenaline | N-メチル基のないアドレナリン |
| dopamine | DOPA(ジヒドロキシフェニルアラニン)+ amine | ドーパのアミン |

- **アドレナリンとエピネフリン**は、同じ「腎臓のそば(上)」をラテン語とギリシア語で言ったもの
  - 1897 年にエイベル (Abel) が副腎の抽出物を epinephrine と名付けた
  - 1900 年に**高峰譲吉**と助手の上中啓三が、初めて純粋な結晶として取り出し、Adrenalin と名付けた
  - 米国では Adrenalin が製薬会社の商標になったので、米国の公定書ではエピネフリンが使われた。日本では 2006 年に日本薬局方の名前がエピネフリンからアドレナリンに改められた
- **nor-** はドイツ語の *N ohne Radikal*「窒素に置換基がない」の略とされる。アドレナリンの窒素についたメチル基がないものがノルアドレナリン
- **アンモニア**は、古代エジプトの神アモン (Ammon) の神殿の近くで取れた塩(塩化アンモニウム、*sal ammoniacus*)から来ている

## 合成
```
チロシン → L-ドパ → ドパミン → ノルアドレナリン → アドレナリン
      ①          ②          ③               ④
```
1. チロシン水酸化酵素(律速段階)
2. 芳香族 L-アミノ酸脱炭酸酵素
3. ドパミン β-水酸化酵素(シナプス小胞の中)
4. **フェニルエタノールアミン N-メチル基転移酵素 (PNMT)**: ほぼ副腎髄質だけにある

### 副腎皮質とのつながり
副腎では、皮質を通った血液が髄質に流れ込むので、髄質は高い濃度の[[コルチゾール]]にさらされる。コルチゾールは **PNMT を誘導**して、ノルアドレナリンからアドレナリンへの変換を増やす。

- [[ベタメタゾン]]の添付文書には、褐色細胞腫に気づかずに投与して褐色細胞腫クリーゼを起こした報告が書かれている。糖質コルチコイドが腫瘍のカテコールアミンの合成・放出を増やすためと考えられている

## 分解
- [[oxidase#モノアミンオキシダーゼ (MAO)|モノアミン酸化酵素 (MAO)]] とカテコール-O-メチル基転移酵素 (COMT) で分解される
- 途中でできる**メタネフリン・ノルメタネフリン**と、最終産物のバニリルマンデル酸 (VMA) が尿に出る
- 血中・尿中のメタネフリン類は褐色細胞腫の診断に使う

## 受容体と作用
| 受容体 | 情報伝達 | 主な場所 | 作用 |
| --- | --- | --- | --- |
| α1 | Gq | 血管平滑筋 | 血管収縮(血圧上昇)、散瞳 |
| α2 | Gi | 交感神経の終末、脳 | ノルアドレナリンの放出を抑える、[[インスリン]]の分泌を抑える |
| β1 | Gs | 心臓、腎臓 | 心拍数・心収縮力の増加、レニンの分泌([[アルドステロン]]の増加) |
| β2 | Gs | 気管支、血管、肝臓、骨格筋 | 気管支拡張、骨格筋の血管拡張、グリコーゲン分解、**K⁺ を細胞内に移す** |
| β3 | Gs | 脂肪、膀胱 | 脂肪分解、膀胱の弛緩 |

- ノルアドレナリンは主に α と β1、アドレナリンは α・β1・β2 のすべてに働く
- [[コルチゾール]]は血管のカテコールアミンへの反応を保つ(許容作用)。副腎不全でショックになる理由の一つ
- 血糖を上げる: 肝臓のグリコーゲン分解と糖新生を増やし、[[インスリン]]の分泌を抑える

## 薬としてのカテコールアミン
| 薬 | 主な用途 |
| --- | --- |
| アドレナリン | **アナフィラキシーの第一選択**(大腿外側に筋注。成人 0.3〜0.5 mg、小児 0.01 mg/kg)、心停止、局所麻酔薬に加えて出血と吸収を減らす |
| ノルアドレナリン | 敗血症性ショックの第一選択の昇圧薬 |
| ドパミン | 心原性ショックなど。少量で腎血流を増やす「腎保護」の効果は否定されている |
| ドブタミン(合成) | β1 作用で心収縮力を上げる。心不全 |

- アナフィラキシーは、[[セファゾリン]]などの β-ラクタム系抗菌薬で起こる重大な副作用の一つ

## 関連する病気
- **褐色細胞腫・パラガングリオーマ**: カテコールアミンを作る腫瘍。発作性の高血圧、頭痛、動悸、発汗
  - 手術の前は、先に α 遮断薬を使ってから β 遮断薬を加える。β だけを先に遮断すると、α の血管収縮が打ち消されずに残り、血圧が急に上がる
  - ステロイド薬([[ベタメタゾン]]など)や[[グルカゴン]]の投与で、クリーゼを起こすことがある

この内容は一般的な生理学・薬理学の知識による。
