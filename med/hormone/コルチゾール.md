# コルチゾール (cortisol)

## 構造
```smiles
C[C@]12CCC(=O)C=C1CC[C@@H]3[C@@H]2[C@H](C[C@]4([C@H]3CC[C@@]4(C(=O)CO)O)C)O
```

- [PubChem CID 5754](https://pubchem.ncbi.nlm.nih.gov/compound/5754)
- 薬としては**ヒドロコルチゾン**と呼ぶ(同じ物質)

## 概要
- 副腎皮質から出るヒトの主な**糖質コルチコイド**。ストレスに対応するホルモン
- 血糖を上げ、炎症と免疫を抑える。[[プレドニゾロン]]・[[デキサメタゾン]]・[[ベタメタゾン]]などのステロイド薬は、コルチゾールの構造を変えて作用を強めたもの
- 分泌量は成人で 1 日およそ 10〜20 mg。**早朝に多く、夜に少ない**日内変動がある

## 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| cortisol | *cortis-*(cortisone から)+ *-ol*(アルコール、水酸基) | コルチゾンのアルコール型 |
| cortex | ラテン語 *cortex*「樹皮・外皮」 | 副腎の外側の部分(皮質) |
| hydrocortisone | *hydro-*「水素」+ cortisone | 水素を加えたコルチゾン |
| glucocorticoid | *gluco-*(ブドウ糖)+ *cortic-*(皮質)+ *-oid* | 血糖に働く副腎皮質ホルモン |

- **コルチゾン** (cortisone) は 11 位がケトン基 (C=O)。そこに水素が 2 つ付いて水酸基 (C–OH) になったものがコルチゾール(ヒドロコルチゾン)で、*-ol* はこの水酸基を表す
- 1930〜40 年代にケンドール (Kendall) が副腎皮質から取り出した物質を「化合物 E」「化合物 F」と呼び、それぞれコルチゾン、コルチゾールになった。1950 年、ケンドール、ヘンチ (Hench)、ライヒシュタイン (Reichstein) がノーベル生理学・医学賞を受賞した

## 合成
コレステロールから副腎皮質の酵素で順に作られる。
1. コレステロール → プレグネノロン(CYP11A1。StAR 蛋白質がコレステロールをミトコンドリアに運ぶ段階が律速)
2. 17α 位の水酸化(CYP17A1)
3. 21 位の水酸化(CYP21A2)。この酵素の欠損が先天性副腎過形成で最も多い
4. 11β 位の水酸化(CYP11B1)でコルチゾールになる

## 分泌の調節(HPA 系)
視床下部-下垂体-副腎 (HPA) 系で調節される。

```
視床下部  →  CRH  →  下垂体前葉  →  ACTH  →  副腎皮質  →  コルチゾール
   ↑                      ↑                                  │
   └──────────────────────┴──────── 負のフィードバック ──────────┘
```

- [[副腎皮質刺激ホルモン放出ホルモン|CRH]] と [[副腎皮質刺激ホルモン|ACTH]] がコルチゾールの分泌を促し、コルチゾールが両者を抑える
- 感染・手術・外傷などのストレスで分泌が大きく増える
- ステロイド薬を長く使うと、このフィードバックで CRH・ACTH が抑えられ、副腎が萎縮する(続発性副腎皮質機能不全)

## 血中での運ばれ方
- 約 80〜90% がコルチコステロイド結合グロブリン (CBG、トランスコルチン)、残りの多くがアルブミンに結合している
- 働けるのは結合していない遊離型(約 5〜10%)

## 受容体
- 細胞質の**グルココルチコイド受容体 (GR)** に結合すると核に移り、遺伝子の転写を変える
  - 抗炎症遺伝子(アネキシン A1 など)を増やす
  - NF-κB・AP-1 を抑えて、炎症性サイトカインや COX-2 を減らす → [[プロスタグランジン]]が減る
- コルチゾールは**ミネラルコルチコイド受容体 (MR)** にも[[アルドステロン]]と同じくらい強く結合する
  - 腎臓の集合管では **11β-HSD2** がコルチゾールを不活性なコルチゾンに変えるので、MR はアルドステロンだけに反応できる
  - 甘草(グリチルリチン)は 11β-HSD2 を阻害するので(甘草を含む漢方薬: [[小青竜湯]]、[[桂枝加芍薬湯]]など)、コルチゾールが MR を刺激して**偽性アルドステロン症**(高血圧・低 K 血症)を起こす
  - 胎盤にも 11β-HSD2 があり、胎児をコルチゾールから守っている([[プレドニゾロン]]の妊娠中の使い方を参照)

## 作用
| 分野 | 作用 |
| --- | --- |
| 糖代謝 | 肝臓の糖新生を増やし、筋肉・脂肪のインスリン抵抗性を起こす → 血糖が上がる([[インスリン]]と反対) |
| 蛋白質 | 筋肉などの蛋白分解を増やし、糖新生の材料にする |
| 脂肪 | 脂肪分解を増やす。長く多いと顔・体幹に脂肪がつき、手足は細くなる |
| 免疫・炎症 | リンパ球の減少、サイトカインの抑制、好中球の遊走抑制 |
| 循環 | 血管の[[カテコールアミン]]への反応を保つ(許容作用)。コルチゾールがないと血圧が保てない |
| 骨 | 骨形成を抑え、腸の Ca 吸収を減らす |
| 副腎髄質 | 副腎の中の血流で髄質に届き、アドレナリンを作る酵素 (PNMT) を誘導する → [[カテコールアミン]] |

## 関連する病気
### 多すぎる: クッシング症候群
- 原因: ステロイド薬(医原性、最も多い)、下垂体の ACTH 産生腺腫(クッシング病)、異所性 ACTH 産生腫瘍、副腎腺腫
- 症状: 満月様顔貌、中心性肥満、皮膚線条、高血糖、高血圧、骨粗鬆症、易感染性

### 足りない: 副腎皮質機能低下症
- 原発性(アジソン病): 副腎そのものが壊れる。ACTH が増え、同じ前駆体 (POMC) からできる MSH も増えて**皮膚が黒くなる**。[[アルドステロン]]も足りなくなる
- 続発性: 下垂体・視床下部の障害や、**ステロイド薬の急な中止**。アルドステロンは RAA 系で保たれる
- **副腎クリーゼ**: 急な副腎不全。ショック・低血糖・低 Na 血症を起こし、ヒドロコルチゾンの静注で治療する
