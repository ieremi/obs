# コルチゾール (cortisol)

## 構造
```smiles
C[C@]12CCC(=O)C=C1CC[C@@H]3[C@@H]2[C@H](C[C@]4([C@H]3CC[C@@]4(C(=O)CO)O)C)O
```

- [PubChem CID 5754](https://pubchem.ncbi.nlm.nih.gov/compound/5754)
- 薬としては**ヒドロコルチゾン**と呼ぶ(同じ物質)

## 概要
- 副腎皮質から出るヒトの主な**糖質コルチコイド**。ストレスに対応するホルモン
- 血糖を上げ、炎症と免疫を抑える。[[プレドニゾロン]]・[[デキサメタゾン]]・[[ベタメタゾン]]などのステロイド薬は、コルチゾールの構造を変えて作用を強めたもの
- 分泌量は成人で 1 日およそ 10〜20 mg。**早朝に多く、夜に少ない**日内変動がある

## 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| cortisol | *cortis-*(cortisone から)+ *-ol*(アルコール、水酸基) | コルチゾンのアルコール型 |
| cortex | ラテン語 *cortex*「樹皮・外皮」 | 副腎の外側の部分(皮質) |
| hydrocortisone | *hydro-*「水素」+ cortisone | 水素を加えたコルチゾン |
| glucocorticoid | *gluco-*(ブドウ糖)+ *cortic-*(皮質)+ *-oid* | 血糖に働く副腎皮質ホルモン |

- **コルチゾン** (cortisone) は 11 位がケトン基 (C=O)。そこに水素が 2 つ付いて水酸基 (C–OH) になったものがコルチゾール(ヒドロコルチゾン)で、*-ol* はこの水酸基を表す
- 1930〜40 年代にケンドール (Kendall) が副腎皮質から取り出した物質を「化合物 E」「化合物 F」と呼び、それぞれコルチゾン、コルチゾールになった。1950 年、ケンドール、ヘンチ (Hench)、ライヒシュタイン (Reichstein) がノーベル生理学・医学賞を受賞した

## 合成
コレステロールから副腎皮質の酵素で順に作られる。
1. コレステロール → プレグネノロン(CYP11A1。StAR 蛋白質がコレステロールをミトコンドリアに運ぶ段階が律速)
2. 17α 位の水酸化(CYP17A1)
3. 21 位の水酸化(CYP21A2)。この酵素の欠損が先天性副腎過形成で最も多い
4. 11β 位の水酸化(CYP11B1)でコルチゾールになる

## 分泌の調節(HPA 系)
視床下部-下垂体-副腎 (HPA) 系で調節される。

```
視床下部  →  CRH  →  下垂体前葉  →  ACTH  →  副腎皮質  →  コルチゾール
   ↑                      ↑                                  │
   └──────────────────────┴──────── 負のフィードバック ──────────┘
```

- [[副腎皮質刺激ホルモン放出ホルモン|CRH]] と [[副腎皮質刺激ホルモン|ACTH]] がコルチゾールの分泌を促し、コルチゾールが両者を抑える
- 感染・手術・外傷などのストレスで分泌が大きく増える
- ステロイド薬を長く使うと、このフィードバックで CRH・ACTH が抑えられ、副腎が萎縮する(続発性副腎皮質機能不全)

## 血中での運ばれ方
- 約 80〜90% がコルチコステロイド結合グロブリン (CBG、トランスコルチン)、残りの多くがアルブミンに結合している
- 働けるのは結合していない遊離型(約 5〜10%)

## 受容体
- 細胞質の**グルココルチコイド受容体 (GR)** に結合すると核に移り、遺伝子の転写を変える
  - 抗炎症遺伝子(アネキシン A1 など)を増やす
  - NF-κB・AP-1 を抑えて、炎症性サイトカインや COX-2 を減らす → [[プロスタグランジン]]が減る
- コルチゾールは**ミネラルコルチコイド受容体 (MR)** にも[[アルドステロン]]と同じくらい強く結合する
  - 腎臓の集合管では **11β-HSD2** がコルチゾールを不活性なコルチゾンに変えるので、MR はアルドステロンだけに反応できる
  - 甘草(グリチルリチン)は 11β-HSD2 を阻害するので(甘草を含む漢方薬: [[小青竜湯]]、[[桂枝加芍薬湯]]など)、コルチゾールが MR を刺激して**偽性アルドステロン症**(高血圧・低 K 血症)を起こす
  - 胎盤にも 11β-HSD2 があり、胎児をコルチゾールから守っている([[プレドニゾロン]]の妊娠中の使い方を参照)

## 作用
| 分野 | 作用 |
| --- | --- |
| 糖代謝 | 肝臓の糖新生を増やし、筋肉・脂肪のインスリン抵抗性を起こす → 血糖が上がる([[インスリン]]と反対) |
| 蛋白質 | 筋肉などの蛋白分解を増やし、糖新生の材料にする |
| 脂肪 | 脂肪分解を増やす。長く多いと顔・体幹に脂肪がつき、手足は細くなる |
| 免疫・炎症 | リンパ球の減少、サイトカインの抑制、好中球の遊走抑制 |
| 循環 | 血管の[[カテコールアミン]]への反応を保つ(許容作用)。コルチゾールがないと血圧が保てない |
| 骨 | 骨形成を抑え、腸の Ca 吸収を減らす |
| 副腎髄質 | 副腎の中の血流で髄質に届き、アドレナリンを作る酵素 (PNMT) を誘導する → [[カテコールアミン]] |

## 関連する病気
### 多すぎる: クッシング症候群
- 原因: ステロイド薬(医原性、最も多い)、下垂体の ACTH 産生腺腫(クッシング病)、異所性 ACTH 産生腫瘍、副腎腺腫
- 症状: 満月様顔貌、中心性肥満、皮膚線条、高血糖、高血圧、骨粗鬆症、易感染性

### 足りない: 副腎皮質機能低下症
- 原発性(アジソン病): 副腎そのものが壊れる。ACTH が増え、同じ前駆体 (POMC) からできる MSH も増えて**皮膚が黒くなる**。[[アルドステロン]]も足りなくなる
- 続発性: 下垂体・視床下部の障害や、**ステロイド薬の急な中止**。アルドステロンは RAA 系で保たれる
- **副腎クリーゼ**: 急な副腎不全。ショック・低血糖・低 Na 血症を起こし、ヒドロコルチゾンの静注で治療する

## 発達障害とのつながり

発達障害で、コルチゾール（HPA 系）の働き方がちがうかどうかが、多く調べられている。**結果はばらつきが大きく、診断に使える検査（バイオマーカー）にはなっていない。** 原因か結果か（発達障害があるとストレスが多い、など）も分かっていない。

### 測り方
| 指標 | 内容 |
| --- | --- |
| 基礎値 | 朝・午後・夜などのある時点の値。唾液か血液で測る |
| **起床時コルチゾール反応**（CAR） | 起きてから 30〜60 分でコルチゾールが急に上がる反応。その日のストレスへの備えと考えられている |
| 日内変動の傾き | 朝から夜への下がり方 |
| ストレス反応 | 人前で話す、などの課題の前後の変化 |
| 毛髪コルチゾール | 髪の毛にたまった量。数か月分の平均を表す |

### 自閉スペクトラム症（ASD）
- **末梢のコルチゾールは高め**：12 の研究（ASD 375 人、対照 335 人）のメタ解析で、ASD のほうが血中などのコルチゾールが有意に高かった（Gao ら、2022 年）
- **起床時の反応（CAR）は、差がない**：子ども・青年の 4 研究（ASD 117 人、定型発達 118 人）のメタ解析で差はなかった（標準化平均差 −0.21、95% CI −0.49〜0.08。Hadwin ら、2019 年）。8〜12 歳の男児 94 人の研究でも、大きさ・ばらつきに差はなかった（Corbett ら、2014 年）
- **日内変動とストレスへの反応**（Taylor と Corbett の総説、2014 年）：
  - 知的障害を伴うなど、支援の必要が大きい ASD の子では、日内リズム全体の乱れがみられる。知的に遅れのない人では、はっきりしない
  - 体へのストレス（採血など）には、HPA 系の反応が **にぶい**
  - 人から評価される社会的なストレスには、反応が **小さい**。一方で、**不快な刺激** や、ふつうは平気な **ちょっとした人づきあいの場面** には、反応が **大きい**
- ASD の人が、変化や予定外のこと、感覚の刺激に強いストレスを感じやすいことと関係すると考えられている
- 先天性副腎過形成（21-水酸化酵素欠損。コルチゾールが作れず、男性ホルモンが増える）と ASD の関係を、遺伝子の情報から推定した研究もある（Liu ら、2025 年、メンデルランダム化）。まだ仮説の段階

### 注意欠如・多動症（ADHD）
- **コルチゾールは低め**：子ども・青年の 19 研究（ADHD 916 人、定型発達 947 人）のメタ解析で、ADHD のほうが **1 日のどの時点でも基礎値が低く**、1 日の合計も低かった。とくに **朝の値が低い**（14 研究、効果量 0.84）。午後は差がなかった（Chang ら、2021 年）
- 2025 年の、より大きなメタ解析（34 研究、ADHD 2,559 人、定型発達 2,076 人）でも、起床時・起床 30 分後・午後・課題の後のコルチゾールが低かった。**ACTH・CAR・毛髪コルチゾールには差がなかった**。**多動・衝動性が強いタイプ** で、低さがいちばんはっきりしていた（Fulun ら、2025 年）
- **ストレスへの反応** は、12 研究のメタ解析で、全体として差がなかった（r = 0。Kamradt ら、2018 年）。研究ごとのばらつきは大きい
- ただし、**併存症** で結果が変わる。11〜15 歳の 138 人の研究では、素行障害・不安・抑うつの症状を差し引くと、ADHD の症状はむしろ **高い** コルチゾールと関係し、反抗挑発症の症状が **低い** コルチゾールと関係していた（Berens ら、2023 年）。ADHD の約 3 分の 2 に、ほかの精神・神経発達の病気が併存する
- 解釈：ADHD では HPA 系の働きが **低い**（覚醒の低さ）という見方がある。覚醒が低いので、刺激を求めて動き回る、という説明もされる（仮説）

### 胎児期のコルチゾール
- 胎盤の **11β-HSD2** が、母親のコルチゾールから胎児を守っている（上の「受容体」を参照）
- 母親の強いストレスや、早産児の肺を成熟させるための **[[出生前ステロイド]]**（ベタメタゾンなど。11β-HSD2 で分解されにくい）で、胎児が多くの糖質コルチコイドにさらされると、子どもの HPA 系や脳の発達に影響し、ADHD などのリスクが上がる可能性が指摘されている（観察研究による。因果関係は確かでない）。フィンランドの約 67 万人の調査では、出生前ステロイドにさらされて正期産で生まれた子で、精神・行動の障害が多かった（ハザード比 1.47。Räikkönen ら、2020 年）

### まとめ
| | ASD | ADHD |
| --- | --- | --- |
| 基礎値 | **高め**（メタ解析） | **低め**、とくに朝（メタ解析） |
| 起床時の反応（CAR） | 差がない | 差がない |
| ストレスへの反応 | 刺激の種類によって、にぶかったり大きかったりする | 全体では差がない |
| 確かさ | 研究が少なく、ばらつきが大きい | 研究は多いが、併存症で結果が変わる |

- どちらも **集団の平均の話** で、1 人ひとりの診断には使えない
- 測り方（唾液か血液か、時刻、年齢、服薬、睡眠）で値が大きく変わる
