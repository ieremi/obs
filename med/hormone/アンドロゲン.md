# アンドロゲン (androgen)

## 構造
テストステロン：

```smiles
C[C@]12CC[C@H]3[C@H]([C@@H]1CC[C@@H]2O)CCC4=CC(=O)CC[C@]34C
```

- [PubChem CID 6013](https://pubchem.ncbi.nlm.nih.gov/compound/6013)（テストステロン）、[CID 10635](https://pubchem.ncbi.nlm.nih.gov/compound/10635)（ジヒドロテストステロン）
- 炭素 19 個のステロイド（**C19 ステロイド**）。17 位に OH、3 位にケトン、A 環に二重結合（Δ4）をもつ
- **ジヒドロテストステロン（DHT）** は、テストステロンの A 環の二重結合に水素が 2 つ付いた（還元された）もの（*dihydro-*「水素 2 つ」）。分子式は C₁₉H₂₈O₂ → C₁₉H₃₀O₂

## 概要
- **男性らしい体をつくり、保つホルモン** の総称。ステロイドホルモンの一つ
- 主なもの

| アンドロゲン | 主に作る場所 | 強さ |
| --- | --- | --- |
| **テストステロン** | 精巣のライディッヒ細胞（男性では約 95%） | 標準 |
| **ジヒドロテストステロン（DHT）** | 前立腺・皮膚・毛包などで、テストステロンから作られる | **最も強い**（受容体に 2〜5 倍強く結合し、離れにくい） |
| DHEA、DHEA-S、アンドロステンジオン | 副腎皮質の網状層（卵巣も） | 弱い。組織でテストステロンや DHT に変わって働く |

- 女性にもあり、卵巣と副腎で作られる（男性の 10〜20 分の 1 ほど）。女性ではエストロゲンの材料にもなる
- 成人男性は約 6〜7 mg/d のテストステロンを作る。朝に高く、夕方に低い日内変動があり、年齢とともにゆっくり減る

## 語源
| 語 | 由来 | 意味 |
| --- | --- | --- |
| androgen | ギリシア語 ἀνήρ (anḗr)、属格 ἀνδρός (andrós)「男」+ -gen（γεννάω (gennáō)「生む」） | 男らしさを生むもの |
| testosterone | ラテン語 *testis*「精巣」+ ster(ol)「ステロール」+ -one「ケトン」 | 精巣のステロイドのケトン |

- 同じ ἀνδρ- の語：android（人型ロボット、「男のような」）、Andrew（人名、「男らしい」）
- ラテン語 *testis* は「証人」とも同じ形。2 つの関係にはいろいろな説があり、はっきりしない

- すべてのステロイドホルモンと同じく、**コレステロール** から作られる（→ [[コルチゾール]]）
- **CYP17** は 2 つの反応（17α 水酸化と 17,20-リアーゼ）を行い、炭素 21 個のステロイドから 19 個のアンドロゲンを作る鍵の酵素。前立腺癌の薬 **アビラテロン** はここを止める（→ [[前立腺癌#ホルモン療法（アンドロゲン除去療法、ADT）]]）
- テストステロンの行き先は 2 つ
  - **5α 還元酵素** で、より強い **DHT** に（前立腺、外陰部の皮膚、毛包など）。阻害薬のフィナステリド・デュタステリドは前立腺肥大症や男性型脱毛症に使う
  - **アロマターゼ**（CYP19）で、女性ホルモンの **エストラジオール** に（脂肪組織、脳、骨など）。男性の骨や脳への作用の一部は、このエストラジオールを通して起こる

- 視床下部の **GnRH** は、数十分〜数時間おきに **パルス状** に出る。これに反応して下垂体前葉が **LH** と **FSH** を出す
  - **LH** → ライディッヒ細胞がテストステロンを作る
  - **FSH** → セルトリ細胞が精子形成を支える。精子形成には、精巣の中の **血液の数十倍の濃度のテストステロン** が要る
- テストステロンと、そこから作られるエストラジオールが、視床下部と下垂体をおさえる（**負のフィードバック**）。セルトリ細胞が出す **インヒビン B** は FSH をおさえる
- GnRH を **パルス状でなく持続的に** 与えると、下垂体が反応しなくなり、LH・FSH がかえって下がる。これを利用したのが前立腺癌の **GnRH アゴニスト**
- **外からテストステロン（や蛋白同化ステロイド）を入れると**、負のフィードバックで LH・FSH が下がり、精巣の中のテストステロンが減るので、**精巣が小さくなり精子が作られなくなる**（男性の避妊法として研究されてきた理由でもある）

## 血液中での運ばれ方
| 状態 | 割合 | 説明 |
| --- | --- | --- |
| **SHBG**（性ホルモン結合グロブリン）に強く結合 | 約 45〜60% | 組織にほとんど渡らない |
| アルブミンに弱く結合 | 約 40〜50% | 組織で簡単に離れて使われる |
| 遊離型 | 約 2% | そのまま細胞に入る |

- 遊離型とアルブミン結合型を合わせて **生物学的に利用できるテストステロン**（bioavailable testosterone）とよぶ
- SHBG は、エストロゲン・甲状腺機能亢進症・加齢・肝硬変で増え、肥満・インスリン抵抗性・甲状腺機能低下症・アンドロゲンで減る。そのため総テストステロンだけでは判断を誤ることがある（肥満では総量が低くても遊離型は保たれていることがある）

## 受容体
- **アンドロゲン受容体（AR）**：細胞の中にある **核内受容体**。ホルモンが結合すると核に移り、DNA の決まった配列（アンドロゲン応答配列）に結合して遺伝子の転写を変える
- 遺伝子は **X 染色体** の上にある（Xq12）。男性は 1 本しかもたないので、変異の影響がそのまま出る
- **アンドロゲン不応症**：AR の変異で、アンドロゲンが働かない。完全型では、染色体が 46,XY で精巣があってテストステロンも高いのに、見た目は女性になる
- **球脊髄性筋萎縮症**（ケネディ病）：AR 遺伝子の中の CAG の繰り返し（ポリグルタミン）が長くなる病気。成人男性に、手足の筋力低下と、軽いアンドロゲン不応の症状（女性化乳房など）が出る

## 作用
### 胎児期
- 6〜7 週以降、精巣のテストステロンが **ウォルフ管** を精巣上体・精管・精嚢に育てる
- 外陰部（陰茎・陰嚢）と **前立腺** は **DHT** でできる
- **5α 還元酵素欠損症**：DHT が作れないので、生まれたときは外陰部が女性型に見え、思春期にテストステロンが増えて男性化が進む

### 思春期以降
| 部位 | 作用 |
| --- | --- |
| 生殖器 | 陰茎・陰嚢の発育、精子形成、性欲 |
| 喉頭 | 声帯が長く厚くなる（声変わり） |
| 筋肉 | 筋肉量・筋力が増える（**蛋白同化作用**） |
| 骨 | 骨密度を上げる。思春期の成長を促し、最後は（アロマターゼでできたエストラジオールの作用で）骨端線を閉じる |
| 皮膚・毛 | ひげ・体毛が増える。皮脂が増える（にきび）。頭頂部の毛は DHT で細くなる（**男性型脱毛症**） |
| 血液 | 赤血球を増やす（腎臓のエリスロポエチンを増やし、鉄の吸収を高める）。男性のヘモグロビン値が女性より高い理由 |
| 前立腺 | 成長を保つ。加齢で大きくなる **前立腺肥大症** にも、**前立腺癌** の増殖にも関わる（→ [[前立腺癌]]、[[PSA]]） |
| 脳 | 性欲、気分、意欲 |

## 関連する病気
- **男性性腺機能低下症**
  - 原発性（精巣の病気。LH・FSH は高い）：**クラインフェルター症候群**（47,XXY）、精巣炎、抗癌薬・放射線
  - 続発性（視床下部・下垂体の病気。LH・FSH は低い）：**カルマン症候群**（嗅覚もない）、下垂体腫瘍、高プロラクチン血症、オピオイドや糖質コルチコイドの長期使用
  - **加齢男性性腺機能低下症（LOH 症候群）**：加齢でテストステロンが下がり、意欲低下、疲れやすさ、性機能の低下などが出る
- **女性のアンドロゲン過剰**：多嚢胞性卵巣症候群（月経不順、にきび、多毛）、先天性副腎過形成（21-水酸化酵素欠損症で、コルチゾールが作れず、材料がアンドロゲンに回る）、アンドロゲンを作る腫瘍
- **アンドロゲンに依存する病気**：前立腺肥大症、前立腺癌、男性型脱毛症
- **蛋白同化ステロイドの乱用**：精巣萎縮・不妊、女性化乳房（アロマターゼでエストロゲンが増える）、赤血球増加、HDL コレステロールの低下、飲み薬（17α-アルキル化したもの）では肝障害

## 薬としてのアンドロゲンと抗アンドロゲン
| 分類 | 例 | 使い方 |

| アンドロゲン | テストステロン エナント酸エステル（筋肉注射） | 男性性腺機能低下症 |
| 5α 還元酵素阻害薬 | フィナステリド、デュタステリド | 前立腺肥大症、男性型脱毛症。[[PSA]] が約半分になる |

| 副作用として抗アンドロゲン作用をもつ薬 | スピロノラクトン | 女性化乳房の原因になる。女性の多毛症に使うこともある |

## 歴史
- 1849 年、アーノルト・アドルフ・ベルトルト（Arnold Adolph Berthold、ドイツ）が、去勢したおんどりに精巣を移植するとトサカが戻ることを示した。**血液を通して働く物質（ホルモン）** の考えの始まりとされる
- 1889 年、シャルル＝エドゥアール・ブラウン＝セカール（Charles-Édouard Brown-Séquard、フランス）が、動物の精巣の抽出液を自分に注射して若返ったと報告し、話題になった（実際にはテストステロンはほとんど含まれず、効果は暗示と考えられている）
- 1935 年、エルンスト・ラクール（Ernst Laqueur、オランダ）らが牛の精巣から純粋なホルモンを取り出し **testosterone** と名づけた。同じ年、アドルフ・ブーテナント（Adolf Butenandt、ドイツ）とレオポルト・ルジチカ（Leopold Ružička、クロアチア生まれのスイス人）がそれぞれ化学合成に成功し、2 人は 1939 年のノーベル化学賞を受けた
