# アルカリホスファターゼ (alkaline phosphatase, ALP)

## 概要
- **リン酸のエステル（R–O–PO₃²⁻）を加水分解してリン酸をはずす酵素**。**アルカリ性（pH 9〜10 ほど）でよく働く** のでこの名前がある（酸性で働くのは酸ホスファターゼ）
- 亜鉛とマグネシウムを含む金属酵素。細胞膜の外側に、GPI アンカーでつながっている
- 体では、**骨の石灰化** に欠かせない
- 臨床では、血液検査の **ALP** として、**胆汁のうっ滞（肝臓・胆道）** と **骨の病気** の目印に使う

- 骨芽細胞の膜にある ALP が、石灰化を妨げる **ピロリン酸** を分解し、石灰化の材料になる **リン酸** を増やす
- 1923 年、ロバート・ロビソン（Robert Robison、イギリス）が、骨の石灰化にホスファターゼが関わると提唱した
- 骨芽細胞が骨を盛んに作るときに血液の ALP が上がるのは、このため（骨型 ALP）

## アイソザイム
| 種類 | 遺伝子 | 主な場所 |
| --- | --- | --- |
| **組織非特異型**（肝型・骨型・腎型） | *ALPL* | 肝臓（毛細胆管の膜）、骨芽細胞、腎臓 |
| 小腸型 | *ALPI* | 小腸の上皮 |
| 胎盤型 | *ALPP* | 胎盤。一部の癌（精上皮腫など）も作る |
| 胚細胞型 | *ALPG* | 精巣など |

- 肝型と骨型は同じ遺伝子からできるが、糖鎖のつき方が違うので、電気泳動や熱への強さで区別できる（骨型は熱に弱い）

## 血液検査としての ALP
### 基準範囲と測定法の変更
- 日本では **2020 年 4 月から測定法が JSCC 法から国際標準の IFCC 法に変わり、数値が約 3 分の 1 になった**

| 測定法 | 成人の基準範囲（共用基準範囲） |
| --- | --- |
| IFCC 法（いま） | **38〜113 U/L** |
| JSCC 法（2020 年 3 月まで） | 106〜322 U/L |

- 新旧のおおよその換算は、IFCC 法 ≈ 0.33 × JSCC 法。古い記録と比べるときは注意する
- 子どもは骨が伸びているので、成人の 2〜4 倍ほど高いのがふつう。思春期にいちばん高い
- 血液型が **B 型・O 型** の人では、脂肪の多い食事のあとに小腸型 ALP が血液に出て、値が上がることがある（空腹時に測る）

### ALP が高いとき
| 原因 | 例 | 見分けの手がかり |
| --- | --- | --- |
| **胆汁のうっ滞** | 胆石・癌による胆管の閉塞、原発性胆汁性胆管炎、薬剤性肝障害、肝転移 | **γ-GTP も上がる** |
| **骨の病気** | 成長期、骨折の治りかけ、**造骨性の骨転移**（[[前立腺癌#骨転移が造骨性になるわけ]]）、骨パジェット病、骨軟化症・くる病、副甲状腺機能亢進症 | γ-GTP は正常。骨型 ALP が上がる |
| 胎盤 | 妊娠後期（2 倍ほどになる） | 胎盤型 |
| そのほか | 一過性高 ALP 血症（乳幼児。数週〜数か月で自然にもどる） | 極端に高いが、病気はない |

- **γ-GTP と組み合わせる** のが基本：ALP と γ-GTP がともに高ければ肝臓・胆道、ALP だけ高ければ骨（や胎盤）を考える。必要ならアイソザイムや骨型 ALP を測る

### ALP が低いとき
- **低ホスファターゼ症**：*ALPL* 遺伝子の変異。ピロリン酸がたまって骨や歯の石灰化が進まず、骨が弱い・乳歯が早く抜けるなど。重いものは生まれる前から骨ができない。酵素を補う薬（アスホターゼ アルファ）がある
- 亜鉛不足、栄養不良、甲状腺機能低下症、くる病でない骨の代謝の低下、大量の輸血のあと
- 劇症型の **ウィルソン病**（銅の代謝異常）では、ビリルビンが高いのに ALP が低いのが手がかりになる

## そのほか
- 牛乳の **低温殺菌が十分かどうか** の確認に使われる。ALP は殺菌の温度でちょうど壊れるので、ALP が残っていれば加熱が足りない
- 分子生物学では、DNA の末端のリン酸をはずす酵素や、ELISA で色を出す酵素として広く使われる
