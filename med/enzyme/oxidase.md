# オキシダーゼ (oxidase)

## 概要
- **酸素分子 (O₂) を電子の受け取り手として使い、基質を酸化する酵素**の総称。酸素は水 (H₂O) か過酸化水素 (H₂O₂)(酵素によってはスーパーオキシド O₂⁻)になる
- 酵素分類では EC 1(酸化還元酵素)に入る。EC 番号の 3 番目が 3 のもの(EC 1.x.3.x)が「酸素を受容体とする」グループ
- 医学・微生物学では、次の 2 つの意味で出てくることが多い
  1. 個々の酵素: キサンチンオキシダーゼ、モノアミンオキシダーゼ、シトクロム c オキシダーゼなど
  2. 細菌の同定に使う**オキシダーゼ試験**(シトクロム c オキシダーゼの有無をみる)

## 名前の由来
| 語 | 由来 | 意味 |
| --- | --- | --- |
| oxidase / oxydase | oxid-(酸化)+ 酵素を表す接尾辞 *-ase* | 酸化する酵素 |
| oxygen(酸素) | ギリシア語 ὀξύς (oxýs)「鋭い、酸っぱい」+ -γενής (-genḗs)「生むもの」 | 酸を生むもの |
| *-ase* | diastase(ジアスターゼ、麦芽のデンプン分解酵素)の語尾から | 酵素 |

- **oxydase** はフランス語の綴り。1890 年代にフランスの化学者ガブリエル・ベルトラン (Gabriel Bertrand) が、漆の木の酵素ラッカーゼを研究して、酸素で物質を酸化する酵素を oxydase と名付けた。英語では oxidase と綴る
- 酸素 (oxygène) は、ラヴォアジエが「すべての酸に含まれる元素」と考えて名付けた(実際には酸素を含まない酸もある)。日本語の「酸素」もこの意味を訳したもの。[[バソプレシン]]の語源にある oxytocin の *oxy-*(速い)と同じ語根
- *-ase*: 1833 年にペイヤンとペルソ (Payen & Persoz) が麦芽から取り出した酵素を diastase と名付けた。のちにデュクロー (Duclaux) が、酵素の名前の語尾を *-ase* にそろえることを提案した

## よく似た酵素との違い
| 酵素の種類 | O₂ の使い方 | 例 |
| --- | --- | --- |
| **オキシダーゼ** | 電子の受け取り手。O は基質に入らず、H₂O や H₂O₂ になる | キサンチンオキシダーゼ、グルコースオキシダーゼ |
| **オキシゲナーゼ** | O 原子を**基質の中に組み込む** | シクロオキシゲナーゼ (COX)、シトクロム P450(モノオキシゲナーゼ) |
| **デヒドロゲナーゼ**(脱水素酵素) | O₂ を使わない。NAD⁺・FAD などが電子を受け取る | 乳酸デヒドロゲナーゼ、キサンチンデヒドロゲナーゼ |

- [[プロスタグランジン]]を作る COX(シクロオキシゲナーゼ)は、アラキドン酸に O₂ を 2 分子組み込むので**オキシゲナーゼ**(EC 1.14.99.1、プロスタグランジンエンドペルオキシドシンターゼ)。[[ロキソプロフェン]]・[[ケトプロフェン]]などの NSAIDs はこれを阻害する
- キサンチンオキシダーゼは、体内ではふだん**デヒドロゲナーゼ型**(NAD⁺ を使う)として働き、傷害や虚血のときに**オキシダーゼ型**(O₂ を使い活性酸素を作る)に変わる

## 主なオキシダーゼ

| --- | --- | --- | --- | --- |
| シトクロム c オキシダーゼ | 7.1.1.9 | ヘム a・a₃、銅 (CuA、CuB) | 呼吸鎖の複合体 IV。シトクロム c の電子で O₂ を H₂O にする | シアン・一酸化炭素・硫化水素で阻害される。細菌のオキシダーゼ試験 |
| キサンチンオキシダーゼ | 1.17.3.2 | モリブデン、FAD、鉄硫黄クラスター | ヒポキサンチン → キサンチン → 尿酸 | [[アロプリノール]]・[[フェブキソスタット]]の標的。メルカプトプリンの分解 |
| モノアミンオキシダーゼ (MAO) | 1.4.3.4 | FAD | モノアミンを酸化的に脱アミノ化する | [[カテコールアミン]]・セロトニンの分解。MAO 阻害薬 |
| グルコースオキシダーゼ | 1.1.3.4 | FAD | ブドウ糖 → グルコノラクトン + H₂O₂ | 血糖測定器・尿糖試験紙 |
| NADPH オキシダーゼ(食細胞型、NOX2) | — | FAD、ヘム | NADPH の電子で O₂ をスーパーオキシド (O₂⁻) にする | 好中球の殺菌。慢性肉芽腫症 |
| NAD(P)H オキシダーゼ(H₂O₂ 産生型、DUOX) | 1.6.3.1 | FAD、ヘム | H₂O₂ を作る | 甲状腺で甲状腺ホルモンの合成に使う H₂O₂ を供給 |
| リシルオキシダーゼ | 1.4.3.13 | 銅 | コラーゲン・エラスチンのリシンを酸化して架橋を作る | 銅欠乏(メンケス病)で結合組織がもろくなる |

EC 番号は KEGG ENZYME で確認した。シトクロム c オキシダーゼは、2018 年に新設された EC 7(輸送酵素、トランスロカーゼ)に移された(プロトンを膜の外に運ぶため)。食細胞型の NADPH オキシダーゼの EC 番号は確認できなかった。

### シトクロム c オキシダーゼ
$$\mathrm{4\,cyt\,c^{2+} + O_2 + 8H^+_{内} \rightarrow 4\,cyt\,c^{3+} + 2H_2O + 4H^+_{外}}$$
- ミトコンドリアの内膜(細菌では細胞膜)にある、電子伝達系の最後の酵素
- 酸素を使う呼吸で使われる酸素のほとんどが、この酵素で水になる
- プロトンを膜の外に運び、ATP 合成に使う濃度勾配を作る
- **シアン化物** (CN⁻)、**一酸化炭素**、**硫化水素**、アジ化物が鉄 (a₃) に結合して阻害する。シアン中毒ではヒドロキソコバラミンでシアンを捕まえる

### キサンチンオキシダーゼ
- プリン代謝の最後の 2 段階を担い、[[アロプリノール]]と[[フェブキソスタット]]はこれを阻害して尿酸を減らす
- メルカプトプリン(アザチオプリンの代謝物)を不活性化するので、阻害薬と併用するとメルカプトプリンが増えて骨髄抑制が起こる
- オキシダーゼ型ではスーパーオキシドと H₂O₂ を作り、虚血再灌流障害にかかわるとされる

### モノアミンオキシダーゼ (MAO)
- ミトコンドリアの外膜にあり、[[カテコールアミン]]・セロトニンなどのモノアミンを分解する
- **MAO-A**: セロトニン・ノルアドレナリンを主に分解する。腸管や肝臓で食事のチラミンも分解する。阻害すると、チーズなどチラミンの多い食品で急な高血圧が起こる(チーズ反応)
- **MAO-B**: ドパミンを主に分解する。阻害薬(セレギリン、ラサギリン)はパーキンソン病の治療薬

### NADPH オキシダーゼ(食細胞型)
- 好中球・マクロファージが細菌を飲み込むと、NADPH オキシダーゼがスーパーオキシドを大量に作る(**呼吸バースト**)。これから H₂O₂、次亜塩素酸などができて殺菌する
- 遺伝的に欠けると**慢性肉芽腫症**になる。カタラーゼを作る菌(黄色ブドウ球菌、セラチア、バークホルデリア、ノカルジア、アスペルギルスなど)の感染を繰り返す。カタラーゼをもつ菌は自分の出す H₂O₂ を分解してしまい、食細胞がそれを殺菌に使えないため

## オキシダーゼ試験
細菌が**シトクロム c オキシダーゼ**をもつかどうかを調べる試験。グラム陰性桿菌の同定の最初の段階でよく使う。

### しくみ
1. 試薬の**テトラメチル-p-フェニレンジアミン**(無色)を、菌を付けたろ紙にたらす
2. 菌がシトクロム c オキシダーゼをもつと、シトクロム c を介して試薬が酸化され、**濃い青紫色**になる(10〜30 秒以内)
3. 色が変わらなければ陰性
- 1956 年にコヴァーチ (Kovács) が、緑膿菌の同定法として報告した

### 結果の例
| 陽性 | 陰性 |
| --- | --- |
| 緑膿菌 (*Pseudomonas aeruginosa*) | 腸内細菌目細菌([[Escherichia_coli\|大腸菌]]、[[Enterobacter]]、[[Citrobacter]]、クレブシエラなど) |
| ナイセリア属(淋菌、髄膜炎菌) | [[Acinetobacter]] |
| ビブリオ属、[[Aeromonas\|エロモナス属]] | ステノトロフォモナス・マルトフィリア |
| カンピロバクター属、[[Helicobacter]] | |
| モラクセラ・カタラーリス | |
| パスツレラ属 | |

- **腸内細菌目細菌はすべて陰性**なので、「グラム陰性桿菌でオキシダーゼ陰性、ブドウ糖を発酵する」なら腸内細菌目細菌と考える
- ブドウ糖を発酵しない菌では、緑膿菌(陽性)と[[Acinetobacter]](陰性)を見分けるのに使う

この内容は一般的な生化学・微生物学の知識による(EC 番号は KEGG ENZYME による)。
