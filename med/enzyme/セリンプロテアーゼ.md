# セリンプロテアーゼ (serine protease)

## 概要
- **活性部位のセリン（Ser）残基を使って、蛋白質のペプチド結合を加水分解する酵素** の総称。プロテアーゼ（蛋白質分解酵素）のなかで最も大きなグループ
- 活性部位には、**セリン・ヒスチジン・アスパラギン酸** の 3 つのアミノ酸が水素結合でつながった **触媒三残基**（catalytic triad）がある
- 消化（トリプシン、キモトリプシン）、**血液凝固**（トロンビン、凝固因子 Xa など）、線溶（プラスミン）、補体、炎症（好中球エラスターゼ）、精液の液化（[[PSA]]）など、体のあちこちで働く
- 多くは **不活性な前駆体（チモーゲン）として作られ、切られて活性化** される。必要な場所・時だけ働くためのしくみ

1. ヒスチジンが、隣のセリンの OH から水素イオン（H⁺）を受け取る。アスパラギン酸は、プラスになったヒスチジンを水素結合で安定させる。これでセリンの酸素が電子を多くもち、**強い求核剤** になる
2. セリンの酸素が、基質のペプチド結合のカルボニル炭素を攻撃し、**四面体中間体** ができる。マイナスになった酸素（オキシアニオン）は、主鎖の NH がつくる **オキシアニオンホール** で安定化される
3. ペプチド結合が切れ、後半のペプチド（アミン側）が離れる。前半は酵素のセリンとエステル結合した **アシル酵素中間体** になる
4. 水が同じしくみでアシル酵素を攻撃し、前半のペプチド（カルボン酸側）が離れて、酵素はもとに戻る

- 触媒三残基は、1969 年にデイヴィッド・ブロウ（David M. Blow、イギリス）らがキモトリプシンの立体構造から見つけた
- キモトリプシンの仲間と、細菌のサブチリシンの仲間は、全体の形（立体構造）がまったく違うのに、同じ触媒三残基をもつ。別々の進化で同じ解決にたどり着いた **収斂進化** の有名な例

## 特異性：どこを切るか
基質のアミノ酸の側鎖が入る **S1 ポケット** の形と電荷で、切る場所が決まる。

| 酵素 | S1 ポケット | 切る場所（そのアミノ酸の C 末端側） |
| --- | --- | --- |
| **トリプシン** | 底に負電荷のアスパラギン酸 | 正電荷の **リシン・アルギニン** |
| **キモトリプシン** | 深く、疎水性 | 大きな **芳香族アミノ酸**（フェニルアラニン、チロシン、トリプトファン） |
| **エラスターゼ** | バリン・トレオニンで浅くふさがれる | **アラニン** など小さいアミノ酸 |

## 主なセリンプロテアーゼ
| 働く場所 | 酵素 |
| --- | --- |
| 消化 | トリプシン、キモトリプシン、エラスターゼ（膵液） |
| 血液凝固 | トロンビン（IIa）、凝固因子 VIIa・IXa・Xa・XIa・XIIa |
| 線溶 | プラスミン、組織プラスミノゲン活性化因子（t-PA）、ウロキナーゼ |
| 補体 | C1r、C1s、B 因子、D 因子など |
| 免疫・炎症 | 好中球エラスターゼ、グランザイム、マスト細胞のトリプターゼ |
| そのほか | カリクレイン（[[PSA]] は組織カリクレインの一つ）、細胞膜の TMPRSS2（新型コロナウイルスの侵入に使われる） |

- **DPP-4**（ジペプチジルペプチダーゼ 4）も、触媒三残基をもつセリン型のペプチダーゼ。N 末端から 2 つのアミノ酸を切り、インクレチンを働かなくする（→ [[リナグリプチン]]、[[シタグリプチン]]）

## 阻害するもの
- **セルピン**（serine protease inhibitor の略）：体が作る阻害蛋白質。プロテアーゼに切られると大きく構造を変え、酵素と共有結合したまま酵素の活性部位をゆがめて、働かなくする
  - **α1-アンチトリプシン**：好中球エラスターゼをおさえる。欠乏すると若いうちから肺気腫になり、異常な蛋白質が肝細胞にたまって肝硬変にもなる
  - **アンチトロンビン**：トロンビンや Xa をおさえる。ヘパリンはその働きを 1,000 倍ほど強める
- **薬**
  - 抗凝固薬：ダビガトラン（トロンビンを直接阻害）、リバーロキサバン・アピキサバン・エドキサバン（Xa を阻害）
  - 膵炎・DIC などに：ナファモスタット、ガベキサート、カモスタット
- **有機リン化合物**（サリン、殺虫剤）は、同じ触媒三残基をもつ **アセチルコリンエステラーゼ**（セリン加水分解酵素）のセリンをリン酸化して、元に戻らなくする
