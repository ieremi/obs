# ESBL

**Extended-spectrum β-lactamase（基質拡張型β-ラクタマーゼ）**の略。細菌が産生し、多くのβ-ラクタム系抗菌薬を分解して効きにくくする **酵素**。

ESBLは酵素の名前であり、これを作る細菌を **ESBL産生菌**という。ESBL産生腸内細菌目細菌は **ESBL-E** と略される。

## 仕組み

β-ラクタム環を加水分解し、抗菌薬を不活化する。「基質拡張」は、分解できる抗菌薬の範囲が広がっていることを表す。

多くのペニシリン系、セファロスポリン系（第3世代を含む）、アズトレオナムが対象。[[セフトリアキソン]]が効きにくくなる原因の一つ。

## 主な産生菌

- [[Escherichia_coli|大腸菌]]（*Escherichia coli*）
- [[Klebsiella|肺炎桿菌]]（*Klebsiella pneumoniae*）
- *Klebsiella oxytoca*

代表的な酵素群には **CTX-M型**などがある。[IDSA 2026](https://www.idsociety.org/practice-guideline/amr-guidance/)

## 保菌と感染

腸内などに存在しても症状がなければ **保菌**。一方、尿路感染症や血流感染症などを起こすことがある。

**培養で検出されたことと、治療が必要な感染症であることは同じではない**。症状、検体の種類、感染部位から判断する。

手指や汚染された物品を介して広がるため、手指衛生と適切な感染対策が重要。[CDC](https://www.cdc.gov/esbl-producing-enterobacterales/about/index.html)

## 隔離・感染対策

**ESBL産生菌の検出だけで、全員に同じ個室隔離が必要になるわけではない**。標準予防策を基本に、施設の方針、患者の状態、病棟の伝播状況に応じて接触予防策・病室配置を決める。

主な伝播経路は、手指や物品・環境を介する **接触**。ESBL自体を理由に陰圧室や空気感染予防策を必要とするものではない。[CDC：MDRO対策](https://www.cdc.gov/infection-control/hcp/mdro-management/summary-recommendations.html)

### 個室隔離と接触予防策の違い

| 対策 | 内容 |
| --- | --- |
| 標準予防策 | 全患者が対象。手指衛生、血液・体液への曝露に応じた手袋・ガウン・顔面防護、器材の適切な処理など |
| 接触予防策 | 標準予防策に追加。入室時の手袋・ガウン、患者専用器材や使用後の消毒、周辺環境の清掃など |
| 個室配置 | 接触予防策を行う患者では望ましい。個室の有無や伝播リスクに応じ、感染対策担当者が代替配置を検討する |

**個室に入れるだけでは対策は完了しない**。逆に、多床室でも患者周囲の区域を分け、適切な接触予防策を行う運用がある。[CDC：接触予防策](https://www.cdc.gov/infection-control/hcp/isolation-precautions/precautions.html)

国内の施設例として、鹿児島大学病院の公開マニュアルでは、ESBL産生菌は多床室で接触予防策を実施する区分に含まれる。これは **同施設の運用例**であり、全国一律の基準ではない。[鹿児島大学病院：接触予防策・監視培養](https://www.hosp.kagoshima-u.ac.jp/ict/yobousaku_hyoujun_keirobetsu/sesshokukansen.htm)

### 個室を優先する場面

下痢や便失禁、覆いきれない排膿・分泌物など、**周囲を汚染しやすい状態**では個室を優先する。集団発生時や、周囲に感染リスクの高い患者がいる場合も配置を再評価する。

個室が不足する場合は、同じ耐性菌を持つ患者の同室配置（コホーティング）などを感染対策チーム（ICT）と検討する。[CDC：MDRO対策](https://www.cdc.gov/infection-control/hcp/mdro-management/summary-recommendations.html)

### 保菌だけでも対策する？

**無症状の保菌者も伝播源になりうる**ため、感染症の治療が不要でも感染対策の対象になることがある。「抗菌薬を使うか」と「接触予防策を行うか」は別に判断する。

介護施設では、急性期病院と同じ一律の居室隔離ではなく、状態に応じて高接触のケア時に手袋・ガウンを使う強化バリア予防策などを選ぶ場合がある。[CDC：介護施設の対策](https://www.cdc.gov/long-term-care-facilities/hcp/prevent-mdro/PPE.html)

### いつ解除する？

**抗菌薬治療の終了や、培養1回の陰性だけで自動的に解除しない**。感染が治っても腸内などの保菌が続く場合があり、MDROの接触予防策の解除時期には一律の確立した基準がない。

排泄物・分泌物の管理、施設の伝播状況、必要に応じた検査などから、施設マニュアルに沿ってICTが判断する。[CDC：MDRO予防・管理](https://www.cdc.gov/infection-control/hcp/mdro-management/prevention-control.html)

## 肺炎との関係

**ESBL産生菌が肺に感染すると、肺炎の原因になりうる**。ESBLは抗菌薬への耐性に関わる酵素であり、肺炎を起こす毒素そのものではない。

例えば、ESBLを産生する肺炎桿菌（*Klebsiella pneumoniae*）が原因菌となることがある。ただし、**肺炎桿菌のすべてがESBL産生菌ではなく、肺炎のすべてが肺炎桿菌によるものでもない**。

### 喀痰で検出されたら

喀痰培養でESBL産生菌が検出されても、**その菌が肺炎の原因とは限らない**。気道への定着や、採取時の汚染も考えられる。

発熱、膿性痰、酸素化の悪化、胸部画像での新たな浸潤影などに加え、検体の質や培養結果を合わせて原因菌かどうかを判断する。[ATS/IDSA：院内肺炎・人工呼吸器関連肺炎ガイドライン](https://www.idsociety.org/practice-guideline/hap_vap/)

### 治療への影響

ESBL産生菌による肺炎では、[[セフトリアキソン]]などの通常のセファロスポリン系に頼れないことがある。原因菌と判断された場合は、薬剤感受性と重症度を踏まえて治療薬を選ぶ。

IDSA 2026では、肺炎を含む尿路外のESBL産生菌感染症に **カルバペネム系を優先**し、重症例ではメロペネムまたはイミペネム・シラスタチンを推奨する。この考え方は主に血流感染症の研究結果を肺炎へ適用したものであり、肺炎に限った直接の比較試験による裏付けとは区別する。[IDSA 2026：Question 1.3](https://www.idsociety.org/practice-guideline/amr-guidance/)

## 抗菌薬選択の考え方

感染部位、重症度、薬剤感受性に応じて選ぶ。**ESBLだから必ず同じ薬を使う、というわけではない**。

| 場面 | 考え方 |
| --- | --- |
| 菌血症など尿路外の感染 | カルバペネム系が優先選択。重症例ではメロペネムなど |
| 腎盂腎炎などの複雑性尿路感染 | 感受性が確認されたST合剤・フルオロキノロン系など。耐性や重症度によりカルバペネム系などを選択 |
| 単純性膀胱炎 | 感受性のあるST合剤など、感染部位に適した選択肢を検討 |

上表は **IDSA 2026の選択肢の一部**。米国のガイダンスであり、日本での承認・入手可能性や施設の方針も考慮する。[IDSA 2026：Section 1](https://www.idsociety.org/practice-guideline/amr-guidance/)

### 有効な抗菌薬の具体例

以下は **薬剤感受性が確認されている場合の候補**。ESBL以外の耐性機構を持つ株には効かないことがある。

| 分類 | 抗菌薬 | 主な位置づけ・注意 |
| --- | --- | --- |
| カルバペネム系 | **メロペネム、イミペネム・シラスタチン** | 肺炎・菌血症などの優先選択。重症例でも中心となる |
| カルバペネム系 | エルタペネム | 尿路外感染などの選択肢。重症・低アルブミン血症では上記2剤を優先 |
| ST合剤 | スルファメトキサゾール・トリメトプリム（TMP-SMX） | 膀胱炎・腎盂腎炎など。全身状態が安定した後の経口切り替えにも候補 |
| フルオロキノロン系 | シプロフロキサシン、レボフロキサシン | 腎盂腎炎などや経口切り替えに候補。併存耐性があるため感受性確認が重要 |
| アミノグリコシド系 | アミカシン、ゲンタマイシンなど | 尿路感染の選択肢。腎毒性に注意 |
| その他 | ニトロフラントイン | 単純性膀胱炎の選択肢。腎盂腎炎・肺炎・菌血症には用いない |
| その他 | 経口ホスホマイシン | 主にESBL産生大腸菌による単純性膀胱炎の代替。Klebsiellaには勧められない |
| β-ラクタム／阻害薬配合剤 | セフェピム・エンメタゾバクタム | 複雑性尿路感染の優先選択肢の一つ。尿路外感染では代替。セフェピム単剤とは区別 |

経口薬への切り替えは、感受性に加えて循環動態の安定、感染源の制御、消化管吸収を確認する。海外で使われる薬も含むため、国内の採用・承認状況を確認する。[IDSA 2026：Questions 1.1–1.3](https://www.idsociety.org/practice-guideline/amr-guidance/)

### 条件付きの薬・通常は避ける薬

- **[[ピペラシリン]]・[[タゾバクタム]]**：IDSA 2026では複雑性尿路感染の代替選択肢。肺炎・菌血症など尿路外感染では、感受性があっても推奨されない。
- **セフェピム単剤**：腎盂腎炎・複雑性尿路感染や尿路外感染では、感受性があっても避ける。
- **[[セフメタゾール]]などのセファマイシン系**：ESBLに分解されにくく、感受性を示すことがある。ただし臨床エビデンスの限界があり、IDSAでは一律に推奨していない。肺炎・菌血症の標準的な優先薬とは区別する。
- **セフタジジム・アビバクタムなどの新規薬**：有効な場合があるが、通常はカルバペネム耐性菌の治療用に温存する。[IDSA 2026：Questions 1.4–1.7](https://www.idsociety.org/practice-guideline/amr-guidance/)

## 混同しやすい点

- **ESBL産生＝カルバペネム耐性ではない**。通常はカルバペネム系への感受性を保つが、別の耐性機構を併せ持つこともある。
- ESBL自体はフルオロキノロン系やST合剤を分解しない。ただし、産生菌が別の耐性機構を持ち、これらにも耐性を示す場合がある。
- **セフトリアキソン耐性＝必ずESBLとは限らない**。ほかの耐性機構もある。[IDSA 2026](https://www.idsociety.org/practice-guideline/amr-guidance/)
