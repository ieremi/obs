# オルメサルタン (olmesartan)

## 構造式

オルメサルタン メドキソミル（薬として飲むもの、プロドラッグ）：
```smiles
CCCC1=NC(=C(N1CC2=CC=C(C=C2)C3=CC=CC=C3C4=NNN=N4)C(=O)OCC5=C(OC(=O)O5)C)C(C)(C)O
```

オルメサルタン（体の中で効くもの）：
```smiles
CCCC1=NC(=C(N1CC2=CC=C(C=C2)C3=CC=CC=C3C4=NNN=N4)C(=O)O)C(C)(C)O
```

- [PubChem CID 130881](https://pubchem.ncbi.nlm.nih.gov/compound/130881)（メドキソミル）、[CID 158781](https://pubchem.ncbi.nlm.nih.gov/compound/158781)（オルメサルタン）
- [[ロサルタン]] に近い **イミダゾール環** の ARB。ロサルタンの塩素とヒドロキシメチル基のかわりに、**カルボン酸** と **ヒドロキシイソプロピル基**（–C(CH₃)₂OH）がつく
- カルボン酸を **メドキソミル基**（5-メチル-2-オキソ-1,3-ジオキソール-4-イルメチル）でエステルにしたのが薬。吸収をよくするため
- メドキソミル：C₂₉H₃₀N₆O₆、分子量 558.6。オルメサルタン：C₂₄H₂₆N₆O₃、分子量 446.5

## 概要
- 三共（いまの **第一三共**）が開発した ARB。アメリカで 2002 年、日本で 2004 年に承認された
- **プロドラッグ**。小腸の上皮・肝臓・血漿のエステラーゼで、速やかにオルメサルタンになる
- 受容体への結合が強く、**降圧が強め** とされる
- 長く飲むと、**体重が減るほどの重い下痢**（スプルー様腸症）が起こることがある。ほかの ARB ではまれな、この薬に目立つ副作用
- いまの日本の製剤は、水なしで飲める **OD 錠**（5・10・20・40 mg）

## 適応（日本）
- 高血圧症

## 用法・用量（日本）
- 成人：1 日 1 回 **10〜20 mg**。1 日 5〜10 mg から始め、**最大 40 mg**
- 小児の臨床試験はしていない

## 作用のしくみ
- オルメサルタンが AT1 受容体に選択的に結合し、Ang II の結合を **競合的** に止める（ヒトの AT1 受容体での IC50 は 1.3 nM）。くわしくは [[ARB#作用のしくみ]]
- 動物では、反射性頻脈がなく、やめたあとのリバウンドもなかった（添付文書）

## 薬物動態

| 項目 | 値 |
| --- | --- |
| 最高濃度になる時間 | 約 2 時間 |
| 半減期（単回） | 5 mg 8.7 時間、10 mg 10.2 時間、20 mg 11.0 時間、40 mg 10.6 時間 |
| 半減期（くり返し、高血圧の患者） | 約 6 時間 |
| 絶対バイオアベイラビリティ | 25.6% |
| 蛋白結合率 | 99%（アルブミンのワルファリン結合部位。ただしワルファリンには影響しない） |
| 排泄 | 尿 12.6%、**糞 77.2%** |

- **食事の影響はほとんどない**
- CYP でほとんど代謝されないので、CYP を介した相互作用は少ない
- 軽度〜中等度の肝障害で、濃度が上がる

## 副作用・注意点
- 共通の注意は [[ARB#共通の注意]]
- **禁忌**：成分への過敏症、**妊婦**、アリスキレンを飲んでいる糖尿病の人
- 重大な副作用：血管性浮腫、腎不全、[[高K血症]]、ショック・失神、肝機能障害・黄疸、血小板減少、低血糖、横紋筋融解症、アナフィラキシー、**重度の下痢**、間質性肺炎
- 血清クレアチニン 3.0 mg/dL 以上の重い腎障害での試験はしていない

### 重い下痢（スプルー様腸症）
- 飲みはじめて **数か月〜数年たってから**、ひどい慢性の下痢と **体重減少** が起こる。生検では、**小腸の絨毛が縮む**（絨毛萎縮）。セリアック病（スプルー）に似ているので「スプルー様腸症」という
- セリアック病の抗体は陰性で、グルテンを抜いても治らない。**オルメサルタンをやめると治る**
- 原因の薬と気づかれずに、長く検査をくり返されることがある。原因不明の慢性の下痢で、オルメサルタンを飲んでいないか確かめることが大事
- 2012 年にアメリカのメイヨー・クリニックが報告し、2013 年に FDA が注意を出した。日本の添付文書にも「長期投与により、体重減少を伴う重度の下痢」と書かれている
- しくみははっきりしないが、腸の免疫（TGF-β など）への影響が考えられている

## 相互作用
| 併用 | 起こること |
| --- | --- |
| K 保持性利尿薬・K 製剤 | [[高K血症]]（とくに腎障害で） |
| 利尿薬 | はじめの降圧が強く出る |
| アリスキレン | 糖尿病の人は禁忌 |
| ACE 阻害薬 | 腎障害・高 K 血症・低血圧 |
| リチウム | リチウム中毒 |
| NSAIDs | 降圧が弱まる、腎機能の悪化 |

## 大規模臨床試験
- **ROADMAP**（2011 年）：2 型糖尿病で尿蛋白がまだない 4,447 人。オルメサルタンで、**微量アルブミン尿が出るのが遅れた**。一方、もともと冠動脈疾患のある人で、**心血管による死亡がやや多かった**（偶然か、血圧の下げすぎによるかは、はっきりしない）
- **ORIENT**（2011 年）：日本と香港の、2 型糖尿病の腎症 577 人。腎臓の事故の合計は、プラセボと差がなかった

## 名前の由来
- **-sartan**：ARB の語幹
- **メドキソミル**（medoxomil）：エステルの部分の **methyl**・**dioxol**・**oxo** などからつくった名前。同じプロドラッグの基は、アジルサルタン メドキソミル（海外の製剤）でも使われる
