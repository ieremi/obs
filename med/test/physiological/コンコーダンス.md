# コンコーダンス（胸部誘導）

## 概要
- 胸部誘導 **V1〜V6 の QRS が、すべて同じ向き** になっていること
  - **陽性コンコーダンス**：すべて上向き（R 波だけ）
  - **陰性コンコーダンス**：すべて下向き（QS 波だけ）
- ふつうの心電図では、V1 から V6 へ進むうちに QRS の向きが下向きから上向きに入れ替わる（移行帯。多くは V3〜V4）。コンコーダンスは、この入れ替わりがない状態
- **幅の広い QRS の頻拍** で見られれば、**[[心室頻拍]]** を強く疑う所見
- **洞調律** で見られたら、心筋梗塞、WPW 症候群、ペーシング、電極の位置などを考える
- 心筋梗塞の診断で使う「ST と QRS が同じ向き」（Sgarbossa 基準）とは別の概念

## なぜ心室頻拍を示すか
胸部誘導の QRS がすべて同じ向きになるのは、**心室の興奮が胸の前後方向にだけ進んでいるとき**。刺激伝導系（脚）を通る興奮では、ふつうこうならない。

### 胸部誘導の並び方

V1〜V6 は、胸の **右前から左横** へ回りこむように並ぶ。QRS の向きは、興奮が **その電極に向かってくる（上向き）か、離れていく（下向き）か** で決まる。

### 脚を通る興奮では、向きが途中で入れ替わる
- 興奮はヒス束から脚に入り、心室中隔から広がる。全体として **右から左へ**（または左から右へ）進む
- そのため V1 と V6 で向きが逆になり、**途中で入れ替わる**（移行帯。ふつうは V3〜V4）
- 脚ブロックでも、脚を出発点にして伝わるので入れ替わりは残る
  - 右脚ブロック：V1 上向き（rsR'）、V6 は R 波のあとに幅の広い S 波
  - 左脚ブロック：V1 下向き、V6 上向き
- だから、**変行伝導を伴う上室性頻拍は、ふつうコンコーダンスにならない**

### 心室から出る興奮は、前後方向に進むことがある

心室頻拍は心室の筋肉のどこかから始まって広がる。始まる場所によっては、興奮が胸の前後方向に進む。胸部電極はみな胸の前側にあるので、どの電極から見ても同じ向きになる。

| 型 | 始まる場所 | 興奮の進み方 | 胸部誘導 |
| --- | --- | --- | --- |
| **陰性コンコーダンス** | 心尖部・前壁（前壁の心筋梗塞の瘢痕など） | 前から後ろへ。すべての電極から **離れていく** | V1〜V6 がすべて下向き |
| **陽性コンコーダンス** | 心臓の底の後ろ側（僧帽弁輪の近く、後壁など） | 後ろから前へ。すべての電極に **向かってくる** | V1〜V6 がすべて上向き |

### 例外：陽性コンコーダンスと WPW 症候群
- 副伝導路を通って心室へ下りる頻拍（逆方向性房室回帰性頻拍）で、副伝導路が **左側後壁** にあると、心室の興奮は心臓の底の後ろ側から始まる。そのため **陽性コンコーダンス** になりうる
- **陰性コンコーダンス** は副伝導路ではほぼ起こらず、心室頻拍にかなり特異的

### 診断上の意味
- **特異度は高い**：あればほぼ心室頻拍（陽性なら WPW 症候群の例外に注意）
- **感度は低い**：心室頻拍の多くはコンコーダンスを示さない。なくても心室頻拍は否定できない

## 洞調律でコンコーダンスを見たら
頻拍でなく **洞調律**（P 波のあとに QRS が続く）でも、胸部誘導の QRS がそろって同じ向きになることがある。考え方は同じで、**心室の興奮が前後方向にかたよっている** 理由を探す。理由は 4 つに分けられる。

1. **興奮の出発点が異常**：脚ではなく、心室の筋肉の一点から興奮が始まる（副伝導路、ペーシング）
2. **前向き・後ろ向きの力が消えた**：心筋梗塞で、その部分の起電力がなくなり、反対向きの力だけが残る
3. **心臓の位置・形の異常**：右胸心、肺気腫など
4. **記録の問題**：電極の位置や付け間違い

### 陽性コンコーダンス（V1〜V6 がすべて上向き）

| 考えること | しくみ | 確かめる所見 |
| --- | --- | --- |
| **WPW 症候群**（左側・左後壁の副伝導路） | 心臓の底の後ろ側から、副伝導路を通って先に興奮が始まる | **PR 短縮、デルタ波**、QRS 幅の拡大 |
| **後壁心筋梗塞** | 後ろ向きの力が消え、前向きの力が残る。V1〜V2 の高い R 波は、後壁の Q 波の鏡像 | V1〜V2 の R/S 比 > 1、ST 低下（急性期）、V7〜V9 で Q 波・ST 上昇、下壁の梗塞の合併 |
| 左室のペーシング（両室ペーシングなど） | 左室の後側壁から興奮が始まる | ペーシングスパイク |
| 右室肥大 | 右室の前向きの力が大きくなる | 右軸偏位、V1 の高い R 波と V5〜V6 の深い S 波（完全なコンコーダンスにはなりにくい） |
| デュシェンヌ型筋ジストロフィー、肥大型心筋症 | 左室後側壁の線維化、心室中隔の肥大 | 側壁の深い Q 波、病歴 |

### 陰性コンコーダンス（V1〜V6 がすべて下向き）

| 考えること | しくみ | 確かめる所見 |
| --- | --- | --- |
| **広範前壁心筋梗塞**（陳旧性） | 前壁の起電力が消え、後ろ向きの力だけが残る | **V1〜V6 の QS 波**、ST 上昇が続けば **心室瘤**。この瘢痕は心室頻拍の発生源になる |
| **右室心尖部ペーシング** | 心尖部（前・下）から後ろ・上へ興奮が進む | ペーシングスパイク、左脚ブロック型、上方軸 |
| **右胸心** | 心臓が右にあるので、左胸の電極から遠ざかる | V1→V6 で R 波がだんだん小さくなる、I 誘導で P・QRS・T がすべて下向き、右胸部誘導（V3R〜V6R）で正常に近い波形 |
| 肺気腫（COPD） | 過膨張で心臓が下がり、胸部電極が心臓より上になる | 低電圧、R 波の増高不良、右軸偏位 |
| **電極の位置が高すぎる・付け間違い** | 電極が心臓より上にあると、興奮は離れていくように見える | 以前の心電図と比べる、電極の位置を確かめて取り直す |

### 確かめる手順
- **QRS 幅**：広ければ、副伝導路・ペーシング・脚ブロック・心筋の病気を考える
- **PR 間隔とデルタ波** → WPW 症候群
- **ペーシングスパイク** → ペースメーカーの有無と設定
- **Q 波・ST 変化** → 心筋梗塞（新しいか古いか）
- **肢誘導**：I 誘導がすべて下向きなら右胸心か、電極の左右の付け間違い
- **以前の心電図と比べる**。急に出たなら、電極の問題か新しい心筋梗塞を疑う
- 必要に応じて **心エコー**（壁運動の異常、心室瘤、肥大）

### 頻拍のときとの違い
洞調律のコンコーダンスは心室頻拍を意味しない。ただし、**広範前壁梗塞**（陰性）や **WPW 症候群**（陽性）は、頻拍になったときにもコンコーダンスを示しうる。前の心電図で同じ形が見えていれば、頻拍のときの判断の手がかりになる。

## 別の意味の concordance
心筋梗塞の診断で使う「ST と QRS が同じ向き」（左脚ブロックでの Sgarbossa 基準の concordance）は、同じ言葉だが別の話。
