# オプトヒン

**オプトヒン（optochin）は、*Streptococcus pneumoniae* の同定に利用する化学物質。** 試験では塩酸エチルヒドロクプレイン（ethylhydrocupreine hydrochloride）を用い、菌の発育が抑えられるかを調べる。

[[Streptococcus#肺炎球菌|Streptococcus pneumoniae]]は通常オプトヒン感受性を示すため、ほかのα溶血性レンサ球菌との鑑別に使う。[UK SMI TP 25：Optochin test](https://www.rcpath.org/asset/CE366F3F-25B9-490F-8C2CFB6728F24987/)

## 名前の由来

**Optochinは、ethylhydrocupreineに用いられた歴史的な商品名。** 1917年の眼科学論文も、ethyl-hydro-cupreinに対する短い商品名として「optochin」を記載している。[Modern Ocular Therapeutics, 1917](https://bjo.bmj.com/content/bjophthalmol/1/5/294.full.pdf)

化学物質としてはキニーネ関連の誘導体で、MorgenrothとLevyが1911年に感染症治療への利用を導入したと記録されている。[JAMA：Chemotherapy of Pneumococcic Pneumonia](https://jamanetwork.com/journals/jama/article-abstract/293967)

| 名称 | 位置づけ |
| --- | --- |
| *optochin* | 歴史的な商品名に由来する呼称 |
| *ethylhydrocupreine* | 対応する化合物の名称 |
| *ethylhydrocupreine hydrochloride* | その塩酸塩。検査用試薬で使う名称 |

**商品名が、さらにどの語根を組み合わせて作られたかは、今回確認した資料では確定できない。** 綴りだけから *opto-* や *-chin* の意味を割り当てることは避ける。商品名の由来と、化合物名・薬理作用の説明は分けて読む。

## 何を見ている検査か

菌を接種した培地にオプトヒンを含むディスクを置くと、感受性の菌では周囲の発育が抑えられ、**[[阻止円]]**ができる。その直径を測り、採用する検査法の基準で判定する。

| 観察 | 意味 |
| --- | --- |
| 十分な阻止円がある | オプトヒンによって発育が抑えられる＝感受性 |
| 阻止円がない・小さい | 耐性または判定の確認が必要 |

「陽性・陰性」より、**感受性・耐性**と書くほうが、何が起きたかが明確になる。

## 作用の原理

*Streptococcus pneumoniae* の膜にある **F₀F₁型H⁺-ATPase**が標的となる。膜に結合したATPase活性の阻害が研究で示されており、関連遺伝子の変化によるオプトヒン耐性も報告されている。[Fenoll et al., 1994](https://pubmed.ncbi.nlm.nih.gov/7934882/)

## 判定で気をつけること

UK SMI TP 25（2025年版）の本文では、所定の条件で**阻止円の直径14 mm以上**を感受性の目安としている。ただし、ディスク・培地・培養条件によって結果は変わるため、数字だけを切り離して使わず、製品説明書と施設の手順に従う。

- オプトヒン耐性の *Streptococcus pneumoniae*がある。
- *Streptococcus pneumoniae* 以外でも感受性を示す菌があり、感受性だけで確定できない。
- 境界的な結果、発育不良、阻止円内のコロニーなどは追加確認が必要。
- CO₂濃度などの条件が阻止円の大きさに影響する。

出典：[UK SMI TP 25](https://www.rcpath.org/asset/CE366F3F-25B9-490F-8C2CFB6728F24987/)、[Arbique et al., 2004：Streptococcus pneumoniaeと近縁菌の同定研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC522306/)。

## 胆汁溶解性と組み合わせる

オプトヒン試験が「物質による発育阻害」を見るのに対し、**胆汁溶解性試験**は胆汁酸塩による菌の溶解を見る。原理の違う情報を、グラム染色・溶血性・その他の同定結果と合わせて評価する。

*Streptococcus pneumoniae* は典型的にはオプトヒン感受性・胆汁溶解性を示すが、例外があるため、単一の性状で同定を完結させない。[CDC：Streptococcus pneumoniae保菌調査の同定プロトコル](https://www.cdc.gov/strep-lab/media/pcr-pneumo-carriage.pdf)

## 治療薬の感受性とは分ける

この試験の目的は主に**菌の同定**。オプトヒン感受性から、ペニシリンや[[セフトリアキソン]]などの治療薬が効くと判断することはできない。治療薬への感受性は別に確認する。
