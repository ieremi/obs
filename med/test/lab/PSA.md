# PSA（前立腺特異抗原）

## 概要
- 前立腺の上皮細胞が作り、精液に分泌される **[[セリンプロテアーゼ]]**。遺伝子は *KLK3*（組織カリクレイン 3）
- 本来の働きは **精液を液状にする** こと：射精直後にゲル状に固まった精液の蛋白質（セメノゲリン）を切って、数十分で液状にし、精子が動けるようにする
- 精液中の濃度は血液の約 100 万倍。ふつうは血液にはわずかしか漏れないが、前立腺の構造が壊れると血液中の値が上がる
- **前立腺癌** の発見と、治療の効果・再発の判定に使う（→ [[前立腺癌]]）
- **前立腺に特異的** だが、**前立腺癌に特異的ではない**（前立腺肥大症や炎症でも上がる）

## 基準値
- 一般には **4.0 ng/mL 以下**
- 年齢とともに前立腺が大きくなるので、年齢ごとの基準を使うこともある（日本泌尿器科学会のガイドライン）

| 年齢 | 基準値 |
| --- | --- |
| 50〜64 歳 | 3.0 ng/mL 以下 |
| 65〜69 歳 | 3.5 ng/mL 以下 |
| 70 歳以上 | 4.0 ng/mL 以下 |

- 4〜10 ng/mL を **グレーゾーン** とよび、生検で癌が見つかるのは 3 割ほど。10 ng/mL を超えると半分ほど

## 値を変えるもの
| 上がる | 下がる |
| --- | --- |
| 前立腺癌 | **5α 還元酵素阻害薬**（フィナステリド、デュタステリド）：約半年で **約半分** になる。癌を見逃さないよう、測った値を 2 倍にして判断する |
| 前立腺肥大症（大きいほど高い） | 男性ホルモン（[[アンドロゲン]]）を下げる治療（前立腺癌のホルモン療法） |
| 急性前立腺炎（数十〜数百になることもある） | 前立腺の手術後 |
| 尿閉、尿道カテーテル、膀胱鏡、前立腺生検 | |
| 射精、自転車・バイクに長く乗る（わずか） | |
| 直腸診（わずか。採血の前に行っても大きな影響はないとされる） | |

## 精度を上げる工夫
- **遊離型 PSA の比（F/T 比）**：血液中の PSA の多くは、阻害蛋白質（α1-アンチキモトリプシン）と結合している。癌では結合型の割合が多く、**遊離型の割合が低い**（およそ 25% 未満で癌を疑う）。グレーゾーンで生検を決めるのに使う
- **PSA 密度**：PSA ÷ 前立腺の体積（超音波・MRI で測る）。前立腺肥大症で高いだけなのかを見分ける。0.15 を超えると癌を疑う
- **PSA の上がる速さ**（PSA velocity）、**倍加時間**（PSA doubling time）：治療後の再発で、倍加時間が短いほど進行が速い

## 治療後の PSA
- **前立腺全摘除術のあと**：前立腺がなくなるので、**検出できないほど低く** なる（PSA の血中半減期は 2〜3 日で、数週間で下がりきる）。その後 **0.2 ng/mL 以上** に上がり、確認されたら再発（PSA 再発、生化学的再発）
- **放射線治療のあと**：前立腺が残るのでゆっくり下がる。いちばん低くなった値（最低値）から **2.0 ng/mL 以上** 上がったら再発とする（フェニックスの定義）
- **ホルモン療法中**：下がり方と、その後また上がり始めるか（去勢抵抗性への移行）を見る

## 歴史
- 1970 年代に、精液中の蛋白質として、日本の法医学（犯罪捜査で精液の痕跡を調べる）の分野などで報告された（γ-セミノプロテイン）
- 1979 年、ワン（Ming C. Wang、アメリカ）らが前立腺の組織から精製し、前立腺特異抗原と名づけた
- 1980 年代後半から前立腺癌の検査に広く使われ、前立腺癌がずっと早い段階で見つかるようになった。一方で、症状を出さない癌まで見つける **過剰診断** の問題も生まれた（→ [[前立腺癌#検診]]）
