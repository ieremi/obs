# 6 分間歩行試験 (6MWT)

## 概要
- 平らな廊下を **6 分間、できるだけ長い距離を歩いてもらい**、その距離(**6 分間歩行距離、6MWD**)を測る検査
- 日常生活に近い運動で、**運動耐容能**(どれだけ体を動かせるか)を簡単に評価できる。特別な機械がいらない
- 歩く前後の**酸素飽和度 (SpO₂)**、脈拍、息切れの程度もあわせて評価する
- [[間質性肺炎]]、COPD、肺高血圧症、心不全などで、重症度・予後の評価、治療の効果判定、在宅酸素療法の検討に使う

## 方法
米国胸部学会 (ATS) のガイドライン(2002 年)と、欧州呼吸器学会・米国胸部学会 (ERS/ATS) の技術基準(2014 年)に基づく。細かい点は一般的な知識による。

### 準備
- **30 m の平らでまっすぐな廊下**。両端にコーンを置き、そこで折り返す
- 3 m ごとに印を付けておくと距離を数えやすい
- 動きやすい服と靴。ふだん使っている杖・歩行器・酸素はそのまま使う
- 検査前に少なくとも 10 分は座って休む。準備運動はしない

### 測定
1. 歩く前に SpO₂、脈拍、血圧、**[[修正ボルグスケール]]**(息切れと疲労)を記録する
2. 「6 分間でできるだけ長い距離を歩いてください。走ったり跳んだりはしないでください」と説明して、スタートする
3. 検査者は一緒に歩かない。**決められた言葉で 1 分ごとに声をかける**(「順調です。あと 5 分です」など)。それ以外の励ましは結果に影響するので言わない
4. 途中で立ち止まったり休んだりしてもよいが、**時間は止めない**
5. 6 分たったら「止まってください」と言い、その場所に印を付けて距離を測る
6. 歩いた後の SpO₂、脈拍、ボルグスケールを記録する。できれば歩いている間の SpO₂ の最低値も記録する

### 2 回行う
- 慣れると距離が伸びる(**学習効果**)ので、ERS/ATS の技術基準は**2 回行うこと**を重要としている(長いほうを採用する)

### 修正ボルグスケール(息切れ・疲労の程度)
| 点数 | 程度 |
| --- | --- |
| 0 | まったくない |
| 0.5 | 非常に非常に弱い(やっと感じる) |
| 1 | 非常に弱い |
| 2 | 弱い |
| 3 | 中くらい |
| 4 | やや強い |
| 5 | 強い |
| 7 | 非常に強い |
| 9 | 非常に非常に強い(ほぼ最大) |
| 10 | 最大 |

詳しくは [[修正ボルグスケール]] を参照(6・8 のような言葉のない数字も選べる)。

## 行わない場合・中止する場合
ATS のガイドライン(2002 年)に基づく(一般的な知識)。

- **行わない(絶対的禁忌)**: 1 か月以内の不安定狭心症、心筋梗塞
- **慎重に判断する(相対的禁忌)**: 安静時の脈拍 120/分 以上、収縮期血圧 180 mmHg 以上、拡張期血圧 100 mmHg 以上
- **すぐに中止する**: 胸痛、耐えられない息切れ、足のけいれん、ふらつき、冷や汗、顔色が青白くなる

## 結果の見方
### 距離
- 健康な成人ではおおむね 400〜700 m
- Enright と Sherrill の予測式(40〜80 歳の健康な成人。1998 年)

$$\text{男性: } 6\mathrm{MWD} = 7.57 \times \text{身長(cm)} - 5.02 \times \text{年齢} - 1.76 \times \text{体重(kg)} - 309\ \mathrm{m}$$

$$\text{女性: } 6\mathrm{MWD} = 2.11 \times \text{身長(cm)} - 2.29 \times \text{体重(kg)} - 5.78 \times \text{年齢} + 667\ \mathrm{m}$$

- 例: 身長 170 cm、65 歳、体重 65 kg の男性の予測値は約 537 m。実際に 400 m 歩いたら、予測値の約 75%
- 例: 身長 155 cm、65 歳、体重 52 kg の女性の予測値は約 499 m
- この式は健康な人の距離のばらつきの約 40% しか説明できない。人種や国によって差があり、日本人向けの式もある
- この論文には 2020 年に訂正 (erratum) が出ている。使う前に訂正の内容を確認する

### 変化の大きさ
- 慢性呼吸器疾患では、**おおむね 25〜33 m** 以上の変化が臨床的に意味のある最小の変化 (MCID) とされる(一般的な知識。原著で確認していない)

### 酸素飽和度
- 歩いている間に **SpO₂ が 4% 以上下がる**、または **88〜90% 未満になる**ことを「労作時の低酸素血症(酸素飽和度の低下)」とすることが多い
- [[間質性肺炎]]、とくに特発性肺線維症では、**歩くと SpO₂ が大きく下がる**ことが多い。安静時の SpO₂ が正常でも下がることがあり、在宅酸素療法の検討に使う
- 歩いた後の脈拍の戻りが遅いことや、SpO₂ の低下が大きいことは、予後が悪いことと関係するとされる

この節の数値の目安(距離の範囲、SpO₂ の基準)は一般的な知識による。

## 使われる場面
| 病気 | 目的 |
| --- | --- |
| [[間質性肺炎]] | 重症度・予後の評価、労作時の低酸素血症の発見、在宅酸素療法の検討 |
| COPD | 重症度・予後(BODE 指数の一部)、呼吸リハビリテーションの効果判定 |
| 肺高血圧症 | 重症度・予後の評価、治療薬の臨床試験の評価項目 |
| 心不全 | 運動耐容能の評価 |
| 手術前 | 肺切除などの前の評価 |
