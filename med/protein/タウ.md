# タウ (tau protein)

## 概要
- 神経細胞の **軸索** に多い、微小管（細胞の骨組みになる管）にくっついて、それを安定させるタンパク質。微小管結合タンパク質（MAP）の 1 つ
- 遺伝子は **MAPT**（microtubule-associated protein tau）で、17 番染色体（17q21.31）にある
- ふつうは水に溶けて、微小管についたり離れたりしている。病気では、**リン酸がつきすぎて** 微小管から離れ、細胞の中で **線維** になって固まる
- タウが固まってたまる病気をまとめて **タウオパチー** とよぶ。アルツハイマー病・[[ピック病]]・進行性核上性麻痺・大脳皮質基底核変性症など
- 名前は、微小管を作る（重合させる）**因子**（tubulin-associated unit、または factor の τ）から。1975 年に、微小管の重合を助ける因子として見つかった（Murray Weingarten、Marc Kirschner〈アメリカ〉ら）

## 構造

### 6 つのアイソフォーム

1 つの遺伝子から、スプライシング（mRNA のつなぎ方）の違いで、成人の脳では **6 種類** ができる。長さは 352〜441 アミノ酸。

| 違いを生むところ | 何が変わるか | 名前 |
| --- | --- | --- |
| **エクソン 2・3** | N 末端側に 29 アミノ酸の挿入が 0・1・2 個 | **0N・1N・2N** |
| **エクソン 10** | 微小管に結合する繰り返し配列（約 31 アミノ酸）が 3 つか 4 つか | **3R・4R** |

- 組み合わせは 3（0N・1N・2N）× 2（3R・4R）＝ 6。いちばん長い **2N4R** が 441 アミノ酸で、アミノ酸の番号はふつうこれで数える
- ふつうの成人の脳では、**3R と 4R がほぼ 1：1**。胎児の脳では、いちばん短い 0N3R だけ
- エクソン 10 は、4 つの繰り返し（R1〜R4）のうち **R2** にあたる。エクソン 10 がないと R1・R3・R4 の 3 つになる
- 4R のほうが、微小管に強くくっつく

### 領域

| 領域 | 働き |
| --- | --- |
| N 末端の突出部 | 微小管から外に突き出る。細胞膜などとの相互作用 |
| プロリンに富む領域 | **リン酸化される場所が多い**。AT8 がつくのもここ |
| **微小管結合領域**（R1〜R4） | 微小管にくっつく。病気のときは、ここが **線維の芯** になる |
| C 末端 | |

- タウは、決まった形をとらない **天然変性タンパク質**。ふつうは、ほどけたひものような状態で、微小管につくときだけ形が決まる

## リン酸化タウ

### リン酸化とは
- タンパク質のセリン（Ser）・トレオニン（Thr）・チロシンに、**リン酸基** がつくこと。キナーゼ（リン酸化酵素）がつけ、ホスファターゼ（脱リン酸化酵素）がはずす
- タウには、リン酸がつきうる場所が **80 か所以上** ある。ふつうでも少しはついていて、リン酸の量で微小管へのつきやすさが調節されている
- タウをリン酸化する主な酵素：**GSK-3β**、**CDK5** など。はずす主な酵素：**PP2A**

### 過剰リン酸化
- 病気のタウは、ふつうの **数倍** のリン酸がついている（**過剰リン酸化**）
- リン酸は負の電荷をもつので、同じく負の電荷をもつ微小管から離れやすくなる。離れたタウは集まりやすくなり、やがて **線維** になる
- 微小管が不安定になり、軸索の中の物の運搬が滞る。線維そのもの、または線維になる前の小さな集まり（オリゴマー）が、神経細胞を傷つけると考えられている
- ただし、リン酸化が原因か、固まった結果かは、まだはっきりしない

### AT8 抗体
- **リン酸化されたタウ** だけにつき、ふつうのタウにはつかないモノクローナル抗体。病理でタウの病変を染めるときの **標準の抗体**
- つく場所（エピトープ）は、**Ser202 と Thr205** の両方にリン酸がついた部分（2N4R の番号）。周りの Ser199・Ser208 のリン酸化も結合に関わるとされる
- Thr205 のリン酸が、Gly207 と水素結合して、ペプチドの鎖を **曲げる**。この曲がった形を AT8 が認識する（Gandhi ら、2015 年）
- 3R・4R の区別なく、リン酸化タウならつく。アルツハイマー病の神経原線維変化も、ピック球も、4R タウの病変も染まる
- アルツハイマー病の病理の進み方を示す **Braak のステージ**（I〜VI）も、AT8 で染めて決める
- ほかのリン酸化タウ抗体：PHF-1（Ser396/Ser404）、AT100（Thr212/Ser214）、AT180（Thr231）など

### 血液・髄液の検査
- 髄液や血液の **リン酸化タウ** は、アルツハイマー病の目印（バイオマーカー）になる
  - **p-tau181**（Thr181 のリン酸化）：髄液の検査で長く使われてきた
  - **p-tau217**（Thr217 のリン酸化）：血液でも、アミロイドがたまっているかをよく反映する。アメリカでは、血液の p-tau217 とアミロイド β42 の比を測る検査が、2025 年に FDA に認められた
- これらは、アミロイドがたまったときに増えるタウで、**アルツハイマー病に特有**。ピック病や 4R タウの病気では、ふつう上がらない

## 3R タウと 4R タウ

### 見分け方
- **RD3** 抗体は 3R タウだけに、**RD4** 抗体は 4R タウだけにつく（Rohan de Silva〈イギリス〉ら、2003 年）。エクソン 10 の有無で変わる、R1 と R2・R3 のつなぎ目の配列を認識する
- 銀染色の **Gallyas 法** は、4R タウの病変をよく染め、3R タウのピック球は染めない

### 病気の分け方

| 種類 | 病気 |
| --- | --- |
| **3R タウオパチー** | **[[ピック病]]**（知られているなかで唯一） |
| **4R タウオパチー** | 進行性核上性麻痺（PSP）、大脳皮質基底核変性症（CBD）、嗜銀顆粒性認知症（AGD）、球状グリア封入体を伴うタウオパチー（GGT） |
| **3R＋4R タウオパチー** | **アルツハイマー病**、慢性外傷性脳症（CTE）、神経原線維変化型老年期認知症 |
| 遺伝性 | *MAPT* の変異。変異によって 3R・4R・両方のどれもありうる |

- *MAPT* の変異のなかには、エクソン 10 のスプライシングを変えて **4R の割合を増やす** ものがある。3R：4R の釣り合いがくずれるだけで病気になりうる
- 4R タウの病気は、神経細胞だけでなく **グリア細胞**（アストロサイト・オリゴデンドロサイト）にもタウがたまるのが特徴。PSP の房状アストロサイト、CBD のアストロサイト斑など

### 線維の形

**クライオ電子顕微鏡** で、病気ごとにタウの線維の芯の折りたたまれ方（フォールド）が違うことがわかった。

| 病気 | 年 | わかったこと |
| --- | --- | --- |
| アルツハイマー病 | 2017 年 | C 字の形をした芯が 2 本並ぶ（Anthony Fitzpatrick、Sjors Scheres、Michel Goedert〈イギリス〉ら） |
| ピック病 | 2018 年 | R1 の後半から R4 までが芯になる、**ピック フォールド**。アルツハイマー病と違う形（Benjamin Falcon ら） |
| CTE | 2019 年 | アルツハイマー病に似るが、真ん中にすきまがある |
| CBD・PSP など | 2020〜2021 年 | 4R タウでも、病気ごとにさらに違う形 |

- **同じタウでも、病気ごとに決まった形で固まる**。形の違いが、どの細胞・どの部位がやられるかの違いにつながると考えられている
- 固まったタウが、ふつうのタウを同じ形に変えて広がる（**シード**、プリオンに似たしくみ）という考えがある。これを利用して、試験管で増やして検出するのが RT-QuIC などの **シード増幅法**

### タウ PET
- タウの線維にくっつく薬を使って、生きているうちに脳のタウを画像にする
- **フロルタウシピル**（アメリカで 2020 年承認）などの第 1 世代の薬は、**アルツハイマー病のタウ**（3R＋4R の線維）によくつく。ピック病の 3R タウや、PSP・CBD の 4R タウには、つきにくい
- 4R タウにもつく薬（PI-2620、florzolotau〈PM-PBB3〉など）が開発されている
