# TDP-43 (TAR DNA-binding protein 43)

## 概要
- ふだんは **細胞の核** にいて、RNA や DNA にくっつき、**RNA のつなぎ方（スプライシング）** などを調節するタンパク質
- 遺伝子は **TARDBP** で、1 番染色体（1p36.22）にある。414 アミノ酸
- 病気では、**核からいなくなり、細胞質で固まってたまる**。これが、**ALS（筋萎縮性側索硬化症）の大部分** と、**タウがたまらない FTLD（前頭側頭葉変性症）の大部分** の病理
- 名前は、HIV の遺伝子の **TAR**（trans-activation response）という DNA の配列にくっつくタンパク質として見つかった、分子量 **43** kDa のタンパク質から（Shirley Ou〈アメリカ〉ら、1995 年）
- [[ピック病]]（3R [[タウ]]がたまる）では TDP-43 は陰性。FTLD を「タウか TDP-43 か」で分けるときの目印になる

## 構造

| 領域 | 働き |
| --- | --- |
| N 末端領域 | TDP-43 どうしが集まる（ふつうの働きに必要） |
| 核移行シグナル（NLS） | 核に入るための目印 |
| **RRM1・RRM2** | RNA にくっつく 2 つの部分（RNA 認識モチーフ）。UG の繰り返しの配列を好む |
| **C 末端領域** | グリシンが多く、決まった形をとらない（**プリオン様** の低複雑性領域）。ほかのタンパク質とくっつき、液滴をつくる。**ALS の遺伝子変異の大部分がここ** |

- C 末端の領域は、細胞の中で油の粒のように集まる **液－液相分離** を起こす。ストレスのときにできる「ストレス顆粒」にも入る。この集まりが固まって戻らなくなるのが、病気の始まりと考えられている

## ふつうの働き
- **スプライシングの調節**：とくに、ふつうは使われない **隠れたエクソン**（クリプティック エクソン）を、mRNA に入らないよう抑える
- 自分の mRNA の量も調節して、TDP-43 の量を一定に保つ（自己調節）
- mRNA の安定性、核から細胞質への運び出し、軸索での局所的なタンパク質合成にも関わる

## 病気でのしくみ

### 病理の特徴
- **核から消える**：ふつうは核が染まるが、病気の細胞では核が空になる
- **細胞質に固まる**：細胞質や神経突起に封入体ができる
- 固まった TDP-43 は、
  - **リン酸化** されている（とくに **Ser409/Ser410**。これを認識する抗体で染めると、病的な TDP-43 だけが染まる。長谷川成人〈日本〉ら、2008 年）
  - **ユビキチン化** されている
  - **切断** されて、C 末端側の 25 kDa・35 kDa の断片になっている

### 核から消えることの害（機能の喪失）
- 核に TDP-43 がないと、隠れたエクソンが mRNA に入ってしまい、**大事なタンパク質が作られなくなる**
- **STMN2**（スタスミン 2）：軸索の伸長と修復に要る。隠れたエクソンが入ると途中で止まった mRNA になり、STMN2 が減る
- **UNC13A**：神経伝達物質の放出に要る。隠れたエクソンが入ると減る。UNC13A の遺伝子の多型は、ALS・FTD のなりやすさに関わることが知られていた。その理由が、隠れたエクソンの入りやすさだとわかった（2022 年）
- 隠れたエクソンからできる異常なペプチドを、髄液で測って TDP-43 の病気の目印にしようとする研究がある

### 固まることの害（毒性の獲得）
- 細胞質の封入体や、固まる前の小さな集まりが、ほかのタンパク質や RNA を巻きこみ、細胞を傷つけると考えられている
- どちらがより大事かは、まだ議論がある。いまは **機能の喪失** を重視する見方が強い

## TDP-43 がたまる病気

| 病気 | TDP-43 の病理の割合 |
| --- | --- |
| **ALS**（筋萎縮性側索硬化症） | 孤発性の **約 97%**。*SOD1*・*FUS* の変異によるものは例外 |
| **FTLD-TDP** | FTLD の **約半数**（残りの多くは FTLD-タウ） |
| **LATE**（辺縁系優位型の加齢関連 TDP-43 脳症） | 高齢者で、海馬・扁桃体にたまる。アルツハイマー病に似た物忘れを起こす（Peter Nelson〈アメリカ〉ら、2019 年に提唱） |
| アルツハイマー病 | 一部で TDP-43 も一緒にたまり、物忘れが重くなる |
| 封入体筋炎 | 筋肉にたまる |

- ALS と FTLD-TDP は、同じ TDP-43 の病気の両端と考えられている。1 人に両方が起こることもある（ALS-FTD）
- TDP-43 の病気をまとめて **TDP-43 プロテイノパチー** とよぶ

### FTLD-TDP の型

封入体の形と、大脳皮質のどの層にあるかで分ける（Ian Mackenzie〈カナダ〉ら、2011 年に統一）。

| 型 | 病理 | 主な臨床像 | 主な遺伝子 |
| --- | --- | --- | --- |
| **A** | 三日月形・楕円形の細胞質の封入体と、短い変性神経突起。皮質の表層に多い | bvFTD、非流暢性失語 | **GRN**（プログラニュリン） |
| **B** | 細胞質の封入体が、皮質の全層に中くらい。突起の病変は少ない | bvFTD、**ALS を伴う FTD** | **C9orf72** |
| **C** | **長い変性神経突起** が表層に多い。封入体は少ない | **意味性認知症**、bvFTD | （ほぼ孤発性） |
| **D** | 短い変性神経突起と、レンズ形の **核内封入体** が多い | 封入体筋炎・骨パジェット病を伴う FTD | **VCP** |
| E | 細かい粒状の封入体が全層に。進行が速い | bvFTD、ALS | |

- 遺伝子と型の対応は、1 対 1 ではない（*C9orf72* では A と B が混ざることもある）

### 遺伝子
- **TARDBP** そのものの変異：家族性 ALS の数%。FTD はまれ
- **GRN**（プログラニュリン）：片方の遺伝子が働かなくなり、プログラニュリンが減る。FTLD-TDP A 型になる
- **C9orf72**：6 塩基（GGGGCC）の繰り返しが異常に長くなる。家族性の ALS・FTD でいちばん多い原因（2011 年に発見）
- **VCP**：D 型になる

## 治療の研究
- TDP-43 そのものを標的にした治療は、まだない
- STMN2 の隠れたエクソンを抑える **アンチセンス オリゴヌクレオチド** などで、失われた働きを補う研究がある
- *GRN* の変異では、プログラニュリンを増やす治療（遺伝子治療・抗体）の治験が行われている
