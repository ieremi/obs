# JCS (Japan Coma Scale)

## 概要
- **意識障害の深さ**を評価する、日本で作られた尺度
- まず**「目を開けているか(覚醒しているか)」**で大きく 3 つ(I・II・III 桁)に分け、それぞれを 3 段階に分ける。3 × 3 の 9 段階なので**「3-3-9 度方式」**ともいう
- **数字が大きいほど重い**([[GCS]] とは逆)
- 救急隊や病院で日本中で使われている。[[GCS]] より短時間で評価できる

## スケール
| 大分類 | 点数 | 状態 |
| --- | --- | --- |
| 0 | 0 | 意識清明 |
| **I 桁: 刺激しないでも覚醒している** | 1 | だいたい意識清明だが、今ひとつはっきりしない |
| | 2 | 見当識障害がある(時・場所・人がわからない) |
| | 3 | 自分の名前、生年月日が言えない |
| **II 桁: 刺激すると覚醒する(刺激をやめると眠り込む)** | 10 | 普通の呼びかけで容易に開眼する |
| | 20 | 大きな声、または体をゆさぶることで開眼する |
| | 30 | 痛み刺激を加えつつ呼びかけを繰り返すと、かろうじて開眼する |
| **III 桁: 刺激しても覚醒しない** | 100 | 痛み刺激に対して、払いのけるような動作をする |
| | 200 | 痛み刺激で少し手足を動かしたり、顔をしかめたりする |
| | 300 | 痛み刺激に反応しない |

### 付け加える記号
| 記号 | 意味 |
| --- | --- |
| R | 不穏 (restlessness) |
| I | 失禁 (incontinence) |
| A | 無動性無言・失外套状態 (akinetic mutism、apallic state) |

- 例: 「JCS 20-R」「JCS III-200」「JCS 3-I」
- II 桁で、開眼できない理由がある(まぶたの腫れなど)ときは、言葉や動作で判断する(一般的な知識)

## 使い方のコツ
1. まず**目を開けているか**を見る → 開けていれば I 桁
2. 開けていなければ、呼びかけ → 体をゆする → 痛み刺激の順に試して、開眼すれば II 桁
3. 痛み刺激でも開眼しなければ III 桁で、手足の反応を見る
- I 桁と II 桁の境目(刺激で開眼するか)が、とくに重要

## GCS との比較
| | JCS | [[GCS]] |
| --- | --- | --- |
| 作られた国 | 日本(1974 年ごろ) | 英国(1974 年) |
| 数字の向き | **大きいほど重い**(0〜300) | **小さいほど重い**(3〜15) |
| 評価の軸 | 覚醒(開眼)が中心の 1 つの軸 | 開眼・言語・運動の 3 つの軸 |
| 長所 | 速く簡単。軽い意識障害(I 桁)を細かく分けられる | 国際的に使われる。重い意識障害を細かく分けられる。予後との関係が研究されている |
| 短所 | 国際的には通じない。気管挿管中などで評価が難しい | 3 つの合計にすると情報が減る。軽い意識障害は分けにくい |

## 内的妥当性と外的妥当性
内的・外的妥当性はもともと研究デザインの用語。ここでは尺度に当てはめて、次のように分けて考える。

- **内的妥当性**：尺度の中身が、測りたいもの(意識障害の深さ)を正しく、ぶれなく測れているか
- **外的妥当性**：尺度の外にある基準(ほかの尺度や予後)と結びつくか。ほかの集団や場面にも当てはめられるか

### 内的妥当性
**強み**
- 「開眼するか」「どの刺激で開眼するか」という 1 本の軸に絞っている。そのため手順が単純で、**覚醒の程度**はよく反映する

**弱み**
- **1 本の軸に別の性質が混ざっている**。I 桁は見当識や名前が言えるかといった**認知の内容**を見る。II・III 桁は**覚醒**と痛み刺激への反応を見る
- **数字は順序だけを表す**。JCS 20 は JCS 10 の 2 倍重いわけではない。そのため平均や差をとる計算には向かない
- **言語と運動の情報が少ない**。開眼以外は、I 桁の言語と III 桁の運動しか見ない
- **開眼や発語ができない理由があると評価がゆがむ**。まぶたの腫れ・顔面外傷・失語・気管挿管・鎮静などが当てはまる
- **評価者間信頼性の研究がほとんどない**。大規模研究の著者自身も、限界としてそう書いている(Shigematsu 2013、Yumoto 2019)。とくに I-1「今ひとつはっきりしない」は基準があいまいで、評価者によって判断が分かれやすい

### 外的妥当性
**ほかの尺度との一致(基準関連妥当性)**

| 比較相手 | 結果 | 文献 |
| --- | --- | --- |
| [[GCS]] | 変換表で GCS の区分と完全に一致したのは 80.3%、1 区分のずれまで許すと 93.2%(検証コホート 821 人) | Nakajima 2023 |
| CRS-R | 順位相関 ρ = −0.82(59 人) | Kitano 2024 |
| 来院時 [[GCS]](小児) | 病院前 JCS との相関 r = −0.745(1,562 人) | Yagi 2013 |

JCS は大きいほど重く、GCS と CRS-R は小さいほど重いので、相関は負になる。

予後の予測力は GCS とほぼ同じ。しかも**桁(0・I・II・III)だけの 4 段階でも、予測力はあまり落ちない**。

**当てはめられる範囲(一般化可能性)**
- 根拠となるデータは**ほぼすべて日本のもの**。評価者も JCS に慣れている。海外の集団や JCS に不慣れな評価者でも同じ性能が出るかは、わかっていない
- 多くは登録データを後ろ向きに解析したもの。たとえば外傷の研究では JCS の欠測が 22.3% あった(Yumoto 2019)
- 言葉が十分でない乳幼児には、成人用の I 桁をそのまま使えない。そのため乳幼児用の JCS が別に使われている(一般的な知識)

### まとめ
- **外的妥当性(予後の予測)は大規模データで裏づけられていて、GCS と同等**
- **内的妥当性には弱みがある**。とくに評価者間信頼性の検証が足りないことと、I 桁のあいまいさ
- 国際比較や研究では GCS への変換が必要になることがある

## 名前の由来
- 1974 年ごろに、太田富雄らが中心になって作った。当初は「3-3-9 度方式」と呼ばれ、のちに Japan Coma Scale と呼ばれるようになった(一般的な知識)
- coma(昏睡)は、ギリシア語 κῶμα (kôma)「深い眠り」から

この項目の由来と使い方のコツは一般的な知識による。
