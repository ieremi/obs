# 修正ボルグスケール (modified Borg scale)

## 概要
- **息切れ(呼吸困難)や疲労の強さ**を、本人が 0〜10 の数字で答える尺度
- 数字の横に「弱い」「強い」などの言葉が付いていて、言葉を見て選べるようにしてある
- [[6分間歩行試験]]の前後、運動負荷試験、呼吸リハビリテーションなどで使う
- スウェーデンの心理学者**グンナー・ボルグ (Gunnar Borg)** が作った **CR10 スケール**(category-ratio scale、10 段階)がもと。呼吸困難の評価用に言葉を少し変えたものを「修正ボルグスケール」と呼ぶ

## スケール
| 点数 | 程度 | 英語 |
| --- | --- | --- |
| 0 | まったくない | Nothing at all |
| 0.5 | 非常に非常に弱い(やっと感じる) | Very, very slight (just noticeable) |
| 1 | 非常に弱い | Very slight |
| 2 | 弱い | Slight |
| 3 | 中くらい | Moderate |
| 4 | やや強い | Somewhat severe |
| 5 | 強い | Severe |
| 6 | | |
| 7 | 非常に強い | Very severe |
| 8 | | |
| 9 | 非常に非常に強い(ほぼ最大) | Very, very severe (almost maximal) |
| 10 | 最大 | Maximal |

- 6・8 のように言葉のない数字も選べる。10 を超えると思えば 11、12 のように答えてもよい(CR10 の考え方、一般的な知識)
- 「息切れ」と「足の疲れ」を別々に聞くことが多い

## 使い方
1. 表を見せて、「今の息苦しさはどのくらいですか」と聞く
2. **検査の前と後**に同じ聞き方で聞く
3. 点数そのものより、**運動による変化**や、治療前後の比較に使う

## もう 1 つのボルグスケール(RPE)
| | CR10(修正ボルグスケール) | RPE スケール |
| --- | --- | --- |
| 範囲 | 0〜10 | 6〜20 |
| 評価するもの | 息切れ・痛みなど、特定の感覚の強さ | 全身の運動のきつさ(主観的運動強度) |
| 特徴 | 比の性質をもつ(2 は 1 の 2 倍くらい) | 6〜20 に 10 をかけると、健康な若い人の心拍数に近くなるように作られた |
| 主な使い方 | 呼吸困難の評価 | 運動処方、心臓リハビリテーション |

## 名前の由来
- ボルグは人名(Gunnar Borg、1927〜2020)
- CR は **category-ratio**(カテゴリーと比)の略。言葉のカテゴリーで選べ、数字どうしの比にも意味があるように作られている

この項目のうち、スケールの言葉以外(RPE、CR10 の考え方)は一般的な知識による。
