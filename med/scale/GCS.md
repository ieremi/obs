# GCS (Glasgow Coma Scale)

## 概要
- **意識障害の深さ**を、**開眼 (E)・言語 (V)・運動 (M)** の 3 つの反応で評価する尺度
- 1974 年に英国グラスゴー大学のティーズデールとジェネット (Teasdale & Jennett) が発表した。世界中で使われている
- 合計は **3〜15 点**で、**点数が小さいほど重い**([[JCS]] とは逆)
- 合計だけでなく、**「E3V4M6」のように 3 つを分けて書く**のが勧められている

## スケール
### E: 開眼 (Eye opening)
| 点数 | 反応 |
| --- | --- |
| 4 | 自発的に開眼する |
| 3 | 呼びかけで開眼する |
| 2 | 痛み(圧迫)刺激で開眼する |
| 1 | 開眼しない |

### V: 言語による最良の反応 (best Verbal response)
| 点数 | 反応 |
| --- | --- |
| 5 | 見当識がある(時・場所・人が正しく言える) |
| 4 | 混乱した会話 |
| 3 | 不適切な言葉(単語は出るが会話にならない) |
| 2 | 意味のない発声(うめき声など) |
| 1 | 発声がない |

### M: 運動による最良の反応 (best Motor response)
| 点数 | 反応 |
| --- | --- |
| 6 | 命令に従う |
| 5 | 痛み刺激の場所に手を持っていく(払いのける、局在がわかる) |
| 4 | 痛み刺激で手足を引っ込める(正常な屈曲、逃避) |
| 3 | 痛み刺激で腕を異常に曲げる(**除皮質硬直**) |
| 2 | 痛み刺激で手足を伸ばす(**除脳硬直**) |
| 1 | まったく動かない |

- 左右で違うときは、**よいほうの反応**をとる
- 気管挿管中などで話せないときは V を「T」(tube)、目が腫れて開かないときは E を「C」(closed)とし、点数を付けない(一般的な知識)

## 重症度の目安
| 合計点 | 重症度(頭部外傷) |
| --- | --- |
| 13〜15 | 軽症 |
| 9〜12 | 中等症 |
| 3〜8 | **重症** |

- **8 点以下**は昏睡とされ、舌が落ち込んで気道がふさがりやすく、自分で気道を守れないことが多い。**気管挿管を考える目安**の一つ(「GCS 8 なら挿管」と覚えることがある)
- 意識清明は E4V5M6 = 15 点

重症度の区切りと挿管の目安は一般的な知識による。

## 評価のコツ
1. まず声をかけ、次に痛み刺激(爪の付け根や、眼の上のくぼみを押すなど)を与える
2. 3 つそれぞれで**いちばんよい反応**をとる
3. 3 つの中で **M(運動)がいちばん予後と関係する**とされる(一般的な知識)
4. 時間を追って、同じやり方で繰り返し評価し、**変化**(とくに 2 点以上の低下)を見逃さない

## 名前の由来
- 英国スコットランドの**グラスゴー**大学(サザン総合病院の脳神経外科)で作られたことから
- coma(昏睡)は、ギリシア語 κῶμα (kôma)「深い眠り」から

## 出典
- Teasdale G, Jennett B. Assessment of coma and impaired consciousness. A practical scale. Lancet. 1974;304(7872):81-84. [doi:10.1016/S0140-6736(74)91639-0](https://doi.org/10.1016/S0140-6736(74)91639-0)
  - 最初の発表では運動の項目は 5 段階で、のちに「異常屈曲」が加わって現在の 6 段階になった(一般的な知識)
