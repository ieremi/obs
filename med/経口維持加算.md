# 経口維持加算

**摂食機能障害があり、誤嚥が認められる入所者が、口から食事を続けられるよう、多職種で食事の観察・会議・計画的な栄養管理を行うことを評価する加算。** このページは介護医療院の入所サービスについてまとめる。

## 単位数とⅠ・Ⅱの違い

| 区分 | 単位数 | 内容 |
| --- | --- | --- |
| Ⅰ | 400単位／月 | 多職種による食事観察・会議、経口維持計画、指示に基づく栄養管理 |
| Ⅱ | 100単位／月 | Ⅰの算定に加え、協力歯科医療機関を定め、所定の専門職が食事観察・会議等に参加 |

**ⅡはⅠに上乗せするため、両方の要件を満たす場合は合計500単位／月。** 1単位10円の地域では総額5,000円、1割負担の利用者の負担は500円となる。換算方法は[[介護報酬の単位]]を参照。

根拠：[報酬告示・別表4「カ 経口維持加算」](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)。

## 対象者

- 現に口から食事を摂っている。
- 摂食機能障害がある。
- 誤嚥が認められる。

食形態を刻み食・ミキサー食等に変更したことだけで算定するものではない。対象となる障害・誤嚥の評価と、計画に基づく特別な管理が必要となる。

## 算定要件

### Ⅰ

1. 医師または歯科医師の指示を受ける。
2. 医師・歯科医師・管理栄養士・看護職員・言語聴覚士・介護支援専門員等が共同して、**月1回以上、食事の観察と会議等**を行う。
3. 継続的に経口摂取を進めるため、個別の**経口維持計画**を作成し、必要に応じて見直す。
4. 計画の作成・見直し時は、本人または家族に説明し同意を得る。
5. 計画に従い、医師または歯科医師の指示を受けた管理栄養士・栄養士が栄養管理を行う。歯科医師から指示を受ける場合は、その管理栄養士等が医師の指導を受けていることが条件。
6. 摂食・嚥下機能の適切な評価、誤嚥等が起きた場合の管理体制、食形態等への配慮、多職種で実施する体制を整える。
7. 所定の定員・人員等の基準を満たす。

ここに挙げた職種名は多職種連携の構成を示すものであり、すべての会議に列挙した全職種が必ず出席するという意味ではない。実際の関与・参加者と検討内容を記録する。

### Ⅱ

Ⅰを算定し、次の両方を満たす。

- 協力歯科医療機関を定めている。
- 食事の観察・会議等に、**施設の配置医師以外の医師、歯科医師、歯科衛生士、言語聴覚士のいずれか**が加わる。

歯科医療機関と契約していることだけでは足りず、実際の参加を確認できる記録が必要。

根拠：[報酬告示](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)、[大臣基準告示第67号](https://www.mhlw.go.jp/web/t_doc?dataId=82ab4584&dataType=0&pageNo=3)、[実施上の留意事項・2024年改正資料](https://www.mhlw.go.jp/content/12300000/001227894.pdf)。

## 会議と食事観察

**月1回以上の食事観察・会議等**で、本人の状態と支援方法を確認し、計画に反映する。会議を開いたことだけでなく、食事観察に基づく個別の管理内容が分かるようにする。

次は検討事項の例であり、全国共通の必須議題一覧ではない。

| 確認すること | 検討例 |
| --- | --- |
| 摂食・嚥下の状態 | むせ、湿性嗄声、口腔内残留、疲労、食事にかかる時間 |
| 食事・水分の摂取 | 摂取量、食形態、とろみ、本人の好み、体重・栄養状態の変化 |
| 食べる環境・介助 | 姿勢、食具、一口量、介助方法、食事のペース |
| 安全管理 | 誤嚥・窒息等が疑われる場合の対応、医師等への連絡方法 |
| 支援の評価 | 前回の対応の効果、変更する支援、担当者、次回評価 |

## 必要な書類・記録

### 食事観察記録の記載項目に法令の指定はあるか

**食事観察・会議等を行う算定上の根拠はあるが、独立した「食事観察記録」の様式や、全員に一律に記載する観察項目が法令で定められているわけではない。** 根拠の性質を次のように区別する。

| 根拠 | 求める内容 |
| --- | --- |
| 報酬告示（平成12年厚生省告示第21号・別表4カ） | 多職種による食事観察・会議等、個別の経口維持計画、計画に従った栄養管理 |
| 実施上の留意事項通知（老企第40号） | 月1回以上の食事観察・会議等、計画の作成・必要に応じた見直し、本人または家族への説明・同意 |
| 厚生労働省の様式例 | 「栄養ケア・経口移行・経口維持計画書（施設）」等、計画・評価を記載するための参考様式 |

上の「会議と食事観察」に挙げた**むせ・湿性嗄声・食事時間・姿勢等は観察項目の例であり、すべてが法令で一律に指定された必須記載項目ではない。** 対象者の課題や計画に応じて観察する。

記録では、**いつ・誰が・何を観察し、その結果どのような栄養管理や計画の見直しにつながったか**を確認できるようにする。これは要件を確認できる記録にするための実務上の整理であり、この表現自体が告示の定型文という意味ではない。

独立した別紙の「食事観察記録」を必ず作成するという意味ではなく、計画書・会議録・日常の介護記録等と合わせて、観察と検討・支援の経過を確認できるようにする。指定権者が示す運用や提出様式がある場合は、それも確認する。

根拠：[報酬告示・別表4カ](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)、[実施上の留意事項通知](https://www.mhlw.go.jp/web/t_doc?dataId=00ta4383&dataType=1)、[厚生労働省：通知・様式例の掲載ページ（別紙様式4－1－1・4－1－2）](https://www.mhlw.go.jp/stf/newpage_38790.html)。

### 整備する書類・記録

| 書類・記録 | 残す内容・時期 |
| --- | --- |
| 対象者の評価 | 摂食機能障害・誤嚥の状況、評価日・評価者、判断の根拠 |
| 医師・歯科医師の指示 | 指示者、日付、栄養管理や支援の内容。歯科医師の指示では医師の指導との関係も確認 |
| 経口維持計画 | 課題、目標、特別な管理方法、職種別の役割、評価・見直しの内容 |
| 説明・同意の記録 | 計画の作成・変更時の説明日、説明相手、同意内容 |
| 食事観察記録 | 実施日、観察者、食事・嚥下・介助の状態、対応と結果 |
| 会議録 | 開催日、参加者の氏名・職種・所属、観察結果、検討・決定内容、計画への反映 |
| 栄養管理・支援の記録 | 計画に沿った実施内容、摂取状況、経過、再評価 |
| Ⅱの追加要件の根拠 | 協力歯科医療機関の情報と、所定の専門職が参加した事実・助言内容 |

「会議録」「食事観察記録」等は内容を示す名称。必要事項を満たすなら、計画書等に記録をまとめる方法も考えられる。専用の書類を増やすこと自体が要件ではない。

厚生労働省は[経口移行・経口維持計画の様式例](https://www.mhlw.go.jp/stf/newpage_38790.html)を公表している。実際の運用では、[改定通知・様式掲載ページ](https://www.mhlw.go.jp/stf/newpage_38294.html)で現行の様式・必要項目を確認する。

## 算定できない場合・関連加算との関係

- **経口移行加算との併算定は不可。** 経管栄養から経口摂取への移行を評価する経口移行加算とは対象・目的が異なる。
- 栄養管理の基準を満たさず、該当する減算を算定している場合は不可。
- Ⅱだけを単独で算定することはできない。
- 特別介護医療院サービス費・ユニット型特別介護医療院サービス費では適用除外となる。

根拠：[報酬告示・別表4の注16およびカの注](https://www.mhlw.go.jp/web/t_doc?dataId=82aa0255&dataType=0&pageNo=2)。
