# 介護報酬の単位

**介護報酬の「単位」は、介護サービスの費用を計算するための点数。** サービスの種類や内容、要介護度、加算・減算などに応じて単位数が決まり、それを円に換算する。

$$
\text{サービス費用}=\text{単位数}\times\text{1単位当たりの単価}
$$

1単位は10円が基本だが、人件費の地域差を反映し、**事業所・施設の所在地とサービスの種類**によって単価が異なる。[大阪府：介護報酬の地域加算](https://www.pref.osaka.lg.jp/o090090/kaigoshien/kaigo/chiikikasan.html)

## 「日・月・回」の意味

| 表記 | 計算方法 |
| --- | --- |
| 30単位／日 | 算定要件を満たす日数 × 30単位 |
| 100単位／月 | 月の算定要件を満たせば100単位 |
| 20単位／回 | 算定対象となる回数 × 20単位 |
| 所定単位数の6.2％ | 対象となる単位数 × 6.2％ |

「月1回まで」「入所後7日まで」などの制限があれば、その範囲で数える。入所日数や実施回数のすべてが、そのまま算定対象になるとは限らない。

## 計算例

**30単位／日の加算を30日間算定し、1単位10円の場合**を考える。

$$
30\times30=900\text{単位}
$$

$$
900\times10=9,000\text{円}
$$

この9,000円は、加算に対応するサービス費用の総額。利用者の負担割合によって、保険給付と自己負担に分かれる。

| 利用者の負担割合 | 自己負担 | 保険給付 |
| --- | --- | --- |
| 1割 | 900円 | 8,100円 |
| 2割 | 1,800円 | 7,200円 |
| 3割 | 2,700円 | 6,300円 |

施設サービスでは、このほかに食費・居住費・日常生活費などがかかる。[東広島市：サービスの費用と利用の目安](https://www.city.higashihiroshima.lg.jp/soshiki/kenkofukushi/1/kaigohokennsiminnnokata/21673.html)

## 介護医療院の1単位の単価

2024～2026年度の地域区分では次のとおり。同じ単位数でも、施設の所在地によって換算後の金額が変わる。

| 地域区分 | 1単位当たり |
| --- | --- |
| 1級地 | 10.90円 |
| 2級地 | 10.72円 |
| 3級地 | 10.68円 |
| 4級地 | 10.54円 |
| 5級地 | 10.45円 |
| 6級地 | 10.27円 |
| 7級地 | 10.14円 |
| その他 | 10.00円 |

出典：[東京都福祉局：地域区分・サービス種類ごとの1単位の単価](https://www.fukushi.metro.tokyo.lg.jp/kourei/hoken/kaigo_lib/tuutitou/0_kyoutuu)。この表は介護医療院サービスの単価であり、訪問介護など別のサービスでは単価が異なる。

実際の請求では、月の単位数の集計方法、割合加算、端数処理などの規定に従って計算する。
