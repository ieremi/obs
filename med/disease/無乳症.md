# 無乳症

**無乳症（むにゅうしょう、agalactia）は、乳汁を分泌できない状態。** 乳房の大きさではなく、乳汁を作り出す機能についての言葉である。獣医学でも使われる。[Merck Veterinary Manual：乳房の生理的障害](https://www.merckvetmanual.com/reproductive-system/udder-diseases-in-cows/physiologic-disorders-of-the-udder-in-cows)

## 名前の由来

ギリシア語の「乳がない」という意味の語に由来する。

| 部分 | 意味 |
| --- | --- |
| *a-* | ない、欠けている |
| *galakt-* | 乳 |
| *-ia* | 状態を表す語尾 |

*agalactia* は状態の名前。細菌の種小名として使われる *agalactiae* は「無乳症の」を表す名詞の属格である。[LPSN：Streptococcus agalactiae](https://lpsn.dsmz.de/species/streptococcus-agalactiae)

## B群レンサ球菌との関係

*Streptococcus agalactiae* は、ヒトでは **B群レンサ球菌（GBS）**として知られる。一方、牛では乳房炎の原因となり、乳量の低下や乳質の悪化を起こす。

「無乳症の」という種小名と、牛の乳汁産生を障害する性質を結びつけると覚えやすい。菌名は歴史的な由来を持つもので、感染したヒトが必ず無乳症になるという意味ではない。[コーネル大学：Streptococcus agalactiae](https://www.vet.cornell.edu/animal-health-diagnostic-center/testing/testing-protocols-interpretations/streptococcus-agalactiae-strep-ag)

## 言葉を分ける

| 用語 | 指しているもの |
| --- | --- |
| 無乳症 | 乳汁を分泌できない状態 |
| 乳量の低下 | 乳汁の量が減ること。完全に出ない状態とは限らない |
| 乳房炎 | 乳房・乳腺の炎症。乳汁産生に影響することがある |
| GBS感染症 | B群レンサ球菌による感染症。感染部位や患者背景で病型が異なる |

無乳症という言葉だけで原因は決まらない。獣医学では、内分泌の問題や乳腺の局所的な問題なども原因となる。[Merck Veterinary Manual](https://www.merckvetmanual.com/reproductive-system/udder-diseases-in-cows/physiologic-disorders-of-the-udder-in-cows)
