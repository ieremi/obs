# クローヌス

## 概要
- **筋を急に伸ばしたとき、筋が勝手に、リズミカルに縮んだりゆるんだりをくり返す** 現象。神経の診察でみる所見
- 典型は **足クローヌス**：足首を急に上へ曲げる（背屈）と、足首がガクガクと上下に動き続ける
- 速さは **1 秒に 5〜8 回**（5〜8 Hz）ほど。頸髄損傷の人のふくらはぎ（ヒラメ筋）では平均 5.4 Hz（4.5〜7.0 Hz）だった。1 分以上続くこともある
- 筋を伸ばす刺激のほか、皮膚への刺激や、末梢神経への電気刺激でも起こる
- 脳や脊髄から下りてくる運動の経路（**上位運動ニューロン**、錐体路）の障害を示す。**痙縮**（筋のつっぱり）といっしょにみられることが多い

## 語源
- 古代ギリシャ語の **κλόνος**（klónos）から。意味は「**激しく入り乱れた動き、混乱**」
- Merriam-Webster は、ギリシャ語での意味を「混乱した群衆、（戦場で兵士たちが）押し合うこと、（腸の）ごろごろした動き」としている。体の中の騒がしい動きにも使われた語
- 英語へは **近代ラテン語**（学術用のラテン語）の clonus を通して入った。英語で使われた最初の例は、Merriam-Webster では **1817 年**、Dictionary.com では 1810〜20 年ごろ
- κλόνος そのものの語源ははっきりしない。「動かす」という意味のインド・ヨーロッパ祖語の語根と結びつける説がある一方、Beekes の『ギリシャ語語源辞典』はこれに懐疑的で、ギリシャ語以前の言語から入った語と考えている

### 同じ語をふくむ用語

| 用語 | 組み立て | 意味 |
| --- | --- | --- |
| clonic（**間代性**） | clonus ＋ -ic | クローヌスのような、ガクガクとくり返す |
| **myoclonus**（ミオクローヌス） | myo-（筋）＋ clonus | 筋が一瞬ピクッと動く |
| tonic-clonic（**強直間代**） | tonic（緊張した）＋ clonic | 体が突っぱったあと、ガクガクとくり返すけいれん |

- 日本語の「**間代**」は clonic の訳語。縮むことと、ゆるむことが、間を置いて交代する様子を表すと考えられる

## 調べ方

| 部位 | やり方 |
| --- | --- |
| **足（足関節）** | 膝を軽く曲げて力を抜いてもらい、足の裏を押して **足首を急に上へ曲げ**、そのまま押し続ける。ふくらはぎの筋（腓腹筋）が伸ばされる |
| **膝蓋（膝のお皿）** | 膝を伸ばした状態で、膝のお皿を **つま先の方へ急に押し下げ**、そのまま押し続ける。太ももの前の筋（大腿四頭筋）が伸ばされる |
| そのほか | 手首、上腕二頭筋など |

### 異常かどうか
- 数回で止まるもの（**一過性**、非持続性）と、押しているあいだずっと続くもの（**持続性**）を分ける。厚労省のセロトニン症候群のマニュアルにある Hegerl らの評価表でも、腱反射亢進の「中等度」を一過性のクローヌス、「重度」を持続性のクローヌスとしている
- **持続性のクローヌスは異常**。一過性のものは、緊張している人や反射が強めの人など、健康な人にもみられることがある
- 何回以上を持続性とするかは、資料によってちがう
- **左右差** があるときは、片側の脳や脊髄の病気を疑う手がかりになる

1. 筋が急に伸ばされると、筋の中のセンサー（**筋紡錘**）が感じ、Ia 線維で脊髄へ伝える
2. 脊髄で **α 運動ニューロン** が興奮し、その筋が縮む（**伸張反射**。膝蓋腱反射と同じ反射）
3. 縮んだあとゆるむと、押し続けている手のせいで、筋がまた伸ばされる
4. ふつうは、脳から下りてくる **上位運動ニューロン** が反射をおさえているので、1 回で止まる。これが障害されると、おさえが弱まり、輪が何度もくり返す

ただし、上の図のような「反射の輪」だけでは説明しきれない。説明は 2 つあり、いまは **両方が関わる** と考えられている。

- **末梢の説（伸張反射がくり返す）**：筋が伸びるたびに伸張反射が起こり、それがくり返す。頸髄損傷の研究では、**反射の経路が長い（脚が長い）人ほどクローヌスが遅かった**。これは反射の輪が関わっていることを示す
- **中枢の説**：脊髄の中の仕組みがリズムを決めている。Dimitrijevic ら（1980）は、運動ニューロンが 1 回発火するたびに、しばらく反応できない時期（不応期）があり、興奮しやすさが戻るまで次の発火が起こらないことを示した。外から刺激のリズムを変えても、クローヌスの速さは変わらなかった
- 頸髄損傷の研究では、片側のふくらはぎの筋だけが働くとクローヌスは長く続き（40 秒超）、反対側の筋なども働くと短く終わった（5 秒未満）。脊髄の中の回路のはたらき方で、続くかどうかが変わる

## 原因

### 上位運動ニューロンの障害
- **脳卒中**
- **脊髄の障害**（けが、頸椎症性脊髄症などの圧迫）
- **多発性硬化症**
- **脳性まひ**
- 筋萎縮性側索硬化症（ALS）、脳腫瘍など

いっしょにみられる所見：**腱反射の亢進**、**痙縮**、**バビンスキー反射**（足の裏をこすると親指が上へ反る）。

### そのほか
- **[[セロトニン症候群]]**（下）
- **重い妊娠高血圧腎症**：反射の亢進やクローヌスは、子癇（けいれん発作）が近いサインとされる。けいれんの予防に [[硫酸マグネシウム]] を使う

## セロトニン症候群とクローヌス

[[セロトニン症候群]] は、セロトニンに作用する薬（SSRI の [[パロキセチン]] など）で起こる副作用。クローヌスはその診断の中心になる所見で、**Hunter 基準の 5 項目のうち 4 項目にクローヌスが入っている**。診断基準や治療は [[セロトニン症候群]] のノートにまとめた。

Hunter 基準に出てくるクローヌスは 3 種類。

| クローヌスの種類 | 内容 |
| --- | --- |
| **誘発性クローヌス** | 足首を曲げるなど、筋を伸ばすと出る |
| **眼球のクローヌス** | 目が勝手に、くり返し動く |
| **自発性のクローヌス** | 何もしなくても出る |

- 悪性症候群と比べると、反射亢進とミオクローヌスはセロトニン症候群に多く（55%・57%）、悪性症候群ではまれ。区別の手がかりになる

## 似ている動き

| 動き | 特徴 | 原因の場所 |
| --- | --- | --- |
| **クローヌス** | 筋を伸ばすと出る。リズミカルにくり返す。動きが大きい | 上位運動ニューロン |
| **ミオクローヌス** | 電気が走ったような、**一瞬のピクッ** とした動き。筋を伸ばさなくても出る | 脳・脊髄のいろいろな場所 |
| **振戦** | ふるえ。じっとしているときや、動かすときに出る | 小脳、大脳基底核など |
| **線維束性収縮** | 筋の一部が小さく、勝手にピクピクする。手足は動かない | **下位運動ニューロン**（脊髄から筋へ行く神経） |
