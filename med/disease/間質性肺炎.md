# 間質性肺炎 (interstitial pneumonia)

## 概要
- 肺の**間質**(肺胞の壁とそのまわりの支持組織)に炎症や線維化が起こる病気の総称。**間質性肺疾患 (ILD)** ともいう
- 肺胞の壁が厚く硬くなるので、**酸素が血液に移りにくくなり**、肺も膨らみにくくなる
- 主な症状は、**乾いた咳**と、**動いたときの息切れ**
- 原因は、膠原病、薬剤、吸い込んだ物質(粉じん・カビ・鳥など)、原因不明(特発性)などさまざま
- 薬の重大な副作用として、とても多くの添付文書に書かれている(下の「薬剤性間質性肺炎」を参照)

## 名前の由来
| 語 | 由来 | 意味 |
| --- | --- | --- |
| 間質 (interstitium) | ラテン語 *inter*「間に」+ *sistere*「立つ、置く」 | 間に置かれたもの(臓器の実質のすき間を埋める組織) |
| 肺炎 (pneumonia) | ギリシア語 πνεύμων (pneúmōn)「肺」。πνεῦμα (pneûma)「息、空気」から | 肺の病気 |

- ふつうの細菌性肺炎は、肺胞の**中**(肺胞腔)に膿や液がたまる(**実質**の炎症)。間質性肺炎は、肺胞の**壁**(間質)が主な場所になる

名前の由来は一般的な知識による。

## 分類
| 分類 | 主な病気・原因 |
| --- | --- |
| **特発性間質性肺炎** (IIPs、原因不明) | **特発性肺線維症 (IPF)**、非特異性間質性肺炎 (NSIP)、特発性器質化肺炎 (COP) など |
| 膠原病に伴うもの | 関節リウマチ、全身性強皮症、皮膚筋炎・多発性筋炎(とくに抗 MDA5 抗体陽性)、シェーグレン症候群 |
| **薬剤性** | 抗がん薬、抗不整脈薬、抗リウマチ薬、抗菌薬、NSAIDs、漢方薬など(下記) |
| 吸入によるもの | **過敏性肺炎**(鳥、カビ、夏型過敏性肺炎のトリコスポロン)、じん肺(石綿、ケイ酸) |
| その他 | サルコイドーシス、放射線肺炎 |

- 特発性のうち最も多く、予後が悪いのが**特発性肺線維症 (IPF)**。高齢の男性・喫煙者に多い

## 症状と身体所見
- 乾いた咳(痰が少ない)
- 動いたときの息切れ。進むと安静時にも息苦しくなる
- **捻髪音 (fine crackles)**: 吸気の終わりに背中の下の方で聞こえる、マジックテープをはがすような「パリパリ」という音
- **ばち指**: 指先が太鼓のばちのように丸くふくらむ(IPF に多い)
- 急に悪くなる(急性増悪)と、発熱・強い呼吸困難・低酸素血症が起こる

## 検査
### 画像
- **胸部 HRCT**(高分解能 CT)が最も大切

| パターン | 所見 | 代表的な病気 |
| --- | --- | --- |
| UIP パターン | 胸膜の直下・肺の下の方に強い網状影、**蜂巣肺**(小さな嚢胞が蜂の巣のように並ぶ)、牽引性気管支拡張 | 特発性肺線維症、関節リウマチ |
| NSIP パターン | 下の方に強いすりガラス影、胸膜直下が保たれることがある | 膠原病、薬剤性 |
| OP パターン | 斑状の浸潤影、逆ハローサイン | 特発性器質化肺炎、薬剤性、膠原病 |
| 過敏性肺炎 | 小葉中心性の粒状影、モザイクパターン、呼気でのエアトラッピング | 過敏性肺炎 |

### 血液検査
- **KL-6**、**SP-D**、SP-A: 傷ついた肺胞上皮(II 型肺胞上皮細胞)から出る物質。間質性肺炎で上がり、病気の活動性の目安になる。KL-6 は日本で開発され、日本ではよく測られる(一般的な知識)
- 膠原病の自己抗体(抗核抗体、リウマトイド因子、抗 ARS 抗体、抗 MDA5 抗体など)

### 呼吸機能と酸素
- **拘束性換気障害**: 肺活量 (VC)、全肺気量 (TLC) が減る
- **拡散能 (DLco) の低下**: 早くから下がる
- 6 分間歩行試験で、歩くと酸素飽和度 (SpO₂) が下がる

### その他
- 気管支肺胞洗浄 (BAL): 感染症や、リンパ球・好酸球の増加(過敏性肺炎、薬剤性、器質化肺炎)をみる
- 肺生検: 診断がつかないとき

## 薬剤性間質性肺炎
- **ほぼすべての薬で起こりうる**。薬の添付文書の重大な副作用に広く書かれている。このノートの drug ノートでは次のものに書かれている

| 系統 | 薬 |
| --- | --- |
| 抗菌薬 | [[セファゾリン]](PIE 症候群を含む)、[[セフメタゾール]]、[[セフトリアキソン]]、[[セフカペン]]、[[アモキシシリン]](好酸球性肺炎を含む)、[[ピペラシリン]]、[[スルバクタム]](ユナシン-S)、[[タゾバクタム]](ゾシン) |
| NSAIDs | [[ロキソプロフェン]] |
| 尿酸降下薬 | [[アロプリノール]] |
| 漢方薬 | [[小青竜湯]] |

- 起こしやすいことで知られる薬の例: ブレオマイシン、アミオダロン、メトトレキサート、EGFR チロシンキナーゼ阻害薬(ゲフィチニブなど)、免疫チェックポイント阻害薬、インターフェロン(小柴胡湯との併用は禁忌)など(一般的な知識)
- **日本人は薬剤性肺障害を起こしやすい**とされる(ゲフィチニブの経験などから、一般的な知識)

### しくみ
- **細胞傷害型**: 薬が肺胞上皮や血管内皮を直接傷つける。用量が多いほど起こりやすい(ブレオマイシン、アミオダロンなど)
- **免疫(過敏反応)型**: 薬に対するアレルギー反応(T 細胞や好酸球による)。量と関係なく起こる。抗菌薬・NSAIDs・漢方薬の多くはこちらと考えられている

### 診断
- その薬を使い始めてから、咳・息切れ・発熱・新しい画像の影が出たら疑う
- 感染症(ニューモシスチス肺炎、ウイルス性肺炎など)、心不全、元の病気の悪化を除外する
- 決め手になる検査はない。薬剤リンパ球刺激試験 (DLST) は参考程度

### 治療
1. **原因と思われる薬をやめる**(軽ければこれだけでよくなることもある)
2. 中等症以上では**副腎皮質ステロイド**([[プレドニゾロン]]など)。重症ではメチルプレドニゾロンの大量静注(パルス療法)
3. 低酸素血症には酸素療法

## 特発性肺線維症 (IPF)
- ゆっくり進行して肺が硬くなる。診断からの生存期間の中央値は 3〜5 年とされる(一般的な知識)
- **抗線維化薬**: ニンテダニブ、ピルフェニドンで、肺活量 (FVC) の低下を遅らせる
- **ステロイドと免疫抑制薬は勧められない**: プレドニゾン・アザチオプリン・N-アセチルシステインの 3 剤併用は、死亡と入院を増やした(PANTHER-IPF)
- **急性増悪**: 数週間で急に悪くなり、死亡率が高い。ステロイドのパルス療法などが行われるが、効果ははっきりしていない
- 肺癌を合併しやすい

## 進行性の線維化を伴う間質性肺疾患 (PPF)
- IPF 以外の間質性肺炎(膠原病、過敏性肺炎、NSIP など)でも、治療しても線維化が進むものがある
- ニンテダニブが FVC の低下を遅らせる(INBUILD)

この項目は一般的な呼吸器病学の知識による(エビデンスの数値は各論文による)。
