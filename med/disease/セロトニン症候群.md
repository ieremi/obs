# セロトニン症候群

## 概要
- **セロトニンに作用する薬**（とくに抗うつ薬）を使っているときに起こる副作用。脳のセロトニンの働きが強くなりすぎて起こる
- 症状は 3 つのグループに分かれる
  - **精神の症状**：不安、焦燥、錯乱、軽躁
  - **神経・筋の症状**：腱反射亢進、ミオクローヌス、[[クローヌス]]、筋強剛
  - **自律神経の症状**：発熱、頻脈、発汗、振戦、下痢、皮膚の紅潮
- **薬を飲み始めたり増やしたりしてから、数分〜数時間で** 出ることが多い
- 原因の薬をやめれば、ふつう **24 時間以内** に消える。ただしまれに 40 ℃以上の高熱が続き、横紋筋融解症・腎不全・播種性血管内凝固（DIC）を起こして命にかかわることがある

## 歴史
| 年 | 出来事 |
| --- | --- |
| 1950 年代 | MAO 阻害作用のある結核の薬（イプロニアジド）と、麻薬性の鎮痛薬（ペチジン）の併用で、不穏・興奮・振戦・反射亢進の例が報告された。いまのセロトニン症候群にあたる |
| 1970 年代 | 動物にセロトニン作動薬を与えたときの異常行動が「5-HT behavioral syndrome」とよばれた。もともとは動物実験の用語 |
| 1982 年 | Insel らが、クロミプラミンと MAO 阻害薬の併用で、不穏・ミオクローヌス・発熱・反射亢進を起こした 2 例を、ヒトのセロトニン症候群として報告した |
| 1991 年 | Sternbach が総説を出し、診断基準を示した。ちょうど SSRI の使用が増えた時期で、関心が高まった |

## どのくらい起こるか
- SSRI を **過量服用** して入院した人では、469 例中 67 例（**14%**）に起こった（Isbister ら）
- フルボキサミンを中心に治療した入院患者 200 人では、典型的なセロトニン症候群は 0 例だった（Ebert ら）
- ネファゾドンで治療した 11,834 人では、症状が 2 つ以上あったのは 53 例（0.4%）だった（MacKay ら）
- まとめると、**過量服用では多いが、ふつうの量では少ない**。ただし **MAO 阻害薬** を併用すると起こりやすい

## 原因の薬
セロトニン神経の働きを強める薬は、すべて原因になりうる。**単剤より、何種類も併用したときのほうが圧倒的に多い**。

| 種類 | 例 |
| --- | --- |
| **SSRI** | フルボキサミン、[[パロキセチン]]、セルトラリン、エスシタロプラム。日本ではいちばん多い |
| 三環系抗うつ薬 | クロミプラミン、イミプラミン、アミトリプチリン |
| SNRI | ベンラファキシン、デュロキセチン（糖尿病性神経障害・線維筋痛症・腰痛などにも使うので、精神科以外の処方にも注意） |
| そのほかの抗うつ薬 | ボルチオキセチン |
| **MAO 阻害薬** | 日本では抗うつ薬としては認められていない。パーキンソン病の MAO 阻害薬（セレギリンなど）と SSRI・三環系の併用はさける |
| 気分安定薬 | 炭酸リチウム |
| 抗不安薬 | タンドスピロン（5-HT₁A 受容体作動薬。死亡例の報告もある） |
| 鎮痛薬・鎮咳薬 | ペチジン、ペンタゾシン、トラマドール、デキストロメトルファン |
| 抗菌薬 | **リネゾリド**（MAO 阻害作用がある。うつ病の人が MRSA 感染症になったときに注意） |
| 検査薬 | **メチレンブルー**（MAO 阻害作用。MAO 阻害薬やベンラファキシンとの併用で報告。単独でも起こりうる） |
| サプリメント | **セントジョーンズワート**（セイヨウオトギリソウ） |
| 違法薬物 | MDMA（エクスタシー）。暑い環境で起こりやすい |

## 起こりやすい人
- はっきりした危険因子はわかっていない
- 抗うつ薬を **大量に** 使ったとき
- **CYP2D6 の働きがとても弱い人**（poor metabolizer）では、パロキセチンが分解されにくく、血中濃度が上がって起こりやすくなる可能性がある
- 体の病気がある人で起こった報告があり、悪性症候群と同じように体の弱さが関わる可能性がある

## 重さによる症状のちがい
| 重さ | 症状 |
| --- | --- |
| **軽症** | 頻脈、発汗、散瞳（瞳が開く）、ときどきの振戦・ミオクローヌス、精神の変化。熱はないか軽い |
| **中等症以上** | 腱反射亢進、**続く** ミオクローヌス・振戦、**筋強剛**。熱は 40 ℃近くになる |

- **予後を左右するのは発熱**。40 ℃以上の高熱が続くと、横紋筋融解症・腎不全・DIC を起こして死ぬことがある
- 診断して治療すれば、多くは後遺症なく治る

## 検査
- **セロトニン症候群に特徴的な検査所見はない**
- 1991 年以降の 168 例では、白血球の増加が 8.3%、CK（筋肉の酵素）の上昇が 26.8% だった。悪性症候群ほど多くない

## しくみ
- Sternbach は、**5-HT₁A 受容体** の刺激が中心と考えた
- しかし、5-HT₁A 受容体を刺激すると体温は **下がる**。セロトニン症候群の半数近くで熱が出るのは、**5-HT₂A 受容体** の刺激によると考えられる
- 筋強剛などの症状や、髄液の研究から、**ドパミン** や **ノルアドレナリン** の神経も関わるとみられる。オピオイド受容体や NMDA 受容体の関与を示す報告もある

## 診断基準
いくつかの基準がある。

### Hunter 基準
オーストラリアの Hunter 地域での SSRI の過量服用の分析から作られた。**クローヌスと反射亢進を重く見る**。

過去 5 週間以内にセロトニンに作用する薬を使っていて、次の **どれか 1 つ** があれば、セロトニン症候群とする。

1. 振戦 ＋ 反射亢進
2. **自発性のクローヌス**
3. 筋強剛 ＋ 38 ℃以上の高熱 ＋（眼球のクローヌス または 誘発性クローヌス）
4. **眼球のクローヌス** ＋（不安・焦燥感 または 発汗）
5. **誘発性クローヌス** ＋（不安・焦燥感 または 発汗）

これらは必ずしも必須ではない、という意見もある。クローヌスの見方は [[クローヌス]] を参照。

### Sternbach の診断基準
最初に作られた基準で、広く使われている。

- A：セロトニン作動薬を追加したり増やしたりしたのと同じころに、次の 10 症状のうち **3 つ以上**
  - 精神の変化（錯乱、軽躁）、興奮、ミオクローヌス、反射亢進、発汗、悪寒、振戦、下痢、協調運動障害、発熱
- B：ほかの病気（感染、代謝の病気、薬物の乱用や離脱）が否定される
- C：症状が出る前に、抗精神病薬を始めたり増やしたりしていない

### そのほかの基準
- **Radomski らの基準**（Birmes らが改変）：症状を主症状と副症状に分け、主症状 4 つ以上、または主症状 3 つ ＋ 副症状 2 つで診断する。より厳しいので、軽い例を見落とすおそれがある
- **Hegerl らの基準**：9 症状を 0〜3 点で採点し（最高 27 点）、**7 点以上** でセロトニン症候群とする。重さの判定に役立つが、使うのは手間がかかる

## 似ている病気
**悪性症候群** との区別がいちばん問題になる。ほかに、甲状腺クリーゼ、脳炎、中枢性抗コリン薬中毒、抗うつ薬の中断症候群、アルコール離脱症候群、悪性高熱症。

| | セロトニン症候群 | 悪性症候群 |
| --- | --- | --- |
| 原因の薬 | セロトニン作動薬 | ドパミン拮抗薬（抗精神病薬など）、ドパミン作動薬の中断 |
| 症状が出るまで | **数分〜数時間** | 数日〜数週間 |
| 良くなるまで | **24 時間以内** | 平均 9 日 |
| 発熱（38 ℃以上） | 46% | 90% 以上 |
| 意識の変化 | 54% | 90% 以上 |
| 筋強剛 | 49% | **90% 以上** |
| 白血球の増加 | 13% | 90% 以上 |
| CK の上昇 | 18% | **90% 以上** |
| 腱反射亢進 | **55%** | まれ |
| ミオクローヌス | **57%** | まれ |
| ドパミン作動薬で | 悪くなる | 良くなる |
| セロトニン拮抗薬で | 良くなる | 効かない |

- セロトニン症候群に特徴的なのは、**不安・焦燥・興奮などの精神症状** と、**ミオクローヌス・反射亢進**
- 重くなるほど区別がむずかしくなる。そのときは、ミオクローヌスがあるか、原因の薬が抗うつ薬かで判断する。両方が同時に起こった例もある

## 治療
1. **原因の薬をやめる**。補液や体を冷やすなどの保存的な治療が基本
   - 70% は 24 時間以内に良くなり、軽い例の多くは入院しなくてよい
2. 重い場合は薬を使う
   - **シプロヘプタジン**（セロトニン受容体をふさぐ抗アレルギー薬）：いちばん報告が多い。まず 12 mg まで飲ませ、症状が続けば 2 時間おきに 2 mg ずつ増やす。1 日 24 mg 程度まで使われている（日本の抗アレルギー薬としての上限は 1 日 12 mg）
   - **ベンゾジアゼピン**（クロナゼパム、ジアゼパム）：ミオクローヌスや不安・焦燥に効く
   - クロルプロマジン：5-HT₂A 受容体をふさぐので効いた報告がある。ただし、けいれんを起こしやすくすることがある
   - プロプラノロール：効くという報告と、否定する意見がある
   - ダントロレン（悪性症候群の薬）：評価は定まっていない。セロトニン症候群を悪くはしないので、悪性症候群と区別できないときは使う意味がある
3. 高熱、呼吸不全、腎不全、DIC などの合併症があれば、その治療をする

## 典型的な例（マニュアルの症例）
- 40 代の女性。うつ病の再発で **セルトラリン** 50 mg/日 とミアンセリン 10 mg/日 で入院治療を始めた
- 第 8 病日にセルトラリンを **100 mg/日 に増やした**。翌日から微熱と不眠
- 第 12 病日：「体が熱い、胸が苦しい、体が動かない」。焦燥、動悸、37.4 ℃の発熱、床をのたうちまわる錯乱状態。**四肢の腱反射亢進** と筋の緊張。白血球・CRP・CK は正常
- ジアゼパム 10 mg を静脈注射すると、動悸・焦燥・筋の緊張はすぐに良くなった。セルトラリンを中止
- 第 15 病日には発熱と腱反射亢進も軽くなった
