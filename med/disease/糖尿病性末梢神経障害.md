# 糖尿病性末梢神経障害

## 概要
- 高血糖が続くことで、**末梢神経**（感覚神経・運動神経・自律神経）が障害される病気
- 糖尿病の三大合併症（神経障害・網膜症・腎症）の中で、**最も早く現れ、最も多い**。糖尿病の人の 3〜5 割にみられる
- 最も多いのは **遠位対称性多発神経障害**。長い神経ほど傷みやすいので、**両足の先から** 症状が始まり、上へ広がる。進むと手にも出る（手袋靴下型）
- ICD-10 では、2 型糖尿病によるものは E11.4、1 型は E10.4。神経の病名としては G63.2（糖尿病性多発ニューロパチー）

## 分類

| 型 | 内容 |
| --- | --- |
| 多発神経障害（最も多い） | 感覚・運動神経障害：両足先のしびれ・痛み・感覚低下 |
| | 自律神経障害：起立性低血圧、胃の動きの低下、排尿障害など |
| 単神経障害 | 脳神経麻痺（動眼神経・外転神経・顔面神経）、手根管症候群、体幹の神経根障害など。急に起こり、数か月で回復することが多い |
| 糖尿病性筋萎縮症 | 腰仙部の神経根・神経叢の障害。太ももの痛みと筋力低下・筋萎縮 |
| 治療後神経障害 | 血糖を **急に** 下げたあとに、強い痛みが出る |

動眼神経麻痺では、瞳孔の反応が保たれることが多い（瞳孔回避）。動脈瘤による麻痺との見分けに使う。

まぶたのピクピク（[[眼瞼ミオキミア]]）は、糖尿病が直接の原因になることはふつうない。

## 原因のしくみ
高血糖が、いくつもの経路で神経と、神経を養う細い血管を傷める。

- **ポリオール経路**：アルドース還元酵素がブドウ糖をソルビトールに変え、神経の中にたまる
- **終末糖化産物**（AGEs）：たんぱく質に糖が結びつき、働きを損なう
- **プロテインキナーゼ C**（PKC）の活性化、**酸化ストレス**
- **微小血管障害**：神経を養う血管が傷み、神経が虚血になる

## 症状

### 感覚・運動神経
- 両足の先・足の裏の **しびれ、ジンジン・ピリピリする痛み、感覚の低下**。夜に強くなりやすい
- 素足で砂利の上を歩くような感じ、薄い紙が貼りついたような感じ
- **アキレス腱反射の低下・消失**、**振動覚の低下**
- 進むと、足の筋肉がやせて変形する（槌趾など）

### 自律神経
- 起立性低血圧（立ちくらみ）
- 胃の動きの低下（胃もたれ・嘔吐）、便秘と下痢をくり返す
- 排尿障害（残尿）、勃起障害
- 発汗の異常
- **無痛性の心筋虚血**：心筋梗塞でも胸の痛みがないことがある
- **無自覚性低血糖**：低血糖の前ぶれ（動悸・冷や汗）が出にくい

## 診断

### 簡易診断基準
糖尿病性神経障害を考える会の「糖尿病性多発神経障害の簡易診断基準」。

**必須項目**（両方を満たす）
1. 糖尿病がある
2. 糖尿病性多発神経障害以外の末梢神経障害を否定できる

**条件項目**（3 つのうち 2 つ以上で、神経障害ありとする）
1. 糖尿病性多発神経障害によると思われる自覚症状がある。**両側** の足趾先・足底の「しびれ」「疼痛」「異常感覚」のいずれか（上肢だけの症状は含めない）
2. **両側のアキレス腱反射** の低下または消失
3. **両側内踝の振動覚** の低下（C128 音叉で 10 秒以下）

### 検査
- **神経伝導検査**：最も客観的。伝導速度の低下、振幅の低下をみる
- **モノフィラメント検査**（5.07／10 g）：足の裏の、身を守るための感覚（防御知覚）が残っているかをみる。足潰瘍のリスク評価に使う
- **心電図 R-R 間隔変動係数**（CVR-R）：自律神経障害の評価。低下していれば障害あり
- 起立試験（起立性低血圧の評価）

### 見分けるべき病気
糖尿病の人に起こった神経障害でも、ほかの原因のことがある。

- **ビタミン B₁₂ 欠乏**（メトホルミンを長く飲んでいる人、胃切除後）
- アルコール、ビタミン B₁ 欠乏
- 尿毒症（[[慢性腎臓病]]）
- 甲状腺機能低下症
- 薬剤（[[ビンクリスチン]]、白金製剤など）
- 慢性炎症性脱髄性多発神経炎（CIDP）
- 腰部脊柱管狭窄症、頸椎症
- 左右差が大きい、運動障害が強い、急に進むときは、ほかの原因を疑う

## 治療

### 1. 血糖などの管理
- **血糖コントロール** が基本。1 型糖尿病では、発症や進行を防ぐ効果がはっきりしている（DCCT）。2 型糖尿病では効果がより小さい
- 血糖を **急に** 下げると、治療後神経障害で痛みが強くなることがある。HbA1c はゆっくり下げる
- 血圧・脂質の管理、禁煙、節酒

### 2. 原因に対する薬
- **エパルレスタット**（キネダック）：アルドース還元酵素阻害薬。ポリオール経路を抑える。日本で承認されている。尿が黄褐色〜赤色になることがある

### 3. 痛みに対する薬

| 薬 | 種類 | 注意点 |
| --- | --- | --- |
| **プレガバリン**（リリカ） | Ca²⁺チャネル α2δ リガンド | めまい・眠気・むくみ・体重増加。腎機能で量を減らす |
| **ミロガバリン**（タリージェ） | Ca²⁺チャネル α2δ リガンド | プレガバリンと同様。腎機能で量を減らす |
| **デュロキセチン**（サインバルタ） | SNRI | 吐き気・眠気。高度の腎障害では使わない |
| アミトリプチリン | 三環系抗うつ薬 | 口渇・便秘・尿閉・起立性低血圧。高齢者では注意 |
| メキシレチン | 抗不整脈薬 | 日本で糖尿病性神経障害の自発痛・しびれに適応がある。不整脈・肝障害に注意 |

- 最初はプレガバリン・ミロガバリン、デュロキセチン、三環系抗うつ薬から選ぶ
- 効かなければ、別の種類に替えるか、組み合わせる。トラマドールなどのオピオイドは次の段階
- NSAIDs（[[ロキソプロフェン]]など）は、神経障害性の痛みにはほとんど効かない

### 4. 自律神経障害への対応
- 起立性低血圧：ゆっくり立ち上がる、弾性ストッキング、ミドドリンなど
- 胃の動きの低下：少量ずつ食べる、[[メトクロプラミド]]など

## 足を守る（フットケア）
感覚が鈍ると、けがや靴ずれに気づかず、**潰瘍・感染・壊疽** から **切断** に至ることがある。

- 毎日、足の裏・指の間を見る（見えにくければ鏡や家族の助けを借りる）
- 素足で歩かない。足に合った靴をはく
- 爪はまっすぐ切る。深爪しない
- **低温やけど** に注意：カイロ、こたつ、湯たんぽ、電気毛布
- 傷・水ぶくれ・色の変化を見つけたら、早めに受診する
- 骨や関節が壊れて足が変形する **シャルコー足** が起こることもある
