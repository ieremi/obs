# 食道癌 (esophageal cancer)

## 概要

- 食道の粘膜から発生する悪性腫瘍。日本では**扁平上皮癌が大部分**を占め、腺癌もある。
- **早期食道癌**は粘膜内にとどまる癌、**表在食道癌**は粘膜下層までにとどまる癌を指す。
- 進行すると周囲の気管・大動脈などへ浸潤し、リンパ節や肺・肝臓などに転移する。

出典：[国立がん研究センター「食道がんについて」](https://ganjoho.jp/public/cancer/esophagus/about.html)

## 組織型の割合（日本）

| 組織型 | 割合 |
| --- | --- |
| **扁平上皮癌** | **90％弱（約9割）** |
| **腺癌** | **約7％** |
| その他の組織型 | 少数 |

- 日本の食道癌における目安。地域・集計時期によって割合は異なる。

出典：[国立がん研究センター「食道がんについて：組織型分類」](https://ganjoho.jp/public/cancer/esophagus/about.html)（2026-10-29確認）

## 症状

- 初期は無症状のことが多い。
- 飲み込んだときの胸の違和感・しみる感じ、食物のつかえ、体重減少。
- 進行すると胸背部痛、咳、嗄声（声のかすれ）などがみられる。

出典：[国立がん研究センター「食道がんについて」](https://ganjoho.jp/public/cancer/esophagus/about.html)

## 初診から確定診断・治療方針決定まで

**受診 → 内視鏡・生検 → 病理で確定診断 → 広がりと全身状態を評価 → 治療方針を決定**という流れが基本。検査は並行して進むこともある。

1. **初診・問診・診察**：つかえ、嚥下時痛、体重減少、食事摂取量などを確認し、既往歴・併存疾患・服薬・飲酒喫煙歴などを把握する。健診の内視鏡などで無症状のまま発見される場合もある。
2. **上部消化管内視鏡**：病変の位置・数・広がり・深さを評価し、疑わしい部分から組織を採取する（生検）。必要に応じて画像強調観察や色素散布を行う。
3. **病理診断で確定**：生検組織を顕微鏡で調べ、癌の有無と扁平上皮癌・腺癌などの組織型を判定する。**腫瘍マーカーやCTだけでは確定診断できない**。
4. **病期の評価**：CTなどでリンパ節・遠隔転移や周囲臓器への浸潤を調べる。必要に応じて超音波内視鏡、PET、食道造影などを追加する。すべての検査を全例で行うわけではない。
5. **治療に耐えられるかを評価**：栄養状態・日常生活の活動度、心肺機能・腎機能などを確認し、本人の希望も含めて治療を選択する。

「**癌かどうかを決める確定診断**」と「**どこまで広がっているかを決める病期診断**」は別。確定後も、治療を決めるための検査が続く。

出典：[国立がん研究センター「食道がん　検査」](https://ganjoho.jp/public/cancer/esophagus/diagnosis.html)、[同「治療」](https://ganjoho.jp/public/cancer/esophagus/treatment.html)

## 検査・診断

- **上部消化管内視鏡と生検**：病変を観察し、採取した組織の病理診断で確定する。
- 超音波内視鏡：壁内への深さや周囲のリンパ節を評価する。
- CTなどの画像検査：周囲臓器への浸潤、リンパ節転移・遠隔転移を評価する。必要に応じてPETなども用いる。

出典：[国立がん研究センター「食道がん　検査」](https://ganjoho.jp/public/cancer/esophagus/diagnosis.html)

### 生検の禁忌・慎重に判断する状況

ここでは**内視鏡による通常の鉗子生検**を扱う。食道癌を疑う粘膜病変では生検が診断の基本だが、出血や穿孔の危険が高いときは、先に安全性を評価する。

| 状況 | 対応・考え方 |
| --- | --- |
| **血管性病変が疑われる**（静脈瘤・血管腫など） | 血管を疑う隆起を通常の腫瘍として安易に生検しない。必要に応じて超音波内視鏡・ドプラや造影CTなどで評価し、採取方法を専門医が判断する |
| **大動脈食道瘻などが疑われる** | 拍動性の隆起、付着血餅、胸部大動脈疾患の既往などに注意。致死的出血の危険があり、生検せず緊急評価を優先する |
| **高度の凝固異常・血小板減少など** | 出血・止血困難のリスクを評価し、補正や延期を検討する。通常の生検に一律の検査値基準を当てはめず、原因・程度・緊急性などで判断する |
| **穿孔が疑われる、呼吸循環が不安定** | 生検だけでなく、診断目的の内視鏡自体の適否を再検討する。全身状態の安定化や穿孔への対応を優先する |

血管性病変・大動脈食道瘻については、生検後出血や瘻孔形成の症例報告がある。一方、**静脈瘤を併存するだけで食道のすべての生検が禁止になる、という意味ではない**。病変と血管の位置関係を評価する。

出典：[生検後の大動脈食道瘻の症例報告](https://pmc.ncbi.nlm.nih.gov/articles/PMC3094773/)、[食道の血管性病変と生検出血リスクの報告](https://www.cghjournal.org/article/S1542-3565%2817%2930381-6/fulltext)、[ASGE「Appropriate use of GI endoscopy」](https://www.asge.org/home/resources/publications/guidelines/appropriate-use-of-gi-endoscopy)

#### 抗血栓薬は一律に禁忌ではない

- **通常の粘膜生検は出血低危険度の処置**で、抗血栓薬を服用していることだけで生検禁忌とはならない。
- 薬剤の種類・併用数・血栓塞栓症リスクを確認する。ワルファリンではPT-INRが治療域内か確認し、過度の抗凝固状態では生検を見合わせる。
- DOACでは服薬時刻・腎機能なども踏まえて実施時期を調整する。休薬による血栓塞栓症もあるため、**自己判断で中止しない**。
- 生検と、出血高危険度の**EMR・ESD**では薬剤の取り扱いが異なる。

出典：[日本消化器内視鏡学会「抗血栓薬を飲んでいるのですが、内視鏡検査は受けられますか？」](https://www.jges.net/citizen/faq/general_09)、[同「内視鏡時の抗血栓薬休薬ガイドラインの現状と将来」](https://www.jstage.jst.go.jp/article/gee/66/3/66_229/_html/-char/ja)（2026-10-29確認）

## ステージ分類

以下は**日本食道学会『食道癌取扱い規約 第12版』（2022年）に基づく、扁平上皮癌の臨床的進行度分類**。T（深達度）、N（領域リンパ節転移）、M（遠隔転移）を組み合わせて決める。

### T：原発巣の深達度

| T | 広がり |
| --- | --- |
| T1a | 粘膜内 |
| T1b | 粘膜下層まで |
| T2 | 固有筋層まで |
| T3r | 外膜まで。隣接臓器への浸潤がなく、切除可能 |
| T3br | 外膜まで。隣接臓器への浸潤が疑われ、切除可能かどうかの境界 |
| T4 | 気管・大動脈・肺など周囲臓器への明らかな浸潤 |

### N・M：転移

| 因子 | 分類 |
| --- | --- |
| N0 | 領域リンパ節転移なし |
| N1 | 領域リンパ節転移1〜2個 |
| N2 | 領域リンパ節転移3〜6個 |
| N3 | 領域リンパ節転移7個以上 |
| M0 | 遠隔転移なし |
| M1a | 切除による治療効果が期待できる、規約で定めた領域外リンパ節への転移 |
| M1b | M1a以外の領域外リンパ節、または遠隔臓器への転移 |

領域リンパ節とM1aに該当するリンパ節は、原発巣の部位などを踏まえて規約で定められる。

### TNMとステージの対応

| T | N0・M0 | N1・M0 | N2/N3・M0、またはM1a | M1b |
| --- | --- | --- | --- | --- |
| T0・T1a | 0 | Ⅱ | ⅢA | ⅣB |
| T1b | Ⅰ | Ⅱ | ⅢA | ⅣB |
| T2 | Ⅱ | ⅢA | ⅢA | ⅣB |
| T3r | Ⅱ | ⅢA | ⅢA | ⅣB |
| T3br | ⅢB | ⅢB | ⅢB | ⅣB |
| T4 | ⅣA | ⅣA | ⅣA | ⅣB |

- **ⅣAは周囲臓器への明らかな浸潤、ⅣBはM1bの転移**が目安。この分類ではM1aだけでⅣBにはならない。
- **臨床分類（cStage）**は治療前の検査、**病理分類（pStage）**は切除標本に基づく。両者を混同しない。
- UICCの分類や別の版とは区分が異なるため、ステージを読む際は分類体系・版を確認する。
- 腺癌にはこの表をそのまま適用しない。食道胃接合部の腺癌について、引用元は胃癌の病期分類を参照している。

出典：[国立がん研究センター「食道がん　治療：ステージと治療の選択」表1・表2](https://ganjoho.jp/public/cancer/esophagus/treatment.html)（2026-10-29確認）

## 治療

日本で多い**扁平上皮癌**を中心とした概要。ステージに加えて、切除可能性、全身状態、本人の希望で選択する。下表は前述の日本食道学会分類を踏まえた目安で、特にⅢ期は切除可能性によって分岐する。

### ステージ別の基本方針

| 病期・状態 | 主な治療方針 |
| --- | --- |
| 0期（粘膜内・リンパ節転移なし） | 条件を満たせば**内視鏡的切除**。深さ・広がりなどによって手術や化学放射線療法を検討 |
| Ⅰ期（T1bN0M0） | **手術または根治的化学放射線療法** |
| Ⅱ〜Ⅲ期で切除可能 | 全身状態が許せば**術前化学療法 → 手術**。手術を希望しない・耐えられない場合などは根治的化学放射線療法 |
| 切除困難な局所進行癌・ⅣA期 | **根治的化学放射線療法**を中心に検討。治療後の切除は専門的な判断が必要 |
| ⅣB期・切除不能再発 | **全身薬物療法**を中心に、症状を和らげる治療を組み合わせる |

出典：[国立がん研究センター「食道がん　治療」](https://ganjoho.jp/public/cancer/esophagus/treatment.html)

### 治療法の具体例

- **内視鏡治療（ESD・EMR）**：食道を温存して粘膜の病変を切除する。切除標本で深達度・切除断端・脈管侵襲を確認し、リンパ節転移や癌の残存リスクに応じて追加手術・化学放射線療法を検討する。広範囲切除後は食道狭窄にも注意する。
- **手術**：食道切除とリンパ節郭清を行い、胃などを使って食物の通り道を再建する。術後は縫合不全、肺炎、反回神経麻痺、嚥下・栄養の問題などに対応する。
- **術前化学療法**：代表は**DCF療法＝ドセタキセル＋シスプラチン＋5-FU（フルオロウラシル）**。体力・臓器機能などに応じて治療を調整する。
- **根治的化学放射線療法（CRT）**：抗癌薬と放射線を併用し、食道を温存しながら根治を目指す。代表的な併用薬はシスプラチン＋5-FU。治療後は内視鏡・画像で評価し、遺残・局所再発には救済手術や内視鏡治療を検討する。
- **術後補助療法**：術前CRT後に完全切除できても、病理で癌が残っていた場合には**ニボルマブ**が選択肢となる。術前DCF後の全例に一律に投与する、という意味ではない。
- **切除不能進行・再発への薬物療法**：免疫チェックポイント阻害薬と化学療法の併用、またはニボルマブ＋イピリムマブなどを検討する。組織型、PD-L1、既治療、臓器機能などを踏まえ、各薬剤の適応に沿って選ぶ。

出典：[国立がん研究センター「食道がんの治療について」](https://www.ncc.go.jp/jp/information/knowledge/esophageal/003/index.html)、[同「食道がん　治療」](https://ganjoho.jp/public/cancer/esophagus/treatment.html)

### 術式

食道癌手術は、**①食道切除＋②リンパ節郭清＋③再建**の組み合わせで理解する。腫瘍の部位・広がり、胃が使えるか、全身状態によって術式が変わる。

#### 部位別の切除・再建

| 部位 | 代表的な術式・考え方 |
| --- | --- |
| **胸部食道癌** | **胸部食道亜全摘＋リンパ節郭清＋胃管再建**が代表的。右胸側から食道を切除し、胃を細長い管にして引き上げ、残した食道と吻合する |
| **頸部食道癌** | 頸部食道切除＋**遊離空腸再建**など。喉頭への広がりによっては**咽頭喉頭頸部食道切除**が必要。可能な症例では喉頭を温存する |
| **食道胃接合部癌** | 組織型と食道への浸潤長などに応じて、食道・胃の切除範囲を決める。腺癌で食道浸潤が短い場合には腹部からの手術、広い場合には胸部操作を伴う手術などを選ぶ |

- **遊離空腸再建**：血管のついた空腸の一部を移植し、頸部の血管とつなぎ直して、咽頭・食道間の通り道を作る。
- 喉頭を切除した場合には声が失われるため、頸部食道癌では喉頭温存の可能性や化学放射線療法も含めて検討する。

出典：[国立がん研究センター「食道がんの治療について：手術」](https://www.ncc.go.jp/jp/information/knowledge/esophageal/003/index.html)、[日本食道学会「手術治療」](https://www.esophagus.jp/public/cancer/07_treatment.html)

#### リンパ節郭清

| 郭清範囲 | 領域 |
| --- | --- |
| **2領域郭清** | 胸部＋腹部 |
| **3領域郭清** | 頸部＋胸部＋腹部 |

- 胸部食道癌は頸部から腹部まで広くリンパ節転移を来しうるため、広範囲の郭清が必要になる。
- **全例で3領域郭清を行うわけではない**。原発部位・転移状況・手術リスクなどで範囲を選ぶ。

出典：[国立がん研究センター「食道がんの手術について」](https://www.ncc.go.jp/jp/ncch/clinic/esophageal_surgery/020/index.html)、[京都医療センター「食道がん」](https://kyoto.hosp.go.jp/html/guide/medicalinfo/surgery/description01.html)

#### 再建臓器・経路・吻合部位

- **再建臓器**：通常は**胃管**。胃切除後や胃にも病変があるなど、胃が使えない場合は結腸・小腸を検討する。
- **再建経路**：**後縦隔経路**（元の食道の通り道）、**胸骨後経路**（胸骨の後ろ）、**胸壁前経路**などから選ぶ。
- **吻合部位**：頸部でつなぐ方法や、胸腔内でつなぐ方法がある。切除範囲と必要な切除断端などを踏まえて決める。

出典：[九州大学病院「外科的治療」](https://www.gan.med.kyushu-u.ac.jp/result/esophageal_cancer/index3)、[日本食道学会「手術治療」](https://www.esophagus.jp/public/cancer/07_treatment.html)

#### 手術のアプローチ

- **開胸・開腹手術**：胸部・腹部を切開して行う。
- **胸腔鏡・腹腔鏡手術**：小さな創からカメラと器具を入れて行う。
- **ロボット支援下手術**：術者がロボットの器具を操作して行う。
- **縦隔鏡下の非開胸食道切除**：頸部・腹部から縦隔に進入して切除する方法。適応を選んで行う。

「胸腔鏡」「ロボット」は**到達・操作方法**を表す名称。食道をどれだけ切除し、どこまで郭清し、何で再建するかとは分けて読む。

出典：[国立がん研究センター「食道がんの手術について」](https://www.ncc.go.jp/jp/ncch/clinic/esophageal_surgery/020/index.html)

### 栄養・症状への対応

- 摂取量や体重を継続して確認し、栄養支援、嚥下リハビリテーション、口腔ケアを行う。
- つかえ・痛みなどには、状況に応じて放射線治療や食道ステント、栄養経路の確保などを検討する。
- **緩和ケア・支持療法は診断時から**、癌への治療と並行して行う。
- 腺癌、とくに食道胃接合部癌は、病期分類・手術・薬物療法の選択が異なるため、扁平上皮癌の治療方針をそのまま当てはめない。

出典：[国立がん研究センター「食道がん　治療」](https://ganjoho.jp/public/cancer/esophagus/treatment.html)

## 腫瘍マーカー

| 組織型 | 主な腫瘍マーカー | 名称 |
| --- | --- | --- |
| **扁平上皮癌** | **SCC、CEA** | SCC：扁平上皮癌関連抗原、CEA：癌胎児性抗原 |
| **腺癌** | **CEA** | 癌胎児性抗原 |

- 診断の補助、治療効果の評価、治療後の経過観察に用いる。
- **正常値でも食道癌を否定できない**。癌があっても上昇しないことがある。
- **高値だけでは癌の有無・部位・進行や再発を確定できない**。内視鏡・病理・画像検査などと合わせて判断する。

出典：[国立がん研究センター「食道がん　検査：腫瘍マーカー検査」](https://ganjoho.jp/public/cancer/esophagus/diagnosis.html)

### その他に使われるマーカー

- **CYFRA（サイトケラチン19フラグメント）**：扁平上皮癌で用いられることがある。[東京医科大学病院「食道がんの基礎知識」](https://hospinfo.tokyo-med.ac.jp/cancer/esophageal/knowledge.html)
- **抗p53抗体**：食道癌で補助的に測定されることがある。[慶應義塾大学病院 KOMPAS「食道がん」](https://kompas.hosp.keio.ac.jp/disease/000234/)
