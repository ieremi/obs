# 胆管消失症候群

**肝内の小さな胆管が減少・消失し、胆汁うっ滞が持続する症候群。** 英語は vanishing bile duct syndrome（VBDS）。単一の原因による病名ではなく、薬物性肝障害、免疫関連疾患、感染症、悪性腫瘍などに伴って生じ得る。[国立医薬品食品衛生研究所・医薬品安全性情報](https://www.nihs.go.jp/dig/sireport/weekly21/23231109.pdf)

## 病態と所見

| 項目 | 内容 |
| --- | --- |
| 障害部位 | 主に肝内の小胆管。太い胆管を石などが塞ぐ病態とは区別する。 |
| 病態 | 胆管の障害・減少により、胆汁の排泄が妨げられる。 |
| 症状 | 黄疸、そう痒、濃い尿など、胆汁うっ滞に伴う症状。 |
| 検査 | ALP・γ-GTP・ビリルビンなどの異常が手掛かりとなる。 |
| 経過 | 遷延する胆汁うっ滞を示し、重症例では肝不全に至ることもある。 |

胆管の減少は肝生検などによる病理評価で確認する。肝機能検査値の異常だけでVBDSと確定するものではなく、胆道閉塞や他の肝胆道疾患の除外も必要。[LiverTox：Vanishing Bile Duct Syndrome](https://www.ncbi.nlm.nih.gov/books/NBK548715/)

## 薬物性の場合

薬物性肝障害のまれだが重篤な転帰の一つ。原因薬を中止した後も、胆管障害による胆汁うっ滞が続く場合がある。原因薬の評価と中止、胆汁うっ滞・そう痒への対応、肝機能の経過観察が重要となり、進行例では肝移植を検討することもある。治療法は原因と重症度によって異なる。[LiverTox](https://www.ncbi.nlm.nih.gov/books/NBK548715/)

## アバコパンとの関係

[[アバコパン]]（商品名：タブネオス）の投与後にも、VBDSを含む重篤な肝機能障害が報告されている。2026年5月のブルーレターでは、VBDSを疑う場合の速やかな投与中止が示された。[製造販売元の安全性速報](https://med.kissei.co.jp/information/info146.pdf)

2026年10月には、有効性の根拠となった試験の信頼性の問題も含め、新規投与の差し控えなどが通知された。最新の対応は[[アバコパン#2026年10月21日の通知]]を参照。
