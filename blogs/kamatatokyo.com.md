# kamatatokyo.com

**過去に『はだしのゲン』関連サイト「ゲンプロ」と、「はだしのゲン日記」などが置かれていたドメイン。** 現在のサイト本文は今回取得できなかったため、以下は過去の外部資料から確認できる内容。

## どんなサイトだった？

ハードコアチョコレートの『はだしのゲン』公式Tシャツの商品紹介では、「ゲンプロ」というファン向けサイトとして `http://kamatatokyo.com/` が案内されている。[公式通販の商品説明](https://core-choco.shop-pro.jp/?pid=5331894)

京都精華大学国際マンガ研究センターの刊行物にも、`kamatatokyo.com/home.html` と、その配下の「はだしのゲン日記」が紹介されている。『はだしのゲン』をめぐるファンのパロディーや二次創作という文脈で言及されたサイトである。[同センター刊行物・吉村和真の論考、注3](https://imrc.jp/images/upload/lecture/data/20101224Comics%20Worls%20and%20the%20World%20of%20Comics.pdf)

## 確認できるコンテンツ・人物

| 項目 | 過去のURL・確認できること |

| ゲンプロ | `http://kamatatokyo.com/`。通販の商品説明にリンク。 |

| 大場みち | 2007年のイベント告知で「はだしのゲン日記」の人物として紹介されている。 |
| ちょいペディア | `http://kamatatokyo.com/tyoi/wiki.cgi`。mixiコミュニティで当時の公式サイトとして案内。 |

2007年10月16日の「はだしのゲン学会」イベントでは、大場みち、北村ヂン、ゲストの表智之が出演者として掲載されている。告知は、漫画研究と、同人・インターネット上のサブカルチャーの両方を扱っている。[LOFT PROJECT・当時の開催告知](https://www.loft-prj.co.jp/schedule/naked/6955)

「ちょいペディア」との関係は、[mixiの当時のコミュニティ説明](https://mixi.jp/view_community.pl?id=1442464)による。ドメイン内のすべてのコンテンツが同じ名義・目的で運営されていたかは、今回確認できていない。
