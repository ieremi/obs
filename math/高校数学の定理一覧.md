# 高校数学の定理一覧

高校数学で使う主な定理・公式・基本法則を分野別にまとめた一覧。中学校で学び、高校でも使うものを一部含む。

## 数と式・方程式・不等式

| 定理・公式 | 内容・条件 |
| --- | --- |
| 因数定理 | 多項式 $P(x)$ について、$P(a)=0$ と、$P(x)$ が $x-a$ を因数に持つことは同値 |
| 剰余の定理 | $P(x)$ を $x-a$ で割った余りは $P(a)$ |
| 二次方程式の解の公式 | $ax^2+bx+c=0$、$a\ne0$ の解は $x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$ |
| 解と係数の関係（二次） | 二つの解を $\alpha,\beta$ とすると、$\alpha+\beta=-b/a$、$\alpha\beta=c/a$。重解は重複して数える |
| 解と係数の関係（三次） | $ax^3+bx^2+cx+d=0$ の解について、$\alpha+\beta+\gamma=-b/a$、$\alpha\beta+\beta\gamma+\gamma\alpha=c/a$、$\alpha\beta\gamma=-d/a$ |
| 二項定理 | 非負整数 $n$ について、$(a+b)^n=\displaystyle\sum_{k=0}^{n}\binom nk a^{n-k}b^k$ |
| 相加平均・相乗平均の関係 | $a,b\ge0$ なら $\dfrac{a+b}{2}\ge\sqrt{ab}$。等号は $a=b$ のとき |
| [[コーシー・シュワルツの不等式]] | 実数 $a_i,b_i$ について、$\left(\sum a_i^2\right)\left(\sum b_i^2\right)\ge\left(\sum a_ib_i\right)^2$ |

## 整数

| 定理・原理 | 内容・条件 |
| --- | --- |
| 素因数分解の一意性 | $2$ 以上の整数は、素数の積として順序を除き一意に表せる |
| ユークリッドの互除法 | 整数 $a,b,q,r$ が $a=bq+r$ を満たすとき、$\gcd(a,b)=\gcd(b,r)$ |
| ベズーの等式 | 整数 $a,b$（両方が $0$ ではない）の最大公約数 $d$ に対して、$ax+by=d$ を満たす整数 $x,y$ がある |
| 鳩の巣原理 | $n+1$ 個のものを $n$ 個の箱に入れると、少なくとも一つの箱に $2$ 個以上入る |

## 平面図形・三角形

三角形 $ABC$ の辺の長さを $a=BC$、$b=CA$、$c=AB$、面積を $S$ とする。

| 定理・公式 | 内容・条件 |
| --- | --- |
| 三平方の定理 | 直角三角形で、斜辺を $c$ とすると $a^2+b^2=c^2$。逆も成立 |
| 正弦定理 | 外接円の半径を $R$ とすると、$\dfrac a{\sin A}=\dfrac b{\sin B}=\dfrac c{\sin C}=2R$ |
| 余弦定理 | $a^2=b^2+c^2-2bc\cos A$ |
| 三角形の面積公式 | $S=\dfrac12bc\sin A=\dfrac{abc}{4R}=rs$。$r$ は内接円の半径、$s=(a+b+c)/2$ |
| ヘロンの公式 | $S=\sqrt{s(s-a)(s-b)(s-c)}$ |
| 角の二等分線の定理 | $A$ の内角の二等分線と $BC$ の交点を $D$ とすると、$BD:DC=AB:AC$ |
| 中線定理（パップスの定理） | $M$ が $BC$ の中点なら、$AB^2+AC^2=2(AM^2+BM^2)$ |
| 重心の性質 | 三角形の三本の中線は一点で交わり、重心は各中線を頂点側から $2:1$ に内分する |

### チェバ・メネラウス

$D,E,F$ をそれぞれ直線 $BC,CA,AB$ 上の点とし、頂点とは異なるものとする。以下の比は正の長さの比。

- **チェバの定理**：$D,E,F$ が各辺の内部にあるとき、$AD,BE,CF$ が一点で交わるための必要十分条件は

$$
\frac{BD}{DC}\cdot\frac{CE}{EA}\cdot\frac{AF}{FB}=1
$$

- **メネラウスの定理**：三点のうちちょうど一つ、または三つが辺の延長上にある配置では、$D,E,F$ が一直線上にあるための必要十分条件は同じ積が $1$ になること。

辺の延長を含めて一般化する場合は、配置や有向線分による符号に注意する。

## 円

| 定理 | 内容・条件 |
| --- | --- |
| 円周角の定理 | 同じ弧に対する円周角は等しく、その弧に対する中心角の半分 |
| 円に内接する四角形の性質 | 向かい合う内角の和は $180^\circ$。逆も成立 |
| 接弦定理 | 接線と弦のなす角は、その角に対応する弧に対する円周角に等しい |
| 方べきの定理 | 点 $P$ を通る二本の割線が円とそれぞれ $A,B$、$C,D$ で交わるとき、$PA\cdot PB=PC\cdot PD$。接点 $T$ への接線なら $PT^2=PA\cdot PB$ |
| 接線の長さの性質 | 円外の一点から引いた二本の接線の、接点までの長さは等しい |

## 三角関数・指数・対数

| 定理・公式 | 内容・条件 |
| --- | --- |
| 三角関数の基本関係 | $\sin^2\theta+\cos^2\theta=1$、$\tan\theta=\sin\theta/\cos\theta$（後者は $\cos\theta\ne0$） |
| 加法定理（正弦） | $\sin(\alpha\pm\beta)=\sin\alpha\cos\beta\pm\cos\alpha\sin\beta$ |
| 加法定理（余弦） | $\cos(\alpha\pm\beta)=\cos\alpha\cos\beta\mp\sin\alpha\sin\beta$ |
| 二倍角の公式 | $\sin2\theta=2\sin\theta\cos\theta$、$\cos2\theta=\cos^2\theta-\sin^2\theta$ |
| 半角の公式 | $\sin^2(\theta/2)=(1-\cos\theta)/2$、$\cos^2(\theta/2)=(1+\cos\theta)/2$ |
| 三角関数の合成 | $a\sin x+b\cos x=\sqrt{a^2+b^2}\sin(x+\alpha)$。$a,b$ が同時に $0$ でないとき、$\cos\alpha=a/\sqrt{a^2+b^2}$、$\sin\alpha=b/\sqrt{a^2+b^2}$ |
| 指数法則 | 正の実数 $a,b$ について、$a^{x+y}=a^xa^y$、$(a^x)^y=a^{xy}$、$(ab)^x=a^xb^x$ |
| 対数法則 | $a>0,a\ne1,M,N>0$ で、$\log_a(MN)=\log_aM+\log_aN$、$\log_a(M/N)=\log_aM-\log_aN$、$\log_aM^r=r\log_aM$ |
| 底の変換公式 | $\log_ab=\dfrac{\log_cb}{\log_ca}$。$a,c>0$、$a,c\ne1$、$b>0$ |

## 数列

| 定理・公式 | 内容・条件 |
| --- | --- |
| 等差数列 | 一般項 $a_n=a_1+(n-1)d$、和 $S_n=\dfrac n2(a_1+a_n)$ |
| 等比数列 | 一般項 $a_n=a_1r^{n-1}$、和 $S_n=\dfrac{a_1(1-r^n)}{1-r}$（$r\ne1$）。$r=1$ なら $S_n=na_1$ |
| 自然数の和 | $\displaystyle\sum_{k=1}^{n}k=\dfrac{n(n+1)}2$ |
| 平方の和 | $\displaystyle\sum_{k=1}^{n}k^2=\dfrac{n(n+1)(2n+1)}6$ |
| 立方の和 | $\displaystyle\sum_{k=1}^{n}k^3=\left(\dfrac{n(n+1)}2\right)^2$ |
| 数学的帰納法 | 最初の場合の成立と、「$n=k$ で成立すれば $n=k+1$ でも成立」を示して、すべての対象となる自然数での成立を証明する |
| 無限等比級数 | $\lvert r\rvert<1$ なら、$\displaystyle\sum_{k=0}^{\infty}ar^k=\dfrac a{1-r}$ |

## ベクトル・座標・複素数平面

| 定理・公式 | 内容・条件 |
| --- | --- |
| 内積と角度 | $\boldsymbol a\cdot\boldsymbol b=\lvert\boldsymbol a\rvert\lvert\boldsymbol b\rvert\cos\theta$（両ベクトルが非零） |
| 垂直条件 | 非零ベクトル $\boldsymbol a,\boldsymbol b$ が垂直であることと、$\boldsymbol a\cdot\boldsymbol b=0$ は同値 |
| 内分点の公式 | $AP:PB=m:n$（$m,n>0$）なら、$\boldsymbol p=\dfrac{n\boldsymbol a+m\boldsymbol b}{m+n}$ |
| 点と直線の距離 | 点 $(x_0,y_0)$ と直線 $ax+by+c=0$ の距離は $\dfrac{\lvert ax_0+by_0+c\rvert}{\sqrt{a^2+b^2}}$ |
| [[ド・モアブルの定理]] | 整数 $n$ に対して、$(\cos\theta+i\sin\theta)^n=\cos n\theta+i\sin n\theta$ |
| 複素数の積と回転 | $z$ に $\cos\theta+i\sin\theta$ を掛けると、原点の周りに角 $\theta$ だけ回転する |

## 極限・微分・積分

| 定理・公式 | 内容・条件 |
| --- | --- |
| はさみうちの原理 | $a_n\le b_n\le c_n$ が十分大きい $n$ で成立し、$a_n,c_n$ が同じ値 $L$ に収束すれば、$b_n\to L$ |
| 中間値の定理 | 閉区間で連続な関数は、両端の関数値の間のすべての値を取る |
| 平均値の定理 | $f$ が $[a,b]$ で連続、$(a,b)$ で微分可能なら、$f'(c)=\dfrac{f(b)-f(a)}{b-a}$ を満たす $c\in(a,b)$ がある |
| 積の微分法 | $(fg)'=f'g+fg'$ |
| 商の微分法 | $(f/g)'=\dfrac{f'g-fg'}{g^2}$（$g\ne0$） |
| 合成関数の微分法 | $\dfrac{d}{dx}f(g(x))=f'(g(x))g'(x)$ |
| 微積分の基本定理 | 連続な $f$ の原始関数を $F$ とすると、$\displaystyle\int_a^bf(x)\,dx=F(b)-F(a)$ |
| 部分積分法 | $\displaystyle\int f(x)g'(x)\,dx=f(x)g(x)-\int f'(x)g(x)\,dx$ |
| 置換積分法 | $x=g(t)$ とおくと、$\displaystyle\int_{g(\alpha)}^{g(\beta)}f(x)\,dx=\int_\alpha^\beta f(g(t))g'(t)\,dt$。適切な連続性・微分可能性を仮定 |

三角関数の微分では角を **弧度法（ラジアン）** で扱う。関連：[[sinの導関数]]。

## 場合の数・確率

| 定理・公式 | 内容・条件 |
| --- | --- |
| 順列 | 異なる $n$ 個から $r$ 個を選んで並べる方法は ${}_nP_r=\dfrac{n!}{(n-r)!}$ |
| 組合せ | 異なる $n$ 個から $r$ 個を選ぶ方法は $\binom nr=\dfrac{n!}{r!(n-r)!}$ |
| 確率の加法定理 | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ |
| 余事象の確率 | $P(A^{\mathrm c})=1-P(A)$ |
| 条件付き確率・乗法定理 | $P(A\cap B)=P(A)P(B\mid A)$（$P(A)>0$） |
| 独立事象の確率 | $A,B$ が独立なら $P(A\cap B)=P(A)P(B)$ |
| 全確率の公式 | $A_i$ が全体を分割し、各 $P(A_i)>0$ なら、$P(B)=\sum_iP(A_i)P(B\mid A_i)$ |
| [[ベイズの定理]] | $P(A\mid B)=\dfrac{P(B\mid A)P(A)}{P(B)}$（条件付き確率が定義できる場合） |
| 期待値の線形性 | $E[aX+bY]=aE[X]+bE[Y]$。独立でなくても成立 |

関連：[[完全順列]]。

## データ分析・確率分布

| 定理・公式 | 内容・条件 |
| --- | --- |
| 分散の公式 | $V[X]=E[X^2]-(E[X])^2$ |
| 分散の変換 | $V[aX+b]=a^2V[X]$ |
| 独立な確率変数の和の分散 | $X,Y$ が独立なら $V[X+Y]=V[X]+V[Y]$ |
| 二項分布の平均・分散 | $X\sim B(n,p)$ なら、$E[X]=np$、$V[X]=np(1-p)$ |
| 標準化 | 平均 $\mu$、標準偏差 $\sigma>0$ の変数について、$Z=(X-\mu)/\sigma$ は平均 $0$、分散 $1$ |
| 標本平均の平均・分散 | 独立に同じ分布から得た大きさ $n$ の標本で、$E[\bar X]=\mu$、$V[\bar X]=\sigma^2/n$ |
| 中心極限定理 | 独立に同じ分布に従う変数が有限の平均・正の有限分散を持つとき、標準化した標本平均の分布は $n\to\infty$ で標準正規分布に近づく |

標準化しただけで正規分布になるわけではない。元の変数が正規分布なら、標準化後は標準正規分布になる。
