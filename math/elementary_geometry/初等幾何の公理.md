# 初等幾何の公理

初等幾何は、**少数の約束（公理）だけを出発点として、図形の性質をすべて論理で導く**体系である。

「見ればわかる」ことも、公理から導けなければ証明したことにならない。逆に、公理さえ認めれば、あとは図を見なくても推論だけで定理が得られる。

**用語**

| 用語 | 意味 |
| --- | --- |
| 定義 | 言葉の意味を決めたもの（例：円とは、1点から等距離にある点の集まり） |
| 公理 | 証明せずに認める前提 |
| 定理 | 公理と定義から証明された命題 |

ユークリッドは、幾何に固有の前提を **公準**（postulate）、量一般に通じる前提を **共通概念**（common notion）と呼び分けた。現代ではどちらも公理と呼ぶ。

## ユークリッドの公準

紀元前300年ごろの『原論』（Elements）第1巻の5つの公準。

1. 任意の点から任意の点へ、直線を引くことができる。
2. 有限の直線を、まっすぐに延長することができる。
3. 任意の点を中心とし、任意の長さを半径として、円を描くことができる。
4. すべての直角は互いに等しい。
5. 1本の直線が2本の直線に交わり、同じ側の内角の和が2直角より小さいならば、2本の直線を限りなく延長すると、内角の和が2直角より小さい側で交わる。

公準1〜3は **定規とコンパスでできる作図** を表している。定規は2点を結ぶ・延長するため、コンパスは円を描くためだけに使い、目盛りは使わない。

公準4は、直角がどこでも同じ大きさであること、つまり **平面が場所によらず一様である** ことを保証する。

## 共通概念

1. 同じものに等しいものは、互いに等しい。
2. 等しいものに等しいものを加えれば、全体は等しい。
3. 等しいものから等しいものを引けば、残りは等しい。
4. 互いに重なり合うものは、互いに等しい。
5. 全体は部分より大きい。

1 は等号の推移律 $a=c,\ b=c\Rightarrow a=b$、2・3 は等式の両辺に同じ量を足し引きしてよいという規則にあたる。

## 第5公準（平行線公準）

第5公準だけが際立って長く、ほかの公準から証明できるのではないかと2000年以上試みられた。

現在よく使うのは、ほかの公理のもとで同値な次の形（**プレイフェアの公理**）である。

> 直線 $\ell$ 上にない点 $P$ を通り、$\ell$ に平行な直線はちょうど1本ある。

ほかの公理のもとでは、第5公準は次の命題とも同値である。

- 三角形の内角の和は2直角（$180^\circ$）に等しい。
- 平行な2直線に1直線が交わるとき、錯角は等しい。
- 互いに相似で合同でない三角形が存在する。

### 非ユークリッド幾何

19世紀にロバチェフスキーとボヤイは、第5公準を **「平行線が2本以上ある」** に置き換えても矛盾のない幾何（双曲幾何）が作れることを示した。そこでは三角形の内角の和は $180^\circ$ より小さい。

これにより、**第5公準はほかの公準から証明できない（独立である）** ことがわかった。公理は「自明な真理」ではなく、**どの世界を考えるかを決める選択** だと見る現代的な見方は、ここから生まれた。

## ユークリッドの穴とヒルベルトの公理

『原論』の証明には、公理に書かれていない前提が暗に使われている箇所がある。

- **命題1（正三角形の作図）**：線分 $AB$ の両端を中心に半径 $AB$ の円を2つ描き、その交点を頂点とする。しかし、2つの円が **交わること** はどの公準からも出てこない（連続性の問題）。

- **命題4（二辺夾角の合同）**：一方の三角形を動かして他方に重ねて証明するが、図形を「動かす」操作は公理にない。
- 「点が2点の **間にある**」「直線が三角形の **内部に入る**」といった位置関係も、図を見て判断しているだけで、公理にない（順序の問題）。

1899年、ヒルベルトは『幾何学の基礎』でこれらを補い、公理を5群に整理した。

| 群 | 内容 | 例 |
| --- | --- | --- |
| I 結合 | 点・直線・平面のつながり | 異なる2点を通る直線がただ1本ある |
| II 順序 | 「間にある」の性質 | パッシュの公理：三角形の1辺を横切る直線は、頂点を通らなければ、ほかのどちらか1辺も横切る |
| III 合同 | 線分・角の合同 | 二辺夾角が等しい三角形では、残りの角も等しい |
| IV 平行 | 平行線の一意性 | プレイフェアの公理 |
| V 連続 | 実数のような切れ目のなさ | アルキメデスの公理：どんな短い線分も、何回か並べれば任意の線分を超える |

ヒルベルトの体系では、点・直線・平面は **定義しない（無定義語）**。ユークリッドの「点とは部分をもたないもの」のような定義は、直観の説明であって証明には使えないからである。ヒルベルトは「点・直線・平面の代わりに、机・椅子・ビールジョッキと言っても成り立たなければならない」と述べたと伝えられる。**意味ではなく、公理が定める関係だけが推論に使われる。**
