# 犠牲フライ

**ノーアウトまたはワンアウトで、外野への[[フライ]]をきっかけに走者が生還したときに、打者に記録されるプレー**。略して **犠飛**。

典型的には、打者は捕球でアウトになるが、走者が[[タッチアップ]]して得点する。

## 例：ワンアウト・走者三塁

1. 打者が外野へフライを打つ。
2. 外野手が捕球し、打者がアウトになる。
3. 三塁走者がタッチアップして本塁へ生還する。

チームに **1点** が入り、打者に **犠牲フライと打点** が記録される。

## タッチアップ

捕球されたフライで進塁するために、元の塁に触れてからスタートすること。

塁について待っていた走者は、**野手が最初に打球へ触れた瞬間**から走り出せる。捕球が完全に終わるまで待つ必要はない。

## 成立条件

- **アウトが2つ未満**：ツーアウトで捕球されると第3アウトになり、そのプレーでは得点できない。
- **外野へのフライ**：外野手、または外野まで出た内野手が扱う打球が対象。ファウルフライでも成立する場合がある。
- **走者が得点する**：次の塁へ進んだだけでは犠牲フライにはならない。

## 打撃成績への影響

| 項目 | 扱い |
| --- | --- |
| 打点 | 記録される |
| 打席数 | 含まれる |
| [[打数]] | 含まれない |
| [[打率]] | 変わらない |
| 出塁率 | 分母に含まれるため、下がる場合がある |

## 捕球できなかった場合

外野手などが失策でフライを落としても、**捕球していても走者が得点できた**と記録員が判断すれば、犠牲フライが記録されることがある。

## 犠牲バントとの違い

犠牲[[バント]]（送りバント）は、走者が得点しなくても、次の塁へ進めれば記録される場合がある。犠牲フライには **走者の得点** が必要。
