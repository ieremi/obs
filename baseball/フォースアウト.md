# フォースアウト

**打者が走者になったことで、元の塁にとどまる権利を失い、次の塁へ進まなければならない走者をアウトにすること**。日本語では **封殺**。

守備側は、走者が到達する前に **ボールを確実に持って進塁先の塁に触れる**だけでアウトにできる。走者自身へのタッチでもアウトにできる。

## 具体例：走者一塁でゴロ

1. 打者がゴロを打ち、一塁へ走る。
2. 一塁走者は、打者走者に押し出される形で二塁へ進む義務が生じる。
3. 守備側がボールを持って、走者より先に二塁に触れればフォースアウト。

## どの走者に進塁義務があるか

打者が走者になり、後ろの塁から走者が途切れずにつながっていると、進塁義務が生じる。

| 投球時の走者 | フォース状態になる走者と進塁先 |
| --- | --- |
| 一塁のみ | 一塁走者 → 二塁 |
| 二塁のみ | なし（二塁走者は二塁にとどまれる） |
| 一・二塁 | 一塁走者 → 二塁、二塁走者 → 三塁 |
| 一・三塁 | 一塁走者 → 二塁（三塁走者は三塁にとどまれる） |
| 満塁 | 一塁走者 → 二塁、二塁走者 → 三塁、三塁走者 → 本塁 |

打者走者も、一塁に到達する前なら、ボールを持った野手が一塁に触れることでアウトにできる。これは厳密には、塁上の走者へのフォースアウトとは区別される。

## フォース状態がなくなる場合

後ろの走者が先にアウトになると、それによる進塁義務はなくなる。

例えば、走者一塁のゴロで **打者走者を先に一塁でアウト**にすると、一塁走者は二塁へ進む義務を失う。その後、二塁を踏むだけではアウトにできず、[[タッチアウト]]が必要になる。

## 第3アウトと得点

**第3アウトがフォースアウトの場合、そのプレーの得点は認められない**。別の走者が先に本塁へ到達していても同じ。

一方、フォース状態ではない走者へのタッチアウトなら、第3アウトより前に本塁へ到達した走者の得点が認められる場合がある。

## タッチアップの帰塁とは別

[[フライ]]の捕球後、塁を離れていた走者が戻る前に守備側が元の塁に触れてアウトにするのは、帰塁違反に対する **アピールアウト**。塁に触れてアウトにする形でも、フォースアウトとは異なる。
