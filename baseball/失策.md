# 失策

**通常の守備ならできるプレーを失敗し、打者・走者を生かす、進塁させる、打席を続けさせるなどしたときに野手につく記録**。エラーともいい、略号は **E**（error）。

「野手」には、守備をしている投手・捕手も含む。公式記録員が判断する。

## 代表例

| プレー | 失策となる例 |
| --- | --- |
| ゴロの処理 | 通常なら一塁でアウトにできるゴロをトンネルし、打者を出塁させる |
| 送球 | 一塁への悪送球で、アウトにできた打者を生かす |
| 捕球 | 捕れるフライを落とし、打者を生かす |
| 追加進塁 | 安打を処理する際のミスで、本来より先の塁へ進ませる |
| ファウルフライ | 捕れるファウルフライを落とし、終わるはずの打席を続けさせる |

**ボールに触れたから失策、触れなかったから安打、とは限らない**。打球の難しさやグラウンドの状態なども考慮する。

## 安打・野手選択との違い

| 記録 | 判断の中心 |
| --- | --- |
| [[安打]] | 通常の守備をしても、打者の出塁を防げなかった |
| 失策 | 通常できる守備を失敗したことが、出塁・追加進塁などの原因になった |
| [[野手選択]] | 打者以外の走者をアウトにしようとした選択などによる |

失策で出塁した場合、打者に安打はつかず、通常は[[打数]]に数える。一方、**安打の後の失策で追加進塁**した場合は、安打と失策を分けて記録する。たとえば単打の処理を誤って打者走者が二塁へ進んでも、必ず二塁打になるわけではない。

## 暴投・捕逸との違い

- **[[暴投]]**：処理困難な投球による進塁など。投手に記録する。
- **[[捕逸]]**：処理できる投球を捕手が処理できなかったことによる進塁など。捕手に記録する。
- **失策**：打球処理や送球などのミス。投手の牽制悪送球や、捕手の盗塁阻止の悪送球も対象になる。

暴投・捕逸を、チームの失策数に加えることはしない。

## 自責点との関係

失策によって生じた得点は、投手の自責点から除く場合がある。失策がなければどう攻撃が進んでいたかを考えて計算するので、**失策の後に入った得点がすべて自責点から除かれるわけではない**。
