# 横浜大洋ホエールズ

セントラル・リーグの球団。1978 年から 1992 年まで、この名前で横浜スタジアムを本拠地にした。親会社は **大洋漁業**（のちのマルハ、現在のマルハニチロ）。球団名の「ホエールズ」は、大洋漁業が捕鯨をしていたことに由来する。

現在の[[横浜DeNAベイスターズ]]の前身。

## 球団名と本拠地の移り変わり
| 年 | 球団名 | 本拠地 |
| --- | --- | --- |
| 1950〜1952 | 大洋ホエールズ | 下関（山口県） |
| 1953 | 大洋松竹ロビンス（松竹ロビンスと合併） | 大阪・下関 |
| 1954 | 洋松ロビンス | 大阪 |
| 1955〜1977 | 大洋ホエールズ | 川崎球場 |
| 1978〜1992 | **横浜大洋ホエールズ** | 横浜スタジアム |
| 1993〜2011 | 横浜ベイスターズ | 横浜スタジアム |
| 2012〜 | 横浜DeNAベイスターズ | 横浜スタジアム |

- 1950 年、2 リーグ分立のときにセ・リーグに加わった
- 1993 年、親会社の名前を外し、地域名だけの「横浜ベイスターズ」に改めた

## 主なできごと
- **1960 年：初優勝・日本一**。前年最下位のチームを三原脩監督が率いてリーグ優勝。日本シリーズでは[[オリオンズ|大毎オリオンズ]]に 4 連勝し、4 試合すべて 1 点差だった
  - この時期は「大洋ホエールズ」で、本拠地は川崎。横浜大洋の名前になってからの優勝はない
- **1978 年：横浜へ移転**。新しくできた横浜スタジアムに本拠地を移し、球団名に「横浜」を加えた
- **1982 年：首位打者争い**。最終盤、長崎啓二（長崎慶一）が中日の田尾安志と首位打者を争い、大洋は田尾を 5 打席連続で敬遠した。長崎が首位打者になったが、批判も受けた
- **1985 年：スーパーカートリオ**。近藤貞雄監督が、足の速い高木豊・加藤博一・屋鋪要を 1〜3 番に並べた

## 横浜大洋時代の主な選手
- 投手：平松政次、遠藤一彦、斉藤明夫、大門和彦、中山裕章、佐々木主浩（1990 年入団）
- 野手：山下大輔、田代富雄、高木豊、屋鋪要、加藤博一、長崎啓二、ポンセ、レオン・リー
