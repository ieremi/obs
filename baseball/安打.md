# 安打

打者が打った球で、守備側の失策（エラー）や[[野手選択]]によらずに塁に出ること。ヒット。

## 種類
進んだ塁の数で分ける。

| 種類 | 打者が進んだ塁 |
| --- | --- |
| 単打 | 一塁 |
| 二塁打 | 二塁 |
| 三塁打 | 三塁 |
| 本塁打 | 本塁（ホームラン） |

- 内野安打：内野で止まった打球でも、一塁でアウトにできなければ安打
- エラーで出塁したときは安打にならない（ただし[[打数]]には数える）

## 関連
- [[打率]] = 安打 ÷ [[打数]]
