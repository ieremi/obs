# セイバーメトリクス

**野球についての疑問を、データと検証によって明らかにしようとする研究・分析。** 選手の能力や貢献、戦術、勝敗の仕組みなどを扱う。

名称は米国野球学会（Society for American Baseball Research）の略称SABRに由来し、ビル・ジェームズが提唱した。難しい指標を使うこと自体より、問いに合うデータ・比較方法を選ぶことが中心となる。[SABR：A Guide to Sabermetric Research](https://sabr.org/sabermetrics)

## 何を調べるか

| 問い | 分析の観点・指標の例 |
| --- | --- |
| 打者はどれだけ得点を生むか | 出塁、長打、wOBA、wRC+ |
| 投手はどれだけ失点を防ぐ能力があるか | [[K%]]、四球率、被本塁打、FIP |
| 選手は総合的にどれだけ貢献したか | 打撃・走塁・守備・投球、WAR |
| 作戦は有効か | 得点期待値、1点以上を取る確率、勝利確率 |
| 今後も同じ成績を残せそうか | 過去の実績、標本数、年齢、環境、予測モデル |

指標は問いの一部を数値化したもの。それぞれ定義・対象・限界があり、1つだけで選手や作戦のすべてを評価することはできない。

## 考え方の例：送りバント

「走者を進めたから成功」と評価すると、アウトを失った費用が抜け落ちる。[[送りバント]]では、進塁とアウトの損失に加え、失敗・出塁の可能性も含めて、通常打撃と比較する。

さらに、平均得点を増やしたい場面と、サヨナラの1点を取りたい場面では目的が違う。得点期待値と勝利確率を使い分ける。[FanGraphs：RE24](https://library.fangraphs.com/misc/re24/)、[Baseball Savant：Game Strategy Explorer](https://baseballsavant.mlb.com/game-strategy-explorer)

## 読み解くときの注意

- **結果と能力を分ける。** 過去に何が起きたかを表す指標と、将来の予測に役立つ指標は同じとは限らない。
- **量と率を分ける。** 三振数が多くても、対戦打者数が多いだけかもしれない。三振の頻度を見るなら[[K%]]を使う。
- **比較条件をそろえる。** リーグ、年度、球場、相手、役割、ルールを考慮する。
- **少数の結果を過信しない。** 数打席・数試合の成績には大きな偶然の変動がある。
- **相関だけで原因を決めない。** ある作戦を選んだチームの勝率が高くても、その作戦が勝率を上げたとは限らない。

こうした注意は分析を行う上での一般的な原則。データの数値を示す際は、出典・集計期間・定義も確認する。[SABR：Asking the Right Questions](https://sabr.org/sabermetrics/asking-right-questions)
