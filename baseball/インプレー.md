# インプレー

**試合が動いていて、プレーが有効な状態**。公認野球規則では「ボールインプレイ」と書く。

インプレーの間は、走者は **自分の判断で進塁でき**、守備側は **アウトにできる**。反対に、プレーが止まった状態を **ボールデッド** という。ボールデッドの間は、走者はアウトにならず、決められた塁へ進むか、元の塁へ戻る以外のプレーはできない。

## いつインプレーになるか
- 試合の開始・再開のときに、投手がボールを持って投手板につき、球審が **「プレイ」** と宣告したとき
- ボールデッドのあとも、同じ手順でインプレーに戻る

## インプレーのまま続く主な場面
- フェアの打球（安打・ゴロ・フライ）
- 捕球された[[フライ]]・[[ライナー]]（ファウルフライを含む）。走者は[[タッチアップ]]して進める
- [[捕逸]]・[[暴投]]
- [[盗塁]]
- 四球。打者と押し出される走者は安全に進めるが、それ以上はインプレーとして進塁をねらえる
- 第 3 ストライクを捕手が捕れなかったとき（[[振り逃げ]]）
- インフィールドフライの宣告。打者はアウトになるが、ボールはインプレー
- 悪送球がフィールド内にとどまっている間

## ボールデッドになる主な場面

| 場面 | その後 |
| --- | --- |
| **ファウルボール**（捕球されなかったもの） | 走者は元の塁へ戻る |
| **死球** | 打者は一塁へ。押し出される走者は進む |
| ボールがスタンド・ベンチなど **ボールデッドの区域** に入った | 状況によって 1 個または 2 個の進塁が与えられる |
| **本塁打**（フェアでスタンドに入った） | 打者と走者は本塁まで進む |
| **守備妨害**（打者・走者による） | 妨害した者はアウト。走者は元の塁へ戻ることが多い |
| 打球が、野手に触れる前に **審判員や走者に当たった** | 状況による |
| **タイム** の宣告 | プレーが止まる |
| **ボーク** | 走者は 1 個ずつ進む（投球が打たれて打者・走者が全員 1 個以上進んだ場合などは、ボークを取り消してプレーを生かす） |

## 遅延ボールデッド
反則があっても **すぐには止めず、プレーが一段落してから** ボールデッドにして処置する場合がある。反則でない側が、プレーの結果のほうが得なら、そちらを選べることもある。

- **打撃妨害**（捕手のミットがバットに触れたなど）：プレーの結果と、打者に一塁を与えることを比べる
- 一部の **走塁妨害**：走者がアウトになりそうな場面でない走塁妨害は、プレーが終わってから、妨害がなければ進めたと思われる塁を与える
- 野手が **グラブや帽子を投げてボールに当てた**：インプレーのまま続き、終わってから打者・走者に進塁が与えられる

## インプレーかどうかで変わること
- インプレー中は、**どの走者も進塁をねらえる** が、アウトになる危険も負う
- ボールデッド中は、与えられた塁までは **安全に進める** が、それ以上は進めない
- 判断に迷ったら、走者はボールを見て止まれるように走り、守備側は **審判のジェスチャー** を確かめる
