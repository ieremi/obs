# タッチアップ

**[[フライ]]や[[ライナー]]が捕球されたときに、走者が元の塁に触れ直してから進塁するプレー**。

塁に触れたまま待っていた場合は、そのままスタートできる。

## スタートできるタイミング

**野手が最初に打球へ触れた瞬間**からスタートできる。捕球が完全に終わるまで待つ必要はない。

打球が捕られる前に塁を離れていた走者は、元の塁へ戻って触れ直してから進塁する。

## 例：三塁から本塁へ

1. ワンアウト・走者三塁で、打者が外野へフライを打つ。
2. 三塁走者は塁に触れて待つ。
3. 外野手が打球に触れた瞬間に、本塁へスタートする。
4. 本塁でアウトになる前に生還すれば得点になる。

このように外野フライをきっかけに得点すると、打者に[[犠牲フライ]]が記録される場合がある。

## 注意点

- **進塁は任意**。送球でアウトになる危険が高ければ、元の塁にとどまってよい。
- 三塁から本塁への走塁だけでなく、一塁から二塁、二塁から三塁などでも行える。
- ファウルフライでも、正しく捕球されればタッチアップして進塁できる。
- 早く塁を離れ、触れ直さずに進塁すると、守備側の **アピール** によってアウトになることがある。
- ツーアウトで捕球された場合は打者のアウトで攻撃が終わるため、そのプレーで走者が生還しても得点にはならない。

## 犠牲フライとの違い

| 用語 | 意味 |
| --- | --- |
| タッチアップ | 捕球された打球で、塁に触れ直してから進塁する走塁のプレー |
| [[犠牲フライ]] | 外野への打球をきっかけに走者が得点したとき、打者につく記録 |

タッチアップして次の塁へ進んでも、**得点しなければ犠牲フライにはならない**。
