# バント

**バットを大きく振らず、投球に当てて、内野へ弱い打球を転がそうとする打ち方**。

遠くへ飛ばすよりも、打球の勢いと方向を調整することをねらう。

## 主な使い方

| 種類 | 目的 |
| --- | --- |
| [[送りバント]]（犠牲バント） | 打者がアウトになる代わりに、塁上の走者を次の塁へ進める |
| セーフティバント | 守備の隙をつき、打者自身が一塁へ出塁することをねらう |
| スクイズ | 三塁走者を本塁へ生還させるためにバントする |

## 送りバントの例

ノーアウト・走者一塁で、打者がバントする。

1. 守備側が打球を処理して一塁へ送球する。
2. 打者は一塁でアウトになる。
3. その間に、一塁走者が二塁へ進む。

成功して犠牲バントと記録されれば、**打席数には含まれるが、[[打数]]には含まれない**。そのため[[打率]]は変わらない。

バントで打者自身が出塁し、[[安打]]と記録された場合は、打数にも安打数にも含まれる。

## 注意点

- バントの打球でも、地面に落ちる前に捕球されれば打者はアウト。
- **ツーストライク後のバントがファウルになり、捕球されなければ三振**になる（スリーバント失敗）。通常のファウルとは扱いが異なる。
- バントしただけで、自動的に犠牲バントが記録されるわけではない。走者の進塁やプレーの内容で決まる。

## 犠牲フライとの違い

| 項目 | 犠牲バント | [[犠牲フライ]] |
| --- | --- | --- |
| 打ち方・打球 | バント | 外野への[[フライ]] |
| 走者の得点 | 必須ではない | 必要 |
| 打数 | 記録が成立すれば含まれない | 含まれない |
