# 盗塁

**走者が、打者の安打などによらず、守備の隙をついて次の塁を奪うプレー**。記録の略号は **SB**（stolen base）。投手が投球する間に走り、捕手の送球でアウトにされる前に次の塁へ到達する形が典型。

## 例：一塁から二塁へ

1. 一塁走者が塁を離れてリードを取る。
2. 投手の動きに合わせて二塁へ走る。
3. 捕手が投球を捕り、二塁へ送球する。
4. 走者がタッチされる前に二塁へ触れればセーフ。

この場合、守備側は原則として走者への**[[タッチアウト|タッチ]]が必要**。二塁でボールを持って塁を踏むだけではアウトにならない。打者が走者となったことで押し出される[[フォースアウト]]の場面とは異なる。

## 種類

| 呼び方 | 内容 |
| --- | --- |
| 二盗 | 一塁から二塁を奪う |
| 三盗 | 二塁から三塁を奪う |
| 本盗・ホームスチール | 三塁から本塁を奪う。成功すれば得点になる。 |
| 重盗・ダブルスチール | 二人の走者が同じプレーで盗塁を試みる |
| ディレードスチール | 通常よりスタートを遅らせ、捕手の返球などの隙を狙う |

重盗では、二人が走ったからといって必ず二人に盗塁が記録されるわけではない。

## 盗塁として記録されるか

**進塁したことと、盗塁が記録されることは別**。セーフ・アウトは審判が判定し、進塁を盗塁・暴投などのどれにするかは記録員が判断する。

| 場面 | 記録上の扱い |
| --- | --- |
| 投球中に走り、通常の送球より先に次塁へ到達 | 盗塁の典型 |
| 暴投・捕逸を見てから走って進塁 | 原則として暴投・捕逸による進塁 |
| 先に盗塁を試みており、その投球が暴投・捕逸になった | 盗塁が記録される場合がある |
| 守備側が進塁に無関心で、走者が進む | 盗塁を記録しない場合がある |
| 捕手の悪送球で、盗もうとした塁からさらに進む | 盗塁と、失策による追加進塁を分ける場合がある |
| フライの捕球後に進む | [[タッチアップ]]による進塁で、盗塁ではない |

捕手が投げなかったという理由だけで、盗塁がつかなくなるわけではない。たとえば一・三塁で本塁への突入を警戒して二塁へ投げなかった場合などは、守備側の意図も踏まえて判断される。[公認野球規則9.07](https://npb.jp/scoring/officialrule_900.pdf)

## 盗塁死・盗塁刺

盗塁を試みてアウトになることを一般に**盗塁死**といい、記録では**盗塁刺（CS：caught stealing）**と呼ぶ。

牽制で元の塁へ戻れずアウトになるプレーが、すべて盗塁刺になるわけではない。次の塁へ進もうとしたかなどによって扱いが異なる。

## 成功率と戦術

盗塁成功率は、通常、次の式で計算する。

$$
\text{盗塁成功率} = \frac{\text{盗塁}}{\text{盗塁}+\text{盗塁刺}}
$$

たとえば盗塁20・盗塁刺5なら、成功率は $20/25=0.800$、80％。

成功すれば走者を先へ進められるが、失敗すれば走者とアウト一つを失う。判断には成功率に加え、点差・回・アウト数・次の打者も関わる。打撃戦か投手戦かによっても、一つ先の塁やアウトの価値は変わるので、「成功率が何％なら必ず走る」という固定の基準にはしない。

成功には足の速さだけでなく、投手の動きの読み、スタート、捕手の送球、スライディングなども関わる。

## 積極的に盗塁を狙いたいタイミング

**一つ先の塁が得点に結びつきやすく、成功する見込みも高いとき**が狙い目。「走る価値がある場面」と「走れる隙」が重なるかで判断する。

### 走る価値が高い場面

以下は戦術上の目安。走者の能力、相手バッテリー、打者、チームの指示も合わせて考える。

| 場面 | 盗塁で得られる利点 |
| --- | --- |
| 終盤の同点・1点差で、一塁に同点または勝ち越しにつながる走者がいる | 二盗すれば、単打で生還を狙える位置へ進める。失敗の影響も大きいため、高い成功見込みが前提。 |
| 二死一塁で二塁が空いている | 二盗で、次の単打を得点につなげやすくする。二死二塁からの三盗より、進塁の価値が大きいことが多い。 |
| 一塁走者が速く、打者がゴロを打ちやすい | 二盗を先に成功させれば、典型的な内野ゴロの併殺を避けやすい。打者が打った場合は盗塁とは別の走塁になる。 |
| 一死二塁で、三盗の成功を強く見込める | 三塁へ進めば、[[犠牲フライ]]や一部の内野ゴロなど、安打以外で得点できる可能性が広がる。 |

### スタートを切りやすい隙

- **投手の本塁への動作が遅い**：足を大きく上げるなど、投球に時間がかかる相手は狙い目。
- **投球動作の癖や間隔を読めた**：本塁へ投げる動きの見極めが、好スタートにつながる。
- **球速の遅い変化球を予測できる**：捕手へ届くまでの時間を利用しやすい。ただし予測が外れる可能性もある。
- **捕手が返球するなどして、守備の注意が緩んだ**：ボールインプレイ中なら、ディレードスチールを狙う余地がある。

投手の投球動作が盗塁の隙を作ることは、[MLBによる投球動作の分析](https://www.mlb.com/phillies/news/aaron-nola-slide-step-stolen-base-prevention)でも説明されている。

通常の盗塁では、**捕手が捕ってから走ると遅いため、投手の動きに合わせて走り始める**。ただし、足が上がっただけで必ず本塁へ投げるとは限らず、牽制への警戒も必要。

### 「必ず走る」とはしない

足が速い走者でも、悪いスタートを無理に押し通さない。とくに終盤の同点走者・勝ち越し走者は、先へ進める価値と失う損失がどちらも大きい。好機に見えても、相手が強く警戒しているなら控える判断もある。

## 盗塁してはいけない・控えたい場面

「してはいけない」には、ルール上できない場合、戦術上控えたい場合、慣習として嫌われる場合がある。

### ルール上、盗塁できないとき

**タイム中などのボールデッド中は、盗塁できない**。規則によって塁が与えられることはあるが、走者の判断で塁を奪う盗塁とは別。[MLB「Dead Ball」](https://www.mlb.com/glossary/rules/dead-ball)

捕球されなかった通常のファウルでは、盗塁のために走っていても投球当時の塁へ戻る。一方、捕手が正しく捕ったファウルチップはボールインプレイなので、盗塁を続けられる。捕球されたファウルフライでは[[タッチアップ]]の規則に従う。

### 戦術上、控えたいとき

以下は判断の目安であり、一律の禁止ではない。

| 場面 | 控えたい理由 |
| --- | --- |
| 終盤に大きく負けている | 一つ先の塁より、複数の走者をためる価値が高い。失敗で走者とアウトを失う影響が大きい。 |
| 二死二塁からの三盗 | 単打でも生還できる可能性があり、三塁へ進む上積みが小さめ。失敗すれば攻撃終了になる。 |
| 無死二塁から、確信の持てない三盗 | 無死で得点圏にいる好機を失う。「三塁で最初・最後のアウトになるな」という走塁の格言がある。 |
| スタートに失敗した・投手の動きを読めていない | 予定していた成功率を見込めない。走る前に状況を見直す。 |
| 後ろの走者が、前の走者との連携なしに走る | 前の塁が空かず、挟殺や走者の渋滞を招く。重盗などの連携が必要。 |
| チームの指示で走らないことになっている | バントや打撃など、別の作戦と食い違う。自由に走れる権限があるかも確認する。 |

「二死だから走ってはいけない」わけではない。二死一塁から二盗し、単打で生還できる位置を狙うことには意味がある。**何アウトかに加え、どの塁を奪うのか**で考える。

### 大差で勝っているときの「暗黙のルール」

大差で勝っているチームの盗塁は、相手への配慮を欠くとして嫌われることがある。ただし、これは**公式ルール上の禁止ではなく慣習**。何点差・何回から控えるかについて、共通の数値基準はない。[MLBによる慣習の紹介](https://www.mlb.com/amp/news/the-unwritten-rules-of-baseball.html)

得失点差が順位に関係する大会などでは事情が異なるため、大会方式やチームの方針も踏まえる。また、大差で守備側が走者に無関心なら、進塁しても盗塁が記録されない場合がある。
