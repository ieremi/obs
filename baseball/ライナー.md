# ライナー

**バットから低く、直線的に鋭く飛ぶ打球**。英語では **line drive（ラインドライブ）** という。

高く弧を描く[[フライ]]や、地面を転がるゴロと区別される。

## ほかの打球との違い

| 打球 | 特徴 |
| --- | --- |
| ライナー | 低く、直線的に鋭く飛ぶ |
| [[フライ]] | 高く上がり、弧を描いて落ちてくる |
| ゴロ | 地面を転がったり、跳ねたりする |

## プレーの結果

- **地面に落ちる前に野手が正しく捕球すれば、打者はアウト**。内野手が捕れば「内野ライナー」、外野手が捕れば「外野ライナー」などと呼ぶ。
- フェアの打球が野手の間を抜けるなどして、失策や[[野手選択]]によらず打者が出塁すれば[[安打]]になる。

**ライナーは打球の種類であり、安打かアウトかはプレーの結果で決まる**。

## 走者の注意点

ライナーも、捕球された場合は[[フライ]]と同様に **[[タッチアップ]]** が必要。

走者が安打になると思って塁を離れていると、捕球後に元の塁へ戻る前に守備側が送球して、走者もアウトになることがある。打者のアウトと合わせて **ダブルプレー（併殺）** になる。
