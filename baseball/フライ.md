# フライ

**空中へ高く上がる打球**。日本語では **飛球** という。

## ほかの打球との違い

| 打球 | 特徴 |
| --- | --- |
| フライ | 高く上がり、弧を描いて落ちてくる |
| [[ライナー]] | 低く、直線的に鋭く飛ぶ |
| ゴロ | 地面を転がったり、跳ねたりする |

## 捕球されたとき

- **地面に落ちる前に野手が正しく捕球すれば、打者はアウト**になる。
- ファウルゾーンで捕球してもアウトになる（ファウルフライ）。
- 走者が進塁するには、元の塁に触れ直す **[[タッチアップ]]** が必要。塁で待っていた走者は、野手が最初に打球へ触れた瞬間からスタートできる。

## 犠牲フライとの関係

ノーアウトかワンアウトで、外野へのフライをきっかけに走者が生還すると、[[犠牲フライ]]が記録される場合がある。

**フライは打球の種類、犠牲フライはプレーの結果につく記録**。すべてのフライが犠牲フライになるわけではない。
