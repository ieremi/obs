# 渋谷駅再開発

渋谷駅の再開発は、**駅の改良・駅ビルの建設・広場や歩行者通路の整備を並行して進める事業**。駅周辺でも複数の再開発が進み、事業ごとに完成時期が異なる。

## 何を変えるのか

- **乗り換えを改善する**：離れていたホームの配置や、改札・コンコースを見直す。
- **駅の東西・南北をつなぐ**：鉄道・幹線道路に分断された街を、地上・地下・デッキの通路で結ぶ。
- **谷地形の高低差に対応する**：「アーバン・コア」と呼ぶ縦方向の移動空間で各階を接続する。
- **駅前の公共空間を整える**：ハチ公広場や東口広場などを整備する。
- **防災・都市基盤も更新する**：雨水貯留施設など、建物の外から見えにくい設備も整備する。

出典：[東急「未来の渋谷」](https://www.tokyu.co.jp/shibuya-redevelopment/future/)、[渋谷区「上空通路と立体動線で、『深い谷』を魅力に変えて。」](https://www.city.shibuya.tokyo.jp/contents/koho-news/1581/20250615_special.html)

## 駅街区の完成予定

東急・JR東日本・東京メトロが進める**渋谷駅街区計画**の予定。以下は「年度」であり、暦年とは異なる。

| 時期 | 主な到達点 |
| --- | --- |
| 2025年5月 | スクランブルスクエア第Ⅱ期（中央棟・西棟）着工 |
| **2030年度** | 駅と歩行者ネットワークが概成。JRの改札・コンコース整備が概ね完了し、東西自由通路も整備 |
| **2031年度** | スクランブルスクエア第Ⅱ期（中央棟・西棟）完成予定 |
| **2034年度** | ハチ公広場などを含めた駅街区全体の完成予定 |

**2030年度の「概成」は、すべての工事の終了を意味しない。** また、2034年度は駅街区の予定で、渋谷周辺のあらゆる再開発が終わる年ではない。

出典：[東急・JR東日本・東京メトロ共同発表（2025年5月9日）](https://www.tokyu.co.jp/company/news/detail/56376.html)

## なぜ長期間かかるのか

渋谷駅では、**列車を走らせ、利用者を通しながら**ホーム・線路・駅舎・通路を段階的に造り替える必要がある。谷地形に加えて、鉄道・道路・地下の渋谷川が重なるため、建物だけを建て替える工事では済まない。

一つの設備を移した跡地で次の工事を進めるため、途中段階では改札や通路が変わる。完成予定の確認と、当日の通行ルートの確認は分けて行う。

出典：[渋谷区「上空通路と立体動線で、『深い谷』を魅力に変えて。」](https://www.city.shibuya.tokyo.jp/contents/koho-news/1581/20250615_special.html)、[東急ほか共同発表](https://www.tokyu.co.jp/company/news/detail/56376.html)
