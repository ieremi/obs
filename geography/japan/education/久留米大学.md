# 久留米大学

**福岡県久留米市にある私立大学。** 1928 年に開かれた **九州医学専門学校** が始まりで、**医学部と大学病院** を中心に、文系の学部も持つ総合大学。略称は「**久大**（きゅうだい）」「久留米大」。

| 項目 | 内容 |
| --- | --- |
| 設置者 | 学校法人 久留米大学 |
| 本部 | 福岡県久留米市旭町 67 |
| キャンパス | **旭町キャンパス**（医学部・大学病院）、**御井キャンパス**（文系の学部）。どちらも久留米市内 |
| 創立 | 1928 年（創立者 **溝口喜六**） |
| 建学の精神 | 「**国手の矜持（ほこり）は常に仁なり**」（国手は名医のこと。医の誇りは仁にある） |
| 学部 | **文学部・人間健康学部・法学部・経済学部・商学部・医学部** の 6 学部 |
| 大学院 | 医学研究科、比較文化研究科、心理学研究科、ビジネス研究科（ほかに法務研究科〈法科大学院〉） |
| 校色 | ダークグリーン |
| 校歌 | 作詞 丸山豊、作曲 團伊玖磨 |

- 2028 年に **創立 100 周年**
- 旭町キャンパスの **本館** は、2021 年に国の **登録有形文化財** になった
- 「九大」（九州大学）とまぎらわしいので、略称の「久大」は地元以外ではあまり通じない

## 沿革

| 年 | できごと |
| --- | --- |
| **1928 年** | 福岡県医師会の誘致で、4 年制の **九州医学専門学校** が久留米に開校。初代校長は伊東祐彦 |
| **1946 年** | **久留米医科大学** になる（旧制の大学） |
| **1950 年** | 新制の **久留米大学** になり、**商学部** を開く |
| 1952 年 | 新制の **医学部** を開く |
| 1980 年代後半〜 | 法学部・文学部などを開く |
| 1994 年 | 経済学部を開く |
| 2004 年 | 法科大学院（法務研究科） |
| 2005 年 | ビジネス研究科 |
| 2024 年 | 医学部に **医療検査学科** を開く |
| **2027 年 4 月**（予定） | 文学部と人間健康学部を組みかえる（下） |

- 医科大学に、あとから文系の学部を足して総合大学になった。新制の大学になったとき、最初に開いた学部は医学部ではなく **商学部**（医学部は 2 年あと）

## 学部（2026 年）

| 学部 | 学科 | キャンパス |
| --- | --- | --- |
| **医学部** | 医学科、看護学科、医療検査学科 | 旭町 |
| 文学部 | 心理学科、情報社会学科、国際文化学科、社会福祉学科 | 御井 |
| 人間健康学部 | 総合子ども学科、スポーツ医科学科 | 御井 |
| 法学部 | 法律学科、国際政治学科 | 御井 |
| 経済学部 | 経済学科、文化経済学科 | 御井 |
| 商学部 | 商学科 | 御井 |

- 医学部以外の学科名は、受験情報のサイトなどからまとめたもので、大学のページで一つずつは確かめていない

### 2027 年 4 月の組みかえ（予定）
- 文学部の **情報社会学科・国際文化学科** を合わせて、文学部 **人文科学科**（仮称、定員 150 人。英語コミュニケーション・国際文化・日本文化の 3 コース）にする
- 文学部の **心理学科・社会福祉学科** と、人間健康学部の **総合子ども学科** を、人間健康学部の **心理学科** と **教育・福祉学科**（総合子ども学専攻・社会福祉学専攻）にする
- いずれも構想中で、変わることがある

## 病院と附属の学校

| 名前 | 内容 |
| --- | --- |
| **久留米大学病院** | 旭町にある大学病院。筑後地方の医療の中心 |
| 久留米大学医療センター | もう一つの病院。大学病院との **再編・統合** が進められている |
| **久留米大学附設中学校・高等学校** | 九州でも有数の進学校。東京大学・医学部への合格者が多い |
| 医学部附属臨床検査専門学校 | 臨床検査技師の養成 |
| 研究所・センター | 先端癌治療研究センター、バイオ統計センター、比較文化研究所 など（記憶による） |

## 押さえどころ
- 久留米大学は、**九州医学専門学校**（1928 年）から始まった、福岡県久留米市の私立大学
- 中心は **医学部と久留米大学病院**（旭町キャンパス）。文系の学部は **御井キャンパス**
- 6 学部：文・人間健康・法・経済・商・医
- 2027 年 4 月に、文学部と人間健康学部を組みかえる予定。2028 年に創立 100 周年
