# 総武線の区間と呼び名

**秋葉原より西でも、黄色い電車はふつう「総武線」とよばれる。ただし正式な路線名で「総武本線」なのは御茶ノ水まで。御茶ノ水より西（水道橋〜三鷹）は、正式には中央本線。**

「総武線」という言葉には、**正式な路線名** と、**電車の運転系統の名前** の 2 つの意味がまざっている。

| 区間 | 正式な路線名 | 走る電車 |
| --- | --- | --- |
| 三鷹〜御茶ノ水（中野・新宿・水道橋など） | **中央本線** | 黄色の各駅停車（中央・総武線各駅停車）。オレンジの中央線快速も中央本線を走るが、別の線路。 |
| **御茶ノ水〜秋葉原〜錦糸町** | **総武本線の支線**（錦糸町〜御茶ノ水、4.3 km） | 黄色の各駅停車。 |
| 錦糸町〜千葉〜銚子 | **総武本線**（東京〜銚子、120.5 km） | 黄色の各駅停車（千葉まで）と、総武快速線。 |
| 東京〜錦糸町 | **総武本線**（地下を通る） | 総武快速線と、横須賀線からの直通。 |

- 黄色の電車は、三鷹〜千葉を一つの系統として走る。JR東日本の時刻表での名前は **「中央・総武線各駅停車」**。駅番号はこの系統で通しの **JB**（JB01 三鷹〜JB39 千葉）。
- そのため、秋葉原より西の駅（御茶ノ水、水道橋、飯田橋、四ツ谷、新宿、中野など）でも、黄色い電車を「総武線」とよぶ人が多い。正確には「中央・総武線（各駅停車）」。
- 秋葉原〜御茶ノ水のひと駅分だけは、正式にも総武本線。

## 実際の案内での呼び方
秋葉原より西の駅について、公式の案内を調べた。**確認できた案内は、どれも「総武線」だけではなく「中央・総武線（各駅停車）」と書いている。** 「総武線」だけで秋葉原より西をさす公式の案内は、見つけられなかった。

| 案内 | 表記 |
| --- | --- |
| JR東日本の時刻表（新宿駅・飯田橋駅・御茶ノ水駅） | 「中央・総武線各駅停車」。新宿駅の東行きは「御茶ノ水・千葉方面」。 |
| JR東日本の駅情報（三鷹駅） | 「中央線・総武線各駅停車」、駅番号 JB01。 |
| 東京都交通局（都営新宿線の市ヶ谷駅、大江戸線の東中野駅の乗り換え案内） | 「JR中央・総武線各駅停車」、「JR中央・総武線」。 |
| 東京都の新宿駅の案内サインの表記集 | 「中央・総武線（各駅停車）」、英語は Chuo-Sobu Line (Local)。 |
| 中野区の施設案内（大久保駅） | 「JR中央・総武線」。 |

- 公式の案内は、三鷹〜千葉の通しの系統として「中央・総武線」と書き、中央本線の区間にも「総武」の名前を入れている。
- 「総武線」だけでよぶのは、主に会話や個人の文章での言い方と考えられる。ただし、駅のホームの表示や車内放送、電車の行き先表示まではすべて調べていないので、「総武線」だけの例がまったくないとはいえない。

## まとめ
- **日常の会話で**：秋葉原より西でも「総武線」で通じる。黄色い電車をさす。
- **公式の案内で**：「中央・総武線（各駅停車）」と書く。秋葉原より西を「総武線」だけでよぶ例は、確認できた範囲にはなかった。
- **正式な路線名としては**：御茶ノ水より西は中央本線。「総武本線」は御茶ノ水が西の端。
- 新宿などで「中央線」というと、ふつうはオレンジの **中央線快速** のことになる。黄色い電車と区別するため、黄色を「総武線」とよぶ習慣があると考えられる。
