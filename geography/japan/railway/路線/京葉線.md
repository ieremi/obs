# 京葉線

**東京駅から、東京湾の埋立地に沿って千葉市の蘇我駅まで走る JR東日本の路線。** もとは貨物線として計画された。舞浜（東京ディズニーリゾート）、新浦安、海浜幕張（幕張新都心）などを通り、蘇我から外房線・内房線へ、西船橋から武蔵野線へ直通する電車もある。

| 項目 | 内容 |
| --- | --- |
| 区間 | 本線：東京〜蘇我 43.0 km。支線：市川塩浜〜西船橋 5.9 km、西船橋〜南船橋 5.4 km。 |
| 駅数 | 本線 18 駅（支線の西船橋を除く）。 |
| 駅番号 | JE（JE01 東京〜JE17 千葉みなと）。 |
| 電化・軌間 | 直流 1,500 V、1,067 mm。 |
| 複線 | 全線が複線。 |
| 全線開業 | 1990 年（東京〜新木場の開業）。 |

## 走る電車
- **各駅停車**：東京〜蘇我。
- **快速**：東京〜蘇我。2024 年 3 月の改正で、通勤快速の廃止と朝夕の快速の各駅停車化があり、その後一部が戻された。詳しくは [[京葉線の快速削減問題]]。
- **外房線・内房線への直通**：蘇我から外房線・内房線へ直通する電車がある。
- **武蔵野線への直通**：東京駅から西船橋を通って武蔵野線へ直通する電車がある。2026 年 3 月の改正では、土休日の朝に武蔵野線から東京駅方面への直通が増えた。
- **特急**：外房線の「わかしお」、内房線の「さざなみ」も京葉線を通って東京駅へ入る。

## 歴史

| 年 | 出来事 |
| --- | --- |
| 1967 年 | 京浜工業地帯（川崎）と京葉工業地域（木更津）を結ぶ **貨物線** として工事が始まる。 |
| 1978 年 | 埋立地が工場用地から住宅地に変わってきたため、旅客列車も走らせる計画に変わる。 |
| 1986 年 | 第 1 期として、西船橋〜千葉みなとで旅客営業を始める。 |
| 1988 年 12 月 1 日 | 第 2 期として、新木場〜市川塩浜〜南船橋、市川塩浜〜西船橋、千葉みなと〜蘇我が開業。新木場で営団地下鉄（いまの東京メトロ）有楽町線とつながる。 |
| 1990 年 | 第 3 期として、東京〜新木場が開業し、全線がつながる。 |
| 2024 年 3 月 | ダイヤ改正で通勤快速を廃止し、朝夕の快速を各駅停車にする。沿線の自治体が反発し、同年 9 月に一部を戻す（[[京葉線の快速削減問題]]）。 |

## 千葉の鉄道への影響
- 京葉線ができる前、東京と千葉の間は総武線が主な JR の路線だった。総武線快速（新小岩→錦糸町）の混雑率は、1987 年度に 266% だったが、1991 年度には 237% に下がった。
- 東京メトロ東西線（門前仲町→茅場町）の混雑率も、1987 年の 233% から 1991 年の 196% に下がった。
- 外房線・内房線への特急や電車の一部が、総武本線から京葉線を通るようになり、総武本線に余裕ができた。
- 1988 年に蘇我駅の駅長だった常澄安範さんは「これ（京葉線）がなかったら、総武線はかなり厳しい状況になっていたと思います」と話している。
- りんかい線は、貨物線として計画されたころの京葉線のトンネルを使ってつくられた。

## 構想（2018 年時点）
乗りものニュースの 2018 年の記事は、次の 3 つの構想をあげている。どれも具体的な進展はないとされていた。

- **羽田空港アクセス線**の臨海部ルート：新木場からりんかい線などを通って羽田空港へ。
- **総武線・京葉線接続新線**：新木場〜津田沼。新木場〜市川塩浜を複々線にする用地はすでにある。
- **中央線方面への延伸**：東京駅の京葉線地下ホームから、新宿を通って三鷹で中央線につなぐ。
