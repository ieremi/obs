# 行った場所をログする方法

行った場所を残すには、**訪問先を記録する方法**と、**移動経路を記録する方法**がある。何を後から思い出したいかで選ぶ。

## 方法の比較

| 方法 | 残せるもの | 向いている用途 | 注意点 |
| --- | --- | --- | --- |
| 手動メモ | 日時、場所、目的、感想 | 店・施設の訪問記録 | 書き忘れや時刻のずれ |
| チェックインアプリ | 選択した店・施設への訪問履歴 | 訪問先の一覧化、再訪の振り返り | 操作のし忘れ、場所の選び間違い、公開範囲 |
| 写真 | 風景、撮影日時、位置情報があれば撮影場所 | 旅行や外出の振り返り | 撮影していない場所は残らない |
| 自動の位置履歴 | 推定された訪問先・移動 | 日々の行動の振り返り | 誤認識や欠落、位置情報の権限 |
| GPSロガー | 時刻付きの位置の列、移動軌跡 | 散歩、登山、サイクリング | 電池消費、屋内などでの測位誤差 |

## 1. Obsidianで訪問先を手動記録

まずは日付ノートに **時刻・場所・一言** を残す。頻繁に行く場所は独立した場所ノートにし、内部リンクでつなぐ。

```markdown
## 行った場所

- 10:30 [[場所名]]：展示を見た。次回は午前中に行きたい。
- 12:15 [[店名]]：昼食。注文した料理と感想。
```

地図で再発見できるよう、住所や地図URLも残す。同名の店がある場合は支店名や地域名を付ける。

### 場所ノートのテンプレート

```markdown
---
tags: [場所]
住所:
緯度:
経度:
地図URL:
---
# 場所名

## 訪問履歴

| 日付 | 目的・感想 |
| --- | --- |
| YYYY-MM-DD | 訪問の目的や印象 |

## 写真・メモ

## 次に行くとき
```

日付ノートか場所ノートのどちらを主な記録先にするか決めると、二重記入を減らせる。もう片方にはリンクだけを置いてもよい。

## 2. 写真を手がかりにする

訪問先で看板や風景を撮り、その日のうちに写真を見ながらメモする。

撮影アプリの設定によっては、写真に緯度・経度が保存される。ただし、**写真に位置情報があることと、移動経路全体が記録されることは別**。

写真だけでは目的や感想が伝わりにくいため、一言のメモと組み合わせると振り返りやすい。

## 3. 自動位置履歴を使う

例として、**Googleマップのタイムライン**がある。有効にすると端末の正確な位置情報を定期的に保存し、訪問先や移動を振り返れる。

タイムラインのデータは端末に保存され、暗号化されたバックアップを有効にする選択肢もある。利用できる機能・設定は端末やアカウントによるため、アプリ内で確認する。[Google：タイムラインデータの管理](https://support.google.com/accounts/answer/3118687?hl=ja)

使い始めたら、短い外出で確認する。

1. 位置情報の権限や、バックグラウンドでの動作設定を確認する。
2. 外出後、訪問先と時刻が正しく残ったかを見る。
3. 誤認識を修正し、残したい訪問だけObsidianへ要約する。
4. 保存期間とバックアップ設定を確認する。

自動履歴は推定を含むため、正確な到着・出発時刻の証明としては扱わない。

## 4. GPS軌跡を残す

GPSロガーで、移動開始時に記録を開始し、終了時に停止する。**GPXなどで書き出せるか**を確認すると、後から別のツールで利用しやすい。

日付ノートに軌跡ファイルへのリンクを置き、行程・立ち寄り先・感想を記録する。GPXを地図上に表示するには、対応するアプリやプラグインが必要で、添付するだけでは地図表示になるとは限らない。

長時間の記録では電池残量に注意する。測位の精度や欠落は環境によって変わる。

## 5. チェックインアプリを使う

**訪問した店や施設を選び、「ここに来た」と記録するアプリ**。自動位置履歴が移動や滞在を推定するのに対し、チェックインでは自分で訪問先を選んで記録する。

代表例は **[Swarm by Foursquare](https://swarmapp.com/)**。場所へのチェックインを蓄積して、訪問履歴を振り返れる。[公式ヘルプ：Swarmのチェックイン](https://support.foursquare.com/hc/en-us/articles/21181809706012-Swarm-check-ins)

### 使い方の流れ

1. 訪問先でアプリを開き、近くの場所から店・施設を選ぶ。
2. 同名の店や隣接施設との取り違えがないか確認してチェックインする。
3. アプリが対応していれば写真や短いコメントを添える。
4. 帰宅後、残したい感想や再訪時の注意をObsidianへまとめる。

**チェックインの記録時刻と、実際の到着・出発時刻は必ずしも一致しない**。移動経路を連続して記録したい場合は、自動位置履歴やGPSロガーを併用する。

### 選ぶときの確認項目

| 項目 | 確認すること |
| --- | --- |
| 場所の探しやすさ | よく行く地域や店が登録されているか、支店を区別できるか |
| 振り返り | 地図・日付・場所から履歴を探せるか |
| メモ | 写真やコメントを残せるか |
| 公開範囲 | 自分用に記録できるか、友人や一般ユーザーに何が見えるか |
| 持ち出し | データのダウンロード方法と、日時・場所などの保存内容 |

Swarmにはプライバシー設定があるため、友人への共有や他人からのチェックインへの言及を含めて確認する。Foursquareは個人データのコピーを取得するための案内も公開しているが、**Obsidianへ直接取り込めるとは限らない**。[プライバシーの説明](https://support.foursquare.com/hc/en-us/articles/12534881021212-Privacy-at-Foursquare)、[データへのアクセス](https://foursquare.com/legal/privacy-center/)

### Obsidianとの組み合わせ

チェックインアプリを「訪問した事実の一覧」、Obsidianを「目的・感想・次回のためのメモ」に使うと、長文を二重に書かずに済む。

```markdown
## 訪問ログ

- 場所：[[店名・施設名]]
- 訪問日：YYYY-MM-DD
- チェックイン：アプリ名（共有用リンクがあれば添付）
- 感想：
- 次回：
```

## 続けやすい運用例

**日常は短い手動メモ、旅行や散歩では写真・軌跡を追加**する。

- 外出中：場所名と一言を記録する。
- 帰宅後：写真や自動履歴で書き忘れを補う。
- 定期的に：場所ノートへまとめ、バックアップを確認する。

全移動を保存する必要がなければ、印象に残った訪問だけ記録してもよい。

## 保存と共有

- 地図サービスでの保存と、手元への書き出しは別。長く残したい内容はMarkdownや対応する書き出し形式でも保管する。
- 自宅・職場・通院先など、行動履歴には個人情報が含まれる。公開するノートや軌跡では、必要に応じて場所・時刻を省く。
- 写真を共有するときは、埋め込まれた位置情報の有無も確認する。
