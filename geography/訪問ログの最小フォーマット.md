# 訪問ログの最小フォーマット

訪問先の記録は、**日付ノートに「時刻・場所・一言」を書く**ことから始める。詳しい情報を最初から全部埋めるより、あとで何を思い出したいかを決める。

[[行った場所をログする方法]]には方法の比較がある。このページでは、手動で書く場合の運用を一つに絞る。

## 最小の一行

```markdown
- HH:mm [[場所名]]：したこと。覚えておきたいこと。
```

時刻が分からなければ「昼ごろ」などでよい。正確でない時刻を後から作らない。店舗名が重複するときは「店名 地域・支店名」にする。

以下は架空の記入例。

```markdown
- 14:00 [[市立図書館 中央館]]：地理の棚を見た。次は地域資料室へ。
```

日付は日付ノートの見出し・ファイル名に持たせ、一行ごとに繰り返さない。

## 二度書きを減らす運用

**訪問履歴の本文は日付ノートを記録元とし、場所ノートには基本情報と日付ノートへのリンクを置く。** 同じ感想を二か所に複製しない。

```markdown
# 場所名

住所：
地図URL：

## 訪問した日

- [[2026-10-20]]

## 次に行くとき

- 
```

独立した場所ノートは、再訪したい場所や情報を残したい場所から作る。リンク先がまだない場所は、まず文字だけで記録してもよい。

## 一言に何を書くか

| 後で知りたいこと | 残す内容 |
| --- | --- |
| なぜ行ったか | 用事、展示、散歩などの目的 |
| どうだったか | 印象、頼んだもの、見つけたこと |
| 再訪時に何を変えるか | 時間帯、持ち物、次の目的 |

緯度・経度や写真は必要になったときに追加する。訪問した店の一覧と移動経路は別の記録なので、経路を残したい日はGPSログなどへの参照を添える。

## 今日の記録欄

2026年10月20日の実際の訪問先は未記入。以下を日付ノートへコピーし、訪問後に埋める。

```markdown
## 行った場所

- 時刻／時間帯：場所名：したこと。一言。
```

自宅・職場などを含む記録を共有するときは、ノート本文に加えて写真の位置情報や地図リンクも確認する。
