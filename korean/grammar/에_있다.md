# 韓国語：〇〇에 있다

キー表現：`〇〇에 있다 / 〇〇에 있어요` — 「〇〇にいる／ある」。

| 常体 | 敬体 | 日本語 | 読み |
|---|---|---|---|
| 學校에 있다 | 學校에 있어요 | 学校にいる | `學校`＝학교 |
| 會社에 있다 | 會社에 있어요 | 会社にいる | `會社`＝회사 |
| 病院에 있다 | 病院에 있어요 | 病院にいる | `病院`＝병원 |
| 公園에 있다 | 公園에 있어요 | 公園にいる | `公園`＝공원 |
| 圖書館에 있다 | 圖書館에 있어요 | 図書館にいる | `圖書館`＝도서관 |

名詞だけを交換し、`에` と `있다 / 있어요` は固定。

- [[에_살다]]：韓國에 살아요。— 韓国に住んでいます。
- 에 있다：學校에 있어요。— 学校にいます。

`살다` は**住む**、`있다` は**いる・ある**。`에` が場所を示す感覚を固める。
