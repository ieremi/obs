# 韓国語：〇〇에 살다

キー表現：`〇〇에 살다 / 〇〇에 살아요` — 「〇〇に住む」。

| 常体 | 敬体 | 日本語 |
|---|---|---|
| 韓國에 살다 | 韓國에 살아요 | 韓国に住む／住んでいます |
| 日本에 살다 | 日本에 살아요 | 日本に住む／住んでいます |
| 東京에 살다 | 東京에 살아요 | 東京に住む／住んでいます |
| 釜山에 살다 | 釜山에 살아요 | 釜山に住む／住んでいます |
| 都市에 살다 | 都市에 살아요 | 都市に住む／住んでいます |

名詞だけを交換し、助詞 `에` と動詞 `살다 / 살아요` は固定。
