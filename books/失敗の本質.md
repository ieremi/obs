# 失敗の本質

『失敗の本質――日本軍の組織論的研究』は、日本軍の六つの戦いを事例として、敗北を戦略と組織の両面から分析する共同研究。個々の指揮官の判断だけでなく、組織として情報を扱い、意思決定し、環境の変化に対応する仕組みに目を向ける本である。[出版社の紹介](https://www.chuko.co.jp/bunko/2024/12/207593.html)、[昭和館の目次情報](https://search.showakan.go.jp/search/book/detail.php?material_cord=000031102)

## 扱う六つの事例

本書の事例研究は、次の順に構成される。

1. ノモンハン事件
2. ミッドウェー作戦
3. ガダルカナル作戦
4. インパール作戦
5. レイテ海戦
6. 沖縄戦

続いて、戦略上・組織上の失敗要因を分析し、環境への適応と組織の自己革新という観点から教訓を検討する。[昭和館の目次情報](https://search.showakan.go.jp/search/book/detail.php?material_cord=000031102)

## 中心となる問い

**過去に成功したやり方を、条件が変わっても続けてしまうのはなぜか。**

出版社が掲載する2024年のあとがきの抜粋では、過去の成功体験への過剰な適応が、組織の自己革新を妨げる問題が指摘されている。以前の環境では有効だった行動でも、環境が変われば有効性を失いうる。成功体験そのものに加えて、それを点検・修正する仕組みがあるかが問題になる。[出版社の特設ページ](https://www.chuko.co.jp/special/shippaino-honshitsu/)

## 読むときの観点

以下は、本書の問題設定を手掛かりにした読書用の問い。本文の項目名や結論をそのまま列挙したものではない。

| 観点 | 確認したいこと |
| --- | --- |
| 目的 | 何を達成するための作戦か。複数の目的が競合したとき、優先順位は明確だったか。 |
| 手段と制約 | 兵力・装備だけでなく、補給・輸送・時間の制約を計画に織り込んだか。 |
| 情報 | 不都合な情報も意思決定者に届いたか。希望と事実を区別したか。 |
| 組織間の調整 | 部隊や組織ごとの判断を、全体の目的に結び付けられたか。 |
| 修正と撤退 | 前提が崩れたとき、計画を変更・中止する基準と権限があったか。 |
| 学習 | 結果を検証し、次の行動や制度を変えたか。失敗を個人の責任だけで処理していないか。 |

## 失政とのつながり

[[失政]]の事例を考える際にも、政策の内容と、それを決めて実行する組織の仕組みを合わせて見る手掛かりになる。

たとえば、産業政策の事例では「技術的に実現できるか」に加え、需要・採算・運営責任・撤退条件を誰が検証したかを問える。政策が期待どおりに進まなかった際に、悪い情報を報告できたか、当初の目標を見直せたかも比較の対象になる。

ただし、これは本ノートでの応用であり、本書が個々の産業政策を評価したという意味ではない。また、軍事作戦と行政・企業では目的や制度が異なるため、同じ原因で失敗したと決め付けず、事例ごとに確かめる必要がある。
