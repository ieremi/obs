# Zsh で新しい順にファイルを選ぶ

Zsh の[[programming/Zshのグロブ修飾子|グロブ修飾子]]を使うと、カレントディレクトリの**更新日時が n 番目に新しい通常ファイル**を指定できる。たとえば 3 番目なら次のように書く。

```zsh
vim ./*(.om[3])
```

コマンドを実行すると、Zsh が該当するファイル名に展開する。`3` を `1` にすれば最新、`2` なら 2 番目。これは入力中にファイル名を画面へ補完する操作ではなく、**コマンド実行時の展開**である。

| 部分 | 意味 |
| --- | --- |
| `./*` | カレントディレクトリの名前に一致。先頭に `./` を付けることで、ファイル名が `-` で始まってもコマンドのオプションと混同しにくい |
| `.` | 通常ファイルに限定。ディレクトリとシンボリックリンクそのものは除く |
| `om` | 更新日時（mtime）の新しい順に並べる |
| `[3]` | その結果の 3 番目を選ぶ。Zsh では 1 番から数える |

該当するファイルが 3 個未満なら、通常は `no matches found` エラーになる。既定では隠しファイルは対象外。更新日時が同じファイル同士の順序には頼らない。 [Zsh：グロブ修飾子](https://zsh.sourceforge.io/Doc/Release/Expansion.html)

## 特定のディレクトリと拡張子に絞る

`./out/` にある `.json` の通常ファイルのうち、更新日時が最も新しいものは次のように指定できる。

```zsh
./out/*.json(.om[1])
```

たとえば内容を表示するなら、次のように使う。

```zsh
cat -- ./out/*.json(.om[1])
```

`[1]` が最初、`[2]` が 2 番目。**Zsh のグロブの添字は、通常 1 から始まる。** `KSH_ARRAYS` オプションを使う場合は添字の扱いが変わるため、通常の設定を前提とする。該当ファイルがない場合、Zsh の通常の設定では `no matches found` になる。シンボリックリンクそのものは `.` により対象外。グロブの展開はコマンド実行時に行われる。

## 実行前にファイル名を挿入したい場合

入力中に n 番目のファイル名を**カーソル位置へ挿入する**なら、Zsh Line Editor（ZLE）のウィジェットを使える。次を `~/.zshrc` に追加する。

```zsh
insert-nth-newest-file() {
  local -a files
  local n=${NUMERIC:-1}

  if (( n < 1 )); then
    zle -M '1 以上の番号を指定してください'
    return 1
  fi

  files=(./*(.Nom))
  if (( n > ${#files} )); then
    zle -M "通常ファイルは ${#files} 個です"
    return 1
  fi

  LBUFFER+=${(q)files[$n]}
}

zle -N insert-nth-newest-file
bindkey '^[n' insert-nth-newest-file
```

Zsh を開き直すか、設定を読み込み直す。Emacs キーバインドの場合、次のように使う。

1. たとえば `vim ` と入力する。**ファイル名を入れたい位置は空にしておく。**
2. `Alt+3` を押して数字の引数を指定する。端末によっては、代わりに `Esc` を押して離し、`3` を押す。
3. `Alt+n` を押す。3 番目に新しいファイル名が挿入される。
4. 内容を確認してから Enter で実行する。番号を指定せず `Alt+n` を押すと最新のファイルを挿入する。

`N` は該当ファイルなしの場合に空の配列にする指定、`${(q)...}` は空白や特殊文字を含むファイル名をシェルで扱えるように引用する指定である。これは既存の文字列の途中を置き換える補完ではなく、カーソル位置への挿入なので、途中まで入力したファイル名の続きに使わない。`Alt+n` が端末や既存の設定に使われている場合は、別のキーに変更する。`zle -M` のメッセージも含め、ウィジェットは対話的な ZLE 上で使用する。 [Zsh：ZLE](https://zsh.sourceforge.io/Doc/Release/Zsh-Line-Editor.html)

## 注意

- 「新しい」は**作成日時ではなく更新日時**である。
- 対象は現在のディレクトリ直下の通常ファイル。サブディレクトリの中は検索しない。
- キーバインドや `Alt+数字` の扱いは、Emacs / Vi モード、端末、ユーザー設定により異なる。
- ウィジェットは実行するたびに並べ直す。途中でファイルが更新・追加されると、同じ番号でも別のファイルになることがある。
