# Zed

**Zed** は Rust を中心に開発されているコードエディタ。高速な編集や共同作業、AI エージェントとの連携を特徴とする。ここでは、導入前に確認したい弱点・トレードオフをまとめる。

## 気になるところ

### VS Code の拡張機能をそのまま持っていけない

Zed は独自の拡張機能の仕組みを使い、VS Code の拡張機能をそのまま引き継ぐことはできない。公式の移行ガイドも、拡張機能の数が VS Code より少なく、特に開発運用やコンテナ、テスト関連では同等の代替がない場合があると説明している。[Zed: VS Code からの移行](https://zed.dev/docs/migrate/vs-code)

ただし、Zed にはターミナル、タスク、LSP、共同編集などの組み込み機能もある。「拡張がない＝必ず機能がない」とは限らない。普段使う拡張や言語サーバーを個別に試すのが確実。

### Obsidian の代わりにはならない場合がある

Markdown ファイルを編集できても、Obsidian のバックリンク、埋め込み、Dataview や Community plugin が Zed で同じように動くとは限らない。テキスト編集を Zed、ノート間の操作やプラグインを Obsidian で行うなど、役割を分けるとよい。同じ保管庫を両方で開く場合は同時編集や競合に注意する。

### Linux では GPU・ドライバーに依存する

Linux 版は Vulkan 対応のグラフィック環境を必要とする。古い環境、仮想マシン、ドライバー設定によっては起動や表示に問題が起こり得る。Linux 版の公式トラブルシューティングには、Vulkan 対応デバイスが見つからない場合の説明がある。[Zed: Linux](https://zed.dev/docs/linux)、[システム要件](https://zed.dev/docs/installation)

### 日本語 IME のインライン入力に関する報告

**報告はある。** 2025年10月の [Japanese Linuxers の投稿](https://jlinuxer.org/t/topic/195)では、Zed 0.208 と fcitx で日本語入力の確定が改善した一方、IME の動作が不安定で、変換中のインライン編集ができないと報告されている。ただし、その投稿だけでは X11／Wayland や詳細な構成は明確でなく、現在の版でも同じとは断定できない。

関連する [Zed の Issue #44710](https://github.com/zed-industries/zed/issues/44710) には、Linux・X11・fcitx5・Zed 0.216.1 で、インラインの変換中表示ではなく別ウィンドウが出るという報告もある。これは**ベトナム語 IME の事例**で、日本語固有の証拠ではないが、同系統の表示問題の参考になる。この Issue は2026年4月に活動がないためクローズされており、修正済みを意味しない。

**日本語を確定できること**と、**変換途中の文字列がカーソル位置に表示されること**は別。IME の種類・バージョン、Zed の版、X11／Wayland、エディタ本文かターミナルかで挙動が違う可能性がある。以前の記録では Plasma 5.27・X11 だったが、現在のユーザー環境での再現や修正状況は未確認。Zed とセッションのバージョン、IME の種類、本文・ターミナルそれぞれの挙動を確認する。

### 移行時に設定を見直す必要がある

VS Code の設定は一部取り込めるが、拡張機能やキーバインドは自動では移行されない。慣れた操作、フォーマッター、デバッガー、言語ごとの環境を確認する手間がある。[移行ガイド](https://zed.dev/docs/migrate/vs-code)

### AI 機能は認証・課金・権限が複雑になりやすい

Zed Agent と、Codex のような外部エージェントでは認証や設定の境界が異なる。外部エージェントは一般に独自の認証・モデル・権限を使うため、Zed の API キーや設定がそのまま効くとは限らない。ファイル変更やコマンド実行を許可する前に、対象と権限を確認する。[[Zed から Codex を使う]]、[Zed: External Agents](https://zed.dev/docs/ai/external-agents)

クラウド AI を使うと、入力やコードの文脈が推論先に送られる。保存や学習の扱いは利用経路・提供元・モデルで異なるため、機密情報を扱う前に確認する。AI を使わずエディタとして利用することもできる。[Zed: AI Privacy](https://zed.dev/docs/ai/privacy-and-security)

### 環境による対応差がある

Zed は macOS・Linux・Windows をサポートしているが、Web 版は提供されていない。プラットフォームごとの機能差も確認する。たとえば公式ドキュメントでは、Zed Agent の OS サンドボックスによる制限は Windows ネイティブのコマンドに同じ形では適用できないと説明されている。これは **Zed Agent についての制約**であり、Codex など外部エージェントの権限設定とは分けて確認する。[インストール要件](https://zed.dev/docs/installation)、[Agent Sandboxing](https://zed.dev/docs/ai/sandboxing)

## 判断の目安

- **試す価値が高い**：軽快なコード編集を重視し、必要な言語・ツールが揃っている場合。
- **併用が無難**：VS Code の特定の拡張機能や、Obsidian のノート機能に依存している場合。
- **先に環境を確認**：Linux の GPU／Vulkan 対応、会社の AI 利用・機密情報の方針が気になる場合。

これらは用途やバージョンで変わる。実際の環境での速度・互換性は未検証。
