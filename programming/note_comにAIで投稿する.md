# note.com に AI で投稿する

**2026 年 11 月の時点で、個人がだれでも使える note の公式投稿 API は公開されていない。** 方法は大きく 4 つある。

| 方法 | 公式か | できること | 向いている人 |
| --- | --- | --- | --- |
| ① note AI アシスタント | 公式 | エディタ内で誤字の検出、相談、炎上リスクの確認 | 自分で書き、AI に手伝わせたい人 |
| ② AI で書いてコピペ | ― | Claude などで下書きし、note のエディタに貼る | ほとんどの個人 |
| ③ note API（提携サービス経由） | 公式 | 外部サービスから note に **下書き** を送る | note pro を使う法人・団体 |
| ④ 非公式 API・ブラウザ自動操作 | 非公式 | 投稿・下書き・閲覧を自動化 | 壊れても自分で直せる人 |

## ① note AI アシスタント（公式）
- note のエディタに組み込まれた AI 機能。2023 年 2 月に β 版として始まり、2025 年 3 月に Google の Gemini を使う形に更新された。
- いまの主な機能は、本文の誤字・表記ゆれの検出と修正案の反映、チャットでの相談である。note pro の利用者は、炎上リスクをワンクリックで確認できる。
- Web ブラウザと Android アプリで使える。
- 公式のヘルプ：[note AIアシスタントについて](https://www.help-note.com/hc/ja/articles/15386354993561)、[利用条件](https://www.help-note.com/hc/ja/articles/15386417475481)。

## ② AI で書いて、手で貼る
- Claude などに Markdown で下書きを作らせ、note のエディタに貼り付けて見出しや画像を整える。
- 公開ボタンは自分で押すので、規約上の心配がなく、いちばん確実である。
- Obsidian で下書きを管理し、できたものを note に貼る流れにすると、このボールトと相性がよい。

## ③ note API（公式・提携向け）
- note 社は外部サービス向けに「note API」を提供している。2026 年 10 月 8 日に、AI 創作支援サービスの StoryHub が、これを使った投稿連携を始めたと発表した。
- できるのは **note への下書きの送信まで** である。公開するかどうかは note の画面で最終確認して決める。有料記事や埋め込みなどは、最初のリリースでは対応していない。
- 対象は **note pro を使う法人・団体** で、事前の連携設定がいる。
- 個人の開発者が直接この API を申し込めるという情報は、見つからなかった。
- 出典：[StoryHub、noteへの投稿連携機能の提供を開始（PR TIMES）](https://prtimes.jp/main/html/rd/p/000000065.000133529.html)、[同（ORICON NEWS）](https://www.oricon.co.jp/pressrelease/3027859/)。

## ④ 非公式 API・ブラウザ自動操作
- note の Web 画面は内部で `note.com/api/...` という API を呼んでいる。これをログイン時の Cookie で直接たたく方法が、個人の開発記事で紹介されている。ただし仕様は公開されておらず、認証まわりの変更で動かなくなった例（CSRF トークンのエラーなど）も報告されている（[Zenn の開発日記](https://zenn.dev/centervil/articles/2025-04-23_054_dev-diary)）。
- Claude から note を操作する **MCP サーバー** も個人が作っている。
  - [note-com-mcp](https://glama.ai/mcp/servers/@shimayuz/note-com-mcp/blob/d8a12a82cd1ac18294125b251e690640b810031f/README.md)：非公式 API で、記事の閲覧・投稿やユーザー情報の取得をする。
  - [note-post-mcp](https://lobehub.com/en/mcp/nullponull-note-post-mcp)：Markdown ファイルからタイトル・本文・タグ・価格を読み、Playwright でブラウザを動かして投稿する。
- 注意点
  - note 社が保証していないので、いつ壊れてもおかしくない。
  - ログイン情報（Cookie）を外部のツールに渡すことになるので、中身を読んでから使う。
  - 大量の自動投稿は、規約違反やアカウント停止につながるおそれがある。使う前に note の利用規約を確かめる。
  - 自動でいきなり公開せず、**下書きまでにして、公開は手で行う** のが安全である。

## まとめ
- ふつうに使うなら、② AI で下書き → 手で貼って公開、が確実である。
- エディタ内で手伝わせるだけなら ① の AI アシスタントで足りる。
- 自動化したい場合、公式の道は ③（note pro の法人向け）だけで、個人なら ④ の非公式な方法になる。
