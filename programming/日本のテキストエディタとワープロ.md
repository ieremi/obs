# 日本のテキストエディタとワープロ

日本のパソコンでは、MS-DOS 時代の PC-9801 から Windows 時代にかけて、日本語の入力や文書作成に対応した多様なエディタ・ワープロが使われた。以下には、プレーンテキストを主に扱う**テキストエディタ**だけでなく、書式や印刷を扱う**ワープロ**も含む。

## 時代と関係

### MS-DOS 時代

PC-9801 などでは、日本語を扱えるエディタが、プログラムだけでなく文章の作成にも使われた。1985年の **MIFES** と1989年の **VZ Editor** は代表例で、価格・速度・マクロなどが比較された。**松**は同じ時代の日本語ワープロで、エディタとは主目的が異なる。[MIFES と VZ の歴史](https://news.mynavi.jp/article/20110912-mifes9/)

VZ Editor 1.6 のソースコードは2024年に公開された。これは MS-DOS 向けの歴史的なソフトウェアの公開であり、現在の Windows 用エディタがそのまま提供されたという意味ではない。[公開リポジトリ](https://github.com/vcraftjp/VZEditor)、[公開の報道](https://www.itmedia.co.jp/pcuser/articles/2411/26/news198.html)

### Windows 時代

MIFES は Windows 版にも展開し、**秀丸エディタ**、**EmEditor**、**TeraPad** などの Windows 用エディタも使われた。**WZ EDITOR** は VZ と同じビレッジセンターから発売されたが、両者を同一のプログラムや作者による単純な Windows 移植と見なさない方がよい。

**松風**は DOS の松と同じ管理工学研究所の製品だが、ショートカットキーなど一部を除き、従来の松とは互換性がないと当時紹介された。**ORGAI** もワープロであり、プレーンテキスト中心のエディタとは区別できる。
