# 一太郎の Esc メニュー

一太郎の**Esc メニュー**は、`Esc` キーで表示し、キーボードでコマンドを選ぶ階層型メニュー。最初のメニューから項目のアクセスキーを押し、次の階層が表示されたら、さらにキーを押して操作を選ぶ。矢印キーでも選択できる。[ジャストシステム：ESCメニューからコマンドを選択する](https://support.justsystems.com/faq/1032/app/servlet/qadoc?QID=039127)

例えば、一太郎の公式サイトには、`Esc` → `C` → `C` でコピーする単位の指定に進む操作が紹介されている。その後、範囲やコピー先を指定する。[一太郎Web：貼り付け回数を指定する](https://www.ichitaro.com/0206/tech/n_121.html)

メニューを見ながら操作でき、キーの並びを覚えればキーボードから手を離さずにコマンドを呼び出せる。通常のドロップダウンメニューとは構成やコマンドが異なる。ジャストシステムは、JW版一太郎の操作に慣れた人にも便利なメニューとして説明している。[ジャストシステム：用語解説](https://support.justsystems.com/faq/1032/app/servlet/qadoc?QID=039327&popup=true)

## KRunner・Spacemacsとの関係

直前のキーに応じて次の操作候補を表示し、順にキーを押すという点では、Spacemacsのリーダーキーによる操作に近い。[[KRunner]]は検索語を入力して候補を選ぶ仕組みなので、Esc メニューのような階層をたどる操作とは異なる。[[Stream Deck]]のボタンも操作の呼び出しに使えるが、押す対象はあらかじめ割り当てたボタンである。

一太郎のバージョンや設定によって、Esc メニューの有効化やキー操作が異なる場合がある。上記サポートページは2008年の情報なので、使用中のバージョンでも確認する。
