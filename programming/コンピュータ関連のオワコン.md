# コンピュータ関連のオワコン

かつて広く使われたものの、後継技術の普及や環境の変化によって出番が減った、コンピュータ関連の技術・製品をまとめるページ。

「オワコン」は「終わったコンテンツ」の略で、技術的な分類ではない。このページでは、**サポート終了・用途の縮小・主流からの交代**を具体的に記録する。分類や評価は本ノートの整理であり、製品提供元の公式な呼称ではない。

## サポート終了が明確な例

| 技術・製品 | かつての役割 | 終了・交代の内容 |
| --- | --- | --- |
| Adobe Flash Player | ブラウザー上の動画・ゲーム・アニメーションなどの実行 | Adobeは2020年12月31日にサポートを終了。HTML5・WebGLなどのWeb標準への移行を案内した |
| Internet Explorer 11のデスクトップアプリ | Web閲覧、企業内の業務システムへのアクセス | 一部のWindows 10で2022年6月15日にサポート終了。旧サイトの互換性にはMicrosoft EdgeのIEモードを案内 |
| [[AltaVista]] | 1995年に始まった初期の代表的な検索エンジン、Web翻訳のBabel Fish | Yahoo!が2013年7月8日に終了。Babel Fishは2012年にBing Translatorへ置き換え |

[Adobe：Flash Playerの終了案内](https://www.adobe.com/products/flashplayer/end-of-life.html)、[Adobe：Web標準への移行方針](https://blog.adobe.com/adobe-flash-update/)、[Microsoft：IE11のサポート終了対象](https://learn.microsoft.com/en-us/lifecycle/announcements/internet-explorer-11-end-of-support)

Flashコンテンツ自体の保存や、IE向け業務システムの互換運用は、一般向け実行環境のサポート終了とは別の問題。特にIEはOSの版やコンポーネントによって扱いが異なるため、「すべてのIE関連機能が同日に終了した」とはしない。

## DOS・旧Windowsの環境に依存するもの

| 用語 | 当時の役割 | 現在の位置付けとしての整理 |
| --- | --- | --- |
| [[QBasic]] | DOS上でBASICを編集・実行する入門用の開発環境 | 旧環境の学習・プログラムの保存や再現の対象。現代の一般的なアプリ開発環境とは用途が異なる |
| [[SMARTDrive]]（smartdrv） | RAMを使ってディスクアクセスを高速化 | DOS・Windows 3.xなどの旧環境の性能改善を理解するための技術 |
| [[バックアップ起動ディスク]]（フロッピー） | 内蔵ディスクから起動できない場合の復旧の入口 | フロッピーという媒体の出番は縮小。一方、別媒体から復旧環境を起動する考え方は、回復ドライブなどに続いている |
| [[Tweak UI]] | Windows 95〜XPの隠し設定を画面から変えるPowerToys | Vista以降の版は出ていない。2019年に復活したPowerToysは別物で、同じ役割はサードパーティのツールが担う |
| [[Microsoft Plus!]] | Windows 95〜XPに足す有料の追加パック（テーマ、ゲーム、IE 1.0など） | 多くの機能は次のWindowsに標準で入った。Vistaのアルティメット エクストラを最後に、Windows 7で廃止 |

この分類は、各ページで説明する動作環境と用途に基づく。**製品が古くなっても、インタープリター・キャッシュ・復旧環境という仕組みまで不要になったわけではない。** [Microsoft：現在のWindowsのバックアップ・復旧機能](https://support.microsoft.com/en-us/windows/experience/backup-recovery/backup-restore-and-recovery-in-windows)

## 古さだけで終了扱いできないもの

| 用語 | 終了扱いできない理由 |
| --- | --- |
| [[CAB]] | Windows Installerなどで使う格納形式として、Microsoftが仕様・利用方法を公開している。一般利用者が直接操作する機会の少なさと、形式の利用終了は別 |
| [[CuteFTP]] | 商用のファイル転送クライアントとして公式製品ページが存在する。昔からある製品というだけでは、販売・開発終了の根拠にならない |
| [[FFFTP]] | 公式リポジトリでソースコード・リリースを公開している。GUIでのファイル転送という用途があり、「FTPという名前だから終了」とは判断できない |

[Microsoft：Cabinet Files](https://learn.microsoft.com/en-us/windows/win32/msi/cabinet-files)、[CuteFTP公式](https://www.globalscape.com/cuteftp)、[FFFTP公式リリース](https://github.com/ffftp/ffftp/releases)

また、暗号化のないFTPと、FTPS・SFTPは区別する。ファイル転送という用途が続いていても、接続方式や運用方法は変わりうる。

## 携帯音楽プレーヤーのブランド

- [[Rio Player]]：初期の携帯MP3プレーヤーの代表例。2005年にRio事業からの撤退が発表された。[当時の報道](https://av.watch.impress.co.jp/docs/20050826/rio.htm)
- [[iRiver]]：2000年代の携帯プレーヤーで知られるが、2012年にはAstell&Kernへ展開した。過去の製品群と、その後の事業を分けて見る。[公式沿革](https://www.astellnkern.com/en/about/index.php)

## 主流から退く理由

- **役割の内蔵化**：外付けのツールの機能が、OSや別の基盤に組み込まれる。
- **標準への置き換え**：特定製品への依存が、複数の環境で使える標準技術に置き換わる。
- **媒体・機器の交代**：フロッピーなどを読み書きする装置自体が減り、別の媒体に移る。
- **保守の終了**：修正や更新が提供されなくなり、新しい環境への移行が必要になる。
- **操作方法の変化**：手動で行っていた作業が、同期・自動配備・クラウドサービスなどに移る。

個別の技術を評価するときは、「何が終わったのか」「何に置き換わったのか」「どこではまだ必要か」を併せて記録すると、単なる懐かしい用語の一覧より変化を理解しやすい。
