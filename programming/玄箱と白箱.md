# 玄箱と白箱

**2000年代半ばに流行した、HDDを自分で組み込むNAS（ネットワーク接続のファイルサーバー）キット。** 中身が小さなLinuxマシンだったので、NASとしてだけでなく、格安で省電力の自宅サーバーとして改造して使う人が多かった。

| 呼び名 | 正式な製品名 | ブランド | 発売 |
| --- | --- | --- | --- |
| **玄箱**（くろばこ） | 玄箱（KURO-BOX） | 玄人志向 | 2004年2月 |
| **白箱**（しろばこ） | LAN Tank | 挑戦者（アイ・オー・データ系） | 2005年6月 |

「玄箱」は玄人志向の「箱」が名前の由来。表記は「黒箱」ではなく「玄箱」。「白箱」はLAN Tankの開発コードで、玄箱への対抗を意識した呼び名。開発者自身は「素箱」と呼んでいたともいう。

## 玄箱

### 特徴

- HDDなしのキットで、余った3.5インチHDDを入れてNASを作る。この形が受けて、他社も同様の製品を出すきっかけになった。
- 中身はLinuxで、開発環境も用意されていた。Debianなどに入れ替えて、Webサーバーやファイルサーバーとして使う例が広がった。
- ベースはバッファローのLinkStation（HD-LANシリーズ）。初期の筐体は、LinkStationのケースを黒く塗ったものだった。

### 経緯

| 時期 | 出来事 |
| --- | --- |
| 2004年2月 | 初代を発売。生産が追いつかず品薄になり、予約を打ち切る販売店や、オークションでの転売が出た。 |
| 2004年9月 | 筐体を玄箱専用の設計に切り替え、品不足が解消。海外向けに「KURO-BOX」も発売。 |
| 2005年12月 | ACアダプタ仕様のKURO-BOXX / KURO-BOX/HGXを限定販売。電源基板の分の空洞に自作基板を載せる改造が楽しまれた。 |
| 2007年2月 | 玄箱/PROを発売。CPUがPowerPCからARMに変わる。 |
| 2008年11月 | 4ドライブのKURO-NAS/X4を発表。 |
| 2009年9月 | KURO-BOX/T4を発売。ファームウェアは素のDebianで、NASとしての設定は利用者が行う。 |

### モデル別の仕様

| モデル | CPU | メモリ | LAN | HDD | その他 |
| --- | --- | --- | --- | --- | --- |
| 玄箱 | PowerPC 200MHz | 64MB | 100BASE-TX | 3.5インチ×1（IDE） | USB 2.0×1 |
| 玄箱/HG | PowerPC 266MHz | 128MB | 1000BASE-T | 3.5インチ×1（IDE） | USB 2.0×2 |
| 玄箱/PRO | ARM9 400MHz | 128MB | 1000BASE-T | 3.5インチ×1 | SATA×2、PCIe x1、フラッシュ256MB |
| KURO-NAS/X4 | ARM9 500MHz | 128MB | 1000BASE-T | 3.5インチ×4（SATA） | ラックマウント型NASがベース |
| KURO-BOX/T4 | PowerPC（MPC8241）266MHz | 128MB | 1000BASE-T | 3.5インチ×4（SATA） | Debian、シリアルコンソール必須 |

### 改造の文化

- **Debian化**：標準のLinuxをDebianに入れ替える。自宅サーバーの定番だった。
- **シリアルコンソール**：携帯電話（mova）用のシリアル変換ケーブルを、RS-232Cのレベル変換に流用する方法が発見されて広まった。
- **クロックアップ**：2007年7月に、玄箱/PROのCPUを500MHzで動かす方法が公式ページに載った。ただし400MHz品のCPUなので、仕様外のオーバークロックになる。
- **既知の問題**：時計がずれる、HDDの起動待ちが不十分で起動に失敗する、など。電源ボタンを2度押すといった対処法が出回った。

## 白箱（LAN Tank）

| 項目 | LAN Tank（SOTO-HDLWU） | 後継：GLAN Tank（SOTO-HDLGW） |
| --- | --- | --- |
| 発売 | 2005年6月 | 2006年1月 |
| CPU | SH-4 266MHz | XScale 400MHz |
| メモリ | 64MB | 128MB |
| LAN | 100BASE-TX | 1000BASE-T |
| HDD | 3.5インチ×2（IDE）、スパンニング・ミラーリング対応 | |
| OS | Debian GNU/Linux | |

- 最初からDebianを採用し、改造を前提にした玄箱への対抗商品だった。
- iTunesから見える音楽サーバー（mt-daapd）などを標準で組み込んでいた。
- GLAN TankはCPUがSH-4からXScaleに変わったため、LAN Tank用のソフトはそのままでは動かない。

## 押さえどころ

- 玄箱・白箱の流行は、安くて小さいLinuxマシンが少なかった時代の自宅サーバー文化の一部。のちにRaspberry Pi（2012年）などのシングルボードコンピュータや、[[Synology]]などの完成品のNASにその役割を譲った。
- 「玄人志向」はバッファロー系の、「挑戦者」はアイ・オー・データ系のブランド。どちらも、サポートを最小限にして安く売る、玄人向けの路線。
- 玄箱は、KURO-BOX/T4以外はすべて販売を終えている。
