# Microsoft Plus!

**Windowsに後から足す、Microsoftの有料の追加パック。** テーマ、スクリーンセーバー、ゲーム、便利ツールなどが入っていた。Windows 95からXPまで出て、多くの機能は次のWindowsに標準で組み込まれた。

| 項目 | 内容 |
| --- | --- |
| 発表 | 1994年1月31日。開発コード名は「Frosting」（ケーキの砂糖衣。Windowsの上に塗るもの、という意味） |
| 最初の製品 | Microsoft Plus! for Windows 95（1995年、Windows 95と同時期） |
| 最後の製品 | Plus! SuperPack for Windows XP（2004年） |
| 後継 | Windows VistaのUltimate Extras。Windows 7で廃止。 |

[[Tweak UI]]などのPowerToysが無料・サポートなしだったのに対し、Plus!は**有料でサポートのある製品**だった。

## 製品の一覧

| 製品 | 発売 | 対象 | 性格 |
| --- | --- | --- | --- |
| **Plus! for Windows 95** | 1995年 | Windows 95 | テーマとシステムの強化 |
| Plus! for Kids | 1997年 | Windows 95 | 3〜12歳の子ども向け |
| **Plus! 98** | 1998年6月 | Windows 98 | テーマ、ゲーム、ツール |
| Plus! Game Pack: Cards & Puzzles | 2000年ごろ（Windows Meのころ） | Windows 95〜2000 | ゲームだけ |
| **Plus! for Windows XP** | 2001年10月25日 | Windows XP | テーマ、音楽、ゲーム |
| Plus! Digital Media Edition | 2003年1月7日 | Windows XP | 写真・音楽・動画のツール |
| Plus! SuperPack for Windows XP | 2004年10月19日 | Windows XP | XP用の2製品をまとめたもの。新機能なし。 |

## Plus! for Windows 95

アメリカでの価格は49.99ドル。いちばん有名な版で、「Plus!」といえばこれを指すことが多い。

| 分類 | 内容 |
| --- | --- |
| **デスクトップのテーマ** | 壁紙、アイコン、マウスポインター、効果音、スクリーンセーバーをまとめて切り替える仕組みと、12種類のテーマ（Dangerous Creatures、Inside Your Computer、Leonardo da Vinci、Mystery、Sports、The 60's USA など） |
| 見た目の強化 | **フォントのアンチエイリアス**（文字のギザギザをなめらかにする）、ウィンドウの中身を表示したままドラッグ、壁紙の拡大表示、ハイカラーのアイコン |
| **3D Pinball for Windows - Space Cadet** | ピンボールゲーム。Maxisの「Full Tilt! Pinball」の1台を移植したもの。 |
| **DriveSpace 3**・Compression Agent | ディスクの圧縮。HDDが数百MBの時代には、容量を増やす手段として使われた。 |
| **System Agent** | 決まった時刻にデフラグやスキャンディスクを動かすスケジューラー。空き容量が減ると警告する。 |
| **Internet Jumpstart Kit** | **Internet Explorer 1.0**を最初に収録した。インターネット接続の設定ウィザードも入っていた。 |
| ダイヤルアップサーバー | 電話回線経由で、外からこのPCに接続させる機能 |
| ダイヤルアップのスクリプト | プロバイダーへの接続手順を自動化する |

### その後どうなったか

- **Internet Explorer**：Plus!から始まり、OSに組み込まれていった。これが後の独占禁止法訴訟（ブラウザーのOSへの抱き合わせ）につながる。
- **テーマ、アンチエイリアス、ドラッグ表示など**：Windows 98ではすべて標準になった。
- **Space Cadet Pinball**：Windows NT 4.0、2000、Me、XPに標準で入った。Vistaで消えたのは、64ビット版に移植したときに衝突判定の不具合が出て、直せる人がいなかったため（チェンがブログで説明している）。
- **System Agent**：のちの「タスク スケジューラ」になった。
- **DriveSpace**：HDDの大容量化とFAT32で不要になり、Windows Me以降は消えた。

## Plus! for Kids

Windowsのチームではなく、家庭向けソフトの部門が作った子ども向けの版。

| ソフト | 内容 |
| --- | --- |
| Talk It! | 打った文字を読み上げる |
| Play It! | 画面の鍵盤で演奏する |
| Paint It! | 子ども向けのお絵かき |
| Protect It! | 保護者が使えるソフトを制限する |

テーマのうち4つ（Baseball、Jungle、Space、Underwater）は、Windows 98とMeに標準で入った。

## Plus! 98

| 分類 | 内容 |
| --- | --- |
| テーマ | 18種類。漫画の「ガーフィールド」や「FoxTrot」を使ったものもあった。 |
| スクリーンセーバー | 3Dの「Organic Art」 |
| ゲーム | **スパイダソリティア**、Lose Your Marbles、Microsoft Golf 1998 Lite |
| ツール | **圧縮フォルダー**（ZIPをフォルダーのように開く）、Deluxe CD Player（CDDBで曲名を取得）、Picture It! Express、ディスククリーンアップの強化 |
| ウイルス対策 | McAfee VirusScan 3.0（6か月分の更新つき） |

スパイダソリティアと圧縮フォルダーはWindows Me以降に、Deluxe CD PlayerはWindows 2000に標準で入った。

## Plus! for Windows XP

「The Ultimate Companion for Windows XP」とうたった。中心は音楽と見た目。

| 分類 | 内容 |
| --- | --- |
| テーマ・スクリーンセーバー | Aquarium、Nature、Da Vinci、Space などのテーマと3Dスクリーンセーバー |
| 音楽 | Windows Media Playerの声での操作、Personal DJ（好みに合わせた選曲）、MP3 Converter、CD Label Maker、スキン、視覚エフェクト |
| ゲーム | HyperBowl、Russian Square、Labyrinth |

**Digital Media Edition**（2003年）はテーマやゲームをやめ、写真・音楽・動画のツールに絞った。Photo Story 2、アナログレコードの録音（Analog Recorder）、Movie Maker 2の効果などが入る。Plus!で初めて**ダウンロード販売**され、唯一**ライセンス認証**が必要な版だった。

## 押さえどころ

- Plus!は「次のWindowsに入る機能の先行販売」に近かった。テーマ、IE、圧縮フォルダー、スパイダソリティアなど、今では当たり前の機能がここから出ている。
- 1995年にIE 1.0を収録したことは、ブラウザー戦争とOSへの組み込みの出発点として歴史的な意味がある。
- XPの時代には目玉が見た目と音楽に移り、新しさが薄れた。Vistaの「Ultimate Extras」に引き継がれたが、中身が少ないと不評で、Windows 7でなくなった。
