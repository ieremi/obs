# Dynalist と Obsidian の違い

**Dynalist は、階層的な箇条書きを操作するアウトライナー。Obsidian は、ローカルの Markdown ファイルを編集し、ノート同士を結びつけるアプリ。** 両方で箇条書きやリンクを使えるが、何を中心に扱うかが違う。

両者は同じ開発者たちにゆかりがある。Dynalist のあとに Obsidian が生まれたが、Obsidian は Dynalist の新しい版ではなく、別の製品である。 [[programming/Obsidianの歴史|Obsidian の歴史]]

## 比較

| 項目 | Dynalist | Obsidian |
| --- | --- | --- |
| 中心となるもの | 階層をもつ箇条書きの項目 | フォルダ内の Markdown ファイル |
| 整理の仕方 | 項目を入れ子にし、折りたたんだり、ある項目にズームしたりする | ファイルやフォルダ、リンク、タグなどで整理する |
| 得意なこと | 箇条書きを組み替えながら、考えやタスクを階層的に整理する | 文章や資料をノートに書き、関連するノートをリンクでつなぐ |
| 保存 | Dynalist のサービスを中心に保存・同期。デスクトップアプリにはローカルのコピーもある | 保管庫内のローカルファイルに保存。同期は必要に応じて別途設定する |
| オフライン | デスクトップアプリはローカルのコピーを保持する。同期できない間の変更には注意が必要 | 基本的なノートの読み書きはオフラインでできる |
| ブラウザ | ウェブアプリを使える | 通常の編集はデスクトップ・モバイルアプリを使う |
| 拡張 | API や、一部有料のカスタマイズ機能がある | コミュニティプラグインやテーマで広く拡張できる |
| 共有 | 文書の共有・共同編集が無料プランに含まれる | 有料の Obsidian Sync で共有保管庫を使える。ほかの同期手段を選ぶこともできる |
| データの取り出し | 文書を HTML、プレーンテキスト、OPML で書き出せる | ノートはすでに Markdown ファイル。固有の記法やプラグインの機能は移行先で再現されないことがある |

Dynalist も Markdown 風の書式や内部リンクに対応する。Obsidian でもリストを折りたたんだり、プラグインでアウトライナー的な操作を補ったりできる。ただし、標準の使い心地は同じではない。 [Dynalist のアウトライナー入門](https://help.dynalist.io/article/129-outliner-101) · [Dynalist の機能](https://dynalist.io/features/full) · [Dynalist の書き出し](https://help.dynalist.io/article/81-export-list-or-document) · [オフライン時の注意](https://help.dynalist.io/article/111-my-dynalist-is-having-trouble-syncing-to-the-server)

## 料金

- **Dynalist**：無料プランでも項目・文書を無制限に作成できる。Pro は年払い換算で月 7.99 米ドル、月払いで月 9.99 米ドル。添付ファイル、履歴、自動バックアップなどが加わる。 [Dynalist の料金](https://dynalist.io/pricing)
- **Obsidian**：アプリ本体は商用利用を含め無料。公式の同期サービス Sync や公開サービス Publish は別途有料。Sync は年払い換算で月 4 米ドル、月払いで月 5 米ドル。 [Obsidian の料金](https://obsidian.md/pricing)

料金は変更されることがある。

## どちらを選ぶか

- **項目を細かく分解し、順番や階層を頻繁に組み替えたい** → Dynalist。
- **長い文章や資料をファイルとして保存し、ノート間の関係を育てたい** → Obsidian。
- **両方ほしい** → Dynalist で構想やタスクを整理し、まとまった内容を Obsidian に移す使い分けもできる。移行時にはリンクやチェック状態などがそのまま再現されるとは限らないため、少量で試すとよい。
