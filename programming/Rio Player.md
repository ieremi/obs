# Rio Player

**パソコンの音楽ファイルを持ち出して聴く、携帯デジタル音楽プレーヤーのブランド・製品群。** 初期の代表機種は、Diamond Multimediaが1998年に発売した **Rio PMP300**。単一のアプリの名前ではなく、ここでは携帯プレーヤーのRioシリーズを指す。[Powerhouse博物館：Rio PMP300](https://collection.powerhouse.com.au/object/433545)

## Rio PMP300

| 項目 | 内容 |
| --- | --- |
| 発売年 | 1998年 |
| メーカー | Diamond Multimedia |
| 基本的な用途 | パソコンから転送したMP3音声を携帯して再生 |
| 内蔵記憶容量 | 32MB |
| 記憶媒体 | フラッシュメモリ |

CDやカセットを入れて聴く機器とは異なり、音声をファイルとして内蔵メモリに保存する。**携帯MP3プレーヤーが普及する初期の代表例**であり、「世界初」とは区別して記述する。[Powerhouse博物館](https://collection.powerhouse.com.au/object/433545)、[Computer History Museum：Rio PMP300](https://www.computerhistory.org/revolution/memory-storage/8/256/1007)

## 32MBには何曲入るか

収録時間は圧縮のビットレートで変わる。たとえば128kbpsの音声なら、1分あたり約0.96MBなので、32MBには計算上約33分入る。4分の曲なら約8曲に相当する。管理領域などを除いた概算であり、曲数が固定されているわけではない。

## 事業の終了

Rio事業は所有企業の変遷を経てD&Mの傘下となり、**2005年に携帯MP3プレーヤー事業から世界的に撤退する方針が発表された**。これはRioの事業の終了であり、音楽ファイルを携帯機器で再生する仕組み自体の終了ではない。[当時の報道：D&M、MP3プレーヤー「Rio」事業から全世界的に撤退](https://av.watch.impress.co.jp/docs/20050826/rio.htm)

## iRiverとの関係

[[iRiver]]も同時代の携帯デジタル音楽プレーヤーで知られるブランドだが、Rioとは別のブランド。両者は、パソコンに保存した音楽を専用機器へ転送して持ち歩く時代を振り返る手掛かりになる。
