# 修飾キー

Shift、Control、Meta、Super、Hyper は、ほかのキーと組み合わせて使う**修飾キー**の名前である。ただし、物理キーの名前、USB のキーコード、OS やアプリでの呼び名は、必ずしも一対一ではない。

| 名 | キーコード（USB HID Usage ID） | マスク（USB HID） | Mac | Linux | Windows |
| --- | --- | --- | --- | --- | --- |
| Shift | 左 `0xE1`、右 `0xE5` | 左 `0x02`、右 `0x20` | Shift ⇧ | Shift | Shift |
| Control | 左 `0xE0`、右 `0xE4` | 左 `0x01`、右 `0x10` | Control ⌃ | Ctrl | Ctrl |
| Meta | **専用の固定コードなし** | 固定マスクなし | 文脈によって Command ⌘、または Emacs の Option ⌥ など | デスクトップでは GUI キー、Emacs では Alt など、環境による | アプリによって Windows ロゴキーを Meta と呼ぶことがある |
| Super | **専用の固定コードなし** | 固定マスクなし | 通常 GUI キーが Command ⌘ として扱われる。Emacs では Command を Super に割り当てることがある | GUI キーを Super と呼ぶことが多い | GUI キーは通常 Windows ロゴキーとして扱われる |
| Hyper | **専用の固定コードなし** | 固定マスクなし | 通常は専用キーがなく、対応アプリなどで割り当てる | 通常は専用キーがなく、キーマップなどで割り当てる | 通常は専用キーがなく、別途割り当てが必要 |

## キーコードの見方

表の `0xE0` などは、**USB HID の Usage ID** である。USB HID には左右の Shift、Control、Alt、GUI が定義されているが、Meta・Super・Hyper という名前の独立した標準修飾キーはない。これらは OS やアプリが別のキーを解釈したり、設定で割り当てたりする。 [USB HID Usage Tables](https://www.usb.org/sites/default/files/hut1_3_0.pdf)

参考として、Alt と GUI の Usage ID も載せる。

| キー | 左の Usage ID | 左のマスク | 右の Usage ID | 右のマスク |
| --- | --- | --- | --- | --- |
| Alt | `0xE2` | `0x04` | `0xE6` | `0x40` |
| GUI | `0xE3` | `0x08` | `0xE7` | `0x80` |

`GUI` は、通常 Mac では Command、Windows では Windows ロゴキー、Linux では Super として扱われる。たとえば Sayo Device で `LeftGUI` を設定すれば、同じ HID の `0xE3` が送られ、接続先の OS がそれぞれ解釈する。設定変更や機種による例外はある。 [Ubuntu：Super キー](https://help.ubuntu.com/stable/ubuntu-help/keyboard-key-super.html)

標準的な HID キーボードの通信では、修飾キーは Usage ID の数値を通常キーの配列へそのまま送るのではなく、修飾キーバイトの各ビットで表す。また、この Usage ID は Windows の仮想キーコードや Linux・macOS の内部コードとは別の体系である。 [USB HID 仕様](https://www.usb.org/sites/default/files/hid1_12.pdf)

マスクは、修飾キーバイト内で該当するビットを示す値。たとえば左 Control と左 Shift を同時に押すと、`0x01` と `0x02` の両方が立ち、値は `0x03` になる。Meta・Super・Hyper のマスクは、それぞれに割り当てられた物理キーによって変わる。

## Meta と Command は同じか

**文脈による。** ブラウザの `metaKey` は Mac では Command を表し、Electron の `Meta` は Mac では Command、Windows・Linux では GUI キーに対応する。一方、Emacs の `M-` は別の意味の Meta であり、Alt や Option に割り当てられることが多い。 [MDN：metaKey](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/metaKey) · [Electron：ショートカット](https://www.electronjs.org/docs/latest/tutorial/keyboard-shortcuts/) · [GNU Emacs：修飾キー](https://www.gnu.org/software/emacs/manual/html_node/emacs/Modifier-Keys.html)
