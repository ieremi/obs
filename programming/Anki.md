# Anki

**Anki** は、**間隔反復**（spaced repetition）で暗記を助ける、オープンソースのフラッシュカード（単語カード）のソフト。忘れかけたころに復習させることで、少ない回数で長く覚えていられるようにする。名前は日本語の「**暗記**」から。

- 作者：**Damien Elmes**（オーストラリア）。2006 年ごろから開発
- ライセンス：**AGPL-3.0**（オープンソース）。ソースは GitHub の `ankitects/anki`
- 医学生・語学・資格試験の勉強でとくによく使われる

| 版 | 対応 | 料金 |
| --- | --- | --- |
| **Anki（デスクトップ）** | Windows・macOS・Linux | 無料 |
| **AnkiDroid** | Android | 無料（別の開発者たちによる） |
| **AnkiMobile** | iPhone・iPad | 有料（作者が作り、開発資金になる） |
| **AnkiWeb** | ブラウザー。端末どうしの **同期** | 無料 |

## しくみの言葉

| 言葉 | 意味 |
| --- | --- |
| **ノート**（note） | 覚える中身のまとまり。「表：cat、裏：猫」のような **フィールド** の集まり |
| **ノートタイプ**（note type、旧名 model） | ノートにどんなフィールドがあり、どんなカードを作るかの型。標準は **Basic**（表と裏）、**Basic (and reversed card)**（両方向）、**Cloze**（穴うめ） |
| **カード**（card） | 実際に復習する 1 枚。1 つのノートから、**テンプレート** に従って 1 枚以上のカードができる（両方向なら 2 枚） |
| **デッキ**（deck） | カードを入れる箱。「英単語::TOEIC」のように `::` で階層にできる |
| **プリセット**（deck preset、デッキのオプション） | 1 日の新しいカードの数、学習の間隔などの設定。いくつかのデッキで共有できる |
| **タグ** | ノートにつけるラベル。検索や絞りこみに使う |
| **コレクション** | 1 人分のノート・カード・復習の記録の全部。中身は **SQLite** のデータベース（`collection.anki2`） |
| **.apkg** | デッキを人に配るときのファイル（ノート・カード・画像や音などのメディアをまとめたもの） |

- **ノートとカードを分ける** のが Anki の特徴。1 つのノート（たとえば「漢字・読み・意味」）から、「漢字 → 読み」「読み → 漢字」の 2 枚のカードを自動で作れる。ノートを直せば、両方のカードが直る

## 復習のしかた
- カードの表を見て思い出し、裏を見て答え合わせをし、**どのくらい思い出せたか** を 4 つのボタンで答える

| ボタン | 意味 | つぎの復習 |
| --- | --- | --- |
| **Again**（もう一度） | 思い出せなかった | すぐ（数分後）にもう一度 |
| **Hard**（難しい） | やっと思い出した | 少しだけのばす |
| **Good**（正解） | ふつうに思い出した | ふつうにのばす |
| **Easy**（簡単） | すぐ思い出した | 大きくのばす |

- 答えるたびに、つぎに出す日（**間隔**）が決まる。うまく思い出せるほど、間隔が 1 日 → 数日 → 数週 → 数か月と長くなる
- カードの状態：**新規**（まだ見ていない）→ **学習中**（はじめの数回）→ **復習**（日をあけて出る）。忘れると **再学習**

### 間隔を決めるアルゴリズム
| アルゴリズム | 内容 |
| --- | --- |
| **SM-2** 系 | 1980 年代の SuperMemo のアルゴリズムをもとにした、Anki の昔からの方式。カードごとの **易しさ（ease）** を掛けて間隔をのばす |
| **[[FSRS]]**（Free Spaced Repetition Scheduler） | 記憶のモデル（難しさ・安定度・思い出せる確率）を使う新しい方式。23.10 から Anki に標準で入った。**自分の復習の記録から最適なパラメーターを計算** し、**目標の正答率**（desired retention、初期値 0.9 ＝ 90%）を決めると、それに合わせて間隔を決める |

- FSRS にすると、同じ覚え具合で復習の回数が減ることが多いとされる
- 26.08 では FSRS のライブラリ（fsrs-rs 6.6.1）が新しくなり、速くなった

## アドオン
- Anki は **Python** で動く部分があり、**アドオン**（拡張機能）で機能を足せる
- 入れ方：「ツール → アドオン → アドオンを取得」で、AnkiWeb に載っている **6 桁〜10 桁のコード** を入れる
- 代表的なもの：[[AnkiConnect]]（ほかのアプリから Anki を操作する。コード `2055492159`）

## よい使い方（一般的なこつ）
- **1 枚に 1 つのこと** だけを書く（最小情報の原則）
- 自分で作ったカードのほうが覚えやすい。ただし、医学などでは、よくできた共有デッキ（AnKing など）も広く使われる
- **毎日少しずつ**。休むと復習がたまる
- 穴うめ（Cloze）は、文の中の大事な語を `{{c1::…}}` で隠す

## 押さえどころ
- Anki は、**間隔反復** の単語カードのソフト。オープンソースで、デスクトップ・Android・ウェブは無料、iPhone は有料
- **ノート**（中身）から **カード**（復習する 1 枚）を作る。型は **ノートタイプ**
- 4 つのボタンで答え、つぎの間隔が決まる。いまは **FSRS** が使える
- 版は **年.月** の番号。最新は 26.09.3（2026 年 9 月）
- ほかのアプリとつなぐには [[AnkiConnect]]
