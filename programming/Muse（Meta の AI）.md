# Muse（Meta の AI）

**Meta の、作業を代わりにやってくれる「パーソナル AI エージェント」。** ふつうのチャット AI のように質問に答えるだけでなく、**メールを書いて送る、予定を入れる、ウェブで調べて比べる、予約や買い物をする** といった作業を、自分で進める。中で動く AI モデルは **Muse Spark**。

| 項目 | 内容 |
| --- | --- |
| 作った会社 | Meta（Facebook・Instagram・WhatsApp の会社） |
| アメリカでの開始 | **2026 年 9 月 8 日**（カナダは 9 月 18 日から） |
| 日本での開始 | **2026 年 10 月 23 日**（日本語の解説記事による） |
| 使う所 | **iPhone・Android のアプリ**、ウェブの **muse.ai**、WhatsApp。アメリカでは Mac のアプリも |
| 必要なもの | **Meta のアカウント**、**18 歳以上** |
| 料金 | **無料**（使用量の上限あり）、**Power** 月 20 ドル、**Maximum** 月 100 ドル |
| モデル | **Muse Spark**（2026 年 4 月に発表。1.3 は 9 月 2 日） |

## 3 つの「Muse」
名前が似ているので、分けて考える。

| 名前 | 何か | だれ向け |
| --- | --- | --- |
| **Muse**（アプリ・エージェント） | 作業を代わりにやるアプリ。このノートの中心 | ふつうの人 |
| **Muse Spark** | 中で動く AI モデル。API からも使える | 開発者 |
| **Muse Code** | 端末で動く、プログラミング用のエージェント（ベータ。macOS・Linux） | 開発者 |

## しくみ
- 一人ひとりに、クラウドの上の専用の仮想マシン（**Muse Secure VM**）が用意され、Muse はその中で作業する。中にブラウザー（Chromium 系）があり、ウェブサイトを開いて操作する
- インターネットへの出入りは、別の見張り役の AI（**Sentinel**）がチェックする
- **アプリを閉じても、作業を続ける**。時間のかかる仕事は、まかせて放っておける

## はじめ方
1. アプリ（iPhone・Android）を入れるか、ブラウザーで **muse.ai** を開く
2. **Meta のアカウント**（Facebook・Instagram のアカウント）でログインする
3. まずは **かんたんな質問を 1 つ** してみる。いきなり Gmail などをつながない
4. 慣れてきたら、**コネクタ**（下）でメールや予定表をつなぎ、作業をたのむ

- 無料の版でも、はじめに **支払いカードの登録** を求められる、という解説がある（求めない、という解説もあり、はっきりしない）

## 画面
| 場所 | すること |
| --- | --- |
| チャット | たのむ。ふつうのチャットと同じ |
| ライブラリ（Library） | 作ったものの置き場 |
| Upcoming（予定） | これから Muse がやること |
| Goals（目標） | 長く続けるたのみごと |
| アクティビティのログ | Muse が **何をしたか** の記録。ときどき見る |
| Identity → Memory | Muse が **覚えていること**。見て、直して、消せる |
| 設定 → コネクタ | Gmail などをつなぐ・はずす |
| 設定 → 権限 | どこまで **確認なしでやってよいか** |
| 設定 → 使用状況 | 今週どれだけ使ったか |
| 設定 → データ管理 | AI の学習に使わせるかどうか |

## たのみ方の例
- 「今週のメールから、返事が要るものを 5 つ選んで、下書きを作って」
- 「来週の火曜の午後に、歯医者の予約を入れられるか調べて」
- 「冷蔵庫にあるもの（にんじん・豚肉・たまご）で、3 日分の献立を作って」
- 「この 3 つの掃除機を、値段・重さ・評判で表にして」
- 「先月のレシートのメールから、経費の一覧を作って」

- **何をしてほしいか**、**どこまでやってよいか**（下書きまで、送る前に見せて、など）、**期限** をはっきり言う
- 覚えておいてほしいことは「覚えて」、忘れてほしいことは「忘れて」と言う

## コネクタ（ほかのサービスとつなぐ）
- チャットで「**Gmail につないで**」と言うか、**設定 → コネクタ** から
- 日本で使えるもの：**Gmail**、**Google カレンダー**、**Instagram**。メルカリ・マネーフォワード ME・チケットぴあは「進めていく」と発表されたが、時期は未定
- アメリカでは、支払い（**Link by Stripe**：一回きりのカード番号を作る）、健康、スマートホーム、飲食店、買い物、音楽などもある。Shop Pay と **1Password** は「近日」（→ [[1Password]]）
- コネクタに **読むだけ** のモードがあれば、はじめはそれを選ぶ
- **つなぎを外しても、それまでに読みこんだ内容（記憶やチャットの記録）は残ることがある**。消したいものは Memory やチャットから消す

## 確認（承認）のしくみ
メールを送る、買う、予約するなどの **大事な操作の前には、Muse が確認を求める**。

| 設定（設定 → 権限） | 意味 |
| --- | --- |
| **一部の操作で確認する**（はじめの設定） | 書きこむ操作と、大事な読みこみは確認する |
| **常に確認する** | なんでも確認する。はじめはこれが安心 |

確認のカードで選べるもの：

| ボタン | 意味 |
| --- | --- |
| 1 回だけ許可 | 今回だけ |
| このタスクで許可 | このたのみごとの間だけ |
| このサイトで許可 | このサイトでは、これからも |
| **常に許可** | ずっと確認しない。**読むだけの、ごく狭い操作以外ではすすめない** |
| 拒否 | やめさせる |

- ブラウザーの操作は、ふだんは見えない所で動く。「**ブラウザーを開く**」で見られ、「**ブラウザーを操作する**」で自分が代わり、「**タスクを止める**」で止められる

## プライバシーの設定
- **設定 → データ管理 → 「AI モデルの改善に協力」**：**はじめはオン**。オフにすると、会話が Meta の AI の学習に使われなくなる（**それまでの会話もふくめて** 外れる、という解説）
- Meta は、学習の前に名前・メールアドレス・電話番号などをのぞく、と言っている
- Meta は、会話や仮想マシンのデータを **広告のしくみには渡さない**、と言っている
- 2026 年の後半に、**自分だけが鍵を持つ暗号化の仮想マシン**（Confidential VM）が出る予定
- **チャットに、銀行の暗証番号・カードのセキュリティコード・パスワードを書かない**

## 開発者向け：Muse Spark の API
**Meta Model API** から、Muse Spark を自分のプログラムで使える。**OpenAI の SDK とそのまま使える**（Chat Completions と Responses。Anthropic の Messages の形にも対応）。

1. **dev.meta.ai** でサインアップし、Model API のダッシュボードで **API キー** を作る（カードの登録が要る）
2. 環境変数 `MODEL_API_KEY` に入れる
3. OpenAI の SDK の `base_url` を `https://api.meta.ai/v1` にする

```python
import os
from openai import OpenAI

# OpenAI の SDK はふつう OPENAI_API_KEY を読むので、MODEL_API_KEY をはっきり渡す
client = OpenAI(
    base_url="https://api.meta.ai/v1",
    api_key=os.environ["MODEL_API_KEY"],
)

resp = client.responses.create(
    model="muse-spark-1.3",          # Meta の 7 月のブログの例は muse-spark-1.1
    input="Explain a tool-call loop in one sentence.",
)
print(resp.output_text)
```

- ウェブ検索は、Responses の `tools` に `{"type": "web_search"}` を入れる

| モデル ID | 100 万トークンあたり（入力／出力） | 送った内容を学習に使うか |
| --- | --- | --- |
| `muse-spark-1.3` | 1.25 ドル／4.25 ドル | 使わない |
| `muse-spark-1.3-contributor` | 0.10 ドル／0.20 ドル | **使う**（そのぶん安い） |

### Muse Code（端末のエージェント）
```sh
curl -fsSL https://dev.meta.ai/install.sh | bash
muse --version
```

- **macOS と Linux** だけ（ベータ）。ログインは、ブラウザーでコードを入れる形（OAuth のデバイスフロー）
- **はじめの設定のモデルは `muse-spark-1.3-contributor`**（学習に使われる側）。仕事のコードで使うなら、学習されない `muse-spark-1.3` にするか、よく考える
- 試していない（このパソコンには入れていない）

## 気をつけること
- **新しいサービスで、情報がまだ固まっていない**。日本で使える機能、無料の上限、カードが要るかどうかなどは、解説によってちがう。**アプリの中と公式のヘルプで確かめる**
- まかせる範囲は、**はじめは狭く**（読むだけ・下書きまで・常に確認する）。慣れてから広げる
- アクティビティのログを、ときどき見る
- 学習に使われたくなければ、**データ管理の設定を最初にオフにする**

## 押さえどころ
- Muse は、Meta の **作業を代わりにやる AI エージェント**。日本では 2026 年 10 月 23 日から、**アプリと muse.ai** で使える
- Meta のアカウントでログインし、**チャットでたのむ**。Gmail・Google カレンダーなどを **コネクタ** でつなぐと、メールや予定の作業もできる
- 大事な操作の前には **確認** が出る。はじめは「**常に確認する**」に
- 無料（上限あり）、Power 月 20 ドル、Maximum 月 100 ドル
- **学習への利用ははじめオン**。いやなら設定でオフ
- 開発者は、**OpenAI 互換の API**（`https://api.meta.ai/v1`、`muse-spark-1.3`）で使える
