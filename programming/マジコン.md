# マジコン

**家庭用ゲーム機で、通常の正規ゲームカートリッジ以外に記録されたプログラムを動かすための機器の通称。** 特にニンテンドーDS用の「R4」などが知られる。不正コピーしたゲームを起動できることが問題となり、日本では輸入・販売への差止訴訟や刑事摘発が行われた。[任天堂・2008年の提訴発表](https://www.nintendo.co.jp/corporate/release/2008/080729.html)

## ファミコンのころのマジコン

**ファミコン時代にも、ディスクからゲームを追加メモリーへ読み込み、実機で動かす非純正機器があった。** Game DoctorやMagic Card系がその例。DS用R4と同じ製品ではなく、仕組みも異なる。[実機・基板写真を掲載した収集家の調査資料](https://www.famicomdisksystem.com/game-doctor-copiers/)

### ディスクシステムを利用する機器

任天堂は1986年2月21日にディスクシステムを発売した。通常は、ディスクドライブからRAMアダプタへゲームデータを読み込み、ファミコンで実行する。店頭の正規ディスクライターで別のゲームに書き換えるサービスもあった。[任天堂・当時の説明書に基づく紹介](https://www.nintendo.com/jp/famicom/hardware/disksystem.html)

Game Doctor系では、このディスク装置を利用し、元はカセット用だったゲームを対応形式に加工したデータなどを、追加RAMに読み込んで実行した。**普通のディスクシステムだけでカセットのゲームを動かせたわけではない。**

### 「コピー機」という名前でも、カセットを直接コピーできるとは限らない

代表的なGame Doctor系は、カセットを差せば自動的に吸い出してディスクに保存する機器ではなかった。専用に加工されたデータを再生する役割が中心で、対応するゲームにも制約がある。ファミコンのカセットには、メモリーの切り替えなどを行う追加回路（マッパー）があり、その違いも動作に影響した。

| 機器の例 | 位置付け |
| --- | --- |
| Game Doctor／Super Game Doctor | ディスクから対応データをRAMへ読み込んで実行する系統。 |
| Magic Card | 別形式も使う系統。他の機器とすべて互換ではない。 |
| Game Master | 実行機能に加え、途中状態の保存などを備える機種。 |

技術的な説明・機種の区別は、[FamicomDiskSystem.comの実機調査](https://www.famicomdisksystem.com/game-doctor-copiers/)に基づく。メーカーの公式仕様書ではないため、機種すべてに一律に当てはめない。

### DS時代との違い

ファミコン時代のこれらは、**磁気ディスクと追加RAMを組み合わせる機器**。後のDS用マジコンとは媒体・構造が異なる。また、店頭で任天堂が提供していた正規のディスク書換サービスと、非純正機器によるコピー・実行は別のもの。

下記の2008年以降の訴訟・法改正はDS用機器に関する経緯。これをそのまま1980年代の法的扱いとして読むことはできない。

確認日：2026年11月19日。機器の正確な発売年や、日本での「マジコン」という呼称の初出は今回確定していない。

## フロッピーを使うマジコン

**一般的な3.5インチのフロッピーディスクを使うものなら、スーパーファミコン時代のバックアップ機器が代表例。** たとえばBung製の **Game Doctor SF7** は、フロッピードライブを内蔵し、ディスクのゲームデータを機器内のメモリーに読み込んで、スーパーファミコン実機で実行する。[取扱店ToToTEK・SF7の製品説明](https://www.tototek.com/store/index.php?main_page=product_info&products_id=17)

### 仕組み

ゲームカセットは通常、カセット内のROMにあるデータを本体が読む。フロッピー式の機器は、ディスクから読み込んだデータを追加メモリーに置き、そこをゲームの供給元にする。このため、**ディスクはデータを運ぶ・保存する媒体で、ゲームそのものは本体と追加メモリーを使って動く**。

SF7の製品説明には、複数ゲームのメモリーへの読み込み、ファイル管理、カセットとのセーブデータ転送、改造コードなども記載されている。コピー機能と改造機能を併せ持つ製品があるため、[[Xターミネーター]]との区別は「一方の機能しか絶対にない」という意味ではなく、主な用途の違いで考える。[ToToTEK・SF7](https://www.tototek.com/store/index.php?main_page=product_info&products_id=17)

### ファミコンのディスクカードとは違う

| 種類 | 媒体・特徴 |
| --- | --- |
| ファミコン用Game Doctor系 | ディスクシステムのディスクカードを利用する系統。対応形式に加工したカセット用ゲームなどを追加RAMへ読み込む。 |
| スーパーファミコン用Game Doctor SF7 | 内蔵3.5インチドライブを利用する。 |
| Multi Game Doctor 1 | ファミコンのディスク装置を利用する構成に加え、後に3.5インチドライブも用意された。 |

ファミコンのディスクカードも磁気ディスクだが、パソコンで一般的だった3.5インチフロッピーと同じ媒体ではない。したがって、**「フロッピーを使うマジコン」がすべてスーパーファミコン用とは限らない**。[任天堂・ディスクシステムの仕様](https://www.nintendo.com/jp/famicom/hardware/disksystem.html)、[実機調査・Game DoctorとMulti Game Doctor 1](https://www.famicomdisksystem.com/game-doctor-copiers/)

### 呼び名の注意

Game Doctorという名前は、ファミコン用とスーパーファミコン用の両方に現れる。製品名だけでなく、対応ゲーム機と型番まで見る必要がある。**Game Doctor SF7の「SF」はスーパーファミコン側の製品を見分ける手掛かり**になる。

取扱説明書の保存資料：[Bung Game Doctor SF7マニュアル（PDF）](https://www.delta-island.com/downloads/bung-game-doctor/user-manual/user-manual-game-doctor-sf7.pdf)。今回のPDFは画像主体で本文テキストを取得できなかったため、上記の機能説明は取扱店の製品記載と実機調査資料に基づく。

確認日：2026年11月19日。機種により対応するゲームや周辺機器が異なる。

## 何をするもの？（DS用の例）

ゲーム機には、正規のゲーム媒体を確認してからプログラムを起動する仕組みがある。DS用マジコンは、その確認の仕組みを回避して、本来は起動できない複製プログラムなどを実機で動かせるようにする。

単にゲームファイルを保存する記憶媒体というだけでなく、**ゲーム機の起動制限を回避する機能**がある点が重要。[経済産業省・技術的手段に関する制度調査、マジコン事件の解説](https://www.meti.go.jp/policy/economy/chizai/chiteki/pdf/H21legalframeworktpm.pdf)

## エミュレーターとの違い

| 用語 | 主な役割 |
| --- | --- |
| マジコン | ゲーム機の実機側で、別の媒体にあるプログラムなどを起動させる機器。 |
| エミュレーター | 別のコンピューター上で、元のゲーム機の動作を再現するソフトウェアなど。 |
| ROMイメージ | ゲーム媒体の内容をファイルとして扱ったもの。起動用の機器や実行環境とは別。 |

機器、実行環境、ゲームデータはそれぞれ異なる。何のデータを、どのように入手・複製・利用したかも分けて考える。

## 日本で問題になった理由

主に二つの問題が関わる。

- **装置の提供**：ゲーム機の技術的制限手段を回避する装置の輸入・販売など。不正競争防止法が問題になる。
- **ゲームデータの利用**：ゲームプログラムの無断複製・配布など。装置の規制とは別に著作権の問題がある。

「不正コピーのゲームを同梱していない機器だから、販売しても問題ない」とは言えない。回避装置そのものの提供が規制対象となり得る。[経済産業省・不正競争防止法の解説資料](https://www.meti.go.jp/policy/economy/chizai/chiteki/pdf/unfaircompetition_textbook.pdf)

## 「持っているだけ」と「販売する」は分ける

上記の判決・摘発は輸入・販売などを対象とする。これを根拠に「所持しているだけで一律に犯罪」と説明するのは不正確。一方、所持と販売を区別することは、コピーゲームの入手・複製・利用が無条件に認められるという意味でもない。

個々の機器や行為の扱いは、回避する仕組み、提供の目的、ゲームデータの利用方法などで判断される。[経済産業省・不正競争防止法逐条解説、技術的制限手段に対する不正行為](https://www.meti.go.jp/policy/economy/chizai/chiteki/pdf/Chikujo.pdf)
