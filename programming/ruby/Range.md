# Range

**始点と終点によって範囲を表すクラス。連番の処理や範囲判定に使う。**

## 基本の使い方

```ruby
(1..3).to_a             # => [1, 2, 3]
(1...3).to_a            # => [1, 2]
(1..5).cover?(3)        # => true
(1..5).cover?(6)        # => false
(1..3).each { |n| puts n }  # 1, 2, 3 を出力
["a", "b", "c"][0...2] # => ["a", "b"]
```

## 終端を含むか

`a..b` は終端 `b` を含み、`a...b` は含まない。配列の切り出しで `0...length` とすると、添字0から `length - 1` までを指定できる。

`cover?` は境界との比較で範囲内かを判定する。`include?` は要素として含まれるかの判定で、特に文字列の範囲では結果が異なることがある。
