# バックアップ起動ディスク

**通常の起動元が使えないときに備えて用意する、別媒体の起動ディスク。** ここでは主に、MS-DOS・Windows 9x時代の予備の起動フロッピーディスクを指す。製品ごとに内容や呼び方が異なり、統一された一つのファイル形式の名称ではない。

たとえばPro-face/XycomのWindows 98 SE復旧手順では、起動可能なCD-ROMを使う方法と、予備の起動フロッピーを作成して使う方法が示されている。[メーカーの復旧手順書](https://www.proface.com/media/55920)

## 役割

内蔵ディスク上のOSが起動できなくても、別媒体から最小限の環境を起動し、診断や復旧、再インストールの準備を行うために使う。起動後に何ができるかは、収録されたプログラムやドライバーによって決まる。

起動ディスク自体は、故障したハードウェアを修復するものではない。また、再インストール用のファイルやバックアップデータが別に必要になる場合がある。

## データのバックアップとの違い

| 種類 | 保存するもの・目的 |
| --- | --- |
| 起動ディスク | OSが起動しないときに、作業用の環境を立ち上げる |
| データのバックアップ | 文書・写真・設定など、失いたくないデータの複製を保存する |
| システムイメージ | OSやアプリを含むディスク・パーティションの状態を復元するために保存する |
| インストール・リカバリーメディア | OSの導入や、メーカーが用意した状態への復旧に使う |

**起動ディスクを作成しても、個人ファイルのバックアップが取れたことにはならない。** 起動する手段と、戻すデータの両方が必要になることがある。[Microsoft：Windowsのバックアップ・復元・回復](https://support.microsoft.com/en-us/windows/experience/backup-recovery/backup-restore-and-recovery-in-windows)

## DOS時代の起動に関わるファイル

Microsoft MS-DOS系の典型例では、次のようなファイルが関係する。必要なファイルや構成はOS・版・機種によって異なる。

| ファイル | 役割 |
| --- | --- |
| `IO.SYS`・`MSDOS.SYS` | 起動やOSの基本機能に関係するシステムファイル。Windows 9xでは、MS-DOS 6.x以前と役割が異なる部分がある |
| `COMMAND.COM` | コマンドを受け付けるコマンドインタープリター |
| `CONFIG.SYS` | 起動時のドライバー読み込みやシステム設定 |
| `AUTOEXEC.BAT` | 起動時に実行するコマンドを記述するバッチファイル |

通常のファイルコピーだけでは、起動セクターなどを含む起動可能な構成を再現できない場合がある。作成には対象OSやメーカーが用意した手順を使う。

## 復旧時の位置付け

メーカーのWindows 98 SE復旧手順の例では、起動フロッピーと復旧用CD-ROMを組み合わせて再インストールする。これはデータを保持したまま起動だけを直す操作と同じではなく、その手順ではCドライブが初期化される。[Pro-face/Xycom：Windows 98 SE復旧手順](https://www.proface.com/media/55920)

現在のWindowsでは、回復ドライブやWindows回復環境、システム修復ディスクなどが復旧の入口になる。古い起動フロッピーとは、対象OS・起動方式・利用できる機能が異なる。[Microsoft：Windowsのバックアップ・復元・回復](https://support.microsoft.com/en-us/windows/experience/backup-recovery/backup-restore-and-recovery-in-windows)
