# Atom

**Atom** は、GitHub が開発したオープンソースのテキストエディタ。Web 技術を利用したデスクトップアプリで、「自分好みに作り替えられるエディタ」として、パッケージやテーマによる拡張を重視した。macOS・Windows・Linux で利用できた。[Atom リポジトリ](https://github.com/atom/atom)

## 歴史

- **2014年**：パブリックベータを公開。[Electron の歴史](https://www.electronjs.org/blog/page/4)
- **2015年**：Atom のために開発されたアプリケーション基盤 **Atom Shell** が **Electron** に改名された。[Electron の発表](https://www.electronjs.org/blog/electron)
- **2022年**：GitHub が Atom の開発終了を発表。現在、本体リポジトリはアーカイブされ、公式の継続開発は終了している。[GitHub: Sunsetting Atom](https://github.blog/news-insights/product-news/sunsetting-atom/)

Atom 本体は MIT ライセンスで公開された。開発が終了した古いソフトウェアを使い続ける場合は、修正されない脆弱性や OS との互換性に注意する。

| [[Zed]]                        | Atom の開発に携わったメンバーが新たに開発したエディタ。Atom の更新版ではなく、Rust を用いて作り直された別のアプリ。        |
