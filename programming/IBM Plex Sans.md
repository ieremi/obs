# IBM Plex Sans

**IBM Plex Sans** は、IBM のコーポレート書体ファミリー **IBM Plex** に属するサンセリフ体。IBM のブランド向けに開発され、2018年に公開された。画面や印刷物の本文、見出し、ユーザーインターフェースなどに利用できる。

## ファミリーと日本語

IBM Plex には Sans のほか、セリフ体の **Serif**、等幅の **Mono**、幅を狭めた **Sans Condensed** などがある。日本語向けには、かな・漢字を含む **IBM Plex Sans JP** が提供されている。欧文用の IBM Plex Sans だけで日本語文字がすべて表示できるとは限らないため、日本語を使う場合は JP 版や適切な代替フォントを指定する。

## ライセンスと入手

IBM Plex はオープンソースとして公開されている。IBM Plex Sans のフォントは **SIL Open Font License 1.1** に基づき、商用・非商用を問わず利用できる。再配布や改変の際には、ライセンスの同梱や予約フォント名に関する条件を確認する。フォントファイルは IBM の GitHub リポジトリや Google Fonts から入手できる。
