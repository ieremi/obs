# Obsidian の Relation と Rollup

**Obsidian にも、Notion の Relation と Rollup に近いことをする方法がある。** 標準の Bases と、ノートのプロパティに書いたリンクを組み合わせる。ただし、Notion と同じ専用のプロパティ型が用意されているわけではなく、集計には数式を使う。

| Notion | Obsidian での対応 | 違い |
| --- | --- | --- |
| Relation | プロパティに別のノートへのリンクを記入する | リンクはデータベース専用ではない。相手側のプロパティに逆方向のリンクが自動で書き込まれるわけではない |
| Rollup | Bases の数式で、リンク先のプロパティを参照・集計する | 専用の Rollup 設定画面ではなく、数式を記述する。更新にも注意が必要 |

Bases は、ノートを行、そのプロパティを列として表示できる標準のコアプラグインである。 [Bases の概要](https://help.obsidian.md/bases) · [Bases の数式](https://obsidian.md/help/formulas)

## Relation にあたるもの

たとえば、プロジェクトのノート `ウェブサイト.md` に、タスクのノートへのリンクをプロパティとして記入する。

```yaml
---
tasks:
  - "[[設計]]"
  - "[[実装]]"
---
```

これは複数のリンクを入れたリスト型プロパティである。プロパティ画面から入力してもよい。Bases で `tasks` を表示すれば、関連するノートへのリンクを一覧できる。

逆方向には、リンク先のノートから**バックリンク**を確認できる。ただし、バックリンクとして見えることと、相手のプロパティにリンクが自動的に追加されることは別である。

## Rollup にあたるもの

リンク先の `設計.md` と `実装.md` に、それぞれ数値プロパティ `hours` を設定する。

```yaml
---
hours: 3
---
```

もう一方のノートには、たとえば `hours: 5` と書く。プロジェクトを一覧する Base で **プロパティ → 数式を追加**を選び、次の式を入力する。

```text
tasks.map(value.asFile().properties.hours).reduce(acc + value, 0)
```

`tasks` の各リンクをファイルとして取得し、それぞれの `hours` を足す。例では **8** になる。リンク先が存在し、`hours` が数値として設定されていることが前提である。ノートが空欄だったり値の型が異なったりする場合は、結果を確認してから使う。 [公式の数式例](https://obsidian.md/help/formulas)

リンク先が 1 件で、集計せず値を取り出すだけなら、次のようにも書ける。

```text
project.asFile().properties.status
```

これは現在のノートの `project` プロパティが指すノートから、`status` を取得する式である。

## 注意点

- **自動更新**：公式ヘルプによると、リンク先のノートだけを変更した場合、Base を開き直すまで参照・集計結果が更新されないことがある。重要な値は再表示して確認する。
- **逆向きの集計**：`file.backlinks` を使ってリンク元から集計することもできるが、すべてのバックリンクが対象になるため、関係のないリンクを含めないよう注意する。また、大きな保管庫では重く、自動更新にも制限がある。 [Bases の数式](https://obsidian.md/help/formulas) · [Bases の構文](https://obsidian.md/help/bases/syntax)
- **保存先**：元データは各ノートのプロパティに、数式は Base に保存される。計算結果が自動的に元ノートのプロパティに書き戻されるわけではない。
- **関係の管理**：Notion の双方向 Relation と違い、双方のプロパティを自動で同期する仕組みとして考えない。必要に応じてリンクを一方向に定め、逆方向はバックリンクや Base で見る。

コミュニティプラグインを使う選択肢もあるが、上の基本的な参照・集計に追加プラグインは不要である。
