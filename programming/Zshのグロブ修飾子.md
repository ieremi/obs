# Zsh のグロブ修飾子

**グロブ修飾子**（glob qualifier）は、Zsh のファイル名パターンの末尾に付け、ファイルの種類や更新日時などで絞り込んだり、結果を並べ替えたりする構文である。 [Zsh 公式マニュアル：Glob Qualifiers](https://zsh.sourceforge.io/Doc/Release/Expansion.html#Glob-Qualifiers)

```zsh
./out/*.json(.om[1])
```

この例は、`./out/` にある `.json` の通常ファイルを更新日時が新しい順に並べ、先頭の一つを選ぶ。

| 部分 | 意味 |
| --- | --- |
| `./out/*.json` | `out` の直下にある `.json` という名前のパターン |
| `.` | 通常ファイルに限定 |
| `om` | 更新日時の新しい順に並べる |
| `[1]` | 先頭を選ぶ |

通常の Zsh では、修飾子を `*(.)` のように末尾の `(...)` に書く。ファイル名の展開はコマンドの実行前に行われる。

## 種類で絞る

| 修飾子 | 意味 | 例 |
| --- | --- | --- |
| `.` | 通常ファイル | `./*(.)` |
| `/` | ディレクトリ | `./*(/)` |
| `@` | シンボリックリンク | `./*(@)` |
| `*` | いずれかの実行ビットがある通常ファイル | `./*(*)` |
| `p` | 名前付きパイプ（FIFO） | `./*(p)` |
| `=` | ソケット | `./*(=)` |
| `%` | デバイスファイル | `./*(%)` |

`./*(.)` はリンク自体を通常ファイルとして扱わない。リンク先が通常ファイルであるリンクも含めたい場合は、`./*(-.)` のように `-` を付けてリンク先の属性を見る。

## よく使う条件

| 修飾子 | 意味 |
| --- | --- |
| `N` | 一致するものがなければ、このパターンを空にする |
| `D` | 隠しファイルも対象にする |
| `U` | 実効ユーザー ID が所有するもの |
| `G` | 実効グループ ID が所有するもの |
| `r`、`w`、`x` | それぞれ所有者の読み取り・書き込み・実行ビットがあるもの |
| `^` | 後続の条件を否定する |

```zsh
print -rl -- ./*(N.)   # 通常ファイル。一致しなければ空
print -rl -- ./*(D.)   # 隠しファイルを含む通常ファイル
print -rl -- ./*(/^F)  # 空のディレクトリ
```

条件は続けて書ける。上の `(/^F)` は「ディレクトリであり、空でないディレクトリではない」という意味。権限の `r` などはモードビットを見るもので、現在のユーザーが実際にアクセスできるかの判定と常に同じではない。

## 時間と大きさ

| 修飾子 | 意味 |
| --- | --- |
| `m` | ファイル内容の更新日時（mtime）による絞り込み |
| `a` | 最終アクセス日時（atime）による絞り込み |
| `c` | inode の状態変更日時（ctime）による絞り込み。作成日時ではない |
| `L` | ファイルサイズによる絞り込み |

```zsh
print -rl -- ./*(.mh-5)  # 過去 5 時間以内に更新された通常ファイル
print -rl -- ./*(.m-1)   # 過去 1 日以内に更新された通常ファイル
print -rl -- ./*(.L0)    # サイズが 0 バイトの通常ファイル
```

時間の単位を省くと日、`h` は時間、`m` は分、`s` は秒。時間差は指定単位の端数を切り捨てて比較するため、`+` を使う場合の境界には注意する。サイズも単位を付けた場合は切り上げて比較する。 [公式マニュアル](https://zsh.sourceforge.io/Doc/Release/Expansion.html#Glob-Qualifiers)

## 並べ替えと範囲

| 修飾子 | 意味 |
| --- | --- |
| `on` | 名前順 |
| `om` | 更新日時の新しい順 |
| `Om` | 更新日時の古い順 |
| `oL` | サイズの小さい順 |
| `OL` | サイズの大きい順 |
| `[n]` | 結果の n 番目 |
| `[n,m]` | 結果の n 番目から m 番目 |
| `[-1]` | 結果の最後 |

```zsh
print -rl -- ./*(.om[1,3])   # 更新日時が新しい通常ファイルを最大 3 件
print -rl -- ./*(.OL[1])     # 最も大きい通常ファイルを 1 件
print -rl -- ./out/*.json(.om[2])  # 2 番目に新しい JSON
```

添字は通常 1 から始まる。`KSH_ARRAYS` オプションが有効な場合は扱いが変わる。更新日時やサイズが同じものの順序には注意する。

## 該当なし・安全上の注意

- 通常、一致するファイルがないグロブは `no matches found` エラーになる。`N` を使うと、そのパターンは空になる。
- **`N` で引数が消えると、コマンドによっては意図しない動作になる。** たとえば `cat -- ./*.json(N)` に一致がない場合、`cat` はファイルを開かず標準入力を読む。削除などのコマンドでは特に、先に `print -rl -- パターン` で確認する。
- `D` を指定せず、`GLOB_DOTS` も無効な通常設定では、名前が `.` で始まる隠しファイルは `*` に一致しない。
- `**/` を使うとサブディレクトリも検索できる。対象が多くなり得るので注意する。
- `(...)` の解釈は Zsh のオプションに依存する。`EXTENDED_GLOB` が有効なら、明示的な `*(#q.)` という書き方も使える。
