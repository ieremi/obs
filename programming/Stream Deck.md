# Stream Deck

**Stream Deck**は、Elgatoのカスタマイズ可能な操作デバイス。キーにショートカットやアプリの操作などを割り当て、ボタンを押すだけで実行できる。多くのモデルは表示を変更できるLCDキーを備え、アイコンや状態を表示する。[Elgato: What is a Stream Deck](https://www.elgato.com/us/en/explorer/products/stream-deck/what-is-a-stream-deck/)

## 使い方

WindowsまたはmacOSのStream Deckアプリで、キーにアクションをドラッグして割り当てる。たとえば、アプリやWebサイトを開く、キーボードショートカットを送る、会議中のマイクをミュートするといった操作に使える。対応するプラグインを追加すると、アプリや機器との連携を拡張できる。[Stream Deck App](https://www.elgato.com/us/en/s/stream-deck-app)

- **マルチアクション**：複数の操作をひとつのキーから実行する。
- **プロファイル**：用途やアプリに合わせてキーの配置を切り替える。
- **フォルダー・ページ**：キーに収まらない操作を整理する。

配信の操作に限らず、オンライン会議、動画・画像編集、日常的なPC操作にも使える。

## 製品と対応環境

キーの数や操作方法が異なる製品があり、Stream Deck +はキーに加えてダイヤルとタッチストリップを備える。スマートフォンやタブレットで使うStream Deck Mobileもある。[Elgato: Stream Deck](https://www.elgato.com/us/en/p/stream-deck)

公式のデスクトップ用アプリはWindowsとmacOSに対応し、Linuxは公式にはサポートされていない。購入時は、選ぶ機種のOS要件を確認する。

## ソフトウェアで再現する

物理的なボタンがなくても、画面上に操作ボタンを並べて、クリックやタッチでアクションを実行できる。物理キーの押し心地や、画面を見ずに操作できる感覚は得られない。

| 方法 | 操作画面 | 条件・特徴 |
| --- | --- | --- |
| [Virtual Stream Deck](https://www.elgato.com/uk/en/explorer/products/stream-deck/virtual-stream-deck-beta-overview/) | Windows・macOSの画面上 | Elgato公式。対応デバイスまたはStream Deck Mobile Proが必要。 |
| [Stream Deck Mobile](https://help.elgato.com/hc/en-us/articles/16786832942221-Elgato-Stream-Deck-Mobile-2-0-Getting-Started) | iOS・Android | 無料で6キーを利用可能。別途、同じネットワーク上のWindowsまたはmacOSのデスクトップアプリが必要。 |
| [Bitfocus Companion](https://bitfocus.io/companion) | 内蔵エミュレーターやブラウザー | 無料・オープンソース。Windows・macOS・Linuxに対応し、Stream Deck本体なしで使える。対応アプリや機器との連携、複数アクションの実行ができる。 |

Virtual Stream Deckは、対応デバイスまたはMobile Proを過去30日以内に接続する必要がある。各方式で使える連携や設定方法は異なるため、操作したいアプリが対応しているか確認する。
