# 松（日本語ワープロ）

**松**は、管理工学研究所が開発した日本語ワープロソフト。NEC の PC-9801 シリーズなどで使われ、パソコンによる日本語文書作成が普及する初期を代表する製品の一つとなった。

## 歴史

- **1983年**：PC-9801 用の「日本語ワードプロセッサ」が登場。初期の製品は BASIC で書かれ、改良版に「松」の名が付いた。[＠IT](https://jibun.atmarkit.co.jp/ljibun01/rensai/genesis/203/01.html)、[1983年のパソコン史](https://pbc.on.coocan.jp/pc100/1983.html)
- **1985年**：MS-DOS 上で動く **松85** が発売された。[天文月報の記事](https://www.asj.or.jp/jp/activities/geppou/item/116-3_122.pdf)
- **1986年以降**：**松86**、**新松**などの版が続いた。版ごとに対応機種や機能は異なる。[松86 の書誌情報](https://ge.nii.ac.jp/ncid/BN03410398)、[日本語ワープロの年表](https://gist.github.com/amuramatsu/33dbb4fd24e790ca609fe64ab7544f0e)

当時の日本語ワープロ市場では、管理工学研究所の松が大きなシェアを占めたが、1985年に PC-9801 向けに登場したジャストシステムの **一太郎**が、その後シェアを伸ばしていった。[アイコム：日本語ワープロの歴史](https://www.icom.co.jp/personal/beacon/electronics/944/)

## ワープロとしての役割

松は、かな漢字変換、文書編集、印刷などを扱う**日本語ワープロ**。プレーンテキストの編集を中心とする MIFES や VZ Editor とは主な用途が異なる。ただし、これらのエディタも文章作成には使われた。

## 松風・松茸との違い

- **松風**：同じ管理工学研究所が Windows 向けに開発したワープロ。DOS の松をそのまま移植したものではなく、当時の紹介によればショートカットキーなど一部を除き従来の松との互換性はない。[Vector：松風の紹介](https://www.vector.co.jp/magazine/softnews/970702/n707022.html)
- **松茸**：同社の日本語入力システム（IME）。ワープロ本体とは異なる。[PC Watch：松茸](https://pc.watch.impress.co.jp/docs/article/981125/k3.htm)
