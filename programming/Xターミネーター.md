# Xターミネーター

**ゲーム中のメモリーの値などを書き換え、残機・体力・所持金などを変更するためのゲーム改造ツールのシリーズ。** 「エックスターミネーター」とも表記される。ゲームテックが公開するスーパーファミコン用「サスケ」の説明書でも、改造コードの入力・選択機能が確認できる。[ゲームテック公式・サスケ取扱説明書](https://www.gametech.co.jp/support/manual_dl/pdf/x_sasuke_20120404.pdf)

## マジコンとの違い

| 機器 | 主な目的 |
| --- | --- |
| **Xターミネーター** | ゲームを実行しながら、値や動作を変更する。 |
| [[マジコン]] | 別媒体にあるゲームデータなどを実機で起動させる。ファミコン時代にはディスクと追加RAMを使う機器もあった。 |

**「ゲームをコピーして動かす」と「ゲーム中の値を変える」は別の機能。** マジコンの話の続きに登場しても、Xターミネーターを単純に同じ種類のコピー機と考えると混同する。機種によって付加機能は異なる。

## どうやって変更する？

たとえば残機数がメモリーのある場所に保存されている場合、その場所へ指定した値を書き込めば、残機数を変更できる。「改造コード」は、こうした変更対象や値などを機器に指示する情報。

ゲームギア版を逆アセンブルした調査では、本体とゲームカセットの間に機器を挟み、割り込み処理に介入して指定のメモリーへ書き込む構造が確認されている。ゲームカセットのROM自体を恒久的に書き換えるのとは異なる。[SMS Power!・ゲームギア版の解析](https://www.smspower.org/Development/XTerminator-GG)

また、「コードを入力する機能」と、ゲーム中の値の変化から変更対象を探す「コードサーチ機能」は別。ゲームギア版には両方がある。ただし、ゲームや機種により対応範囲は異なり、誤動作や表示の乱れが起こる場合もある。[同解析資料](https://www.smspower.org/Development/XTerminator-GG)

## 機種・版の例

| 対応機種・版 | 確認できること |
| --- | --- |
| スーパーファミコン用「サスケ」 | ゲームテック公式サイトに取扱説明書が残っている。 |
| セガサターン用 Ver.3 | 保存された説明書に、コードサーチやバックアップメモリーなどの項目がある。 |
| ゲームギア用 | ROMの逆アセンブルに基づく仕組みの調査が公開されている。 |

出典：[サスケ公式説明書](https://www.gametech.co.jp/support/manual_dl/pdf/x_sasuke_20120404.pdf)、[サターン版Ver.3説明書の保存資料](https://ppcenter.webou.net/sti/x_terminator/files/xt3_manual.pdf)、[ゲームギア版の解析](https://www.smspower.org/Development/XTerminator-GG)

同じシリーズ名でも、対応ゲーム機・版・付属機器が違えば機能も異なる。サターン版の機能をスーパーファミコン版にもあるものとして読まない。ファミコン用機器の話と、スーパーファミコン用「サスケ」の話も区別する。

資料確認上の限界：サスケ説明書は検索結果で本文の一部を確認したが、PDF全体は取得サイズ制限で読み込めなかった。発売年やシリーズ全製品の一覧は今回確定していない。
