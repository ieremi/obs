# Obsidian で表計算

**できる。ただし、普通の Markdown の表には、Excel のようにセルの数式を計算する機能は標準ではない。** やりたいことに応じて、標準の Bases、コミュニティプラグイン、外部の表計算ソフトを使い分ける。

| やりたいこと | 方法 | 特徴 |
| --- | --- | --- |
| ノートにある数値を一覧にして計算する | 標準の Bases | 1 行が 1 ファイル。プロパティから計算列をつくり、列の合計や平均を出せる |
| ノート内の小さな表で計算する | Spreadsheet Table などのプラグイン | Markdown の表に数式を書けるが、対応する数式や動作に制約がある |
| Excel のようなシートを操作する | Sheet Plus などのプラグイン | セルを備えた表計算画面を使える。保存形式や有料機能に注意 |
| 複雑な表や既存の Excel ファイルを扱う | Excel、LibreOffice Calc など | Obsidian の外で編集する。互換性が重要な場合に向く |

## 1. 標準機能の Bases

Bases はノートのプロパティを一覧表示する標準プラグインである。たとえば、購入品ごとにノートをつくり、それぞれに数値の「単価」と「数量」を設定すれば、計算式で「金額」を表示できる。表の列には合計や平均などの集計も設定できる。 [Bases の概要](https://help.obsidian.md/bases) · [表ビューの集計](https://help.obsidian.md/bases/views/table)

大まかな手順：

1. **設定 → コアプラグイン → Bases** を有効にする。
2. 対象の各ノートに、数値型のプロパティ `price` と `quantity` を設定する。
3. 新しい Base を作成し、対象ノートを絞り込んで `price` と `quantity` を表示する。
4. 数式プロパティを追加し、式に `price * quantity` を指定する。
5. 必要なら、計算列の見出しを右クリックし、集計から合計を選ぶ。

これは **1 行が 1 ノート**の一覧であり、1 枚のノート内にある普通の Markdown 表をそのまま計算する機能ではない。Excel のセル `A1`、`B2` のように自由に値を配置する表とも異なる。

## 2. Markdown の表に数式を入れる

[Spreadsheet Table](https://community.obsidian.md/plugins/spreadsheet-table) は、Markdown の表にセル参照や `SUM` などの数式を記入し、結果を表示するコミュニティプラグインである。表と数式はノート内のテキストに残る。

**設定 → コミュニティプラグイン → 閲覧**から `Spreadsheet Table` を探してインストールし、有効にする。たとえば、ノートの表を次のように書ける。

```markdown
| 品目 | 数量 | 単価 | 金額 |
| --- | ---: | ---: | ---: |
| ノート | 2 | 300 | =B2*C2 |
| ペン | 3 | 100 | =B3*C3 |
| 合計 | | | =SUM(D2:D3) |
```

このプラグインでは見出しを 1 行目と数えるので、最初のデータは 2 行目になる。数式の表示はプラグインの設定や表示モードに依存する。プラグインなしでは通常、計算結果ではなく数式の文字列が見える。

**注意**：表の行・列の移動や並べ替えによって参照が自動調整されない。Excel と計算結果が異なる場合もあるため、重要な計算は検算する。作者はモバイルでの動作を未検証としている。 [プラグインの説明と制限](https://community.obsidian.md/plugins/spreadsheet-table)

## 3. 表計算シートを使う

[Sheet Plus](https://community.obsidian.md/plugins/sheet-plus) は、Obsidian 内に表計算シートを作成し、ノートに埋め込めるコミュニティプラグインである。通常の Markdown 表を直接計算する方法とは異なる。

- **設定 → コミュニティプラグイン → 閲覧**から `Sheet Plus` をインストールして有効にする。
- プラグインの作成コマンドや画面からシートを作成する。
- 公式のプラグイン紹介ではデスクトップとモバイルに対応し、`.xlsx` のインポート・エクスポートは有料機能とされている。対応する関数や Excel との互換性は事前に確認する。

コミュニティプラグインは第三者が開発するソフトウェアである。導入前に権限や公開元を確認し、大切なデータはバックアップしておく。

## 4. 外部の表計算ソフトを使う

`.xlsx` や `.ods` のファイルを保管庫に置き、Excel や LibreOffice Calc で開く方法もある。Obsidian のノートからファイルへのリンクを張れば、文章と関連づけられる。高度な関数、複雑な書式、ほかの人とのファイル交換が必要なら、専用ソフトのほうが無難な場合が多い。
