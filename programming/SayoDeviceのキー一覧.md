# Sayo Device のキー一覧

Sayo Device のキー割り当て画面に表示されている、通常の英字・数字以外のキーをまとめる。画面下部のボタンには、一般的な操作キーだけでなく、国際配列用や電卓用、特殊な端末向けのキーもある。

**表示名は用途の手がかりであり、選択したキーがすべての OS・アプリでそのとおりに動くとは限らない。** 特殊なキーは無反応の場合もある。画面だけでは、それぞれのボタンが実際に送信するコードをすべて確認できないため、以下は表示名と USB HID の一般的な定義に基づく説明である。 [USB HID Usage Tables](https://www.usb.org/sites/default/files/hut1_3_0.pdf) · [QMK のキーコード一覧](https://docs.qmk.fm/keycodes)

## Linux で Super キーを使う

**画像の画面なら、下段にある `LeftGUI` を割り当てる。** 一般的な Linux デスクトップ設定では、GUI キーは Super として扱われる。`RightGUI` も右側の Super として使えることが多い。特殊な再割り当てがなければ、OS 側の追加設定は通常不要。 [Ubuntu：Super キー](https://help.ubuntu.com/stable/ubuntu-help/keyboard-key-super.html)

1. Sayo Device の設定画面で、Super にしたい物理キーを選ぶ。
2. キー割り当て画面の下部にある **`LeftGUI`** を押し、右下の **OK** を押す。
3. 元の設定画面に戻り、機種や画面に応じた保存・書き込み操作を行う。OK はこの選択ダイアログの確定であり、機器への保存まで完了したとは限らない。
4. 設定したキーを単独で押すか、押しながら別のキーを押して、デスクトップの Super ショートカットを試す。たとえば Ubuntu の GNOME では、通常 Super 単独でアクティビティ画面が開く。

`LeftGUI` は Mac の表示では Command ⌘ に相当する。画面で `Linux/Mac` が選択されていても、Linux 側がその GUI キーを通常の設定で Super と解釈すれば使える。機器やキーボードの Win ロック、Linux 側のキー再割り当て、デスクトップのショートカット設定によっては異なる。

### 動作しないとき

- 設定を機器へ保存したか、正しいキー・レイヤーを編集したかを確認する。`LeftGUI` を押し続けながら別のキーを押す操作と、単独で押す操作の両方を試す。
- **Wayland** では `wev`、**X11** では `xev -event keyboard` を起動し、表示されたウィンドウにフォーカスして対象キーを押す。インストールされていない場合もある。`Super_L` などと表示されれば認識の手がかりになる。デスクトップが Super を先に処理すると、確認ツールに届かない場合もある。 [ArchWiki：キーボード入力](https://wiki.archlinux.org/index.php?title=Hotkeys)
- `xev` は Wayland 上では XWayland のウィンドウを対象とするため、Wayland 全体の入力確認とは限らない。`echo "$XDG_SESSION_TYPE"` でセッション種別を確認できる。

Sayo Device の設定画面には修飾キーと通常キーを組み合わせるモードもある。**Super キーを押しながら他のキーを自由に使いたい場合**は `LeftGUI` 単独を割り当てる。特定の `Super+文字` をワンボタンで送りたい場合は、使用中の機種のショートカット設定で GUI と文字を組み合わせる。 [Sayo Device のキー設定](https://github.com/Sayobot/SayoDevice_manual/blob/main/docs/en/docs/std/web_hid/key.md)

## 修飾キー

| 表示 | 意味 |
| --- | --- |
| `LeftControl` | 左の Control。 |
| `RightControl` | 右の Control。 |
| `LeftShift` | 左の Shift。 |
| `RightShift` | 右の Shift。 |
| `LeftAlt` | 左の Alt。Mac では通常 Option。 |
| `RightAlt` | 右の Alt。配列によっては AltGr などとして使われる。 |
| `LeftGUI` | 左の GUI キー。Windows ロゴ、Mac の Command、Linux の Super として使われることが多い。 |
| `RightGUI` | 右の GUI キー。機能は環境や設定による。 |

詳しくは [[programming/修飾キー|修飾キー]]。物理的な Alt が Emacs の Meta になることはあるが、Alt、Meta、Super、Hyper はすべて同じものではない。

## ファンクションキー

| 表示 | 意味 |
| --- | --- |
| `F13`〜`F24` | 追加のファンクションキー。ショートカットに割り当てられることがある。対応や既存の割り当ては OS・アプリによる。 |

## 編集・操作

| 表示 | 意味 |
| --- | --- |
| `Execute` | 実行を意図するキー。 |
| `Help` | ヘルプを開くことを意図するキー。 |
| `Menu` | メニューを開くことを意図するキー。上段の `MENU` との送信コードの一致は画像だけでは確認できない。 |
| `Select` | 選択を意図するキー。 |
| `Stop` | 停止を意図するキー。 |
| `Again` | 直前の操作をもう一度行うことを意図するキー。 |
| `Undo` | 操作の取り消し。 |
| `Cut` | 切り取り。 |
| `Copy` | コピー。 |
| `Paste` | 貼り付け。 |
| `Find` | 検索。 |
| `AlternateErase` | 別方式の消去を意図した特殊キー。 |
| `SysReq/Attention` | システムへの要求や注意喚起を意図した特殊キー。 |
| `Cancel` | キャンセルを意図するキー。 |
| `Clear` | 消去を意図するキー。下方には電卓用とみられる別の `Clear` もある。 |
| `Prior` | 「前」を意味する特殊キー。通常の Page Up と同じとは限らない。通常の Page Up にしたい場合は `Page Up` を選ぶ。 |
| `Return` | 復帰・改行などを意図する特殊キー。通常の Enter と同じコードとは限らない。 |
| `Separator` | 区切りを意図する特殊キー。 |
| `Out` | 特殊な入力・端末操作向けのキー。動作は環境依存。 |
| `Oper` | 特殊な入力・端末操作向けのキー。動作は環境依存。 |
| `Clear/Again` | 消去または再実行を意図する特殊キー。 |
| `CrSel/Props` | カーソル選択やプロパティに関連する特殊キー。 |
| `ExSel` | 選択の拡張に関連する特殊キー。 |

これらは名前が示す操作のための専用キーコードであり、たとえば `Copy` が必ず `Ctrl+C` を送るわけではない。

## 電源・音量・ロック

| 表示 | 意味 |
| --- | --- |
| `Power` | 電源操作を意図するキー。OS の設定によっては終了などにつながるため注意。 |
| `Mute` | 消音の切り替え。 |
| `VolumeUp` | 音量を上げる。 |
| `VolumeDown` | 音量を下げる。 |
| `LockingCaps` | ロック機構付き Caps Lock 用の特殊コード。 |
| `LockingNum` | ロック機構付き Num Lock 用の特殊コード。 |
| `LockingScroll` | ロック機構付き Scroll Lock 用の特殊コード。 |

`Locking` が付くものは通常のロックキーとは別の HID コードで、一般的な OS で同じ動作をするとは限らない。

## 国際配列・言語

| 表示 | 意味 |
| --- | --- |
| `Non-US#and~` | 米国配列以外のキーボードにあるキー向けのコード。入力文字は配列や OS による。 |
| `Non-US\and\|` | 米国配列以外の別のキー向けのコード。入力文字は配列や OS による。 |
| `International1`〜`International9` | 国・地域別キーボード向けのキーコード。日本語配列に対応する番号もあるが、実際の機能は環境による。 |
| `LANG1`〜`LANG9` | 言語・入力モード関連のキーコード。番号の役割は OS や配列による。 |

## テンキー・電卓向け

画面下部の記号や英字は、位置と並びから拡張テンキー用の HID キーに対応する可能性がある。**通常の文字キーと同じ文字を入力するとは限らない。** 一方、`=`、`Comma`、`EqualSign` など同じ意味に見える複数のボタンの実際のコードは画像だけでは確定できない。

| 表示 | 意図される用途 |
| --- | --- |
| `=`、`EqualSign` | 等号。普通のキーとテンキー用などでコードが異なる場合がある。 |
| `Comma` | カンマ。テンキー用の区切り記号として扱われる場合がある。 |
| `00`、`000` | 電卓・テンキーで複数のゼロを入力するためのキー。 |
| `ThousandsSeparator` | 桁区切り。 |
| `DecimalSeparator` | 小数点の区切り。 |
| `CurrencyUnit`、`CurrencySub-unit` | 通貨単位、補助通貨単位。 |
| `(`、`)`、`{`、`}` | テンキー向けの括弧。 |
| `Tab`、`Backspace` | テンキー向けの Tab、Backspace とみられる。上部の通常キーと別コードの場合がある。 |
| `A`、`B`、`C`、`D`、`E`、`F` | テンキー向けの英字。16 進数の入力などを意図したもの。 |
| `XOR` | 排他的論理和。 |
| `^`、`%`、`<`、`>` | 演算や比較に使う記号。 |
| `&`、`&&`、`\|`、`\|\|` | 論理演算などに使う記号。 |
| `:`、`#`、`Space`、`@`、`!` | テンキー向けの記号・スペース。 |
| `MemoryStore` | 電卓のメモリーへの保存。 |
| `MemoryRecall` | メモリーの読み出し。 |
| `MemoryClear` | メモリーの消去。 |
| `MemoryAdd`、`MemorySubtract` | メモリーへの加算・減算。 |
| `MemoryMultiply`、`MemoryDivide` | メモリーへの乗算・除算。 |
| `+/-` | 数値の符号の切り替え。 |
| `Clear` | 電卓の入力などの消去。前述の `Clear` とは別コードの場合がある。 |
| `ClearEntry` | 入力中の値の消去。 |
| `Octal`、`Decimal`、`Hexadecimal` | 8 進数、10 進数、16 進数のモードを意図するキー。 |

## 上部のキーボード図

上部には `Tab`、`CapsLock`、`Shift`、`Control`、`Option`、`Command`、`Space`、`Enter`、`Delete`、`End`、`Page Down`、矢印キー、テンキーなどの一般的なキーも表示される。`Linux/Mac` が選択されているため、図には `Option` や `Command` の表記がある。見た目の表記と、接続先での実際の動作は必ずしも同じではない。

## 試し方

割り当てを保存したら、まず無害な場所で試す。特殊キーが反応しなければ、OS のキーボードイベント確認ツールや Emacs の `C-h k` などで認識を確認する。反応しないからといって機器の故障とは限らず、OS やアプリがそのキーに対応していない場合もある。
