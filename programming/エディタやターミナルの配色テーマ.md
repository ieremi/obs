# エディタやターミナルの配色テーマ

エディタやターミナルの**配色テーマ（カラースキーム）**は、背景・文字・構文強調などの色をまとめたもの。同じ名前でもアプリごとに移植版があり、色や対応範囲が完全に同じとは限らない。

## 配色テーマの歴史

今日のテーマは、コードを構文に応じて色分けする機能と、画面全体の配色を交換・移植する文化の両方から発展した。次は代表的な出来事であり、テーマ同士がすべて直接影響し合ったという意味ではない。

| 時期 | 出来事 |
| --- | --- |
| 1980年代 | 色付きの構文強調を使うエディタが登場。1985年の IBM の LEXX はその初期の例の一つ。色分けの仕組み自体と、配色の組み合わせとしてのテーマは別のもの。 [LEXX](https://en.wikipedia.org/wiki/LEXX_%28text_editor%29) |
| 1990年代 | 構文強調が各種エディタで発展。たとえば Elvis 2.0 は1996年に汎用的な構文強調を導入し、Vim 5.0 は1998年に色による構文強調を備えた。 [Vile FAQ](https://www.invisible-island.net/vile/vile.faq.html) |
| 2006年 | Wimer Hazenberg が [[TextMate]] 向けに **Monokai** の配色を作成。後に多数のエディタに移植される。 [作者の記事](https://monokai.com/articles/monokai-pro-beautiful-functionality-for-professional-developers/) |
| 2011年 | Ethan Schoonover が **Solarized** を公開。暗色と明色の両方を持ち、明度や色相の関係を意識した16色のパレットとして設計された。 [Solarized 公式](https://ethanschoonover.com/solarized/)、[WIRED](https://www.wired.com/story/very-mathematical-history-perfect-color-combination/) |
| 2016年 | **Nord** のパレットが公開される。青灰色を軸とする16色を、エディタだけでなくさまざまなアプリに展開する。 [Nord リリース履歴](https://github.com/nordtheme/nord/releases) |
| 2017年 | Monokai の作者が、配色に UI やアイコンを組み合わせた **Monokai Pro** を公開。 [作者の記事](https://monokai.com/articles/monokai-pro-beautiful-functionality-for-professional-developers/) |
| 2020年代 | **Catppuccin** や **Oxocarbon** のように、一つのパレットを複数のエディタ・ターミナルなどへ移植するプロジェクトが広がる。Oxocarbon は IBM Carbon に着想を得ている。 [Catppuccin](https://github.com/catppuccin/catppuccin)、[Oxocarbon](https://github.com/nyoom-engineering/oxocarbon) |

**配色の設計**と、エディタがコードのどの部分を「関数」「コメント」などと認識するかは別の問題。同じテーマ名でも、構文解析の方法や移植版の実装によって見え方が変わる。

## 代表的なテーマ

| テーマ | おおまかな印象 | 主なバリエーション |
| --- | --- | --- |
| [Tokyo Night](https://github.com/folke/tokyonight.nvim) | 夜景を思わせる青・紫系の落ち着いた配色 | Night、Storm、Moon、Day |
| [Catppuccin](https://catppuccin.com/) | 柔らかいパステル調。正しい綴りは Catppuccin | Latte、Frappé、Macchiato、Mocha |
| [Gruvbox](https://github.com/morhetz/gruvbox) | 茶色や黄土色を使った、レトロで温かみのある配色 | Dark、Light |
| [Nord](https://www.nordtheme.com/) | 青灰色を中心とした寒色系の落ち着いた配色 | 基本は暗色 |
| [Dracula](https://draculatheme.com/) | 暗い背景に紫や鮮やかなアクセントを組み合わせた配色 | 多数のアプリ向けの移植版 |
| [Rosé Pine](https://rosepinetheme.com/) | くすんだバラ色や紫を使った柔らかい配色 | Main、Moon、Dawn |
| [Solarized](https://ethanschoonover.com/solarized/) | 明暗両方を考慮して設計された抑制的な配色 | Dark、Light |
| [Everforest](https://github.com/sainnhe/everforest) | 緑系を中心とした穏やかな配色 | Dark、Light |
| [Kanagawa](https://github.com/rebelot/kanagawa.nvim) | 日本画から着想を得た、落ち着いた配色 | Wave、Dragon、Lotus |
| [One Dark](https://github.com/atom/one-dark-syntax) | Atom エディタに由来する、暗い背景と控えめな構文色 | アプリごとに移植・派生版あり |
| [Monokai](https://monokai.com/articles/monokai-pro-beautiful-functionality-for-professional-developers/) | 暗い背景に鮮やかな色を組み合わせた配色 | オリジナル、Monokai Pro、各種移植版 |
| [Oxocarbon](https://github.com/nyoom-engineering/oxocarbon) | IBM Carbon に着想を得た高コントラストの配色 | Dark、Light（対応は移植版による） |
