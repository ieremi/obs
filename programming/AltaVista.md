# AltaVista

**1995年に始まった、初期のWebの代表的な検索エンジン。** コンピュータメーカーのDEC（Digital Equipment Corporation）の研究所が作った。Webのページを丸ごと全文で検索でき、当時としては圧倒的に速くて大きかった。Googleの登場までは検索の代名詞だったが、持ち主が何度も変わり、2013年に終了した。

| 項目 | 内容 |
| --- | --- |
| 開発 | DECの研究所（カリフォルニア州パロアルト） |
| 公開 | 1995年12月15日 |
| 名前 | スペイン語で「高い眺め」。研究所の周りの景色から。 |
| 最初のURL | altavista.digital.com（DECのドメインの下） |
| 終了 | 2013年7月8日。以後はYahoo!の検索に転送。 |

## 作った人たち

| 人物 | 役割 |
| --- | --- |
| ポール・フラハティ | 発案者 |
| ルイス・モニエ | Webのページを集めるクローラー「Scooter」を書いた |
| マイケル・バロウズ | 索引（インデックス）を作るプログラムを書いた。のちにGoogleに移る。 |
| アイリーン・ラング | 初代CEO |

## なぜ強かったか

- **DECのコンピュータの宣伝**だった。当時最速クラスの64ビットCPU「Alpha」を積んだサーバー（AlphaServer 8400 TurboLaser）で、大量のデータをさばけることを見せる狙いがあった。
- 公開時の索引は**約1,600万ページ**。当時のほかの検索エンジンより桁違いに大きかった。
- **全文検索**：ページの題名や要約だけでなく、本文のすべての単語から探せた。
- 検索の書き方：「+」で必須の語、「-」で除外する語、""で語句、**NEAR**で近くにある語、などを指定できた。
- 画面は検索窓だけの簡素なものだった。
- 初日に30万回ほど使われ、1997年には1日8,000万回を超えた。

## Babel Fish

1997年に始めた、Webの**機械翻訳**サービス。文章やWebページを英語・フランス語・ドイツ語・日本語などに訳せた。翻訳エンジンはSYSTRANのもの。

名前はSF小説『銀河ヒッチハイク・ガイド』で、耳に入れるとどんな言葉もわかるようになる魚から。

| 時期 | 出来事 |
| --- | --- |
| 1997年 | AltaVistaのサービスとして開始 |
| 2008年 | Yahoo!のサービス（Yahoo! Babel Fish）に移る |
| 2012年5〜6月 | Microsoftの**Bing Translator**に置き換えられ、終了 |

## 持ち主の移り変わり

| 時期 | 出来事 |
| --- | --- |
| 1996年 | Yahoo!の検索結果を独占して提供する |
| 1998年1月 | **Compaq**がDECを96億ドルで買収。AltaVistaもCompaqのものに。 |
| 1998年 | 無料のWebメールを開始。Yahoo!との契約が終わる。 |
| 1998年8月 | Compaqがaltavista.comのドメインを330万ドルで買う。それまでは別の会社のものだった。 |
| 1999年1月 | Compaqが独立会社にし、Yahoo!のような**ポータルサイト**に作り替え始める |
| 1999年6月 | 投資会社**CMGI**が株の83%を約23億ドル分で取得 |
| 1999年10月 | 「smart is beautiful」の宣伝に1億2,000万ドルを使う |
| 1999〜2000年 | 株式の上場を計画したが、ドットコムバブルの崩壊で取りやめ |
| 2002年2月 | Webメールを終了 |
| 2003年2月 | 検索広告の**Overture**が1億4,000万ドルで買収 |
| 2003年7月 | **Yahoo!**がOvertureを買収し、AltaVistaもYahoo!のものに |
| 2013年6月28日 | Yahoo!が終了を発表 |
| 2013年7月8日 | **終了**。Yahoo!の検索に転送されるようになった。 |

## 衰えた理由

- **ポータル化**：検索を磨くより、ニュース、メール、買い物などを詰め込んだポータルサイトになろうとした。画面が重くなり、検索の強みが薄れた。
- **Googleの登場**：1998年に始まったGoogleは、リンクの関係からページの重要度を測る方法（PageRank）で、より役に立つ結果を出した。2000年の調査ではAltaVistaの利用者は17.7%、Googleは7%だったが、すぐに逆転した。
- **持ち主の交代**：DEC、Compaq、CMGI、Overture、Yahoo!と、4〜5年で何度も変わった。方針が定まらず、Yahoo!に入ってからは自前の検索技術も使われなくなった。
- **スパム**：単語が多く入っているページを上位にする仕組みだったので、キーワードを詰め込んだページに弱かった。

## 押さえどころ

- AltaVistaは「Webのすべてを全文で検索する」ことを最初に大規模にやって見せた検索エンジン。技術では先頭を走っていた。
- 衰えた原因は技術より経営にある。検索だけに集中したGoogleと対照的に語られることが多い。
- 名前は消えたが、Babel FishのようなWeb翻訳は、Google翻訳やBing Translatorに受け継がれている。
